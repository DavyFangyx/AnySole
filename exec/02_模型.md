## embeddings.py

正弦时间 PE：`pe[t, 2i]=sin(t/10000^{2i/d})`，`pe[t, 2i+1]=cos(...)`。输出 `(Tw, d)`，不注册成过大的 buffer 也行，但 `Tw=20`、`d=256` 固定。

模态嵌入：`nn.Embedding(3, d)`，id 0=V，1=T_raw，2=T_phys。

三个可学习 null token：`nn.Parameter` 各 `(1, 1, d)`，名字 `null_v` `null_traw` `null_tphys`。

扩散步嵌入：正弦编码 `tau`（标量步，0..999）→ MLP `Linear(d,4d)+SiLU+Linear(4d,d)`，给姿态头 AdaLN/加法用。

---

## encoders.py

| 模块 | 输入 | 结构 | 输出 |
|---|---|---|
| V-Enc | `(B,20,2048)` | Linear(2048→d) + 时间 PE + 模态嵌入 0 | `(B,20,d)` |
| T-Enc raw | `(B,20,96)` | Linear(96→d) + 时间 PE + 模态嵌入 1 | `(B,20,d)` |
| T-Enc phys | `(B,20,12)` | Linear(12→d) + 时间 PE + 模态嵌入 2 | `(B,20,d)` |

`config_id` `(B,)`：

- `CONFIG_VT=0`：三路都用真实输入
- `CONFIG_V=1`：T_raw 与 T_phys 整段换成对应 null token broadcast 成 `(B,20,d)`
- `CONFIG_T=2`：V 整段换成 null_v

实现：先编码，再用 `where` 按 batch 替换，不要真的把 Linear 权重丢掉。null 替换发生在投影之后。

---

## fusion.py

`torch.cat([V, T_raw, T_phys], dim=1)` → `(B,60,d)`。

`nn.TransformerEncoder`：4 层，`nhead=8`，`dim_feedforward=1024`，`dropout=0.1`，`batch_first=True`。`norm_first=True` 可以。

输出 `F` `(B,60,d)`。下标约定冻结：

- `F[:, 0:20]` V
- `F[:, 20:40]` T_raw
- `F[:, 40:60]` T_phys

---

## pose_head.py（预测 x0）

输入：`x_tau` `(B,20,138)`，`tau` `(B,)` long，`F` `(B,60,d)`。

分区（原始 BVH 顺序，不要重排关节）：

- body `x_tau[..., 0:90]` → 15 关节 × 6D，`Linear(6, d)` 名 `proj_body`
- left `x_tau[..., 90:114]` → 4 关节，`proj_left`
- right `x_tau[..., 114:138]` → 4 关节，`proj_right`

拼成 token `(B, 20, 23, d)`，加时间 PE（沿帧）+ 组嵌入 `nn.Embedding(3,d)`（0 body / 1 left / 2 right）。reshape `(B, 460, d)`。

结构顺序冻结：

1. 2 层自注意力（可用 `TransformerEncoder` 2L，nhead=8，ff=1024，dropout=0.1，batch_first）
2. 注入 `tau`：AdaLN 或 token += MLP_tau(tau)（二选一，推荐相加，实现简单）
3. cross-attn：Query=姿态 token，Key/Value=`F`。`nn.MultiheadAttention(d, 8, batch_first=True)`
4. FFN
5. 三个 Linear(d→6) 分别映回 body/left/right，cat 回 `(B,20,138)` = `x0_hat`

不要一组 Linear 打所有关节。不要预测 epsilon。

---

## traj_head.py

`F` reshape `(B,3,20,d)`，对 dim=1 mean → `(B,20,d)`。

2 层 `TransformerEncoder`（nhead=8，ff=1024，dropout=0.1，batch_first）→ `Linear(d,3)` → `v_hat` `(B,20,3)`。

`trans_hat = torch.cumsum(v_hat, dim=1)`。不要再加额外积分头。

---

## aux_heads.py

- T rec：`Linear(d,96)` 作用在 `F[:,20:40]` → `pressure_hat` `(B,20,96)`
- V rec：`Linear(d,2048)` 作用在 `F[:,0:20]` → `vfeat_hat` `(B,20,2048)`

## 完成标准

CPU、`B=2`：

```python
from anysole.models import AnySoleModel
from anysole.types import *
m = AnySoleModel()
out = m(torch.randn(2,20,2048), torch.randn(2,20,96), torch.randn(2,20,12),
        torch.randn(2,20,138), torch.randint(0,1000,(2,)), torch.tensor([0,2]))
assert out["x0_hat"].shape == (2,20,138)
assert out["trans_hat"].shape == (2,20,3)
assert out["F"].shape == (2,60,256)
out["x0_hat"].sum().backward()
```
