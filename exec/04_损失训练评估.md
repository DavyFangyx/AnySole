## losses.py

`compute_losses(out, batch, config_id, weights) -> dict`

`out` 来自 `AnySoleModel`：`x0_hat v_hat trans_hat pressure_hat vfeat_hat F`。

| 键 | 公式 | 何时 |
|---|---|---|
| `L_pose` | MSE(`x0_hat`, `pose_gt`) | 全部 |
| `L_traj` | MSE(`trans_hat`, `trans_gt`) + `traj_cumsum_w` * MSE(`cumsum(v_hat,1)`, `trans_gt`) | 全部 |
| `L_Trec` | MSE(`pressure_hat`, `T_raw`) | 全部 |
| `L_Vrec` | MSE(`vfeat_hat`, `V_feat`) | 仅 `config_id == CONFIG_T`；其它 config 该项为 0 |
| `L_kp` | MSE(FK(`x0_hat`, **`trans_gt`**, offsets, parents), `kp_gt`) | 全部 |
| `L_con` | BCE(`soft_contact`, `contact_gt`) | 全部 |
| `loss` | 加权和 | |

接触用**预测姿态 + GT trans**，不要把轨迹头误差混进姿态损失。FK 调用 `anysole.geometry.fk_pose6d`。

脚：左 17+18，右 21+22。每只脚：

- `height` = 该脚两关节世界坐标 Y 的 **min**
- `speed` = 该脚两关节 `||xyz[t]-xyz[t-1]||` 的 **mean** × 40；第 0 帧 speed 复制第 1 帧
- `soft = sigmoid((0.05 - height) / 0.02) * sigmoid((0.20 - speed) / 0.05)`
- 两脚拼成 `(B,20,2)`，与 `contact_gt` 做 BCE

`L_Vrec` 按 batch 元素 mask：`mask = (config_id == 2).float()`，再 `mean` 时只在 mask 上平均；若整 batch 都不是 T，该项为 0 且不进 backward 图也行。

返回的 dict 每个值都是标量 tensor，便于 log。

## train.py

入口：`python -m anysole.train --config configs/v1.yaml`

额外 CLI：`--epochs` `--batch-size` `--limit-sessions` `--device`。`--limit-sessions N` 只取 split 前 N 个 session，方便冒烟。

循环：

1. `AnySoleDataset(mode="train")`。cache 缺失就 `FileNotFoundError`，错误信息指向 `python -m anysole.data.extract_hrnet --cam-id 3`。训练脚本**禁止**现场提 HRNet。
2. DataLoader：`collate_fn=collate_windows`，`batch_size` 默认 256，`num_workers=4`，`shuffle=True`。
3. 每步 `config_id = sample_config_ids(B)` 写入 batch。
4. 按 config 把丢掉的模态输入置 0（额外保险；模型内部仍换 null token）：
   - CONFIG_V：`T_raw.zero_()` 且 `T_phys.zero_()`
   - CONFIG_T：`V_feat.zero_()`
5. `tau = randint(0, 1000, (B,))`，`x_tau = diffusion.q_sample(pose_gt, tau)`
6. `out = model(...)`，`losses = compute_losses(...)`，`loss.backward()`，Adam `lr=1e-3`。融合 NaN 时把 lr 降到 `1e-4` 并 continue，不要崩。
7. 每 50 step print 各损失项。
8. 存 `out_dir/ckpt_last.pt`。若做 val，按 VT 配置的 MPJPE 存 `ckpt_best.pt`；val 可以很粗，甚至第一版只存 last。

checkpoint 至少含：`model` `optimizer` `epoch` `config`。

不要在 train 里跑 DDIM。

## eval.py

入口：`python -m anysole.eval --config configs/v1.yaml --ckpt ...`

对 VT / V / T 各跑一遍。姿态用 DDIM 50，轨迹用回归头。

指标（毫米 / 度，打印即可，不必写成复杂框架）：

- MPJPE：`||pred_kp - gt_kp||` 均值 ×1000，kp 用 `fk_pose6d(x0_hat, trans_hat, offsets, parents)`
- PA-MPJPE：每帧 Procrustes 对齐后再算
- MPJRE：6D→rotmat 的测地角均值（度）
- traj ATE：`||trans_hat - trans_gt||` 均值 ×1000
- contact acc：` (soft>0.5) == (contact_gt>0.5) ` 的准确率

可选：按 session 调 `write_bvh` 写出预测 BVH。root XYZ 必须是厘米：`pose_trans_to_motion` 已做 ×100。用原 `hierarchy` 字符串，不要改骨架。

## infer.py

入口：`python -m anysole.infer --ckpt ... --session S12021 --config-id {0,1,2}`

非重叠 20 帧窗，concat。最后不足 20 的尾巴丢掉或右侧 pad 再切回，二选一写进注释。输出 BVH 到 ckpt 同级或 `--out`。

`--config-id` 缺省按输入齐不齐：有 V cache 且有压力 → 0；只有 V → 1；只有 T → 2。
