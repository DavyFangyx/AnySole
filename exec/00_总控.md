## 1. 冻结接口（所有 Codex 必须遵守）

环境：`/data/fangyuxuan/miniconda3/envs/touch_gait/bin/python`（Python 3.8，Torch 2.4）。新文件保留 `from __future__ import annotations`。

| 量 | 值 |
|---|---|
| `Tw` | 20 |
| fps | 40 |
| `d` | 256 |
| 关节 | 23，Skeleton3 BVH |
| `pose_gt` | `(B, 20, 138)`，6D |
| 切片（原始 BVH 顺序） | body `0:90`，左腿 `90:114`，右腿 `114:138` |
| `trans_gt` | `(B, 20, 3)` 米，窗口相对轨迹 |
| `vel_gt` | `(B,20,3)` m/s，session 首帧为 0，其余为前向差分×FPS；`trans_gt=cumsum(vel_gt)/FPS` |
| `trans_anchor` | `(B,3)` 米，窗口前一帧世界位置；轨迹损失不使用，评估/拼接及世界坐标 FK 辅助项使用 |
| `kp_gt` | `(B, 20, 23, 3)`，BVH FK + root trans |
| `T_raw` | `(B, 20, 96)` = 左48+右48，`clip(x,0,1023)/1023` |
| `T_phys` | `(B, 20, 12)`，已在 `pressure.py` |
| `contact_gt` | `(B, 20, 2)` = `contact.npy[:, 6:8]` |
| `V_feat` | `(B, 20, 2051)` = AnySole HRNet `(2048)` + CLIFF 归一化 `bbox_info` `(3)`，不是 MotionPRO `feature_hrnet.pth` |
| `F` | `(B, 40, 256)` = `[V(20), T(20)]`，其中 `T=cat(T_raw,T_phys)` 后经单个 Linear 投影 |
| config | 默认 VT=0/V=1/T=2 概率 `0.50/0.25/0.25`，由训练配置 `config_probs=[VT,V,T]` 调节，永不空 |
| 欧拉 | BVH `Yrotation Xrotation Zrotation` = scipy `'YXZ'` degrees |
| 6D | rotmat 前两列；解码 Gram-Schmidt |
| crop | **256x192**，不是 256x256 |
| 扩散 | cosine 1000 步，预测 x0，DDIM 50，eta=0，手写，不用 diffusers |

关节名与 parents 以 [anysole/types.py](/data/fangyuxuan/projects/gait/AnySole/anysole/types.py) 为准：

Hips Spine Spine1 Spine2 Spine3 Neck Head

LeftShoulder LeftArm LeftForeArm LeftHand

RightShoulder RightArm RightForeArm RightHand

LeftUpLeg LeftLeg LeftFoot LeftToeBase

RightUpLeg RightLeg RightFoot RightToeBase

parents = (-1,0,1,2,3,4,5,4,7,8,9,4,11,12,13,0,15,16,17,0,19,20,21)

## 3. 路径

序列：`/data/fangyuxuan/projects/gait/Baselines/MotionPRO/data/sequences/cam3/{date}/{subject}/{sid}/`

划分：`/data/fangyuxuan/projects/gait/Baselines/MotionPRO/data/splits/splits.csv`（val==test 是故意的）

压力：`/data/fangyuxuan/projects/gait/PressureWasher/outputs/fake_marked/reconstruction_20260817_161459_fake_marked/{date}/{subject}/{rec_name}/pressure_{left,right}.csv`

CLIFF：`/data/fangyuxuan/projects/gait/AnysoleWorkspace/dependencies/MotionPRO/cliff_ckpt/hr48-PA43.0_MJE69.0_MVE81.2_3dpw.pt`

yaml：`MotionPRO/lib/model/backbone/hrnet/models/cls_hrnet_w48_sgd_lr5e-2_wd1e-4_bs32_x100.yaml`

cache：`/data/fangyuxuan/projects/gait/AnysoleWorkspace/derived/AnySole/hrnet_cache/cam3/{sid}.pt`，形状 `(T,2051)` float32；最后 3 维是归一化 `[cx,cy,b]`

BVH：优先读取 `align_meta.json["bvh_path"]`；迁移后若该绝对路径失效，则从 `workspace://sources/raw/<date>/mocap_ori_bvh/<session_id>/` 解析，骨架 Skeleton3，72 channel

对齐（必须与 MotionPRO 一致）：

`t_grid = visual_start_s + arange(n_frames) / 40`

`t_mocap = t_grid - offset_s`

压力按 `t_grid_us` 线性插值。BVH 按 `t_mocap` SLERP。窗口内任一 `fake_mask` 为 1 则丢整窗。质量 C/D 已不在 cam3 序列里。
