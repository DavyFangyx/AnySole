## cosine 调度（从 MDM 原样搬，不要改公式）

```python
def get_named_beta_schedule(schedule_name, num_diffusion_timesteps):
    if schedule_name == "cosine":
        return betas_for_alpha_bar(
            num_diffusion_timesteps,
            lambda t: math.cos((t + 0.008) / 1.008 * math.pi / 2) ** 2,
        )

def betas_for_alpha_bar(num_diffusion_timesteps, alpha_bar, max_beta=0.999):
    betas = []
    for i in range(num_diffusion_timesteps):
        t1 = i / num_diffusion_timesteps
        t2 = (i + 1) / num_diffusion_timesteps
        betas.append(min(1 - alpha_bar(t2) / alpha_bar(t1), max_beta))
    return np.array(betas)
```

派生量：

- `alphas = 1 - betas`
- `alphas_cumprod`
- `alphas_cumprod_prev = cat([1, alphas_cumprod[:-1]])`
- `sqrt_alphas_cumprod`、`sqrt_one_minus_alphas_cumprod`

`q_sample`：

`x_tau = sqrt(abar_t) * x0 + sqrt(1-abar_t) * noise`

从 `x0_hat` 反推 eps：

`eps = (x_tau - sqrt(abar_t) * x0_hat) / sqrt(1-abar_t)`

张量用 float32。`_extract(arr, tau, x_shape)` 把 `(1000,)` 抽成 `(B,1,1)` 可广播。

## DDIM 50 步，eta=0

时间表：从 999 均匀抽 50 个步，再加 0。每步：

1. 模型预测 `x0_hat`
2. 由 `x0_hat` 算 `eps`
3. MDM / DDIM 公式 12：

`sigma = eta * sqrt((1-abar_prev)/(1-abar)) * sqrt(1-abar/abar_prev)`

`x_prev = sqrt(abar_prev) * x0_hat + sqrt(1-abar_prev-sigma^2) * eps + sigma * noise`

`eta=0` 时无随机项。最后一步 `t=0` 直接返回 `x0_hat`。

`ddim_sample_loop(model, x_T, tau_related_kwargs)` 的 `model` 调用必须和训练时 `AnySoleModel.forward` 一致：每次传入当前 `x_tau`、当前 `tau`、以及冻结的 `V_feat, T_raw, T_phys, config_id`。`F` 可以在循环外先算一次并缓存，如果模型提供了 `encode_fusion(...)`；没有这个方法就每步全 forward，不要为了缓存去改 02 的冻结签名。

`clip_denoised`：v1 关掉（6D 不是 [-1,1] 图像）。
