# 统一数据协议 v1

- 时间轴：以 `visual_start_s + frame_index / 40` 为视觉时间，`mocap_time = visual_time - offset_s`；`frame_index` 从 0 开始，禁止负索引和重复帧。
- 相机：默认 `cam3`。压力与 BVH 只在中央底座按此时间轴对齐；下游不得重新生成时间轴或 split。
- 动捕：AnySole 只读取 `smpl_path` 指向的 SMPL-NPZ（标准 SMPL-24、axis-angle、米、源帧率通常为 120 Hz），按上述时间轴重采样并保持 native SMPL-24/144D 6D 旋转协议；不再映射到 Skeleton3/BVH-23。`bvh_path` 是共享 manifest 中的 baseline-only 字段，仅供 Step2Motion 使用，AnySole 不读取它。模型内部的关节顺序与 parent hierarchy 固定为标准 SMPL-24；世界坐标单位为米，root/pelvis translation 和每关节世界位置均保留。
- BVH：原始 BVH 的 Euler Y-X-Z 通道在中央适配层转换为 6D 旋转；root 平移由厘米转米，重采样使用 BVH `Frame Time` 和线性时间采样。
- 压力：左右脚各 48 点，行列为 `4x12`；manifest 和原始缓存均采用 `left | right`。原始量程记录为 0–1023；当前序列若为 0–255，必须在适配层一次性除以 255（AnySole 的 `normalize_raw` 负责该步骤）。48 点到其他表示只能使用确定性适配，不能把 16 通道结果当原始协议。
- mask：`fake_frame_indices` 明确列出补帧；`valid_frame_indices` 为不含 fake 的有效帧。全零压力帧仍是观测值，不自动标 fake。
- split：只有同时具备 `pressure_left.csv`、`pressure_right.csv`（原始触觉 CSV，不是 C3D/derived pressure）、视频目录、SMPL NPZ 和 BVH 的 session 才标记 `eligible_anysole=1` 并写入 `splits/default/splits.csv`；缺任一项的 session 保留在 manifest 但不进入 AnySole split。当前 IID/OOD 均采用 subject-disjoint 划分，下游只读取 manifest。
