# 评估配置说明书

**唯一现行评估说明书**（2026-10-21 合并原 `metrics_指标改动说明.md` 与 `EVALUATION_PROTOCOL_AUDIT.md`，两旧文件已删）。裁定细节唯一登记处 = `Baselines/决策/` 五份档案 + `Baselines/01_Baseline复现说明.md`；本文只描述**当前真实评估配置**（以代码与磁盘实况为准）。

评估流程：**模型输出 → 求解（唯一实现）→ 对应指标 → 组成实验**。资格判据：模型原生生成什么就评什么，清单外一律 `—`，绝不写 0、不补造、不回填。

## §1 生成清单（模型输出 → 可评什么）

## §4 组成实验

**公共 evaluator**：`python -m Baselines.utils.evaluate --model <alias> --split test`——读基线统一产物 `predictions/`，公共求解器算指标，写 `results/baselines/<Model>/metrics/<split>_comparison.json`（schema v2）+ 同名逐 session CSV。alias = motionpro / pressure_toolkit / vp_mocap / step2motion / fpp_v2t / all。`--surface-metrics` 默认开，`--no-surface-metrics` 使 `pve_mm` 全列 `—`。AnySole 主模型自产明细+brief 不变（`anysole/eval.py`）。

**消费端**（`results_display/script/`）：

| 视图 | 脚本 | 内容 |
| --- | --- | --- |
| R_Test1 | `r_test1_compare.py` | 逐 session 并排可视化（原生骨架：SMPL-24 native / BVH-23 native） |
| R_Test2 | `r_test2_compare.py` | 跨模型统一指标表（公共求解器就地计算；`--write-model-metrics` 写 schema v2） |
| R_Test3 | `r_test3_traj.py --compare` | 根轨迹视图（仅 root_translation 来源合法的模型；SMPL 配 SMPL root GT、BVH 配 BVH） |
| R_Test4 | `r_test4_v2t.py` | V2T 压力视图（与 R_Test2 同一压力求解器，数值逐位一致） |

**路径规范**：baseline 结果 canonical `results/baselines/{MotionPRO,Step2Motion,pressure_toolkit,FPP-Net,VP-MoCap}/`，各有 `predictions/` 与 `metrics/`；FPP-Net V2T 与 VP-MoCap V2M 分根（`predictions/v2t/`、`predictions/eval_motion/`）；AnySole 行按 `<model>_<contact>/<run>/predictions/eval_motion/` 展开（`--variant` 指定 run，省略则扫描全部）；历史源码仓库名 `Baselines/pressure_tookit/` 仅存于源码路径，workspace/结果/注册表一律 `pressure_toolkit`。

**重新生成流程**（重训/新导出后）：
1. AnySole：`python -m anysole.eval --model-name <M> --contact-method <C>` 刷新 predictions 与 metrics；
2. baseline：`AnysoleWorkspace/tool/export_baseline_motion.py` 按模型导出，`validate_baseline_exports.py --split test --model all` 校验；
3. evaluator：`python -m Baselines.utils.evaluate --model all --split test`；
4. 消费端：`r_test2_compare.py --split test --by-mode --write-model-metrics --force` → `r_test1_compare.py` / `r_test3_traj.py --compare` / `r_test4_v2t.py`。

**数值测试**（`tests/`，touch_gait 环境）：test_public_metrics 101 / test_protocol_consumer 61 / test_baseline_utils 34（2026-10-01 复跑通过）。
