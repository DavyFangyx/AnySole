## 0. 结论（TL;DR）

09-27 V2T 四层指标重构把 FPP-Net 的训练接触 GT 从原生 `press2Cont`（顶点级触觉接触）
切到了 `f6_soft`（脚级软值广播）。两者**语义层级不同**：

| | 原生 press2Cont | 现在的 f6_soft |
|---|---|---|
| 来源 | 触觉压力（每格 sigmoid 归一化，>th 判接触） | BVH 运动学状态机 motion_f6 + 压力一致性 pressure_f6 |
| 粒度 | **格级/顶点级**：同一只脚内脚跟、脚趾可不同 | **脚级标量广播**：一只脚 96 个 SMPL 足部顶点同值 |
| 值域 | 二值 {0,1}（顶点 sum>0.5 后二值化） | 4 档软值 {0.05, 0.30, 0.70, 0.95} |

**最实质的破坏在下游**：PoseTransOpt 按 toe/heel 四区域消费 FPP-Net 接触输出
（每顶点 >0.5 二值化 → 区域计数 → 逐区域优化约束），其设计前提就是**脚内空间变化**。
f6_soft 广播后模型监督信号中不存在脚内差异，预测必然整脚同值，四区域逻辑被架空，
接触约束退化为"整脚开/整脚关"。4 档软值在 0.5 阈值下也坍缩成二值（0.70 与 0.95 无区别）。

**处置决定（用户拍板）**：方案 A —— FPP-Net 训练接触 GT 回退原生 press2Cont，
恢复顶点级语义。执行清单见 §6，本报告只做记录。

## 2. 原生语义（切换前：press2Cont）

原生代码**至今仍在库中**（未删除），可直接对照：

- `lib/Dataset/InsoleModule.py:102-107` `sigmoidNorm`：每格压力按像素权重 sigmoid 归一化；
- `lib/Dataset/InsoleModule.py:121-138` `press2Cont`：`press_sigmoid > th` → **格级二值接触**
  （数据集注释明确被替换的调用为 th=0.5）；
- `lib/Dataset/InsoleModule.py:141-177` `getVertsPress(soft=False)`：每 SMPL 足部顶点
  对分配格**求和**，>0.5 → 1，得到**顶点级二值**接触（每脚 96 顶点）。

语义：**顶点级、脚内空间变化、二值、源=触觉压力**。脚跟/脚趾可以不同
（脚跟离地、脚尖仍触地的过渡相可表达），这正是下游 PoseTransOpt 消费逻辑的设计前提。

> 注：git 中无该文件历史（`Baselines/` 下 FPP-Net 代码未纳入版本控制，
> `git log --all` 无记录），原生调用代码本身不可查，以上由现存函数与切换注释重构。

## 3. 现在语义（切换后：f6_soft）

- `lib/Dataset/PressDataset/PED_tempKPCont.py:113-127`：读 `contact_f6_soft.npy`
  `[frame_idx, 6:8]` 脚级软值 → 广播到 31×22 网格（左脚 `:11`、右脚 `11:`）；
- `PED_tempKPCont.py:163-167`：`getVertsPress(soft=True)` 对分配格取**均值**
  （同脚所有格同值 → 均值 = 脚级值），不二值化 → `contact_smpl` (192,)；
- `lib/Trainer/trainer_tempkpSMPLCont.py:61-62`：训练损失
  `loss_cont = 0.8 × BCE(pred_cont, contact_smpl)`（w_cont=0.8，压力 MSE 仅 0.2）。

语义：**脚级、脚内无空间变化、4 档软值、源=运动学状态机+压力一致性**。
同一只脚的 96 个顶点目标是同一个标量，梯度无法教出任何脚内空间结构。

## 4. 影响面

### 4.1 训练接触头

网络 `cont_output`（`TemporalKpSMPLNet_Series_mlp.py:104-111`）的输入只有**压力头的预测输出**
（484→192 MLP + Sigmoid），不是视觉特征——f6_soft 监督的实际作用点是
"压力图 → SMPL 足部顶点接触"这一步读出。GT 失去脚内空间结构后，
该读出被训练成整脚常量，原生可表达的 heel/toe 过渡相信息彻底丢失。

### 4.2 评估（V2T 接触级指标）

`Baselines/utils/solver.py::contact_smpl_metrics`（MSE + BCE）与训练损失同式——
数值上自洽，但语义从"顶点级接触准确性"变为"脚级接触强度复现"。
二值化诊断图 contact_pred/gt 的口径随之改变。

### 4.3 下游 PoseTransOpt（最实质的破坏）

`Baselines/VP-MoCap/PoseTransOpt/lib/dataset/dataset_mmvp.py:46-95`：

1. 每顶点 `>0.5` 二值化；
2. 每只脚分 **toe 半（顶点 0:48）/ heel 半（48:96）**，共 4 个区域（LT/RT/LH/RH）；
3. 区域 flag = 区域内接触顶点数 > `thres_contact`；
4. `lib/loss/losses.py::loss_3d_t` 按这 4 个 flag 施加逐区域优化约束。

f6_soft 训练出的模型输出整脚同值：0.70/0.95 → 该脚四区域全开；0.05/0.30 → 全关。
**heel/toe 区分消失，四区域设计形同虚设**，接触约束退化为整脚级开关。
（切换时两套测试 99+63 只验证管线可跑、指标可算，未验证接触语义本身，故未抓住。）
