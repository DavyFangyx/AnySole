# 与本项目对照表：


对照模型 = 本项目 V3_3B（V2M 纯视觉口径；账本 `V方案_性能对照.md` + `results/AnySole/V3_3B_joint_and/…/metrics/test_brief.json`，2026-10-21 增补）。本文模型在本文数据集、本项目模型在本项目数据集，数据集与 GT 均不同，**仅作粗浅并排，不作排名/结论依据**。数值按本文单位换算（位置误差 cm）。

| 方法 | MPJPE ↓（cm） |
| :--- | :---: |
| 本文方法（完整，Step2Motion 数据集） | 11.4 (11.7) |
| 本项目 V3_3B | 5.33 |

注：
- 本项目原值 53.29 mm（`mpjpe_mm`，pelvis 对齐口径），按本文单位 ÷10 换算为 cm；本文 MPJPE 对齐方式未详，**对齐口径不同，数值不可直接比大小**。
- 本项目模型另有 VT2M（V+触觉）口径（PA 42.23，见账本）；本文模型为单输入，故对照取 V2M。

**本文有、本项目无对应指标的**（不并排）：
- MPJPELegs（腿部子集）：本项目无公开腿部子集指标；诊断层 `MPJPE_lower` = 85.75 mm（含足部、pelvis 对齐，口径不同）。
- MPJVELegs（腿部速度误差）：本项目指标集**无速度误差指标**（temporal 指标只有加速度误差 `accel_error_m_s2` 与 jerk `jitter_*_m_s3`）。
- MRPE（表2，米）：本项目同族指标为 `traj_ATE` = 54.14 mm（逐帧根轨迹误差均值）；本文 MRPE 为米级序列累积漂移（最优 6.41 m），**定义为不同量，不并排**。
