# 评估整改总控

> 日期：2026-09-26  
> 本目录是本轮评估整改的现行任务分配书。实施者必须先读本文件，再读自己负责的任务书。  
> 当前阶段只分配工作；各任务完成后由主 Agent 与用户按 `04_联合验收与历史清理任务书.md` 共同查验。

## 1. 总目标

建立一条尊重各模型真实功能与输出的评测链路，并整理最终结果目录：

1. 同一任务的同名指标使用相同公式、单位、时间轴、有效帧和聚合方式。
2. 不强迫不同运动表示相互转换；SMPL 使用 SMPL GT，BVH 使用 BVH GT。
3. 模型有足够真实输出、只是缺少指标实现时，补充统一求解器。
4. 模型没有必要输出时，不用 GT、模板、启发式规则或不唯一逆解补造指标，结果显示 `—`。
5. `Baselines/` 只放源码，`AnysoleWorkspace/` 放数据与过程产物，`results/` 只放最终导出结果。
6. 每个正式 baseline 都提供稳定的 `predictions/` 和 `metrics/`；训练模型另有 `checkpoints/`，优化方法不创建空 checkpoint 目录。

## 2. 已锁定的决策

以下决策不得由实施 Agent 自行修改：

- 删除 common19，数值评测和并排可视化都不再依赖它。
- AnySole、MotionPRO、pressure_toolkit、VP-MoCap 等 SMPL 输出使用各自对应的 SMPL GT。
- Step2Motion 使用原生 BVH-23 输出和 BVH GT。
- `root_orientation_deg` / `root_orientation_drift_deg` 就是现有 yaw / yaw-drift 公式的正式名称；公式集中到根目录 `metrics.py`。
- `pve_t_mm` 取消。
- V2T 正式指标固定为 9 项压力指标，不含 contact 四项。
- 当前 motion 模型没有经过训练且显式导出的正式 contact prediction；正式 `contact_f1` 为不适用，展示为 `—`。训练正则和诊断可保留，但不得进入正式表。
- Step2Motion no-IMU 是测试探针，不按正式模型管理、不进入 registry 和主排名。正式 Step2Motion 主干保留 50 维输入、BVH 派生近似 IMU 和 translation head。
- pressure_toolkit 的表面和 shape 来自模板/拟合。公共评测不报告 `pve_mm`、`shape_vertex_std_mm` 或其他 shape/vertex 类指标，即使导出文件中存在 vertices/shape。
- 其他模型是否能计算 PVE，按自身真实输出和已批准口径判断，不能从 pressure_toolkit 的裁定外推。
- 各模型最终结果文件格式不要求统一；统一的是结果目录入口、指标语义和消费约定。
- 实施 Agent 不得自行删除现有结果。所有删除动作集中到任务 04，由主 Agent 与用户查验后执行。

## 5. 公共能力契约

正式模型注册项需要声明真实输出能力，至少覆盖：

```yaml
protocol: smpl24 | bvh23 | pressure
capabilities:
  joint_positions: true
  direct_joint_rotations: false
  root_translation: true
  root_rotation: true
  predicted_surface: false
  predicted_shape: false
  pressure_prediction: false
  contact_prediction: false
```

同时记录来源类型：

- `model_prediction`
- `method_optimization`
- `ground_truth_fallback`
- `template_reconstruction`
- `derived_for_visualization`

只有 `model_prediction`、经任务书批准的 `method_optimization`，以及由这些输出确定性计算得到的量可以进入公共指标。其他来源只能用于诊断或可视化。

## 7. 总体验收门槛

- 正式执行代码和现行说明中不存在 common19。
- 相同任务的同名指标调用同一公共求解器。
- 缺失能力输出 `null`/空值，展示为 `—`，不得写 0。
- pressure_toolkit 的公共 PVE/shape/vertex 指标为 `—`。
- Step2Motion no-IMU 不出现在正式模型 registry 或主比较表。
- 正式 Step2Motion 确认加载 50 维输入和 `model_trans.pth`。
- 每个正式 baseline 有非空 `predictions/` 和 `metrics/`。
- pressure_toolkit 的过程文件不再写入 `results/baselines/pressure_toolkit/`。
- R_Test1/2/3/4 均能从新路径完成消费，且 GT 与预测协议匹配。
- 旧结果清理前有精确文件清单、大小、可恢复性和用户确认。
