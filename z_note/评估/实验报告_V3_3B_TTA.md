# 实验报告：V3_Bv1 多视角 TTA（第一阶段：原方案 + TTA，关节点版）

## 论证命题

原方案（V3_Bv1，VT 条件）在多视角推理时，经推理时优化（TTA，零训练）
提升姿态精度；并区分「增加视角与直接聚合」与「迭代优化」的各自收益。

## 设计规则（2026-10-26 裁定）

1. 优化只使用推理时可得信息；GT 只进独立评估，不进初始化、优化、停止条件
   与迭代结果选择。
2. 输入条件 = 原方案：CONFIG_VT（真实 V + 真实 T 恒真）。T 属原方案输入，
   不是触觉约束（触觉约束留待第二阶段）。
3. 多视角 = 每相机读取各自 HRNet 缓存（dataset.py：cam_id 切换 cache_root，
   2026-10-26 修复——此前 cam_id≠3 不切换目录，四分支均读 cam3 特征）。
4. 优化变量 = per-view h（pose head 部位表示：decoder 输出、_unembed 前——
   论文 token_out 的对应位置；梯度只经冻结的 _unembed/SMPL·FK 层，不回传
   decoder/fusion/编码器）+ per-view t_v + 共享 β 叶子 (10,) init 零
   （论文 Θ0 的 β 槽位；协议拟合 betas 是标注 GT 不进优化，由 L_2D 塑形、
   L_reg 锚零）。
5. t_v 定义 = 世界骨盆位置：P_world = P_SMPL − J_pelvis(θ,β) + t_v，
   J_pelvis = 当前预测人体的骨盆（非 GT）。init = 四视角检测骨盆三角化
   （推理时可得，pinhole 近似），不带 GT 偏移项。
6. L_2D 预测链 = 论文口径：θ → SMPL(θ, β)（中性模型，可微 LBS）→ 网格读出
   → 相机投影（含畸变，可微）。读出全部 24 SMPL 关节 + 7 smplx 附加关节
   （鼻/大趾×2/小趾×2/跟×2）；监督子集 = Halpe-26 有对应标签的 21 点
   （14 身体关节 + 7 表面点）。H26 17（头顶）映射待验证（模板顶点 3689
   偏中线 4.3cm、低于最高点 1.55cm），暂不参与损失。不声称复现论文的
   44+35 解剖点监督。
7. L_con = θ 星形到 1-δ 滤波 virtual view（纯模型输出）——virtual view 为
   每轮聚合锚（简化设计），非论文的独立 Θ0 优化变量，不声称完整复现。
8. 比较三臂：① 单视角 init；② 多视角直接聚合（1-δ 滤波，不迭代）；
   ③ 多视角 TTA（per-view 精修 + 精修后聚合）。FK-24 评估衡量原评估骨架
   下的姿态精度，不证明优化后的 β/网格/世界平移准确。

## 实验设计

- 模型：V3_Bv1 生产 ckpt（ckpt_best，tw20_st20_…_sd1），推理全程冻结、零训练
- 优化变量：per-view h (tw×9,256) + per-view t_v (tw,3) + 共享 β 叶子 (10,)
- 损失：
  - L_2D（权重 1e-2）：SMPL 网格读出（24 关节全读出 + 7 附加关节）+ t_v
    经标定链投影（含畸变，可微）vs RTMPose 检测 2D（同 1624×1240 像素
    空间，score≥0.5 掩码），监督 21 点
  - L_con（权重 1.0）：θ 星形到 1-δ 滤波 virtual view（纯模型输出）
  - L_reg（权重 1e-2）：h / 姿态 / t_v / β 锚定初值（β 锚零）
- 优化器：Adam；200 步 + 20 步线性 warmup + 全局梯度裁剪 0.1；每窗在
  0/30/50/100/150/200 步记录三臂与各项损失值。学习率在验证集（--split val，
  S12 十二会话）{0.01, 0.03, 0.06, 0.1} 扫描选定后跑测试集。
- 数据：test 36 会话（S13+S14）× 4 相机，同帧窗口对齐（tw=20、stride=20），
  每会话前 16 窗口
- 指标：窗口级 PA-MPJPE（项目口径 pelvis_align + pa_mpjpe，anysole.utils.metrics）
- 入口：`python anysole_tta/run_tta.py --device cuda:7`（产物
  metrics/anysole_tta_stage1.json）

## 损失尺度审计与权重（2026-10-26，S12011 首窗 init）

| 项 | 单位 | 值（init） | ‖∂(λ·项)/∂h‖ | ‖∂/∂t_v‖ | ‖∂/∂β‖ |
|---|---|---|---|---|---|
| L_2D | px²（均值，21 点掩码） | 4555（RMS≈67px） | 6.7e-4 | 5.1e-3 | 7.3e-4 |
| L_con | rad²（逐元素均值） | 0.019（RMS 元素≈0.14≈8°） | 6.5e-4 | 0 | 0 |
| L_reg | 各叶自身单位 MSE | 0（init 锚定恒零） | 0 | 0 | 0 |

权重推导（值与梯度同比双平衡）：λ2d·4555 ≈ 0.019 → λ2d ≈ 3.5e-6；
λ2d·226 ≈ 6.5e-4 → λ2d ≈ 2.9e-6（λ=1 时的 ∂l2d/∂h = 226）→ 取
**λ2d = 3e-6（px²）、λcon = 1.0（rad²）**；L_reg 为锚定项（init 梯度为零、
随优化增长），λreg = 1e-2 按保护角色设定。审计前 λ2d=1e-2 用归一化坐标
（err²~1e-3 量级），L_con 梯度主导 750 倍、2D 证据不可见——已修正为
px² 物理单位 + 平衡权重。

## 结果（2026-10-26，36 会话 × 前 16 窗 × 30 步）

| 臂 | 口径 | PA-MPJPE |
|---|---|---|
| cam3 单视角 init | 臂①基准（原方案单视角，VT） | 49.3 |
| ① 单视角均值 | 4 相机逐视角均值 | 62.0 |
| ② 多视角直接聚合 | 1-δ 滤波，不迭代 | 56.4 |
| ③ TTA per-view | 迭代优化后逐视角 | 56.4 |
| ③ TTA + 聚合 | 精修后 1-δ 聚合 | 56.1 |

分组：S13（18 会话）init 58.9 → refined 53.5；S14（18 会话）65.2 → 59.3。
参照：生产协议 cam3 VT2M 42.2 / V2M 41.1（cam3 init 49.3 与之差 ~7mm，
窗口全集与 robustness 设置的口径差异未逐项归因，登记待核）。

## 判读

1. 三臂机制全部工作：直接聚合兑现 −5.6（vs 四相机均值）；TTA 逐视角精修
   兑现 −5.6；TTA + 聚合兑现 −5.9。
2. 「增加视角与直接聚合的收益」与「迭代优化的额外收益」已分开：聚合拿走
   全部增量，迭代优化在聚合之上的边际为 −0.3mm——设计规则：多视角 TTA 的
   增益兑现点在各视角的一致性聚合，迭代优化部分需要更强的证据约束（如
   解剖表面点）才能贡献聚合之外的增量。
3. 四相机均值基线（62.0）比 cam3 单视角（49.3）高 12.7：模型按 D1 只吃
   cam3 特征训练，1/2/4 相机分支是分布外输入，拉高均值基线；1-δ 聚合部分
   抵消（56.4）但仍未低于 cam3 单视角。设计规则：多视角收益的兑现条件 =
   各视角落在模型训练分布内——四相机扩展线的训练规模完成后重测本三臂。
4. β 叶子位移近零（h 叶子容量远大于 β 的同一动力学，登记同前）。
5. GT 零进优化（本版全链核查通过）；评估口径为 FK-24 协议（GT 只进评估）。

## 历史（口径已作废）

- 2026-10-24 pilot（CONFIG_V 条件 + kp2d24 GT 投影 + GT 平移锚）：修复两个
  实现 bug 后 TTA 中性（8 会话 refined 26.3 vs init 26.4）。pilot 另有数据层
  缺陷：cam_id 未切换 HRNet 缓存目录，四分支均读 cam3 特征（L_con≡0、
  virtual≡init，多视角结构退化）——中性结论不可判读。
- 2026-10-26 中间版本依次作废：v_tok 叶子（encoder 侧，非 token_out 对应
  位置）→ F 叶子（fusion 输出，优化融合表示的变体——非 decoder 输出
  token）→ h 叶子（部位表示，decoder 输出/_unembed 前，本版）。骨盆平移
  曾混用 SMPL 原点（t_v = 三角化骨盆带 22cm 偏移），已改为世界骨盆定义。
