# 门控随遮挡实验报告

日期：2026-11-05。对象：V7_Cv5（双门：根速度门 + 姿态门）与 V7_Cv7（无门）。问题：视觉遮挡加重时，Cv5 的学习门控是否打开（更信任触觉），以及这对其触觉收益的影响。

## 1. 口径

- 数据与模型：act8020 动作分层 split，`ckpt_last`，训练 seed 101（ckpt 目录 `_sd101`）；cell = `V7_Cv5_act8020_s1` / `V7_Cv7_act8020_s1`；遮挡 cell = 同名 `_evalocc010`–`_evalocc100`。评估只评 val（27 会话、494 窗）。
- 遮挡协议：HRNet 视觉缓存 `cam3_occ_lowerNNN`，bbox 底部整幅涂黑 NNN%，模型不知道退化发生；occ000 = 无遮挡。
- 行为口径：沿用 E6 门控分解。逐会话 `Δ_s = VT_s − V_s`（PA-MPJPE，mm；负 = 触觉有帮助），按帧数加权：

  `ΔE = Σ w_s Δ_s / Σ w_s`，`ΔE⁺ = Σ w_s max(Δ_s,0)/Σ w_s`，`ΔE⁻ = Σ w_s min(Δ_s,0)/Σ w_s`。

  抑制率 = `1 − ΔE⁺_Cv5/ΔE⁺_Cv7`；保留率 = `ΔE⁻_Cv5/ΔE⁻_Cv7`；两者只在分母 ≥0.05 时报告。
- 门值口径：固定 Cv5 ckpt，在 val 的 VT 条件读取 `route_gate`。Cv5 为窗口级门（tw 内时间均值池化后过 MLP），根速度 query 一个门、9 个姿态 query 共享一个门，g∈(0,1)，g 越大越信任触觉。Cv7 无门（模块上等价 g≡1），作为无门参照。
- 统计：门值按窗口×帧平均；行为表按会话帧数加权；分动作每类仅 2–5 会话，作观察不作统计结论。

| 50 | 0.249 | 0.204 | 1.4% | 0.2% |

| 10 | +1.024 | −0.912 | 140.8% | 76.2% |
| 20 | −0.126 | −1.309 | 94.8% | 77.1% |
| 30 | −2.155 | −2.193 | 71.5% | 85.9% |
| 40 | −5.129 | −3.370 | 63.6% | 78.3% |
| 50 | −8.012 | −4.675 | 58.6% | — |
| 60 | −10.519 | −4.947 | 47.0% | — |
| 70 | −17.230 | −6.404 | 37.2% | — |
| 80 | −18.253 | −7.843 | 43.0% | — |
| 90 | −15.889 | −4.656 | 29.3% | — |
| 100 | −15.308 | −4.680 | 30.6% | — |

- 0–20%：双门更好；干净档把无门模型 +1.85 mm 的触觉伤害压到 +0.16 mm，10–20% 时双门已为净收益。
- 交叉点约在 30%；40% 起无门模型的触觉收益增长更快，双门被门值限制：
  - 70–80%：无门 ΔE ≈ −17.2 / −18.3 mm，双门仅 −6.4 / −7.8 mm，无门拿到约 2.3–2.8 倍收益。
  - 有益分量保留率由 84% 降至 29–43%。
- 有害分量 `ΔE⁺` 在 occ40（Cv5）/ occ50（Cv7）后约等于 0，高遮挡已没有可抑制的有害分量，抑制率自 occ50 起无定义；此时门的作用只剩压住收益。

跨指标方向一致（PA-MPJPE / MPJPE / GlobalMPJPE / traj_ATE@0.5s）。以 MPJPE 为例：occ080 无门 −21.50 mm、双门 −9.15 mm；occ090 无门 −35.04 mm、双门 −6.15 mm。GroundPen / FootSliding / Jitter 在 occ90–100 分母趋零、波动大，只作观察。

## 3. 判读

1. 当前门控不随遮挡打开：root 门只在高遮挡轻微上移（0.25→0.35），姿态门维持低位甚至下降。门学到的是“近干净视觉下的触觉噪声抑制”，不是“视觉可靠性检测”。
2. 该行为在低遮挡是净收益（干净档避免 +1.7 mm 伤害，10–20% 稳定获益），在高遮挡变成瓶颈：视觉失效、触觉成为主要可靠信号时，门仍保持关闭，按 Cv7 参照只能兑现约 30–43% 的触觉收益。
3. 设计规则：门要覆盖遮挡场景，需要把视觉可靠性/遮挡档显式作为门条件（如输入视觉 token 置信度、遮挡比例），或在训练期混入遮挡样本，让门见过“V 不可靠、T 可靠”的输入分布；仅靠当前 V/T token 拼接与干净训练分布，门会收敛到近常数低值。
4. 方向性佐证：根门开得多的会话缺口略小（r≈−0.37），说明“开门”方向本身有效，问题在幅度和覆盖面；姿态门没有该方向性。

## 5. 局限

- Cv5 与 Cv7 是两次独立训练，行为对照包含结构与训练差异，不是同权重下开关门的干预；门值结论来自 Cv5 自身，不受该混淆影响。
- 高遮挡下 `ΔE⁺≈0`，抑制率无定义；该区间以净 ΔE 与有益分量保留率为准。
- val 27 会话、分动作 2–5 会话，分动作数字只作观察。

判读

门的失效不是“开得不够大”，而是根本没有把遮挡/视觉可靠性作为输入信号：训练分布以干净视觉为主，门收敛成一个固定偏置很低的噪声抑制器。低遮挡时它正确（触觉有噪声）；高遮挡、视觉失效、触觉成为唯一可靠信号时，它仍然保持关闭，直接封顶了触觉救援能力。

跨指标方向一致（MPJPE/GlobalMPJPE/traj_ATE@0.5s 同构）；GroundPen/FootSliding/Jitter 在 occ90–100 分母趋零、出现大幅波动，只作观察不作结论。另需注意 Cv5 vs Cv7 是两次独立训练，差异含结构+训练，不是同权重开关门干预（沿用 E6 既有门控表口径）。
