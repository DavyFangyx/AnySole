## 全局冻结协议

| 项目 | 冻定值 |
|---|---|
| AnySole 主干 | 根目录 `anysole/`、`configs/` |
| 统一工作区 | `AnysoleWorkspace/`（manifest + splits + derived + dependencies） |
| baseline | `Baselines/Step2Motion`、`Baselines/MotionPRO`、`Baselines/pressure_tookit`、`Baselines/VP-MoCap` |
| 相机 | cam3 |
| 目标帧率 | 40 Hz |
| 动捕协议 | 原生 SMPL-24（axis-angle、米、世界系）；`bvh_path` 为 baseline-only（Step2Motion） |
| 压力源 | 左右脚各 48 cells（4×12，0–1023/0–255 由适配层一次归一）；确定性映射到各 baseline 表示 |
| mask | fake/invalid 不参与训练和评估，以 manifest `fake/valid_frame_indices` 为准 |
| split | `splits/default/splits.csv`（subject-disjoint IID，val==test；OOD 由 make_splits 生成）；下游只读 |
| 统一评估 | `results/<Model>/predictions/eval_motion/<session>.npz` → `evaluate_compare.py` → `Test2_comparison/` |

## 阶段门禁

### Gate 1：数据底座

- [ ] session manifest 完成且可复查
- [ ] 23 joints、40 Hz、offset、frame count 通过
- [ ] 压力布局、左右脚和量程测试通过
- [ ] IID/OOD split 无交叉泄漏
- [ ] fake/invalid 统计已冻结

### Gate 2：各 baseline 可运行

- [ ] AnySole 根目录 import/train/infer smoke test
- [ ] MotionPRO dataset/train/test smoke test
- [ ] Step2Motion process/train/test smoke test
- [ ] pressure toolkit 单帧或短序列 smoke test

### Gate 3：统一输出

- [ ] 所有模型输出 session/frame/valid
- [ ] 所有关节可转换到原生 SMPL-24（19 关节语义交集进入 Test2 对比）
- [ ] world 坐标、米制和 40 Hz 一致
- [ ] 无 GT 观测泄漏

### Gate 4：统一评估

- [ ] GT→GT evaluator 全部误差为 0
- [ ] world MPJPE 已实现
- [ ] pelvis-aligned MPJPE 已实现
- [ ] Procrustes MPJPE 已实现
- [ ] trajectory/Accel/Jitter/contact 已实现
- [ ] session/frame 加权规则已记录

### Gate 5：最终实验

- [ ] IID 结果已完成
- [ ] OOD 结果已完成
- [ ] VT/V/T 或对应模态消融已完成
- [ ] 各模型训练配置、checkpoint、随机种子已登记
- [ ] 结果可由命令重新生成
