# 三个 baseline 复现总体验收矩阵

## 全局冻结协议

| 项目 | 冻定值 |
|---|---|
| AnySole 主干 | 根目录 `anysole/`、`configs/`、`outputs/`、`tests/` |
| 统一工作区 | `AnysoleWorkspace/` |
| baseline | `Baselines/Step2Motion`、`Baselines/MotionPRO`、`Baselines/pressure_tookit` |
| 相机 | cam3 |
| 目标帧率 | 40 Hz |
| 动捕外部协议 | Skeleton3，23 joints，统一 world coordinates |
| 压力源 | 左右脚各 48 cells；模型内部可降维/栅格化 |
| mask | fake/invalid 不参与训练和评估，具体规则由 Agent 01 冻结 |
| split | IID 与 OOD-subject 两套；所有模型读取同一 manifest |

## 阶段门禁

### Gate 1：数据底座

- [ ] session manifest 完成且可复查
- [ ] 23 joints、40 Hz、offset、frame count 通过
- [ ] 压力布局、左右脚和量程测试通过
- [ ] IID/OOD split 无交叉泄漏
- [ ] fake/invalid 统计已冻结

### Gate 2：各 baseline 可运行

- [ ] AnySole 根目录 import/train/infer smoke test
- [ ] MotionPRO dataset/train/test smoke test
- [ ] Step2Motion process/train/test smoke test
- [ ] pressure toolkit 单帧或短序列 smoke test

### Gate 3：统一输出

- [ ] 所有模型输出 session/frame/valid
- [ ] 所有关节可转换到 Skeleton3 23 joints
- [ ] world 坐标、米制和 40 Hz 一致
- [ ] 无 GT 观测泄漏

### Gate 4：统一评估

- [ ] GT→GT evaluator 全部误差为 0
- [ ] world MPJPE 已实现
- [ ] pelvis-aligned MPJPE 已实现
- [ ] Procrustes MPJPE 已实现
- [ ] trajectory/Accel/Jitter/contact 已实现
- [ ] session/frame 加权规则已记录

### Gate 5：最终实验

- [ ] IID 结果已完成
- [ ] OOD 结果已完成
- [ ] VT/V/T 或对应模态消融已完成
- [ ] 各模型训练配置、checkpoint、随机种子已登记
- [ ] 结果可由命令重新生成
