# AnySole 项目概述（工作摘要）

**AnySole —— Any model, any view, any solo generated well**

AnySole 从鞋垫压力（触觉）与 RGB 视觉生成 3D 人体运动，主模型为扩散式 V+T→M 生成：训练阶段同时输入视觉与触觉；部署阶段可仅输入视觉、仅输入触觉、或视觉与触觉同时输入——一个模型，任意输入组合，无需重训或微调。

## 目标

CVPR 投稿。

## 数据集

- **模态**：4 台同步 RGB 相机（cam1–4）+ 左右脚鞋垫压力传感器 + 光学动捕（c3d）
- **采样**：40 Hz 同步采集
- **压力**：单脚 31×11 压力网格，16-bit 克值分辨率，50 kg 量程
- **GT**：SMPL-24（主模型与 SMPL 系基线口径）、BVH-23（Step2Motion 口径）
- **规模**：多日期、多被试、11 类动作（含上楼梯等）；split 为 train/val/test = 104/36/36（val=test）
- **辅助模态**：人体 mask、深度、相机标定

## 模型与数据流

- **训练**：视觉 + 触觉 → 3D 人体运动；触觉既是输入模态，也作为跨视角一致性监督量
- **部署**：任意输入子集——仅视觉 / 仅触觉 / 视觉+触觉——同一模型直接推理

## 机制主张

1. **触觉为视觉提供足部运动的精修**：足-地接触是视觉观测的盲区，触觉直接测量接触与受力，为足部运动提供细粒度精修，选用一些足部精修的指标进行对照，并配失效对照图。

2. **视觉为触觉提供全局信息的感知**：触觉仅覆盖足底局部，躯干与全局位移的感知由视觉提供；体现在仅触觉输入的推理中各项指标的全面提升。与 T 专家模型（Step2Motion以及其他基线模型）、以及本工作的 T 单流训练模型、或者其他纯触觉生成动作的模型，进行对照，

主要指标为全局性参数、指标

3. **触觉作为一致性监督量，赋予模型多视角输入能力**：足底压力与相机视角无关，训练中作为跨视角一致性锚，使模型天然支持多视角输入。
是训练过程中使用触觉作为一致性指标进行训练 + 使用触觉作为一致性指标快速在真实环境中部署。

有标定的多视角作为参考上限存在。

## 部署场景

一个模型覆盖多种部署场景，灵活（flexible）适配，**跨地形、跨环境**：
输入设定统一记作 V1（单目）、Vn（n 个视角）、T（仅触觉）、V1+T、Vn+T。

- **单视角 V1**：单目 RGB 常规部署
- **单触觉 T**：光照差、遮挡等视觉受限环境；触觉测量与光照无关
- **多视角 Vn（双视角 V2 / 三视角 V3 / 任意 N 视角 Vn） + 触觉监督 T**：以触觉作为一致性监督量，任意相机组合共同推理，**无需多相机标定**即可快速部署。
    - 部署的时候使用触觉 T 作为一致性监督量。
