# AnySole 项目概述

## 动机

- **互补盲区**：相机看得见全身与全局位移，几乎看不见足-地接触；鞋垫精确感知接触与受力，感知不到脚踝以上。两类传感器天然互补。
- **传感器可用性多变**：光照会失效，人可能走出画面，隐私限制排除摄像头，实验室外的多相机几乎从不标定。真实世界中哪种传感器可用，既不固定也无法预知。
- **现有方法绑定固定输入配置**：融合方法要求测试时双模态同时存在；单模态方法在训练阶段即丢弃另一模态，浪费了互补信息。
- **问题**：能否一个模型从两种感觉联合学习，并在其一缺席时仍保留互补性——train with both, deploy with either。

## 核心贡献

1. **视触统一的运动生成模型**：扩散式 V+T→M，一套权重支持单目、多视角、仅触觉及其任意组合推理，无需重训或微调。
4. **多模态数据集**：4 路同步 RGB + 双足压力鞋垫 + 光学动捕真值。

2. **跨模态互补性的正迁移发现**：联合训练后，互补性在某一模态缺席时依然保留——仅触觉推理保留全局感知（V→T），仅视觉推理保留足部精修（T→V），且触觉的优势随视觉证据退化而增大。
3. **触觉作为跨视角一致性锚**：足底压力与视角无关，训练期作一致性监督，使模型获得无标定多视角融合能力。

## 数据集

- **模态**：4 台同步 RGB 相机（cam1–4）+ 左右脚鞋垫压力传感器 + 光学动捕（c3d）
- **采样**：40 Hz 同步采集
- **压力**：单脚 31×11 压力网格，16-bit 克值分辨率，50 kg 量程
- **GT**：SMPL-24（主模型与 SMPL 系基线口径）、BVH-23（Step2Motion 口径）
- **规模**：多日期、多被试、11 类动作（含上楼梯等）；split 为 train/val/test = 104/36/36（val=test）
- **辅助模态**：人体 mask、深度、相机标定
- **统一协议**：主模型与四个基线（MotionPRO、Step2Motion、pressure_toolkit、VP-MoCap）在同一数据、同一 split、同一指标口径下对比

## 模型与数据流

- **训练**：视觉 + 触觉 → 3D 人体运动（扩散式 V+T→M）；触觉既是输入模态，也作为跨视角一致性监督量
- **部署**：任意输入子集——同一套权重直接推理，无需重训或微调

## 部署场景

输入设定统一记作 V1（单目）、Vn（n 个视角）、T（仅触觉）、V1+T、Vn+T：

- **单视角 V1**：单目 RGB 常规部署
- **多视角 Vn（V2 / V3 / …）**：以触觉为一致性监督量，任意相机组合共同推理，无需多相机标定即可快速部署
- **单触觉 T**：光照差、遮挡等视觉受限环境；触觉测量与光照无关
- **V1+T / Vn+T**：双模态协同推理

- **跨地形、跨环境**：数据覆盖平地、上楼梯等动作，触觉物理约束跨地形一致；同一模型在不同地形、不同环境完成部署，灵活适配

## 指标

- **关节位置/旋转误差（MPJPE 家族）**：PA−MPJPE（分身体部位）、MPJPE、GlobalMPJPE、W−MPJPE100、MPJRE
- **全局/世界系**：traj_ATE、RootOrientationDrift、GlobalMPJPE
- **物理合理性**：FootSliding、GroundPen、Jitter_pred
