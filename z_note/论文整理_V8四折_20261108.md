# 论文实验配置与实验组（V8 四折，2026-11-09）

## 0. 数据集与协议

- **9 名受试者、11 类动作**。
- **四折 LSO，Cross-Subject Generalization**：每折 **训练 5 人 / 测试 3 人 / 评估 1 人**。
  - fS5S6S11：test S5/S6/S11，eval S12
  - fS5S11S12：test S5/S11/S12，eval S13
  - fS6S7：test S6/S7，eval S14（S13 退出留出池，test 2 人）
  - fS5S6S8：test S5/S6/S8，eval S7
- 四折 test 并集 **98 个会话**；只评 test；ckpt = `last`；退化档为 eval-only。
- 主模型 **V8_Cv5**；消融对照 **V8_Cv7（无门）/ V8_Cv4（单门）/ V8_Cv2（随机 dropout）/ V8_Cv6（始终 VT）**。
- 外部基线：V 块 GVHMR / SAM3DB / WHAM；T 块 Step2Motion；VT 块 MotionPRO / VP-MoCap / MMVP。
- 指标：姿态 **PA-MPJPE**；轨迹/全局 **GlobalMPJPE**（`traj_ATE` 列使用 `RootAbs`）；物理 **GroundPen**（辅 FootSliding）。

## 1. E2 主性能

**目的**：验证同一个 ckpt 在 V / T / VT 三种输入配置下均可推理，并与各输入类型的参考方法比较。

**场景**：clean test，同一 ckpt，只改变推理时的可用输入。

**实验组 / 对照**：

- U = V8_Cv5（V / T / VT 三行同一 ckpt）
- 内部对照 = V8_Cv7 / Cv4 / Cv2 / Cv6
- 外部基线 = V 块三个视觉基线、T 块 Step2Motion、VT 块三个视触基线

**结果**：V8_Cv5 的 V / VT / T PA 为 **42.63 / 42.71 / 83.04**；V 块外部基线 51.9–53.8；T 块 Step2Motion 101.6。姿态与物理指标领先；Global/traj 落后 SAM3DB、优于 WHAM/GVHMR。

**补充：重叠窗评估**

- 目的：验证相邻窗重叠组装能否降低窗口接缝导致的抖动，并检查姿态精度是否保持。
- 场景：同一四折 ckpt，`--overlap-stride 10` 三角权重装配，与现协议（非重叠 20 帧硬接）对照。
- 结果：PA V **42.63→41.06**、VT **42.71→40.99**、T **83.04→79.45**；Jitter V **−70%**、VT **−72%**、T **−39%**；代价是 T 行 FootSliding **+26%**（23.33→29.43），主表轨迹口径 RootAbs 无税。
- 产物：`E2_MainPerformance/Main_Table2_E2_OverlapZeroTax_V8_Cv5.csv`、`Full_Table5_E2_OverlapStride_V8_Cv5.csv`

**产物**：`results_display/Etest_crossfit_v8/E2_MainPerformance/`

## 2. E4 消融

**目的**：分别回答两个问题——门控是否必要（门控效果），以及训练时是否需要对模态数据做 dropout（训练条件）。

**场景**：clean test，同配方、同数据，只改变门控结构或训练条件。

### 2.1 门控效果

固定三条件枚举训练，比较无门 / 单门 / 双门：

| 模型 | 门控 | VT PA | Δ(VT−V) PA |
|---|---|---|---|
| V8_Cv7 | 无门 | 46.29 | **+3.20** |
| V8_Cv4 | 单门（姿态/根共享） | 43.02 | +0.34 |
| V8_Cv5 | 双门（姿态 + 根） | **42.71** | **+0.08** |

**结果**：双门最好；单门已能收回大部分收益；无门在 clean 下仍有 +3.20 的触觉伤害。

### 2.2 训练条件 / 数据 dropout

固定双门，比较三条件枚举 / 随机模态 dropout / 始终 VT：

| 模型 | 训练条件 | V PA | VT PA | Δ(VT−V) PA |
|---|---|---|---|---|
| V8_Cv5 | V/T/VT 枚举 | **42.63** | **42.71** | **+0.08** |
| V8_Cv2 | 随机模态 dropout | 43.26 | 43.48 | +0.22 |
| V8_Cv6 | 始终 VT | **47.69** | 43.37 | −4.32 |

**结果**：枚举训练最好；随机 dropout 接近但略差；始终 VT 把 V 支路训练退化（V PA 47.69），其负 Δ 不是融合成功。

**产物**：

- `E4_ComponentAblation/Main_Table1_E4_GateEffect.csv`
- `E4_ComponentAblation/Main_Table2_E4_TrainingCondition.csv`
- 五模型全量：`Full_Table1_E4_Ablation_AllMetrics.csv`

## 3. E5 视觉退化

**目的**：考察视觉证据退化时触觉增益如何变化，以及门控在哪些退化区间抑制负迁移、哪些区间保留增益。

当前包含三种情形：**2D 遮挡、时间断流、场景遮挡**。三者各自独立成图，不混合口径。

### 3.1 2D 遮挡

**场景**：occ000 / 020 / 040 / 060 / 080 / 100 六档；按人体框底部逐级遮挡下肢，遮挡帧重跑视觉前端；同一 ckpt。

**实验组 / 对照**：Cv5 / Cv4 / Cv2 / Cv6 / Cv7；每模型 V 与 VT 两行。

**结果**：occ020–040 门控族 ΔPA 全负（Cv5 **−0.95 / −2.82**），无门 Cv7 **+2.23 / −1.13**；occ080–100 无门收益更大（Cv7 −8.99 / −12.89），交叉点约 occ060–080。

**产物**：`results_display/Etest_crossfit_v8/E5_OcclusionRobustness/`

### 3.2 场景遮挡 / 静态柱

**目的**：用真实场景物体遮挡替代黑色 bbox 遮挡，检验触觉在“人走进柱后、整身被遮住、再走出”时的作用。

**场景**：

- cam3 标定坐标系中放一根 **0.4 × 0.4 × 2.2 m** 灰色静态柱，位置约 **(1.45, −2.3, 0.4 m)**；
- 用相机标定把柱子投影到 RGB；受试者走进柱子后面、整身被遮住、再走出；
- 按 SAM 人体 mask 逐帧计算 visible fraction，得到 **clean / partial / full** 三档；
- 只对“柱子进入人体 crop”的 active 帧重跑视觉前端，其余帧直接复制 clean 特征，bbox / bbox_info 保持干净。

**实验组 / 对照**：

- 动作 03 / 04 / 05 / 08 / 09；四折 LSO，fS6S7 用 S13-out；
- 模型：V7_Cv5、V7_Cv7 + V8_Cv5 / Cv4 / Cv2 / Cv6 / Cv7 / Cv8（排除 SD2 / RT / tphys / RM / PO）。

**结果**：V8_Cv5 ΔPA **−6.02**、Cv7 **−3.63**；full 档 PA：T **103.1** < VT **113.3** < V **129.7**。

**产物**：`results_display/Etest_crossfit_v8/E5_SceneOcclusion/`

### 3.3 时间断流

**目的**：考察视频帧连续丢失时，触觉能否在视觉时间上下文断裂的情况下继续提供运动证据。

**场景**：连续断流比例 ρ = 0 / 10 / 20 / 40 / 60 / 80%；ρ 越大，可用视觉帧越少；同一 ckpt。

**实验组 / 对照**：V8_Cv5（VT vs V）与 V8_Cv7（VT）对照；T-only 作水平参考。

**结果**：V8_Cv5 的 Δ(VT−V) 随断流率单调转负——PA **+0.08（ρ=0）→ −3.25（ρ=80）**，Global **+1.41 → −2.25**，GroundPen **−1.74 → −2.02**；PA 的交叉点约在 ρ=10–20%，Global 约在 ρ=60%。Cv5 的 PA/Global 在全部档位低于 Cv7。

**产物**：`results_display/Etest_crossfit_v8/E5_TimeGap/`

### 3.4 可视化

- `E5_OcclusionRobustness/SMPLHeatmap/`：按视角（front / back / side）与遮挡档位，把 VT−V 的增益投影到 SMPL 身体表面，用热图显示触觉帮助集中在哪些部位。

## 4. E6 接触相位与门控

**目的**：考察门控在步态相位层面是否抑制触觉负迁移、保留正增益，以及增益集中在哪些接触阶段。

**场景**：按接触标签划分稳定支撑 / 摆动 / 落脚附近 / 离地附近；同一 ckpt；V 与 VT 对比。

**实验组 / 对照**：

- 门控模型 **V8_Cv5** vs 无门模型 **V8_Cv7**；
- E6-B：occ000 的 ΔE⁺ 有害分量 / ΔE⁻ 有益分量与抑制率 / 保留率；
- E6-A：四相位增益 G = VT − V；
- 三层代表指标：姿态 **PA-MPJPE**、轨迹 **GlobalMPJPE**、物理 **GroundPen（相位版 pen）**。

**结果**：

| 指标 | Cv5 抑制率 / 保留率 | Cv5 净 Δ | Cv7 净 Δ |

| PA-MPJPE | 69.3% / 124.6% | +0.08 | +3.20 |
| GlobalMPJPE | 73.2% / 149.6% | **−1.76** | +2.22 |
| GroundPen | 69.6% / 77.8% | **−1.74** | −1.26 |

相位 G：

| 指标 | 模型 | Stance | Swing | Strike | Off |
|---|---|---|---|---|---|
| PA | Cv5 / Cv7 | −0.14 / +2.42 | −0.42 / +1.71 | −0.05 / +3.80 | +0.62 / +3.18 |
| Global | Cv5 / Cv7 | −0.98 / +2.07 | −3.01 / +0.45 | −2.77 / +1.29 | −2.01 / +3.99 |
| pen | Cv5 / Cv7 | −1.38 / −1.08 | −1.64 / −1.65 | −1.02 / +0.09 | −2.23 / −0.51 |

## 5. E9 轨迹续写

**目的**：考察视觉在场景遮挡区间完全缺失时，触觉 / IMU 能否续写全局轨迹，并与纯视觉与外部 IMU 基线比较。

**场景**：四折 LSO woS13；每折 test 的 scene-occ manifest 会话，动作 **03 / 04 / 05 / 08 / 09**（08 为 3 折）；指标 = **遮挡区间内 root ATE**（full_event 并集）。

**实验组 / 对照**：

- VT 基座 = V8_Cv5；
- 外部基线 = Step2Motion；
- 消融臂 = Anysolo-TI / Anysolo-I；
- 系统臂 = 纯 VT、纯 Hybrid（学习式 IMU）。

**结果**（遮挡内 ATE，mm，四折 fold-level mean±std）：

| 动作 | Step2Motion | Anysolo-TI | VT | Hybrid | H+VT0.50 | H+VT0.75 |
|---|---|---|---|---|---|---|
| 03 | 316.6±91.5 | 362.5±65.7 | **211.9±13.5** | 261.1±35.0 | 211.2±22.0 | 230.7±28.7 |
| 04 | 345.8±92.1 | 345.9±34.7 | **204.4±34.1** | 345.9±98.9 | 203.8±86.1 | 266.7±93.6 |
| 05 | 792.7±317.2 | 477.2±91.0 | **280.0±55.5** | 339.2±119.1 | 290.8±69.2 | 310.0±91.1 |
| 08 | 405.2±135.7 | 644.1±10.1 | 353.2±28.4 | 292.9±50.8 | **304.1±32.7** | 293.3±40.7 |
| 09 | 862.5±330.6 | 447.5±120.7 | **222.8±22.4** | 339.6±110.0 | 249.2±55.8 | 289.6±82.4 |

VT 在五个动作上全部低于 Step2Motion；H+VT0.50 与 H+VT0.75 也全部低于 Step2Motion；纯 Hybrid 在 03/05/08/09 低于或接近 Step2Motion，04 持平。四折 std 较大（尤其 05/09），不做显著性主张。

**产物**：`results_display/Etest_crossfit_v8/E9_TrajectorySceneOcc/`
