## 1. E2 主性能

**目的**：验证同一个 ckpt 在 V / T / VT 三种输入配置下均可推理，并与各输入类型的参考方法比较。

**场景**：clean test，同一 ckpt，只改变推理时的可用输入。

**实验组 / 对照**：

- U = V8_Cv5（V / T / VT 三行同一 ckpt）
- 内部对照 = V8_Cv7 / Cv4 / Cv2 / Cv6
- 外部基线 = V 块 GVHMR / SAM3DB / WHAM / MMVP（FPP-Net + PoseTransOpt）；T 块 Step2Motion；VT 块 MotionPRO

**结果**：V8_Cv5 的 V / VT / T PA 为 **42.63 / 42.71 / 83.04**；V 块外部基线 51.9–66.2；T 块 Step2Motion 101.6。姿态与物理指标领先；Global/traj 落后 SAM3DB、优于 WHAM/GVHMR/MMVP。

**T 块正式行** = `V8_Cv5（T+BiFoot, position 同口径）`：V8 T2M 姿态 + BiFoot T/IMU 轨迹（GT 首帧位置单锚；世界系逐帧位移直接累加，不做 yaw 旋转；姿态取 V8 T2M cell）。**所有 V8 模型/消融的 T 行统一用这一 BiFoot 分支（无 TTA、无 Ramp）**：姿态/ROD 取各自 T2M cell，轨迹列共享同一 BiFoot 轨迹。**S2M 与 T+BiFoot 全部按同一口径重评、帧加权汇总**：姿态 **83.0 vs 101.6**、MPJPE **161.1 vs 184.4**、Global **347.4 vs 397.9**（4/4 折）、traj **284.6 vs 340.9**（4/4 折）、W100 **419.9 vs 444.1**（3/4 折）、GP **48.6 vs 64.3**（4/4 折）更好；ROD **45.4 vs 34.2**、FS **25.0 vs 7.1**、Jitter **2351.7 vs 368.1** 落后。轨迹消融（同 T2M 姿态，只换轨迹臂）：Global **400.6→347.4**、traj **342.4→284.6**，四折全部改善。旧 T2M root head 行保留为 legacy 对照（其 Global/traj 为 cell 自锚，不与本行做同口径比较）。

注：此前 T 块曾用 `frame_local + calibrate_gt_course` 的 yaw 变换积分，会把**已经世界系对齐**的预测再旋转一次，两臂都被抬高（S2M Global 481.3、BiFoot 481.6），造成“Global 持平”的假象。已核实 adapter 目标 `ds.poses[:,:3]` 就是**世界系逐帧根位移**（目标累加可精确复现 GT 根轨迹，0.00mm）；改为 GT 首帧位置单锚 + 直接累加后，S2M 存档逐项复现官方汇总（**9/9 指标差 0**）：PA 101.595、MPJPE 184.389、Global 397.935、traj 340.884、W100 444.059、GP 64.300、FS 7.119、Jitter 368.147、ROD 34.162。官方读数与同口径重评现已完全一致，不再需要单独的 position-only 对照行。

## 2. E4 消融

**目的**：分别回答两个问题——门控是否必要（门控效果），以及训练时是否需要对模态数据做 dropout（训练条件）。

**场景**：clean test，同配方、同数据，只改变门控结构或训练条件。

### 2.1 门控效果

固定三条件枚举训练，比较无门 / 单门 / 双门：

| 模型 | 门控 | VT PA | Δ(VT−V) PA |
|---|---|---|---|
| V8_Cv7 | 无门 | 46.29 | **+3.20** |
| V8_Cv4 | 单门（姿态/根共享） | 43.02 | +0.34 |
| V8_Cv5 | 双门（姿态 + 根） | **42.71** | **+0.08** |

**结果**：双门最好；单门已能收回大部分收益；无门在 clean 下仍有 +3.20 的触觉伤害。

### 2.2 训练条件 / 数据 dropout

固定双门，比较三条件枚举 / 随机模态 dropout / 始终 VT：

| 模型 | 训练条件 | V PA | VT PA | Δ(VT−V) PA |
|---|---|---|---|---|
| V8_Cv5 | V/T/VT 枚举 | **42.63** | **42.71** | **+0.08** |
| V8_Cv2 | 随机模态 dropout | 43.26 | 43.48 | +0.22 |
| V8_Cv6 | 始终 VT | **47.69** | 43.37 | −4.32 |

**结果**：枚举训练最好；随机 dropout 接近但略差；始终 VT 把 V 支路训练退化（V PA 47.69），其负 Δ 不是融合成功。

**T 行口径**：E4 的 `U@T` 行 = 各模型自己的 T2M 姿态 + **共享 BiFoot 轨迹**（无 TTA / 无 Ramp）；Global / traj / GP / FS / Jitter 来自 T+BiFoot（GT 首帧位置、世界系直接累加），姿态 / ROD 来自各自 T2M cell。T 行 `traj_ATE` 在本表用 RootAbs 3D RMS（321.078±72.046）；Global 随姿态不同（Cv5 347.4、Cv6 374.1）。

## 3. E5 视觉退化

**目的**：考察视觉证据退化时触觉增益如何变化，以及门控在哪些退化区间抑制负迁移、哪些区间保留增益。

当前包含三种情形：**2D 遮挡、时间断流、场景遮挡**。三者各自独立成图，不混合口径。

**基线**：主表用 WHAM / GVHMR / MotionPRO 三条参考线；occ/gap 为 **V8 98 会话**、scene 为 **25 会话**；不并入 V8 均值。SAM3DB 在 full/detail 作诊断。基线 `traj_ATE` 为原始绝对根 **mean**（无自锚），模型列为 `RootAbs` 自锚 **3D RMS**；同属无 GT 锚口径，但公式/聚合不同。

**WHAM 基线对齐（2026-11-13）**：E5 的 WHAM 曲线已按 **E2 四折 WHAM clean 值**做 per-metric 常数偏移（PA −0.153、Global +8.384、FS +0.077、GP −1.970、traj +8.294），保持退化曲线形状；因此 E5 clean 处 WHAM traj = **263.8**（与 E2 一致，比主模型 257.1 略差），不再使用 `e5_clean` 单次 run 的 255.5。主模型与 WHAM 仍是 self-anchor 3D RMS vs raw absolute 3D mean，不能按单点排序。

**T-only 参考口径**：T-only 行已从 legacy T2M root head 替换为 **T+BiFoot**（各模型/消融共享 BiFoot 轨迹；PA / ankle-foot 仍为 T2M 姿态，Global / FS / GP / traj 来自 T+BiFoot）。2D/gap 用 full clean 四折值，scene 用 E5 scene 会话子集；`traj_ATE` 用 3D RMS 以保持 RootAbs 列义。T-only 与 V/VT 的 cell 协议不同（T 为 GT 首帧单锚，V/VT 为 cell 自锚/GT anchored），不跨行比较绝对值。

## 4. E6 接触相位与门控

**目的**：考察门控在步态相位层面是否抑制触觉负迁移、保留正增益，以及增益集中在哪些接触阶段。

**场景**：按接触标签划分稳定支撑 / 摆动 / 落脚附近 / 离地附近；同一 ckpt；V 与 VT 对比。

**实验组 / 对照**：

- 门控模型 **V8_Cv5** vs 无门模型 **V8_Cv7**；

## 5. E9 轨迹续写

**目的**：考察视觉在场景遮挡区间完全缺失时，触觉 / IMU 能否续写全局轨迹，并与纯视觉与外部轨迹基线比较。

**场景**：四折 LSO woS13；scene-occ manifest 会话，动作 **03 / 04 / 05 / 09**（每折 n = 17 / 4 / 6 / 19）；两个任务：

- **SceneOcc（短任务）**：真实 VT 位置 + 虚拟 VT 速度；
- **HalfPlane（长任务）**：相对保持虚拟锚 + 虚拟速度。

指标 = **遮挡区间 3D root ATE（RMS）**；另报全程 3D RMS / Mean（`Main_Table3/4`）。**积分口径：世界系逐帧位移直接累加 + VT 入口位置锚，不做 yaw/psi0 旋转**（adapter 目标即世界系位移，累加可复现 GT 根轨迹）；Ramp 在 e0 再消费一次 VT；TTA 为 token 级测试时优化（H 路径、端点约束 `vt[e0]−vt[n0]`、λ=0.01、400 步）。**只报 3D**；2D occ 仅在 `detail/` 作诊断。

**实验组 / 对照**：

- 外部轨迹基线 = **MotionPRO**（v4 `carpet_v4_anysolebbox` 四折）；
- 外部轨迹基线 = **Step2Motion**（官方 `TransformerTranslation` 在同一 adapter/test clips 上重跑，n0 VT，entry-only）；
- 主方案 = **BiFoot-Entry**（n0 VT）；
- 主方案 = **BiFoot-Ramp**（n0 + e0 VT）；
- 主方案 = **BiFoot-TTA**（token 级 TTA）。

| HalfPlane（长） | 265.1 | 265.6 | 246.8 | **173.4** | 177.6 |

逐动作 mean±std 见 `Main_Table1`；全程 3D RMS/Mean 见 `Main_Table3/4`。**Ramp / TTA 在两个任务上都低于 Step2Motion 与 MotionPRO；BiFoot-Entry 也低于两个基线。** SceneOcc：Ramp **143.6** 最好，TTA 167.4 次之；HalfPlane：Ramp **173.4** 最好，TTA 177.6 略差 4.2，且收益集中在 05（344.1→196.3），03/04/09 都差于 Ramp。E9 为遮挡场景分支实验，独立报告其 VT 入口锚、遮挡区间口径。

| 指标 | 定义 / 实现 | 使用实验 | 可比性 |
|---|---|---|---|
| PA-MPJPE | 逐帧相似对齐 PA-MPJPE（含尺度） | E2/E4/E5 cell、E6-B `pa_mpjpe_mm`、E6-A PA | 同一实现，可跨表 |
| GlobalMPJPE | 自锚列 `global_mpjpe_selfanchor_mm`（模型每窗自估锚，零 GT 锚） | E2/E4/E5/E6-B | 同一列；`global_mpjpe_mm` 是 GT-anchored 变体，只作诊断（旧 E6 误用，故出现 −1.76 反号）；**E2/E4/E5 的 T 行例外**：T+BiFoot（GT 首帧位置、世界系直接累加、无 TTA/Ramp），不与 V/VT 自锚块比较；E2 T 专用表用 3D mean，E4/E5 的 RootAbs 列用 3D RMS；S2M 同口径值与官方汇总逐项一致 |
| W-MPJPE100 | 自锚列 `w_mpjpe100_selfanchor_mm` | E2/E4/E5/E6-B | 同一列；GT-anchored 变体只作诊断 |
| GroundPen | GT 地面线穿透（GT anchored） | E2/E4/E5 cell、E6-B `ground_pen_mm`、E6-A `pen`（相位版） | 同一实现，可跨表 |
| FootSliding | GT 接触帧公共关节脚滑（GT anchored） | E2/E4/E5 cell、E6-B `foot_sliding_mm` | 同一实现，可跨表 |
| traj_ATE | E2/E4/E5/E6-B 主模型 = `RootAbs`（自锚 3D root RMS）；E2/E5 基线 = 原始 root absolute mean；**E2 T 块 = GT 首帧位置单锚、同管线世界系直接累加、3D mean（S2M 340.9 vs BiFoot 284.6）**；E4/E5 的 T 行为 T+BiFoot 分支（无 TTA/Ramp；E5 的 traj_ATE 用 3D RMS 保持 RootAbs 列义）；E9 = 遮挡区间 3D root ATE（VT 入口锚、世界系直接累加，RMS） | 见左 | **不是单一锚定义**：只在同组行内比较；E9 不与 E2/E5/E6 的 `traj_ATE` 跨表；E6-A 相位表不放轨迹列 |
