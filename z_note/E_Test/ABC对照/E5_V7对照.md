## 判读

0. **best/last 口径差异**：C 的 best（落 ep665，即旧口径的「ep665 规则选点」）在 test 侧的兑现比 last 小——Δ踝足 occ010 −3.39→−1.89、occ030 −5.29→−2.63、ΔPen −4.83→−3.03，T2M PA 89.1→91.5——「val 最优 ≠ test 兑现最优」，对应 ckpt 规则自述的 val≈test 漂移风险（V/VT +4~6mm、T +4.5~20mm 量级）。零税不受影响（两口径五档 ΔPA 均 ±0.65 内）。
1. **E5 命题在 C 上成立**：Δ 随遮挡加深而增大（Δ踝足 −0.70 → −3.39 → −3.82 → −5.29，ΔATE −0.59 → −1.54 → −2.08 → −3.43，ΔPen −1.67 → −2.51 → −3.06 → −4.83），occ010–030 单调兑现「视觉退化越多、T 帮助越大」；occ050 处 V2M 自身退化到 54，T 的绝对帮助回落但 Δ 仍全负。
2. **全程零税**：C 的五档 ΔPA ∈ [−0.43, +0.56]——与 A/B 的「健康档收税 +0.7~+3.3、重遮挡才翻负」形成对照。门把「税与兑现的取舍」转成了「零税 + 全档兑现」。
3. **A/B 的无门签名**：ΔPA 在 occ000–030 恒为正（A +2.24~+3.34、B +0.70~+2.09），到 occ050 双双翻负（−0.44 / −1.88）；ΔPen 分化——A 全档为负且随遮挡加深（−2.94 → −6.96），B 在 occ000–030 为正（+0.48~+1.26）、occ050 才转负——T 的物理帮助与姿态税并存，正是候选 C 要修掉的模式。
4. **B 的足-地一致性未显示独立增益**：B 的 ΔPen 不优于 A（健康档 B +0.9 vs A −2.9、occ050 B −2.0 vs A −7.0）——L_foot 在共享骨架里没有带来可区分的额外兑现（与 B 方案已知输入「接触头摆动相召回 0.51、支撑区间偏保守」一致）。
5. **保留结论**：V7_Cv1 = 唯一同时通过 E2 筛查与 E5 命题的候选；A/B 作对照行。

数据边界：单 seed；occ 交叉评估与 cam3 同 ckpt 同协议；外部 V1 基线行待补；best 的 epoch = A 710 / B 580 / C 665（tau0 快照，仅防爆炸备份语义，此处并列作口径对照）。
