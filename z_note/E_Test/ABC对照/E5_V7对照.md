## 判读

0. **选点口径修正（2026-10-26，C 行更新）**：规则选点 ep665（val VT PA 最小）在 test 侧的兑现比第一轮的 ckpt_last 小——Δ踝足 occ010 −3.99→−1.89、occ030 −5.90→−2.63、ΔPen −5.66→−3.03，T2M PA 87.6→91.5——「val 最优 ≠ test 兑现最优」，对应 ckpt 规则自述的 val≈test 漂移风险（V/VT +4~6mm、T +4.5~20mm 量级）。零税不受影响（五档 ΔPA 仍 ±0.6 内）。

1. **E5 命题在 C 上成立**：Δ 随遮挡加深而增大（Δ踝足 −1.0 → −4.0 → −4.6 → −5.9，ΔATE −0.6 → −1.9 → −2.7 → −3.8，ΔPen −1.8 → −3.3 → −3.9 → −5.7），occ010–030 单调兑现「视觉退化越多、T 帮助越大」；occ050 处 V2M 自身退化到 54，T 的绝对帮助回落但 Δ 仍全负。
2. **全程零税**：C 的五档 ΔPA ∈ [−0.89, +0.38]——与 A/B 的「健康档收税 +2~+4、重遮挡才翻转」形成对照。门把「税与兑现的取舍」转成了「零税 + 全档兑现」。
3. **A/B 的无门签名**：ΔPA 在 occ000–030 恒为正（+2.1~+4.1），到 occ050 才翻零；ΔPen 全档为负且随遮挡加深（−2.9 → −9.2 / −2.7 → −5.7）——T 的物理帮助与姿态税并存，正是候选 C 要修掉的模式。
4. **B 的足-地一致性未显示独立增益**：B 与 A 的 ΔPen 曲线几乎重合（−2.7~−5.7 vs −2.9~−9.2）——L_foot 在共享骨架里没有带来可区分的额外兑现（与 B 方案已知输入「接触头摆动相召回 0.51、支撑区间偏保守」一致）。
5. **保留结论**：V7_Cv1 = 第一轮唯一同时通过 E2 筛查与 E5 命题的候选；A/B 作对照行归档。
