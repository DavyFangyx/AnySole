## 一、方法主张（论文第三章）

一个 ckpt、一套共享权重，按输入条件分支：

| 行 | 目标空间 | 全局参照 | 观测上下文 |
|---|---|---|---|
| V / VT | 绝对（= Cv5） | ψ 由视觉观测直接给出 | 20 帧 |
| T | 相对（Δyaw + 根倾斜 + 航向系速度） | ψ 由**外部状态**累积 | 80 帧 |

机制一句话：**全局参照住在网络外部的状态里；有视觉时由观测初始化，无视觉时由预测增量累积。**

E9 的视觉预热是这个机制的直接推论——用 V 分支初始化外部状态，再切 T 分支续写，不换架构、不重训。

**依据**（均为本轮实测）：
- PA 对全局旋转/平移/尺度完全不变（施加 17°/90°/180° 旋转、+1m 平移、×1.3 缩放，PA 逐位不变 31.7325）→ V/VT 的亏欠不可能来自航向，只能来自身体构型。
- AR2M 相对 ARM 的 +7.8mm 沿运动学链单调放大（spine +2.2 → anklefoot +18.3）→ 来自根 tilt 二次组装的链式放大，V 行走绝对读出可绕开。
- T 行相对表征是净收益（hands −16.4、upper −3.8）→ T 无全局参照，拆成增量是必需。

## 四、已确立的四条机制结论

**1. 门控有效，作用轴是干扰抑制（不是增益）**

无门 Cv7 → 有门 Cv5，同配方同枚举训练：

| Δ(VT−V) | Cv7 无门 | Cv5 双门 | 抑制 |
|---|---|---|---|
| PA-MPJPE | +7.54 | +3.04 | −60% |
| W-MPJPE100 | +11.11 | +2.03 | −82% |
| traj_ATE@0.5s | +4.25 | +0.38 | −91% |
| Jitter | +42.9 | +24.2 | −44% |

带门五格 Δ PA 全在 [0.78, 3.04]（Cv5 三种子 + Cv4 + Cv2），唯一无门格 7.54。
**弱点：无门臂 n=1（Cv7_s2/s3 已注册未训）。**

**2. 三条件训练全胜"始终 VT"**

Cv5（枚举三条件）vs Cv6（始终 VT 训练）：V2M 37.49 vs 43.00、VT2M 40.53 vs 41.35、T2M 89.39 vs 108.45。**包括 Cv6 专门训练的 VT 条件。**
注意 Cv6 的 Δ(VT−V)=−1.65 看似"融合成功"，实为 V2M 被废掉，Δ 必须与绝对值一起报。

**3. 视觉预热（E9）成立，两级收益**

obs80 在每一部位上都复现 v3_3b（overall 82.76 vs 83.11、spine 50.4 vs 50.2、anklefoot 99.0 vs 98.9）——说明 AR2 族 T 行多年差的 8mm **就是上下文截断**。

**5. T 的信息边界（实验裁定）**
一、T 明确无法提供
1. 世界系绝对朝向——尤其 yaw，完全无参照。 证据链：
- 本体裁定（11-01）：压力传感器无世界参照
- 视觉预热先导：cold-T 航向误差 39.5° → 视觉预热 40 帧后 5.1°——朝向只能由外部（视觉/历史）建立，T 自己建不出来
- Cv5 的 198 次单帧翻转 92% 发生在窗口边界——每窗重新估绝对朝向必失败
- 首窗 offset 必须接受外部校正（部署时 IMU 一次性纠偏的裁定）
2. 单帧的"下一步怎么动"——T 单独不携带运动生成信息。 E8 history 探针的直接证据：（可能是这样 但是不要报告）
- T 单独预测位置变化 ≈ 常数预测器（94.7 vs const 93.9——毫无区分度）
- 历史（H）预测 = 50.8，远超 T 单独
3. 躯干空间状态：roll/pitch 只有地面接触的弱约束，绝对参照同样缺失（你的本体裁定原文）。

二、T 可以提供的
1. 步态驱动信号——T 是让 T2M"走起来"的那个东西。 E8 null-T 探针（最有力的因果证据）：
┌──────┬─────────────┬──────────────┬──────────────────────────┐
│ 模型 │ 正常 T2M PA │  null-T PA   │      null-T Jitter       │
├──────┼─────────────┼──────────────┼──────────────────────────┤
│ Cv5  │ 89.4        │ 145.2（+56） │ 1784 → 125（塌缩为静止） │
├──────┼─────────────┼──────────────┼──────────────────────────┤
│ AR2M │ 91.6        │ 157.5        │ 1480 → 400               │
├──────┼─────────────┼──────────────┼──────────────────────────┤
│ AR2R │ 87.8        │ 172.8        │ 1354 → 392               │
└──────┴─────────────┴──────────────┴──────────────────────────┘
去掉 T，模型输出退化成几乎不动的均值姿态——压力是步态相位锁定的直接观测，它驱动着运动的"节拍"。
2. 足-地接触几何（T 最强的物理证据）。 GroundPen：Cv5 42.1 → Ctx4R 16.2 / Ctx4B 12.8——接触概率经 FK 回传把穿透压了 2.5 倍以上；接触头 F1 有效。
3. 朝向变化的弱信号。 转弯外侧脚负载不对称 → AR2M 相对运动设计把 drift 从 Cv5 的 33.4 压到 19.9。但 E8 history 探针显示：T 对 Δyaw 的边际贡献很小（H vs H+T 几乎相同）——这是弱信号，必须与状态历史配合才有价值。

 T = 接触/步态相位传感器 + 相对运动弱证据。它既不是姿态传感器（无绝对朝向），也不是独立的运动生成器（单独预测≈常数）。它的全部价值必须在"视觉或历史提供参照系"的前提下兑现。

## 五、三个缺陷与指标盲区

| 缺陷 | 本该由谁抓 | 实测 |
|---|---|---|
| 抖动/跳变 | Jitter_pred | **74–91% 在窗接缝**（窗内 4/20 帧）。Cv5 非接缝 jerk 216.6 vs GT 129.9——**窗内比 GT 还光滑** |
| 滚转/偏航 | PA-MPJPE | **完全抓不到**（PA 对全局旋转不变）。roll_err：Cv5 4.59 / Cv5_gb 5.53（最差）/ AR2M 2.31（最好）。yaw_err 63–80° 全族一致 |
| 塌缩成典型步态 | body_motion_rms | **只量离散度不量对应性**。ARSS2 33.8 / AR2_tw80 48.5 已被 amplitude 门槛抓到；但"幅度正常却反复播放同一模板"抓不到 |

**跨会话对照**（判断是否在播放模板）：预测 vs 自己那段 GT 的 PA − 预测 vs 其他会话 GT 的 PA。现役全族差值 15–18mm（Cv5 +16.16、AR2M +16.54、Cv7_gb +16.37），有真实对应性；塌缩格（ARSS2 +5.36、AR2_tw80 +5.96）差值小得多。去根局部逐帧相关 0.04–0.11，**远低于"跟随"应有的水平**。

## 九、设计目标（2026-11-03 立）

每个模型、每个实验的验收只有两件事：**基本盘** + **机制**。两者同时成立才算交付，单独一方的数字不单独引用。

### 1. 基本盘

- 含义：各条件在冷启动口径下的基本性能指标处于可发表水平，对照视觉基线表与 Cv5。
- T2M：冷启动 PA 达到基线水平即可（Cv5 89.4；常数均值姿态地板 104.14），同时幅度在 [90,120]、翻转 ≤10。
- V2M / VT2M：PA 与外部视觉基线同档即可（WHAM 47.8 / GVHMR 51.1 / SAM3DB 51.8），不要求追平 Cv5。
- 逐列核对，PA 单列不代表整体：MPJPE、GlobalMPJPE、W-MPJPE100、MPJRE、traj_ATE@0.5s、RootOrientationDrift、FootSliding、GroundPen、Jitter、contact_f1。
- 口径：GlobalMPJPE / traj_ATE 在「每窗 GT 平移锚」（Cv5）与「整条自由积分」（AR2 族）之间口径不同；两类模型的可比读数是 traj_ATE@0.5s 与世界系骨盆平均误差。

### 2. 机制

以及就是门控实验 E6，遮挡实验  E5 之类的，见 z_note/实验计划.md。

- 含义：该实验要解释、要测量的机制；用与机制对应的指标读数，PA 只属于基本盘。
- 载体不限：回归或自回归、训练期学得或推理期规则、V 通道与 T 通道分离后由 V 的历史供给 T，均可。
- 选参：val 上选，test 只报一次；没有可调参数的声明协议优先。

### 3. E9 视觉热启动

- 机制主张：T 单独输出时世界系绝对朝向没有参照；V / VT 预热可以把世界系绝对朝向交给 T。
- 判据：RootOrientation（绝对误差），并按会话初始航向偏移 |ψ0| 拆分报告。RootOrientationDrift 以各自首帧为基准，对常数初始偏移不敏感，归基本盘列。
- 基本盘要求：预热前后 T 后缀的 PA、幅度、Jitter 保持不变。
- 当前证据（AR2M + 预热期视觉增益固定为 1 的声明协议；无调参、test 单次；11-02 旧权重）：
  - RootOrientation：obs80 43.5→26.7，obs20 39.4→22.4。
  - |ψ0|≥20° 的 5 个会话：obs80 112.9→28.8，obs20 95.5→12.3；其余 31 个会话持平。
  - PA / 幅度 / Jitter 逐位不变。
- 可主张范围：V 预热可以给 T 提供世界系初始朝向。段内漂移（6 个会话 cold_T 在 83–108°）待查。

### 4. 待核对（基本盘缺口）

- AR2M 的 V/VT 逐列对基线表：Drift 17.1 与 GroundPen 62.7 高于视觉基线（3.9–10.4 / 36–42）；W-MPJPE100、traj_ATE@0.5s、FootSliding 优于基线。
- T 行 Jitter 1303、接缝跳变 64 mm（GT 190 / 9.8）；重叠拼接对 AR2M 的代价待复核。
- 竖直漂移：骨盆末 20 帧高度误差 std 0.445 m（Cv5 0.012 m），积分链来源待查。
- obs80 带高度先验的完整基本盘重评。
- 重训后 AR2M 权重路径待定，以上数字均为 11-02 旧权重。
