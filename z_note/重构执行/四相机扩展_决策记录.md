## 1. 背景与目标

T 信息量判定三实验（`z_note/multimodal_fusion/T信息量判定实验.md` §5）结论：V 太强，VT 相对 V 在 19 指标普遍退化，T 的价值只在物理量（穿透 −5.8mm）、难例（V 误差最高 10% 窗口 VT 胜率 65%）、V 缺失（ρV=0）场景显现。

**新假设**：削弱 V（换成单相机视角）后，VT−V 的 delta 符号翻转（从退化变提升）。

实验 = 四个相机（1=top / 2=left / 3=front / 4=right）各自作为视觉输入，全流程（数据 → 模型 → 实验 → 展示）跑通并比较；cam3 = 现有数据参照，既有 cam3 实验数字与结果目录零改动。

## 3. 决策点 D1：帧轴协议

**状态：已裁定（2026-10-12），待数据层落地后以统计表复核。**

### 裁定

四相机统一 cam3 帧轴：n_frames / visual_start_s / mocap_start_s / offset_s 沿用 manifest 的 cam3 历史值；仅图像源换成相机 k 的前 n 张 JPEG（build_shared 已有 `images[:n] + [images[-1]]*(n−len)` pad/truncate 逻辑）；压力仍按各相机首帧墙钟绝对锚定（现有 `video_start_day_s` 绝对重采样逻辑自动成立，per-camera 行为已内建）。

### 依据（主库农场实测）

- 4 相机 JPEG 文件名共墙钟（S8023 实测：cam3 首帧 165958.951，cam1 165958.974 → 相机间首帧偏移 ≤±25ms）；
- 各相机 fps 39.5–40.0 → 对 40fps 合成轴的末端漂移 ≤2 帧；cam3 自身 39.889fps 已有 ~1 帧同量级近似（非新引入误差）；
- JPEG 数 339–342 vs manifest n=340 → pad/truncate ≤1 帧；
- 覆盖度：4 日期（0804/0807/0808/0810）全部 rec 均含 1/2/3/4 相机目录 + meta.json——**农场已齐，无需再导入任何原始数据**；证据只读 JPEG 文件名 + meta.json，不解码图像。

### 执行路线（数据层）
