## R1 归档要点

1. **入口尺度**（全部实测，方法见证据文件③④）：原生 160×120→96×96 长轴 20.833mm/px、足印 11.52×7.68px；虚拟毯 320×120→96×96 长轴 41.667mm/px、足印 5.76×7.68px（面积比 0.500000，各向异性 1.333→2.667，足印像素纵横比方向反转）。320→96 定点采样下 128/320 行（40%）永不进入口。conv1(stride2) 后足印 2.88×3.84 格 vs 原生 5.76×3.84。
2. **方案更正入档**：此前"预降采样（方案 B）可恢复原生足印尺寸"算术不成立——96px 覆盖 4m 时足印恒为 5.76×7.68px；B 的真实收益仅为消除 40% 丢行（入口非零像素 +22.5%），且必须走消费端实现。恢复原生入口语义只有两条路：缩短视场（C，需窗口信号+模型改动）或提高入口分辨率（D，入口 192×96 一行改动、模型零结构改动、数据零重产、前向 +62.3%）。
3. **锚点问题（材料性，与入口裁定独立）**：毯锚于世界原点角（x∈[0.006,1.494]×y∈[−3.994,−0.006]m），受试者以原点为中心行走（脚 x∈[−0.27,0.23]、y∈[−2.50,2.36]m）→ 53.8% 帧空、30/140 session 全空、每 session 长轴使用中位 21.2cm/400cm。**主会话独立复验**：140 份 artifact.json 聚合（frames_any_paint 24,287 + frames_out_of_bounds 28,325 = 52,612）与逐 session 抽查（S5011 全部 512 帧只画在列 [0,3]/120×行 [0,8]/320 的角部条带）均吻合。A/B/D 全部继承该问题，仅 C 能消除；即使重锚，~10% session 行走跨度 >4m（最大 4.57m），越界不可完全消除。
4. **前提修正两条**：① `FRAPPE.py:129` 为 `resnet18(pretrained=True)` 且本机缓存权重存在——触觉主干为 ImageNet 初始化（conv1 随机），"从零训练"口径需修正；② `results/baselines/MotionPRO/checkpoints/imagepressure2smpl/` 存有旧 ckpt（09-22/23），配置指向已废弃 `workspace://derived/...` 旧链，不可用于 adapter_v1 数据。

## R2 归档要点

1. **几何层通过**：链位精确（smpl.npy vs raw np.interp maxabs ~3–7e-08 float32；keypoints.npy == SMPL 前向 joints[:,:24] maxabs 0.000e+00m）；静止帧（<0.15m/s，n=13）帧级对齐 4.5px；五个控制组（×10/×1/×1000/z-up-first）IoU 全 0.000；尺度不变校验（相机离毯面 179.5cm、光轴俯角 15.6°、319.1px/m、头高 1.517m）全合理；镜像对照比值 8–14× 排除 L/R 镜像。
2. **时间层不通过**：lag 0 逐关节中位 39.9px（任务书 ≤20px 阈值之上）；亚帧扫描极小点 +9.25~9.75 帧（17 关节中 15 个独立 argmin ∈[+8.75,+11.25]）；偏移随运动方向反号（+x→dx +32.8、−x→dx −30.1）且随速度单调（静止 4.5→慢 28.4→行走 45.9px）——纯时间错位，非静态几何误差；独立第二 2D 源（YOLOX 检测框）IoU 峰 +10 帧复核一致。
3. **根因与影响面**：偏差位于共享事实层时钟对齐（S5091 `visual_time_s − mocap_time_s = 0.631612s` 恒定；真值约需 ≈0.869s，即修正为逐 session 一个标量）。全库 140 session 扫描 lag* 覆盖 −17…+26 帧：53 个高误差 session 中 47 个可被时间平移修复、38 个 lag 0 已 ≤8px、6 个修不动（2D 串人）。**影响不止 MotionPRO**：共享 facts 层是所有模型 visual↔mocap 配对的底座，图像条件类指标（视觉→运动、MJE/PVE）会系统性变差；3D/压力自身指标不受影响。方向确认（哪侧时钟错）需独立同步源，重投影只能定配对差。
4. 顺带观察：原生消费端 `image_pressure.py:238` 只取 keypoints `[:, :23]`（丢 R_hand，左右不对称，上游设计）；原生 MotionPRO 链不用相机（focal_length 硬编码 608），相机链问题只影响 2D 校验/评估路；542 帧中 226 帧（41.6%）点云不落检测框（多人串人，数据质量侧面）。

## R3 归档要点

1. **映射**：右脚源通道 34（列 35）→ 31×11 的 8 格 (4..7,5..6)，逐值直通（4204 帧抽样 0 处不一致）；独占 3/96 顶点（SMPL 6653/6661/6701，192 维的 1.56%），0 个部分污染；左脚同格健康（0/139 判据命中）。
2. **三条通道**（fleet 139 session/51,828 帧，S12102 无 valid 帧除外）：
   - (i) 权重膨胀（最重，数据级）：判据命中 53/139；S11 mean_press 91.4→209.0（2.29×）、S7 1.80×；全库 256,041/17,258,724（1.48%）接触对被压成假阴性；两个标定 session（S7011/S11011）均被命中 → 源头置零后权重重算即自愈；
   - (ii) 输入饱和：8/484 维在 10,390 帧（20.05%，91 session）sigmoid>0.99 饱和；尖峰/环邻 17.3×（最坏 61.5×）；全量最大原始值 10,392；
   - (iii) 二值假接触（最小）：th=0.5 轻载假接触 160 帧（0.313%，47 session），完全腾空 0 帧；多为"抬升的地板"（中位 212，>1023 仅 3.4%）→ 整段置零丢 9.88% 真实质量。
3. **附带发现（同批登记）**：随附 FPP 侧车顶点 GT 实为已退役 th=0.7（GT=0 而 sig>0.7 = 0 帧；GT=0 而 sig>0.5 = 4785 帧）；38 个 session 用旧权重（S8×9/S12×11/S13×18；侧车均写于 09-27 22:58–22:59，早于双足承重修复）。
4. **值域登记**：31×11 无 clip 直通（max 10,392）；FPP 原生 lib 无 1023 假设（grep 0 命中，maxNorm 死代码）；AnySole/MotionPRO 为 /1023 有界截断——同一故障只把 FPP"打死"（Σraw 无界 + per-subject 自适应均值），跨模型对比需对口径。

## 交叉影响注记

- R1 锚点 + R2 时钟共同决定 **MotionPRO 训练数据的可用性**：30/140 session 触觉全空（锚点）、图像↔GT 错位 ~0.24s（时钟）；两者都不修则 MotionPRO 在 half-empty 数据 + 抢跑监督上训练。
- R3 影响 **FPP-Net** 训练与评估（权重/输入/顶点 GT 三层），且 E3 公共 contact GT 口径必须吸收其附带发现（th=0.7 侧车、旧权重 session）。
- 三者共同支撑此前建议的"**已知系统偏差清单**"（E5 前随正式结果冻结）：深度 −11%、clip 压平、V3 判据 0.66–0.80、锚点空毯、时钟残差、故障格三通道。
