## 1. 已裁定并落地的条目

### M1：pressure_tookit ICP 口径（用户裁定：无问题，按推荐落档）

- **裁定**：正式口径 = **CPU**（代码默认即 CPU，显式固化）；GPU 当前**不转正**。
- **实测（2026-09-28，S10101 5 帧链）**：
  - 根因：`depthTerm.py:34-69` GPU kNN 返回**平方距离**被当线性距离过 0.05m 门 → 有效门 0.224m（放宽 4.47×）。登记表 #17 的"~1e-6 等价"为 f32 舍入量级，漏了平方/线性门语义改动。
  - CPU vs GPU：transl 最大 1.75mm / body_pose 0.013 rad / loss +2.8~4.3%；一行 sqrt 修复后 loss 差缩至 +0.036%（~120×），f32 残留仍 ~1mm/1e-2 rad——等价不成立。
  - 开销：GPU 1.74×（非所称 3.5×）。
- **落地**：`run_full_mmvp.py` `FORMAL_ICP_DEVICE=cpu`、conf 显式 `PRESSURE_ICP_DEVICE=cpu`；缺陷记录不修。

### M2：canvas 640 + 内参缩放（用户裁定：无问题，按推荐落档）

- **裁定**：640,576 + dIntr 缩放 = 正式口径（转正）；native（1624×1240）留作高保真选项。
- **实测**：比 native 快 2.56×；代价 = 拟合结果变 2.1mm/0.019 rad、少解出 32% 可见顶点（几何自洽，无 GT 无法判优）。
- **落地**：canvas/maxiters/dIntr 缩放规则全部写入 run artifact（`work.pressure_toolkit.run.v1` parameters），口径漂移拒绝执行。
- **附带**：DepthPro 自估 focal ≈1261 vs 标定 cam3 fx 1329–1408（~11.7%）系统偏差，数据侧待确认（Q1 族）。

### M3：maxiters 扫描（无拍板项，实测定案）

- **实测**：maxiters 已接通且完全确定（前 N 步逐位一致）；30 次欠收敛（transl 3.3mm）、50 次 6mm 不达标；100→300 进入平坦盆地（loss ±0.06% 抖动，位姿非唯一）。

## 2. 实验完成、待拍板的条目

### M12：FPP-Net 推理 batch 化（已落地，无需拍板）

- **前提修正**：推理循环本来就是批循环（`--batch_size` 默认 1 从未启用），文档 12/13 的"逐 session → 批推理"表述已改。
- **落地**：`infer_smplcont.py` batch 默认 1→32 + `--allow_tf32` 开关（batch 路径默认关 TF32）+ 队列默认 batch 32/workers 4。commit：Baselines `cedd921`、主仓 `bf26da7`。
- **证据**：关 TF32 后批/逐帧 max 2.4e-7（<1e-6 ✓，12,566 帧全 split 实测）；端到端 7.0×（88.6→12.7s）；逐字节一致不可达（浮点归约序 1-2 ULP，非实现缺陷）；原生口径（batch=1 + TF32 默认）可回。
- **附带发现**：打印指标的 batch 差异 = 尾批加权假象；可视化分支 latent bug（只出 [0]，实际不可达）；`dataset_split_temporal5.npy` 的 val 与 test 逐字节相同；FPP 生产 checkpoint 不在盘（需重训）。

### M13：AMP 扫描（实验接近完成，终表待出）

- **fp16：四模型全不达标**——MotionPRO（1.22×、10/118 步溢出、val MPJPE +16%）、Step2Motion（pose 1.69× 但 val +10.1%；trans 1.06× + 4 步跳过）、AnySole（4/8 步触发非有限梯度守卫、loss +55%、下游 VT2M 321.8 vs 297.3）、FPP（进行中）。
- **bf16：AnySole 全链达标**（1.68×、0 跳过、loss +0.33%、下游 VT2M 292.5/V2M 258.1/T2M 290.9 vs 原生 297.3/244.4/295.6、显存 20.2→11.5GB）；**MotionPRO bf16 数值干净但 0.63×（无加速）不达标**；Step2Motion/FPP bf16 待出。
- 判读：fp16 溢出是量程伪影；bf16 是唯一可行路线，但加速只发生在 AnySole（大模型）；基线小模型带宽/开销主导，AMP 无收益。
