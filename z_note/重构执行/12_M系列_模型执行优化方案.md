## 1. 定位与准入标准

M = **执行层优化**：算力 / 内存 / 时间开销下降，算法语义与数值精度不变。

**准入三条件（缺一不进 M）**：

1. **开销实测**：改动前后的速度 / 显存 / 迭代数对比表（同输入同机）；
2. **精度等价证据**：原生路径 vs 加速路径的数值 diff 表（同输入；如 GPU ICP 的 ~1e-6 级）；
3. **登记为"扩展"性质条目**（Baselines 仓库登记 + 一次提交 + 证据测试）：正式 baseline
   口径必须可开关——**正式复现跑 = 原生口径，M 开关只用于批量生产与迭代**。

M **不做**：模型结构、loss 公式、数据语义、评估口径改动（属 T / E 管辖）。

## 3. 新 M 候选清单（按模型，T 完成后逐个评估）

**pressure_tookit**（M 范例最成熟，blocked 解除后第一优先级）
- M1 拍板：GPU ICP 批跑默认 vs CPU 正式口径 + 两者 diff 全量重测（含深度/关键点全 session）；
- M2 画布 640 + 内参缩放正式化：精度 diff 表 + 速度表，达标则入 M 条目；
- M3 迭代数扫描：maxiters 生效（#12）后扫 30/50/100 迭代的精度曲线，找"无损最小迭代数"；
- M4 多 session 并行调度（多 GPU，run_full_mmvp 已有 --gpu 基础）。

**PoseTransOpt**
- M5 逐 session 多 GPU 并行（140 sessions × 154488 文件，调度级加速）；
- M6 投影批量化（perspective_projection 逐帧调用 → 向量化）；
- M7 迭代截断扫描：max_iter 2001 → 实测 loss 收敛曲线，找 Δloss 早停的最优等价截断。

**Step2Motion**
- M8 训练早停（epochs_pose 100 / epochs_trans 200 → 收敛曲线证据 + 早停机制）；
- M9 DDIM 采样加速（DDPM T=200 → 少步）：**需谨慎**——与 AnySole Test9.1（τ0-vs-DDIM 根因）经验联动，采样器改动必须做 τ0 / 多样性 / 重建三对照，达不到等价就不进 M。

**MotionPRO**
- M10 batch_size 64→16 复核（登记表 #9 待核缘由：显存 vs 刻意）——若显存允许恢复 64 即提速；
- M11 AMP 混合精度（与通用 M13 合并做对照实验）。

**FPP-Net**
- M12 推理 batch 化（前提修正：循环本就是批循环，实为"启用 batch 32 + workers 4 + batch 路径关 TF32"，已落地）。

**通用**
- M13 AMP 扫描：四个学习型模型统一做一次"原生 vs AMP"速度/精度对照，达标者各自成 M 条目。

**AnySole（主模型，是否纳入待拍板）**
- M14 若纳入：推理采样步数 / batch 推理等算力侧优化；模型效果侧的历史（E6.x/Test12 等）不属于 M。

## 4. 执行顺序与纪律

```text
T1/T2 完成（每模型 smoke 过）
  → M 按模型顺序：pressure_tookit（M1–M4）→ FPP-Net（M12 + A3 移植）
    → Step2Motion（M8/M9）→ MotionPRO（M10/M11）→ PoseTransOpt（M5–M7）
    → 通用 M13 AMP
  → E 系列（评估收尾，正式结果全部用原生口径跑出，M 开关关闭）
```

每条 M = 一个 commit（Baselines 登记 + 证据测试 + 开销/精度两张对照表）；
与 T2 同纪律：`git diff 111220c -- <模型>` 恰好等于该模型全部登记条目（T + M）。

## 6. 与 E 系列的分界（一句话）

M 只加速"跑出来"；E 只关心"跑出来的数字怎么比"。正式评估结果必须原生口径生成——M 开关打开的产物不进 E 的正式表，只进开销/精度对照证据。
