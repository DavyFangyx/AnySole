## 2. E1–E5 条目（11 号文档 §9 预览的展开）

### E1 同体系比较（主线）

六模型输出两套协议（SMPL-24：AnySole / MotionPRO / PoseTransOpt / pressure_tookit；
BVH-23：Step2Motion；V2T：FPP-Net）在同一评价体系下比较。protocol-aware 的
root / trajectory / temporal / foot sliding 处理已具备；E1 的工作 = 把六模型正式结果
全部过公共 evaluator，产出统一指标表 + 每模型的协议说明行。

### E2 能力门控矩阵

六模型 × 指标矩阵：不评的项标 `—`（如 Step2Motion 不评 MPJAE/PVE/shape/contact、
FPP 只有 V2T 九项）。T 系列产出的"每模型监督/输出协议清单"（《模型输入与监督信号.md》）
是矩阵列的最终依据。

### E3 公共 contact GT 口径裁定

- **输入**（T 系列交付）：接触监督口径对照——MotionPRO 权重-only / Step2Motion 无 /
  FPP 顶点级 GT / PoseTransOpt 4-flag / pressure_tookit 9-region；
- 已有先例：f6_soft 语义错配 → 回退 press2Cont（方案 A 已拍板）；
- **数据侧输入**：D7 漂移探究结论（10 号文档 D7 子节，未提交）——右脚 cell 35 单通道
  间歇故障占超 1023 压力质量 76.5%、clip 压平中位 9.7%/最大 42.9%；FPP pixel_weight
  拍板（#2）与 press2Cont 阈值（0.5 已定方向）都属 E3 的接触侧口径；
- 交付：公共 contact GT 的最终裁定 + 全部消费端口径一致化。

### E4 指标口径

- foot sliding 指标对应的前置 = T 完成后模型输出协议定版；
- U7：pressure_tookit PVE 在新 metrics 启用 vs 旧任务书禁用——需裁决；
- 数据口径：跨 session 尺度对齐勿用 max/p99（被故障格劫持），用非零均值/p90（D7 探究建议）。

### E5 交付 gate

指标落 results_display → 对外数字冻结。
