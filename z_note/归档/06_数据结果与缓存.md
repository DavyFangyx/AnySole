## 数据版本不能按编号判旧

- 当前 `hf-raw` 有 2304 个软链接，其中 2301 个解析到仓库外，初查无断链；本目录 `du` 只有约 84M，不代表原始数据已被复制入仓库。移动链接时相对路径也可能失效。
- 当前压力 `tactile_v3`、SMPL 来源、offset 修正、虚拟 IMU、接触包版本与帧映射均是实验输入身份的一部分；编号 v3 不意味着废弃。
- `shared/facts`、protocol/manifests/splits/calibration、`virtual_imu`、raw config 与 sensor layout 先作为保留核心，逐消费者确认。不能只留导出特征而丢掉时间轴及 GT 来源。
- 当前默认 `splits.csv` 为 88/12/36；旧 README 为 92/12/36。四折各有独立文件；`fS6S7` 去掉 S13 为 73/18/31，旧带 S13 文件为 73/18/49。必须保存精确文件与内容身份，不能用新 split 覆盖旧复现输入。
- `z_note/data_spilts_fixpipe/` 的副本仍含带 S13 的旧 F3。不能仅因文件名相近就把它作为当前四折来源或声称与 protocol 全部相同。

## 必做调查

1. 先用 `rg --files --hidden --no-ignore` 列目标文件，再按精确目录/URI 搜全仓读写方，包含 `raw://`、`shared://`、`model-input://`、`work://` 解析和可配置根。读取硬编码路径与配置间接引用。
2. 分开登记源码/协议、不可再得原始数据、可再建事实/表示、前端特征、训练/拟合中间产物、正式权重/预测/指标、历史证据、展示副本。是否可再建必须有输入、版本、环境和命令，不只写“可重跑”。
3. 枚举软链接原文和解析目标、断链、仓库外所有权、链接链和硬链接；分别统计链接树大小及实际唯一资产大小。仓库外目标只调查，不删除/移动，也不隐含获得修改权限。
4. 精确核对所有数据版本的会话与帧映射、采样率、长度、关键缺文件；报告 actual/expected 的来源。没有完整核验时不得声称 140 会话、缓存全量或可重建已验证。
5. 旧压力 handoff v1/v2/v3、offset/SMPL/split 审计、BVH/SMPL 历史数据按当前消费者和 rebuttal 证据价值调查。别删当前 GT、时间修正证据或 Q11 引用来源。
6. `results/diagnostics/20261112_v8_gate_frozen`、`20261111_variant_sweep`、`20261111_final_protocol`、`20261111_halfplane_occ`、`20261115_imu_yaw_branch` 及 Q1/Q2/Q3/Q7/Q9/Q10/Q11/Q12/Q14/Q15 实际来源优先锁定。枚举 Supplement 全部 Q 项，不能仅凭此例表判定其余无用。
7. `results_display/Etest_crossfit_v8`、s10、branches、旧 `_archive_*wrongsplit*` 按被采用/被消费/历史解释逐项判定；错误 split 产物若是问题定位唯一证据，应先留足可恢复记录。
8. `z_note/归档` 已有历史链接指向曾被清理的对齐扫描目录，Q11 给了 `88a95fd^` 恢复线索。由 01 确认该历史对象可读取，必要时纳入历史恢复资产；不把缺目录补成伪数据。

## 验收

交付精确资产清单：原路径、解析目标、版本/校验、使用者、唯一性、可重建命令/前提、耗时/存储成本证据、保留位置和恢复验证。未实测的成本标明未实测，不编数字。

从隔离恢复位置读取保留数据、配置、权重和 manifest，检查数组/帧轴契约及路径解析。恢复中若需物化相对链接或路径映射，先列所有受影响消费者；原证据保持可追溯。

保存实际 `du`、文件/链接检查、覆盖与校验命令的原始输出。当前链接初查仅覆盖 `hf-raw`、assets、work/visual_baselines 和 baselines_deliverables，不能冒充全仓链接核验。
