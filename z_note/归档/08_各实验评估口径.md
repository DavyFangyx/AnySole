## 1. 统一到什么粒度

**统一单位是实验内的一项明确比较。** 同一比较的模型、消融臂或输入模式，使用同一定义的指标、同一评分样本、同一聚合及同一允许对齐规则。不同输入条件或边界信息按任务标明。

- 同一 E5 条件的表、图、汇总、逐折明细必须来自相同原始统计。
- E2 与 E5 可以使用不同样本集；E9 可以只评缺失区间并使用 RMS。写清实验定义即可，不要求跨实验数值相同。
- 跨实验若确实复用了同一预测、指标、评分帧及聚合，那么相同项应一致；不通过常数偏移把两个不同协议的结果强行对齐。
- 正式结果由固定输入重评后生成；旧表、手工修改、历史汇总及图上读数不能代替原始评测来源。
- 本文取代早期任务书中“无条件要求跨实验同值”的解释。已有 02/03 调研是事实记录；后续按本文整理，保留历史版本及变化原因。

### 2.2 评分帧和尾部处理

1. 每个实验先确定 session 列表，再固定各 `(fold, session, condition)` 的 frame ID 列表；列表由 GT 支撑、原始观测有效性和该实验预定窗口/事件规则决定，不按某个模型的误差或预测是否成功筛选。
2. E2/E4/E5 以最终 Residual 的正式 `evaluation_contract.sessions[].frame_ids` 为基准。其 clean 帧列表已与 `protocol/splits/crossfit_woS13/<fold>_manifest.jsonl` 的钉定帧核对一致，可复用；后续不靠旧 V7 名称推断一致。
3. 完整 20 帧窗口的有效覆盖在产生基准帧列表时确定一次，包括头部支撑不足、尾部不完整窗和中部无效段。消费端直接按 frame ID 读取，**不得再把筛选后的帧数裁成 20 的倍数**。
4. 非连续帧保留原始时间戳。不能拼成伪连续序列计算滑移、速度、加速度或 jitter；相邻帧/高阶差分只在原始时间轴连续且均有效的支持上计算。
5. baseline 的 `valid_mask` 用于验证它是否覆盖已规定帧；不允许与其取交集后悄悄改变评分样本。若有缺失，报告确切缺失 ID，该比较记为 `partial`，修复来源或推理后再评。
6. 不补齐、截断、借用其它条件或填造缺失预测。预先定义的公共 GT/任务有效范围裁剪是协议的一部分；模型失败导致的临时裁剪不是协议。

当前 clean 的声明/实评会话数为 66/66、58/57、31/31、51/51。F2 的 `S12102` 在最终 contract 中为 0 个评分帧，所有方法共同记为“任务有效覆盖为零”，不能把 58 会话写成全部已评分，也不能由某个脚本独立静默跳过。

### 2.3 聚合分母

E2/E4/E5 的常规误差采用折内 micro、四折等权 mean±std，`ddof=0`：

`m_f = Σ_s S_fs / Σ_s N_fs`；`mean = Σ_f m_f / 4`；`std = sqrt[Σ_f (m_f - mean)² / 4]`。

`S` 是逐指标的有效误差总和，`N` 是它的实际样本数：

| 指标类型 | 折内分母 |
|---|---|
| 逐帧姿态、根位置、地面代理误差 | 有效帧数；先在一帧内按规定关节集合平均 |
| 接触条件滑移 | GT 判为接触的有效“帧对 × 足部关节”数 |
| 角度误差 | 按该指标定义的有效帧/关节样本数 |
| 时序差分 | 连续有效时间模板及关节样本数 |

不能把所有 session 指标都按 `n_valid_frames` 加权，尤其不能这样合并接触条件滑移。条件差值先在同折配对计算，再对四折差值算 mean/std；不能把两边 std 相减。

必须有完整四折才能标为“四折结果”；缺折不按剩余折计算后仍写 n=4。四折重复出现的 session 作为不同 `(fold, session)` 记录保留，不去重成一次 pooled 统计。std 不是置信区间，也不表示四折是独立抽样的受试者。

## 3. 指标和信息使用规则

### 3.1 姿态和根轨迹

| 名称 | 本规范定义 |
|---|---|
| PA-MPJPE | 每帧使用全体 SMPL-24 关节估计一次 Sim(3)，再取逐关节 L2 距离平均；不逐部位独立拟合 |
| MPJPE | 每帧预测与 GT 分别减去各自 pelvis，仅平移对齐，24 关节距离均值；不做尺度/朝向拟合 |
| Ankle-foot MPJPE | 与 MPJPE 相同的 pelvis 对齐；仅左右 ankle/foot 四关节平均，明确是否 PA 版本 |
| GlobalMPJPE | 相同世界系下 24 关节绝对位置距离均值；采用该行明确的根轨迹，不附加 GT 对齐 |
| Mean Root Position Error | `1000 × mean_t ||p_pred(t)-p_gt(t)||₂`；逐帧三维 L2 距离均值，输入为米 |
| RootOrientationDrift | 每会话相对首个评分帧的 yaw 变化之差，wrap 到 [-π,π) 后取绝对值并平均，单位度；不每窗重置 |
| MPJRE | 同语义 SMPL 关节旋转之间的 SO(3) 测地角均值，单位度；没有真实对应旋转输出时记为不适用 |

E2/E4/E5 的正式根轨迹量选定 **Mean Root Position Error**。`root_ate_mm`、`root_mae_selfanchor_mm` 可映射到该量，但须先核对轨迹身份和支持帧；`RootAbs` 的 RMS 不得仅改名后填入该列。RTE 百分比是另一个量，不混用。

### 3.2 轨迹、锚定与辅助信息

统一公式并不能消除输入信息不对等。E2/E4/E5 按以下规则报告：

- **V/VT 无测试 GT 定位组**：使用模型自锚或方法原生世界轨迹。仅允许真实标定和由 train/val 预先确定后冻结的变换；不消费 test GT 位置、朝向、每窗 GT 锚或 test 拟合的模型偏差修正。
    - 例如：V8_IMU_Residual @V（V2M）与 @VT（VT2M）行

- **T 条件初始化组**：根平移统一为“会话首个评分帧 GT 位置单锚 + 世界系位移直接累加”，不添加后续 GT 位置锚，不按窗口重置，不用整个测试轨迹拟合旋转/尺度。世界系位移不额外做 yaw 旋转。初始位置与初始朝向是两个独立条件：BiFoot-Yaw 或基线若使用 GT 初始 yaw，须另行标注，不能由 `gt_start_position_only` 字段推断；只有朝向信息条件也匹配时才把 Global/朝向相关量当作同条件比较。先按实际实现记录，不为补说明自动给方法增加 GT yaw 输入。表注明这是给定初始位置的重建任务。
    - 例如：V8_IMU_Residual @T Step2Motion

- T 组与 V/VT 组的绝对定位列分块说明，不把 GT 初始化差异解释为模态或模型性能差异。PA/MPJPE 也须声明实际传感器输入，例如主模型的 T 包含虚拟 IMU。
- `GlobalMPJPE`、平均根位置误差、GroundPen-p5 和 FootSliding 必须使用同一行的同一套世界关节轨迹；不能 Global 用自锚、GroundPen 偷换为每窗 GT 锚而省略标注。
- 如需保留历史“GT Anchored”诊断，独立放入明确标注的辅助结果；不能填入上述正式世界轨迹列。

- GVHMR / WHAM / MMVP：test-GT 校准参考组——世界系注册用逐日期 GT 拟合平移 b（该日期全部会话 GT 骨盆最小二乘）。
- MotionPRO：动捕定位辅助（虚拟压力垫参考）——输入地毯逐帧脚印位置/方向来自 mocap。

两类已发现的特权信息必须单列，不靠统一评分帧掩盖：

1. **MotionPRO 的虚拟地毯**：Q5 明确逐帧足迹世界位置与朝向来自 mocap BVH。该行属于“mocap 定位辅助的虚拟压力垫参考”，可报告相同指标，但单列为辅助输入组；不能称为同样只用 RGB+鞋垫的无 GT 输入基线。地毯范围 train-only 并不能消除逐帧定位辅助。
2. **测试集拟合世界平移 b**：Q3 明确部分结果用该折全部测试会话拟合逐日期平移。这些世界位置/轨迹/地面指标归“test-GT 校准参考组”，不放进无测试 GT 定位组。PA/MPJPE 对常数平移不变的结论不受此项影响，仍须有相同评分帧及聚合。

不在本轮为此重训模型；先按来源把行分组。正式无 GT 定位列只使用满足规则的预测，必要时从未施加 test 拟合修正的原始输出重新评估。

`translation_anchor=None` 只描述该评估层的锚定字段，不能证明上游导出的预测没有经过逐日期/逐模型平移校准。03 将视觉基线概括为“无 test 拟合平移”，与 Q3 已记录的测试集 b 拟合不能直接合并为同一结论；需按具体 variant 的预测导出来源判断，不按模型名一概归组。

### 3.3 地面和滑移

正式地面量命名为 **GroundPen-p5**，含义限定为“低于 GT 会话水平参考面的关节深度代理”：

- 同一会话使用同一固定 `floor_y`：对规范 GT 全部原始有效支撑帧的 24 关节 Y 坐标取第 5 百分位。地面只确定一次，不因模型、遮挡档、评分子集或窗口重新估计。
- `d_t = max_j max(0, floor_y - y_pred(t,j))`，报告 `1000 × mean_t d_t`。GT 用相同帧和相同公式给出参考值，不从预测数值中扣除 GT 值。
- action 11 楼梯保留在预定全量集合中；该水平面量不是台阶碰撞或足底穿模率。正文解释和表注保留此限制，不为改善数字临时排除楼梯，也不声称该量证明楼梯物理正确。

**FootSliding**：四个 ankle/foot 关节；原始连续帧对中 GT 对应关节速度低于 0.3 m/s 定为接触，统计预测关节在这些帧对上的三维位移均值，单位 mm/有效接触帧对。GT 只定义评分条件，不能用于修正预测。折内按有效接触帧对×关节总数合并，不按总帧数加权 session 均值。

Jitter 若报告，沿用公共指标的 pelvis-relative 关节三阶时间差分及 m/s³ 单位，使用真实连续帧，不从不连续掩码结果虚构 40 Hz 连续序列。

### 4.1 E2 的正式采用方式

PA-MPJPE/MPJPE/GlobalMPJPE/Mean Root Position Error/ROD/GroundPen-p5/FootSliding 按节 3 的定义和分组报告；其它指标放明细。

主模型 T 行明确为“同一最终 checkpoint 的 T2M 姿态 + BiFoot 位移 + BiFoot-Yaw 航向”，不是原生 T2M 根头。主表、逐折明细、图中同名 T 行必须使用同一装配，原生 T2M 根头单列为诊断。

Q10 的 pinned-fold 结果可作为帧选择与常规姿态汇总的现有来源，不能据此默认所有世界轨迹、地面、滑移分母及特权信息已经符合本文。Q1 的 mean-root 定义并入 E2，不再保留两个都叫正式主表却来源不一致的版本。

### 4.3 E6 的独立分析口径

主量：全身每帧一次 PA 对齐后的部位误差，`ΔT = E(VT)-E(V)`，`ΔV = E(VT)-E(T)`；负值表示加入该模态后误差降低。每折在相同窗口/帧上先配对算差，再跨折汇总。

部位先按固定关节集合均值，再按帧累计；不逐部位独立 PA 对齐。根速度为独立量，`||v_pred-v_gt||`，单位 mm/s，不与姿态 mm 共用色标。

实际主统计脚本 `e6_ft_contribution.py` 的条件为 clean/occ020/occ050/occ090；以此明确为本版定量条件，纠正旧实验计划写 Occ100 的差异。Occ100 如保留为已有独立补充，注明其来源和评分集，不把 90 与 100 改名互换。

teaser 使用固定 session、时刻、条件和色标；快照颜色为附近 ±100 ms 的局部误差差值均值，不是整个窗口均值。GT SMPL 作为着色载体须注明。示例不代表总体统计，不按不同方法各自挑选最好时刻。

注意力 `a_T = w_T/(w_V+w_T)` 固定为同帧对角元素，先按头平均、逐层算比值再平均层；它不是模态总权重或因果贡献。Router 的 k 只属于对应 Router 模型，不能标作 Residual 的门值。旧相位/gate 表若保留，单独注明统计单位和定义，不混入主部位表。

### 4.4 E9 的任务、记录单位和边界信息

E9 继续报告 3D **缺失区间根位置 RMS** 和 **全会话根位置 RMS**，可附 mean，但不同量分列。对一个 `(fold, session)`：先将其所有已定义缺失区间的实际有效评分帧取并集，计算 `1000 × sqrt(mean ||p_pred-p_gt||²)`；再对记录的 RMS 等权平均。不能把会话 RMS 的平均称作全体帧 pooled RMS。

固定 short=SceneOcc，long=HalfPlane；动作03/04/05/09，排除 S5091，不以结果好坏增删记录。当前两个任务各有46条 fold-session 记录，动作数量17/4/6/19；同一 session 在不同折不去重。std 跨这些记录、ddof=0；**不是四折 std，也不是逐事件 std**。记录内可含多个事件。

沿用当前有效评分掩码的端点处理，冻结明确 frame ID；现有 `e9_final_protocol.metrics` 使用 `start:end` 的半开切片，不能凭自然语言的“含出口帧”擅自多加一帧。若原始 manifest 的端点声明与实际评分掩码冲突，记录并解决后再生成正式结果，不静默变更。

| 臂/信息类型 | 必须声明的内容 |
|---|---|
| MotionPRO/Step2Motion/BiFoot Entry | 入口锚；缺失区间内使用各自预测，不使用出口观测。MotionPRO 的 mocap 压力定位辅助仍须标明 |

短时现有位置边界来自真实 VT 估计，但 TTA 方向来自 GT 派生受控噪声观测；长时边界位置与方向使用 GT 派生的合成观测。沿用实际 seed/扰动/筛选参数并明确为**受控边界观测实验**；不能写成全程无 GT 的端到端视觉恢复。

共享的边界观测必须对可使用该观测的各臂使用同一实例。Entry 与 exit-assisted 的对比衡量加入恢复侧信息后的系统变化；TTA 与只用端点的对比还包含方向信息差异，不能把全部差值归因于潜变量优化。机制的同条件结论只在输入信息匹配的臂间成立。

全会话轨迹在事件外沿用同一 VT；它是 VT+缺失段补全的组合，不是纯传感器全程积分。代表性图与按动作/总体表使用同一记录来源和原始统计，不能独立计算出另一套值。
