## 必须形成的口径记录

在本文件追加表格或按实验记录，至少包括：

| 层级 | 必须核对的内容 |
|---|---|
| 比较身份 | 实验、表图路径、模型/模式、条件、折、checkpoint/预测身份、是否历史参考 |
| 指标 | 数学公式、单位、关节集合、PA 对齐粒度/自由度、坐标轴、根与姿态来源；轨迹/物理专项见 03 |
| 数据支持 | GT 版本、session ID、frame ID/时间戳、valid mask、帧列表或现有哈希、评分帧数、被排除会话及原因 |
| 窗口 | tw/stride、完整窗口规则、头尾边界、重叠帧是否去重及拼接权重、中间无效 gap 的处理 |
| 会话内 | 逐关节/逐帧/逐窗/逐事件的顺序、误差取平方/开方的位置、接触帧/帧对或其它有效分母 |
| 会话间 | frame micro、session macro、subject macro、event macro 或其它权重；实际权重来源 |
| 折之间 | 是否折间等权、重复 test 会话是否按 fold-session 计数、mean/std 的样本单位和 ddof |
| 缺失与展示 | NaN/缺文件/不足四折如何处理、舍入位数、表格与曲线是否来自同一原始统计 |
| 生成链 | 运行环境、现有命令、源码版本、输入/输出、前置步骤、后处理/替换/历史常数平移及覆盖顺序 |

帧加权均值应写明：会话均值 `m_s = Σ e_st / n_s`，折均值 `m_f = Σ n_s m_s / Σ n_s`；四折再等权平均。会话等权则是 `Σ m_s / S`，与帧加权不同。std 必须写清是四折之间、会话之间还是事件之间；mean±std 不是置信区间。

若采用 RMS，应从平方误差总和和总计数恢复，不能用会话 RMS 的帧加权均值冒充 pooled RMS。median、R²、接触条件滑移和角度等指标分别核对实际合并规则。

## 调研步骤

1. 建立采用产物清单；核对投稿使用版本。未提供论文源文件时，先把磁盘各版本差异列清，标明尚不能确认投稿采用路径。
2. 对每个现有生成入口先 `rg` 扫所有读写方，读取代码和参数，不执行有写入副作用的导出器。关注 diagnostics 源码、`.tmp_scripts`、独立 Baselines 与旧结果树。
3. 从原始逐折/逐会话指标重算汇总，和表图逐项核对。显示值按既有舍入规则比较；底层数值按已证明的确定性与精度比较，不能为消除差异而放宽容差。
4. 同一比较的每个模型逐折核对 session/frame 列表，不能只比帧数相等。记录 missing/extra/duplicate 的精确 ID。发现尾裁、自动交集、跳过 None 等改变支持集的行为，列为待修正项，不默许为统一协议。
5. 核对 E2 clean 与 E5 occ000/gap000；Scene clean 只与同 scene 子集比较；E4 Residual 与对应 E5 同条件；E6 相同 checkpoint 的 V/T/VT 配对；E9 只在相同事件和边界信息下对照。Q1/Q10 及其它 Q 表逐一核对。
6. 区分三种原因：仅旧产物未同步、评分/聚合不同需固定预测重评、输入/预测身份不同需另查。形成最小修复方案，不在未保存投稿版前覆盖结果。
7. 给出最终单向生成顺序，说明哪些脚本会覆盖已经修正的表；把其引用纳入 04/05/06 的保留边界。只整理现有入口，不新增用户未要求的脚本。
