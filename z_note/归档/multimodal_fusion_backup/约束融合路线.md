# 约束融合路线（2026-10-15 起）

定位：诊断层（Appendix/T信息量判定实验.md）两个支柱的裁定实现——T 的增量在位置
空间（支柱 1）、价值在地面参照量（支柱 2）。抛弃加性残差范式（界 ~−1mm
已封死），改为**物理中介的约束式融合**：V 专才（姿态 + 校准不确定度）+
T 物理头（接触概率，强监督）+ 可微约束层（支撑静止 / 贴地 / 防穿透 /
平滑）+ 固定规则回退（逆方差，不学门控）。

零训练探针先行（判死门槛）：

## 探针 B：T 接触可读性（2026-10-15，已过闸）

- **方法**：压力 48 格/足 → 逐会话逐格基线扣除 + log1p → 逻辑回归（逐帧
  逐足，无时序上下文）；目标 = 运动学接触（kp_gt 足高 + 4/6cm 施密特带，
  无循环）为主、生产口径 joint_and 为次；对照 = tactile_abs / tactile_rel
  / 每会话最优阈值（阈值族天花板）；
- **结果**（val 36 会话 / 12520 帧，池化 F1）：

| 目标 | 分类器（左/右） | tactile_abs | tactile_rel | 每会话最优阈值 |
|---|---|---|---|---|
| 运动学（bvh_h 规则） | 0.933 / 0.966 | 0.000 | 0.729 | 0.961 |
| joint_and（生产） | 0.967 / 0.976 | 0.000 | 0.735 | 0.985 |

  逐会话 F1：运动学目标 0.917±0.109 / 0.959±0.054——左脚弱于右脚、
  方差大；
- **判读**：接触可读 ✓，分类器 ≈ 阈值族天花板；tactile_abs=0 的根因 =
  跨会话压力增益差异（逐会话基线必要）；接触须由压力读出，运动学接触
  在该数据集退化（见下）；
- **产物**：`z_note/probes/probe_b_contact_classifier.py` +
  `results/AnySole/probes/probe_b_contact.json` + `.probe_b_frames.npz`
  （train/val 逐帧 kp_gt/T_raw/contact/floor 缓存）。

## 探针 A：接触约束 oracle（2026-10-15，未定论）

- **方法**：冻结 V3_3B_vonly 输出 + GT 运动学接触驱动的零参数约束后处理
  （支撑相冻结 / 高度标定 / 摆动防穿透 / 根速度修正）→ 全面板（PA /
  MPJPE / 全局 MPJPE / 根轨迹 ATE / 穿透 / 滑步 / 接触 F1）；
  
  判死门槛 = 穿透 ≤ 3B-VT 水平（22.2mm）且 PA Δ ≤ +0.3；
- **迭代与数字**（val，V-only 基线 43.11 PA / 27.0 穿透 / 50.5 ATE）：

| 版本 | 修正 | 穿透 | 滑步 | ATE | PA |
|---|---|---|---|---|---|
| v1 逐帧根+整骨平移 | — | 19.0 | 3.2 | 386.7 ✗ | 54.1 ✗ |
| v2 软骨架 | 爆炸定位到个别会话 | — | — | — | — |
| v3 退化守卫+相长上限 | 相均值根 | 21.7 ✓ | 8.4 | 143.9 ✗ | 52.7 ✗ |
| v3 GT根（天花板） | 根=GT | 21.7 ✓ | 8.4 | 2.2 ✓ | 48.0 ✗ |

- **未定论原因（两条，均已定位）**：
  1. **运动学接触语义退化**：全数据集 ~91% 帧足高 <5cm（1cm 阈值仍
     82%），train/val 一致；站立类任务（如 S13011 重心横移）恒接触是
     **正确** GT，但行走类会话的运动学接触也接近全接触——冻结约束覆盖
     90%+ 帧、锁死预测误差，PA +4.9 的来源即此。个别会话（S1409x /
     S1309x / S13082）极端化到 +170~190mm（接触率 1.00）。**接触必须
     由 T 读出（探针 B），运动学阈值不适用**；
  2. **根通道闭式实现缺陷**：世界帧差分的足速混入预测自身的滑步偏置
     （10mm/帧 ≈ 0.4 m/s），相均值后系统性注入根速度（+93mm 漂移）；
     正确形态 = 姿态空间的足部相对速度（约束层的 K 步可微展开职责，
     闭式 numpy 抄近路所致）；
- **待裁定**：①可信接触 GT 口径（用户 D_Test3/D_Test9 人工核查后裁定）；
  ②val 会话任务类型表（行走 / 站立分层——探针 A/B 的分层判读与约束层
  的接触语义都依赖它）；
- **产物**：`z_note/probes/probe_a_contact_oracle.py` +
  `results/AnySole/probes/probe_a_contact_oracle.json` + `.probe_a_pred.npz`
  （V-only 逐帧预测缓存）。
