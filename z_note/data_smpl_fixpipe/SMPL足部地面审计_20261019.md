触发：D9Test_bvh_smpl_compare 可视化大量 SMPL 足部低于地面线。审计对象：raw 农场 300 session、本目录 fixpipe 6 文件、D9Test 渲染管线、lizhe 侧提取配置。地面口径：g0 = archive y=0（物理地面，经 BVH 趾关节与足区 marker 两路证实）；g1 = estimate_floor_y（全 24 关节 y 的 5 分位，D9Test SMPL 面板地面线）。

## 1. 陷入地面：对物理地面真实但浅；可视化观感是地面线口径放大
**穿透情况**
- 浅穿透普遍：74% session 有足底低于 y=0 的帧（27 session mesh 审计）；帧级 >0.5cm 15.2%、>1cm 3.7%，普通站立足底 −0.6~0cm；
- 深穿透是角例：>2cm 仅 0.6% 帧、2/27 session（最大 34mm），集中在 toe-off 趾尖下插与前掌负重类动作；
- 关节级无穿透：300 session 全量 FK，踝/趾关节中心低于 y=0 仅 3/300（最深 4mm）；

- 观感主因 = 口径放大：g1 比物理地面高 1.8~4.4cm（D9Test 9 session 实测）+ SMPL 足底顶点在踝下 6.7~7.1cm → 支撑足渲染 h≈−1.8~−4.6cm，99.5% 帧"穿透"g1 是口径必然，即使拟合完美也如此；
- BVH 交叉验证：SMPL 踝 p2 = 46~88mm，比同 session BVH 踝低 12~35mm；但 SMPL 踝 min 中位 6.8cm ≈ 解剖值 6.7–7.7cm → 差异是 BVH 关节定义（~10cm）vs SMPL 关节定义（~6.8cm），不是拟合整体偏低。

## 2. 管线配置：正确，无错配

- 出处 lizhe 侧提取批次 manifest（0804/0808 批 batch_manifest.json）：body_model=smpl / gender=neutral / output_skeleton=SMPL-24 / output_unit=m / world_motion=preserved，与 archive 元数据逐项一致；
- 风险登记：archive surface_model_sha256 与本地 SMPL_NEUTRAL.pkl 不一致、_validate_archive 不比对 sha256；实测影响可忽略（两口径 FK 差 0.04–0.29mm）；
- 管线地面定义 11 处，不一致点：SMPL/BVH 面板地面不同源；接触几何两套（顶点 vs 关节中心差 2~7cm）；constraints_g/h 预测侧 25 分位 floor（第二种定义）；D9Test README「BVH 踝~10cm vs SMPL 踝~5cm」被两面板参考差污染。

## 3. 两份数据：足部都没问题；fixpipe 修的是树契约，不是足部

- fixpipe 6/6 与 raw 同名 session 重叠、帧数逐一相同，本质是 2026-10-18 的同源 c3d MoSh 重拟合（非从 raw npz 派生）；
- 已修：SMPL-24 树契约补齐（joints/joints_rest/joint_names/joint_parents/hierarchy_schema 与 anysole 定义逐项相等、自洽 1e-12）；S8051 trans 单帧毛刺消除；
- 未修：轴角长路径 >π（24/300 文件，135 文件 pelvis >π）、marker 毛刺；重拟合引入散点帧级差异（1.5–12% 帧某关节 >1cm，最大 7.6cm S9021 f1394 右膝）；
- 足部高度两份一致（同 session 差 ≤0.7mm）：踝 min 中位 6.8cm ≈ 解剖值，无普遍贴地；「关节 y min 0~3cm」全是跖骨关节——解剖高度本就只有 1.8~2.1cm；
- 「SMPL npz 根居中」说法不成立（trans y≈1.1m、z 跨度中位 1.27m）；
- 替换判读：6 session 可以替换（契约补齐、统计等价），也可以不替换（raw canonical FK 与 fixpipe 关节差仅 0.04–0.29mm）；其余 294 session 无 fixpipe 版。

## 设计规则

- 判「陷入/贴地」用 g0 = archive y=0 为地面；不用 estimate_floor_y 当绝对地面（恒高于物理地面 1.8~8.6cm）；
- 接触判据用足底顶点（smpl_contact 口径）；不用 foot 关节中心近似足底（跖骨关节解剖高度 ~2cm，会把正常站立系统性误判成贴地）；
- 跨源对照显示统一到 archive/mocap 世界 y/z=0；各源各自估 floor 会污染跨源高度差判读。
