# 基准（Reference Frame，2026-11-03 立）

**用途**：给任何模型/任何实验提供固定坐标系，回答「它自己是啥程度」。
**与 `现状.md` 的分工**：本文件是**尺子**（冻结，永不改）；`现状.md` 是**当前水位**（滚动）。两者冲突时，尺子部分以本文件为准，当前数字以 `现状.md` 为准。

**统一口径**：`test` split、36 会话、12500 scored 帧、`kp_gt` 24 关节、逐帧相似对齐 PA-MPJPE（mm）。轨迹列用 `traj_ATE@0.5s`（短程口径；`traj_ATE` 整条自由积分在「每窗 GT 平移锚」与「整条积分」两族之间不可比，仅作附列）。

**冻结声明**：第一、二节的全部数字不随新模型出现而改动。新结果只进第六节滚动榜；要改冻结点需显式裁定并记日期。

## 四、反向地板警告（最容易被审稿人一击废掉的地方）

常数均值姿态（一个**完全冻结不动**的姿态）在三个物理指标上的值：

| 指标 | 冻结姿态 | 我们 U@VT（Cv3） | 谁赢 |
|---|---|---|---|
| FootSliding | **0.0** | 9.13 | 冻结姿态 |
| Jitter_pred | **0.0** | 722.97 | 冻结姿态 |
| GroundPen | **11.97** | 19.33 | 冻结姿态 |

**这三项的地板是反向的**：越不动越好看，塌缩可刷。外部基线里也有同样签名 —— MotionPRO GroundPen **1.13**、MMVP FootSliding **3.19**，都显著「优于」我们。

**对有限叙事的直接后果**：把 GroundPen / FootSliding 当辅助尺子报（如 GroundPen 五档 15/15 全帮、−2.4~−4.1mm）时，**必须同时报幅度**，否则一句「冻结姿态 GroundPen 11.97 比你 20.3 好」就废掉整组证据。FootSliding 本轮幅度（0.02~−0.30mm）本就不宜当卖点，建议只留附表。

同理，**接触 F1 不能用于「触觉输入 vs 纯视觉」的对比** —— 纯视觉模型没有接触观测，该指标结构性不公平，只能在 VT 内部横比或作触觉独有信息的存在性证据。

## 五、判读模板

任何新模型，三块各出一行：

```
<块>  PA=<值>   相对地板 −<Δ>   相对外部最好 <±Δ>   相对冻结点 <±Δ>   门槛<过/不过>
```

例（主模型 Cv5）：

```
V   PA=37.49   相对地板 −66.65   相对 WHAM        −10.28   相对冻结点 +0.50   硬门全过 / 软门超幅度+翻转
T   PA=89.40   相对地板 −14.74   相对 Step2Motion  +6.81   相对冻结点  0.00   硬门全过 / 软门超幅度+翻转
VT  PA=40.53   相对地板 −63.61   相对 MotionPRO   −18.57   相对冻结点 +1.40   硬门全过 / 软门超幅度+翻转
```

归一化分数（可选，仅用于 PA/MPJPE 这类正向指标）：
`(地板 − 模型) / (地板 − L2外部最好)`，>1 = 已超外部最好。
**不得用于 FootSliding / Jitter / GroundPen**（见第四节）。
