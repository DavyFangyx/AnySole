## 5 注意事项

1. **曝光轴呈阈值效应，当前六档有四个“无影响”**（5 会话 V2M，MPJPE/PA）：
   clean 38.50/26.47；G=0.5 37.50/26.06；G=0.2 37.50/28.08；G=0.05 56.70/48.10；
   G=8 39.24/24.00。即弱光 0.5/0.2 与过曝 2/4/8 基本不伤 V2M，只有近全黑 G=0.05
   断崖（MPJPE +47%、PA +82%）。缓存路径已证使用。补充单会话探测：G=16 V2M
   MPJPE 39.93（clean 31.91）、G=32 42.66，G=64 人体近乎洗白。
   2026-11-04 用户裁定：**保留原设计档位**（0.5/0.2/0.05、2/4/8），
   “过曝基本无影响、弱光仅极档断崖”如实作为结果呈现；G=16/32 探测仅作
   记录，不新增档位、不改机制。
2. 曝光全量未跑（按“管线 + 冒烟”范围）。实测 325 帧单会话单档 warm ≈14 s（含模型加载），
   48 会话 × 6 档单卡约 1 小时量级，可 3 卡并行。
3. 正式评估同时遍历 val + test，曝光与断流缓存都需 `--split test` 与 `--split val` 两轮。

## 6 全量执行命令

```bash
BG=AnysoleWorkspace/model_inputs/AnySole/adapter_v1/visual/hrnet/bbox_cam3
# 断流（numpy，秒级）
for r in 10 20 40 60 80; do
  python -m anysole.data.make_gap_cache --rho $r --split test
  python -m anysole.data.make_gap_cache --rho $r --split val
done
# 曝光（HRNet；每档一个进程，CUDA_VISIBLE_DEVICES 分卡）
for g in 0.05 0.2 0.5 2 4 8; do
  python -m anysole.data.extract_hrnet --cam-id 3 --split test --exposure-gain $g --bbox-root $BG
  python -m anysole.data.extract_hrnet --cam-id 3 --split val  --exposure-gain $g --bbox-root $BG
done
# 入队 11 个 eval cell
python configs/z_gen/gen.py v7_eval_visual
# 全量完成后导出
python results_display/script/e_results_export.py --experiment e5 --models V7_Cv5
```
