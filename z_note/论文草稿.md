AnySole：基于目标特异性门控的统一视触人体运动重建
摘要
视觉与触觉的融合能够补充单一模态下人体运动的缺失信息。视觉能够观测全身关节运动和整体位移，而可穿戴足底压力鞋垫能够直接测量足底载荷，因此两种模态的结合具有潜在价值。本文提出 AnySole，一种统一的视触人体运动重建框架，使用同一组模型参数支持纯视觉（V）、纯触觉（T）以及视触联合（VT）三种推理模式。模型采用独立的时序编码器表示两种模态，通过共享运动解码器预测关节姿态和根运动，并使用两个目标特异性门控模块分别调节压力信息对这两类输出的贡献。我们在同步采集的RGB视角、双侧可穿戴足底压力和光学动作捕捉数据上开展评估。结果表明：当前 V7_Cv5 检查点的初步结果揭示了条件性融合权衡：与 V 单模态推理相比，VT 推理将地面穿透误差从 23.396 降至 20.286，但 PA-MPJPE 从 37.495 上升至 40.533。在逐级下肢遮挡条件下，以各自无遮挡状态为基准计算的探索性曲线显示，VT 在部分姿态和足地接触指标上的误差增幅小于 V。一个具有代表性的接触阶段序列进一步显示，门控能够抑制部分较大的有害融合波动，但也可能削弱原本有益的触觉增益。
1. 引言
从视频中恢复三维人体运动是计算机视觉领域的重要问题，在运动理解、动画、体育分析和人机交互等场景中具有广泛应用。现代单目方法能够根据时序图像证据估计人体关节姿态，并逐步扩展到全局运动估计。然而，当人体下肢受到遮挡、人物处于视觉歧义区域，或摄像机无法提供充分的足地交互证据时，视觉信息的可靠性会明显下降。此时，重建结果可能在视觉上仍然合理，却存在足部滑动、地面穿透或根运动估计不准确等问题。
足底触觉压力能够提供互补观测。它可以在不依赖外部视线的情况下测量载荷转移和足底接触信息。这类信息对于支撑、落地和重心转移尤为重要。与此同时，足底的触觉压力仅能感知局部的接触受力情况，无法确定上半身关节运动或完整人体姿态。因此，视觉与足底压力观测的是同一运动过程的不同侧面：视觉提供较广泛的运动学覆盖，足底压力提供局部且直接的物理证据。
将两种信号结合必然带来性能提升。压力信息可能约束足地交互，却未必能改善摄像机已经充分观测到的关节姿态。在这种情况下，无条件融合可能扰动原本准确的视觉预测。当前实验也体现了这一现象：在无遮挡输入下，统一模型的 VT 模式相较于 V 模式改善了地面穿透误差，但部分姿态指标有所下降。因此，本文关注的核心问题是：如何使单一模型支持视觉、足底压力以及视触联合输入，同时针对不同预测目标选择性地利用压力信息？
为解决这一问题，本文提出 AnySole，一种统一的视触人体运动重建框架。模型在 V、T 和 VT 三种输入条件下联合训练，并在推理时使用同一个检查点。模型通过独立的时序编码器提取视觉和压力特征，再由共享运动解码器完成预测。考虑到压力对局部关节姿态和全局运动的作用可能不同，我们设计了两个目标特异性门控模块，分别为姿态门控和根运动门控。当两种模态同时存在时，门控分别调节压力信息对相应预测分支的贡献；当仅有一种模态可用时，共享解码器则使用对应的单模态表示。
本文的主要贡献如下：
（1）提出统一的视触人体运动重建任务与模型，使同一个共享模型能够处理纯视觉、纯触觉和视触联合三种输入配置（并非亮点，最多算是附加功能，T2M的原因主要是面临极度视觉缺失的情况下，可以通过单触觉进行推理；而视觉则作为我们模型的主干，当然也理所当然地被保留了下来），无需针对不同配置分别训练模型。
（2）面对xx的问题（面对传统的视触觉融合方法，在多种模态之间融合的过程中。模态相互干扰和影响的问题 暂时，还是应该优化），提出目标特异性门控融合机制，分别为关节姿态和根运动设置独立门控，以调节两种模态同时输入时足底压力特征的贡献。
（3）建立结合多摄像机 RGB、可穿戴足底压力鞋垫和光学动作捕捉的同步采集与评估流程，并通过视觉遮挡和不同足部接触阶段分析模态互补性。（删除）
2. 相关工作
2.1 基于视觉的人体运动重建
人体网格恢复方法根据单张图像或时序视频观测估计人体关节结构。近期研究进一步提升了单目重建的时间一致性和世界坐标系运动估计能力，例如 WHAM 和 GVHMR。基于扩散模型的运动先验也被用于改善噪声观测或遮挡条件下的重建效果。尽管取得了上述进展，视频对于足地交互仍然提供间接证据。因此，即使整体姿态在视觉上看似合理，遮挡和深度歧义仍可能导致下肢关节及物理一致性方面的误差。
2.2 基于压力及视触信息的人体运动重建
压力传感能够提供直接的接触和载荷证据。已有研究探索了压力垫、可穿戴鞋垫，以及压力与视觉或惯性观测相结合的方案。MMVP 研究了结合视觉和压力传感器的多模态动作捕捉；MotionPRO 探索了压力在人类动作捕捉及相关任务中的应用；Step2Motion 利用压力感知鞋垫重建人体运动；GRIP 则在基于物理的建模框架中结合稀疏惯性传感与鞋垫压力。这些工作证明了物理传感的价值，同时也体现出压力接触证据与全身视觉观测之间存在明显的不对称性。（2.3直接作为2.2的最后一句，并入2.2，因为它本质上是2.2的一个当前的局限，尤其是当前的视觉触觉融合重建人体网格中，触觉融合更是没有条件，这更是一种严重的机制缺失以及局限
- 基于压力的运动估计与视触融合：鞋垫类（SolePoser、Step2Motion、FoRM 等）、地垫类（MotionPRO），以及 MMVP。
2.2 Pressure-based and Visuo-tactile Motion Reconstruction
- 仅压力的运动估计：鞋垫类（SolePoser、PressInPose、FoRM、Step2Motion）与地垫类。压力能较好地约束下肢与轨迹，但上半身存在歧义。
- 视触融合：按融合机制介绍。一类是优化拟合，把压力或接触作为约束项（MMVP 的 RGBD-P 拟合、基于接触的优化方法）；另一类是特征层融合（MotionPRO 的交叉注意力）。）

2.3 不完整或冲突证据下的多模态融合（建议删除）
处理模态缺失的一种常见策略是在训练阶段向模型提供不同的输入模态子集，例如采用模态掩蔽或随机丢弃。这类训练能够提高模型在某一传感器流缺失时的运行能力，但其本身并不能决定某一模态应当对不同预测目标产生多大影响。对于足底压力而言，这一区别十分重要：压力对足部接触和根运动的贡献，可能不同于其对上半身或全身关节姿态的贡献。本文通过独立的姿态门控和根运动门控研究这一问题，并在受控视觉遮挡和接触阶段分析中评估相应的跨模态交互。
3. 方法
3.1 问题定义与总体框架
给定长度为 L 的时序窗口，记来自单个摄像机的视觉输入为 I_{1:L}，与之同步的双侧足底压力测量为 P_{1:L}。模型接收以下三种输入配置：
A = {(a_V, a_T) = (1,0), (0,1), (1,1)}
其中，a_V 和 a_T 分别表示视觉和触觉传感是否可用。重建目标包括局部人体姿态 θ_{1:L}、全局根节点朝向 R_{1:L} 以及根节点平移 t_{1:L}。在 SMPL 等运动学人体表示下，这些参数共同定义三维关节序列 J_{1:L}。
AnySole 为两种输入流分别设置时序编码器：
M_V = E_V(I_{1:L}),     M_T = E_T(P_{1:L})
其中，M_V 和 M_T 分别表示对应的时序特征。两个编码器在融合前保留各自模态的特定信息。共享运动解码器将选定或融合后的表示映射为局部姿态和全局根运动。对于上述三种输入配置，模型均使用相同参数；推理阶段不针对特定配置进行微调。
图1展示了 AnySole 的整体结构。视觉时序编码器处理单视角 RGB 序列，触觉时序编码器处理双侧足底压力序列。对于联合输入，两个独立门控分别调节压力信息对姿态和根运动表示的贡献。共享解码器使用同一个检查点支持 V、T 和 VT 三种推理模式。
3.2 目标特异性视触门控解码
两种模态提供不同类型的证据。视觉特征描述全身外观和关节运动，压力特征则直接反映足底载荷与接触状态。因此，两种模态对关节姿态和全局根运动的贡献可能不同。为此，我们引入两个独立门控 g_θ 和 g_r，分别调节压力信息对这两类预测目标的影响。
对于目标分支 q∈{θ,r}，令 h_q^V 和 h_q^T 分别表示投影后的视觉特征和触觉特征。在联合输入条件下，门控后的表示定义为：
z_q = h_q^V + g_q(M_V, M_T) ⊙ h_q^T,    q∈{θ,r}
其中，g_q(·) 表示可学习门控，⊙ 表示逐元素调制。两个门控具有独立参数，使模型能够针对姿态和根运动分配不同程度的压力信息。对于单模态推理，解码器直接接收对应模态的表示：
z_q = h_q^V，若 (a_V,a_T)=(1,0)
z_q = h_q^T，若 (a_V,a_T)=(0,1)
z_q = h_q^V + g_q(M_V,M_T) ⊙ h_q^T，若 (a_V,a_T)=(1,1)
随后，姿态表示和根运动表示由解码器联合解码。该设计将“模型能够接收某一模态”与“当两种模态同时存在时，模型应在多大程度上使用该模态特征”这两个问题区分开来。
3.3 跨输入条件训练
我们在集合 A 中定义的三种输入条件下训练同一个共享模型。对于每个训练序列，相应的视觉和压力观测均可获得，而被选中的输入条件决定模型实际接收哪一路或哪几路数据。训练目标写为：
L_train = Σ_{a∈A} π(a) [λ_θ L_pose^a + λ_r L_root^a + λ_s L_smooth^a]
其中，π(a) 表示分配给各输入条件的训练概率。姿态损失和根运动损失分别监督局部关节运动与全局运动，时间正则项则用于鼓励预测结果保持时序连贯。具体损失定义、权重、输入条件采样计划、优化器和时序窗口配置，需要在投稿前根据最终训练配置补充。
显式覆盖 V、T 和 VT 三种条件，与仅使用联合输入训练或仅依赖随机模态丢弃有所区别。我们通过受控模型变体检验这种区别，包括三条件枚举训练、随机模态 dropout 和仅 VT 输入训练。所有变体应使用相同的数据划分、模型容量和训练预算。只有在完成相同条件下的消融实验后，才能判断显式条件枚举是否带来可测量的优势。
4. 实验
实验围绕三个问题展开：（1）同一个检查点在视觉、触觉和联合输入配置下表现如何；（2）当下肢视觉证据退化时，足底压力能够提供哪些信息；（3）目标特异性门控和训练策略如何影响跨模态交互。除非另有说明，以下数值均转录自最新提供的 V7_Cv5 实验总结。这些数值属于初步点估计，尚未从最终留出预测中重新导出被试层面的不确定性。

因此，负值表示增加压力输入后误差降低，正值表示触觉融合产生干扰。图3展示了一个具有代表性的开合跳序列。无门控模型在若干时间区间出现较大的正向波动，而单门控和双门控变体能够抑制其中部分波动。动作层面的阶段汇总也表明，在某些阶段，门控会降低原本有益的负向波动幅度。因此，当前证据说明门控能够调节跨模态交互的强度。

5. 局限性与结论
本文研究基于视觉和可穿戴足底压力的人体运动统一重建。AnySole 使用独立的时序编码器、共享运动解码器，以及分别面向关节姿态和根运动的目标特异性门控。一个检查点能够在纯视觉、纯触觉和视触联合三种输入条件下进行评估。当前实验表明，两种模态之间存在条件性互补关系。在无遮挡输入下，VT 相较于 V 改善了地面穿透和根朝向漂移，但部分姿态指标和足部滑动指标有所变差。在逐级下肢遮挡条件下，探索性的归一化曲线显示，VT 在部分指标上具有较小的误差增幅。一个代表性接触阶段序列进一步说明，门控能够抑制部分有害的融合波动，但也可能削弱有益的触觉贡献。
本文仍存在部分局限。当前数值结果主要为初步点估计，需要在冻结的留出测试集上重新评估，并补充被试层面的不确定性。E4 消融矩阵已经定义，但数值尚不完整；E6 接触阶段分析仍需统一符号口径并补充聚合统计。当前遮挡实验依赖基于人体检测框的遮挡掩码，后续应扩展到更自然的遮挡物。数据集规模、具体参与者划分、同步统计和评估单位也需要完整记录。此外，在当前表格所列的若干指标上，纯触觉模型仍弱于 Step2Motion；当前 VT 模型也未能在所有姿态指标上超过纯视觉推理。这些局限限制了本文能够作出的广泛优越性声明。
总体而言，AnySole 提供了一个统一框架，用于研究在不同输入配置下如何结合视觉与足底压力证据。当前结果支持进一步研究目标特异性融合，以控制跨模态干扰，并为可靠视触人体运动重建建立了聚焦的实验基础。
