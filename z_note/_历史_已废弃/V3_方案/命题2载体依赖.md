# 命题 2 载体依赖：T 特征里的足部信息在零税载体上消失（2026-10-19）

数字与复现见 `z_note/probes/probe_v3_hv1_carrier_20261019.md`；本文件只记
发现与设计规则。

## 发现

命题 2（T 的增量信息集中在足部，探针路径 A 在 B 载体上显著为负*）在
H 生产载体（V3_Hv1 ckpt_best）上不复现：anklefoot 点估计翻正（+0.81，
不显著）、r_foot 不显著（−0.61）、l_foot 显著为正（+2.23*）。三项零训练
验证（B 载体逐位重现校准 + H t_tok 接触读出 = 训练头天花板 + 混合载体
换 B t_tok 后信号恢复且放大到 −3.3/−4.7）闭合因果链：

**足部线性信息消失在 T 编码器侧，与 V 侧无关。** 原因 = H（以及 E/G）的
foot_conv 唯一监督是接触 BCE，特征空间被接触任务吸收（线性读出即可
达到训练头水平）；B 的 foot_conv（aux 压力重建 + 融合梯度）保留了足部
姿态信息，但 B 的融合税挡住了利用。混合条件下 H 的 v_tok（vonly 专才，
更干净）配 B 的 t_tok 可提取的足部信号比原探针更大——信息真实存在、
可恢复、且在当前 V 载体上更值钱。

## 设计规则

1. **零税架构与 T 编码器监督正交**：T 不进 V 通路（零税）并不要求 T 编码
   器只学接触——把 aux 监督从 T 流拿掉是 E/G/H 共同的无意代价，不是零税
   的必要条件。
2. **命题 2 的兑现链 = 编码器监督 → 载体复测 → 残差头**：预注册必须以
   当前载体的复测数字为证据（10-19 裁定），复测先行。
3. **线性读出 = 训练头天花板 = 特化信号**：当 ridge 从 t_tok 读到训练头
   水平（接触 F1 0.912 vs 0.91），说明特征空间已被该监督充分吸收——
   这是「编码器信息单一化」的可用诊断。

## 行动

1. **H v2 = v1 + T 流 aux 压力重建**（λ_trec=0.1，B 的已验证配方；只加
   监督不加塔，T 侧仍不出内容），重训两配置；
2. 复测（同一探针管线，新载体）确认足部信号恢复；
3. 按复测数字预注册一阶足部残差头（t_tok → 足部残差，接触门控、输出
   饱和）——命题 2 的兑现实验。

**2026-10-19 更新（用户裁定：两分支一次完成，消融结构一次成型）**：
v1 / v2 / v3 三模型直接构成消融链——v2 − v1 = 编码器监督贡献，
v3 − v2 = 残差头纯贡献，复测作为训练后的确认而不是前置闸门。

- **V3_Hv2**（队列 00548/00549）：v1 + aux 压力重建头（λ_trec=0.1）。
- **V3_Hv3**（队列 00550/00551）：v2 + 一阶足部残差头——t_tok →
  每足 6D 残差（Linear 256→12），接触软门控（×c）、输出饱和（每足范数
  上限 0.05）、只写足关节（10/11）6D 槽位；λ_foot_res=1.0，损失只监督
  「修正后」足 6D 且基础部分 detach（V 塔不被残差损失触碰——零税的训练
  侧保证）；V2M 行不应用残差，VT/T 行在残差层之前应用。

预注册判据（cam3 + occ010，test，ckpt_best）：
① 零税保持：v2/v3 的 VT2M PA − V2M PA ≈ 0；
② 残差头纯贡献：v3 − v2 的 PA-MPJPE_lower / PA-MPJPE_anklefoot（对齐
   口径）为负（或至少持平）——命题 2 兑现的直接判据；
③ 编码器监督贡献：v2 − v1 的 PA-MPJPE_lower ≥ 持平，零税保持；
④ 滑步/穿透不劣于 v2（残差不碰根、只写足 6D）；
⑤ 训练后复测（同一探针管线）：v2/v3 载体足部信号恢复（符号口径）。

实现：`model_v3h.py`（t_rec_head / foot_res_head 按 model_name 前缀条件
构建，v1 ckpt 逐键兼容）+ `apply_foot_residual`；`losses.py`
（L_foot_res，detach 基础）；`train/eval/eval_protocol` v3h 分支应用残差；
`TRAIN_ARG_FLAG_MAP` + `--lambda-foot-res`；registry 三版本条目。
冒烟全过（v1 兼容 / 饱和 / 足部唯一写入 / 损失 / 残差+约束链）。

**2026-10-19 实测落定（v1/v2/v3 三版本 + 训后复测）**：
- 特征层：v1 r_foot −0.61（信号消失）→ **v2 −2.99* / v3 −3.05***（aux 重建
  恢复，≈B 同源 −2.89）——载体依赖修复成功，阻断点 = 编码器监督，已解；
- 模型层：零税三版本保持（−0.013/−0.009/−0.009）；②残差头纯贡献 ≈0
  （对齐口径 −0.002/−0.004）——**结构性原因**：残差头只写足关节 6D，足
  关节位置由父链（踝）决定，改自身旋转只改朝向不改位置——对位置指标
  结构上无力（探针增益经全姿态读出隐含修正腿链进入位置指标）；
- 修正方向：残差头落点改踝关节（7/8）6D——踝旋转经 ~128mm 杠杆直接
  移动足位置，小角度 ≈ 平移（穿透诊断「误差是平移」的最小姿态实现）。
  **已实现（2026-10-20）为 V3_Hv6**：v5 无锚结构 + 踝落点（损失槽位
  42:54，state dict 与 v5 逐键一致）；预注册沿用 v3−v2 判据（现为
  v6−v5 = 落点修复纯贡献），队列 00569/00570。同时按 10-20 分层扫描
  证据（`V3_H设计错误裁定.md` §2 强化：误差方向逐条件不可读）预期
  受信息层压制——v6 是 H 线收口实验，不承载兑现承诺。
