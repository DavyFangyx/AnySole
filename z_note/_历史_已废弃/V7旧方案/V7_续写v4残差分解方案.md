# V7 续写 v4：锚点系残差分解方案（2026-11-01 设计稿，待裁定）

## §1 背景与设计主张

- 模态本体（用户裁定，2026-11-01）：T（压力）**原则上没有**世界系绝对偏航/滚转
  信息（传感器无世界参照；滚转有地面接触弱约束但绝对参照同样来自世界系）；
  但 T **可以学朝向残差**——力的分布编码朝向变化（转弯外侧脚负载、滚转 CoP 横移）。
- v1 暴露偏差的根因（判别实验）：teacher forcing 下模型学会「信任/复制 ctx」——
  绝对量在目标空间里，复制就是捷径。v3（ctx3，输入侧硬填 + 门控）约束了它，
  但绝对量仍在目标里。
- **v4 主张（分支设计的完整形态）**：把「绝对量通道」与「残差生成通道」在
  **表示层**分开——模型永远工作在锚点系，绝对航向只存在于链式携带与出口组合；
  生成器的训练目标里没有绝对量，复制捷径在表示层被结构性消除。

## §2 表示定义

### 2.1 锚

- T-only 行：锚 = 窗首帧（帧 0）的根朝向，`R_a`（3×3 旋转矩阵）。
  - 训练：`R_a = pose_gt[0]` 的根 6D（GT 锚，teacher forcing）；
  - 评估：`R_a =` ctx 块帧 0 的根 6D（上一窗预测）。
- V/VT 行：`R_a = I`（恒等，等价于无锚——目标/输出/评估与 Cv5 完全一致）。
- 首窗/跳窗复位（T 行）：无 ctx → `R_a = I`，绝对模式起跳（模型先验出航向）。

### 2.2 残差目标（T-only 行，训练侧）

```
R_world(j,t) = R_a ⊙ R_res(j,t)      j = 0..23（全部 24 关节，6D）
v_world(t)   = R_a ⊙ v_res(t)        （根速度，3D）
p_world(t)   = p_a + Σ_{k<t} R_a ⊙ v_res(k) / FPS
```

- 训练目标 = `R_res(j,t) = R_aᵀ ⊙ R_gt(j,t)`、`v_res(t) = R_aᵀ ⊙ v_gt(t)`；
  帧 0 的根残差 = 恒等（锚就是帧 0 的 GT 朝向）。
- 变换位置：**训练循环侧**（backward_v7_enum / val `_evaluate` 内按 `cid==T`
  做），不在数据集侧——数据集保持绝对 GT + ctx 块（枚举采样在循环内定条件，
  数据集不知道 cid；双列目标空间浪费且易错）。
- V/VT 行目标不变（绝对）。

### 2.3 ctx 块注入（T-only 行，模型侧）

- ctx 块仍为 10 帧 × [根 6D + 根速度 3 + flag]（绝对，评估链携带同 ctx3）。
- 模型 forward 内转残差后再槽位替换：
  `R_a = block[:, 0, :6]`（rot6d→rotmat）；
  注入内容 = `R_aᵀ ⊗ block 逐帧根 6D`、`R_aᵀ ⊗ block 逐帧速度`（帧 0 = 恒等/零速
  残差）+ 时间 PE；替换前 nf 帧的根速度 query 与根朝向 query 槽位。
- 门控同 ctx3：V 在场或 flag=0 不替换（保留学习 query）。
- 需要的几何助手：`rot6d_to_rotmat` / `rotmat_to_6d`（评估协议已在用，torch 版）。

### 2.4 评估出口组合（T-only 行）

- 世界 6D = `R_a ⊙ R_res`（FK 前组合）；世界轨迹 = `trans_anchor + cumsum(R_a ⊙ v_res)/FPS`。
- 位置锚口径沿用现协议：`trans_anchor`（GT，帧 left-1）——与 v3/现协议同口径，
  PA 对齐不变、十指标可比；旋转锚来自链（预测），位置锚来自 GT（现协议约定）。
- `R_a` 沿链携带：每窗一个（上一窗在窗首帧的根朝向预测）。

## §3 模型结构（相对 ctx3 的改动）

数据流（T-only 行）：

```
训练：GT 绝对 ──[R_a]──▶ 残差目标；ctx 块（绝对）──[R_aᵀ⊗]──▶ 残差槽位替换
      模型：V(零) + T + 残差 ctx ──▶ 残差 pose + 残差 v_hat（头结构不动）
      损失：残差目标 vs 残差输出（接触头/门控不变）
评估：残差输出 ──[R_a ⊙]──▶ 世界 6D + 世界轨迹（FK 不变）
V/VT：R_a = I、不注入 —— 与 Cv5 完全一致
```

相对 ctx3 的差异：

| 项 | ctx3 | v4 |
|---|---|---|
| T 行训练目标 | 绝对 | 锚点系残差（训练循环内变换） |
| ctx 注入内容 | 绝对状态 | 同一锚转残差后的状态 |
| 模型输出空间 | 绝对 | 残差（目标空间无绝对航向） |
| 评估出口 | 直接 | `R_a ⊙` 组合 |
| 其余 | — | 全同（门控/槽位/头/接触头/配方） |

- 结构参数增量：**零新增参数**（ctx_emb 复用；几何变换是确定性算子）。
- pose 统计（pose_mean/pose_std）：拟合混合分布（V/VT 绝对 + T 残差，枚举 2:1
  混合）——根 6D 均值 ≈ 2/3 绝对均值 + 1/3 恒等附近；统计拟合代码不动，
  只喂变换后的分布（拟合循环同样按 cid 变换）。

## §4 训练

- 配方与 Cv5 完全一致（枚举三条件、740ep、bs256、f6_soft、ckpt 选点门不变）。
- 目标变换在 `backward_v7_enum`（训练）与 `_evaluate`（val）内：`cid==T` 的窗口
  pose_gt/vel_gt 乘 `R_aᵀ`（`R_a = pose_gt[0]` 根 6D）；V/VT 不变。
- 首窗（left==0）flag=0 → `R_a = I`（无变换）——首窗训练 = 绝对模式（与评估
  首窗一致）。
- ctx_ss（并行会话的 scheduled sampling）可叠加：噪声加在**锚**上（训练目标
  与注入块同时用带噪 `R_a`）——锚级噪声是 v4 的天然扩展位，不在本方案范围。

## §5 评估

- 协议路由同 ctx3：T 行链式（stride=tw//2，发射规则同 v1）；V/VT 行非重叠
  标准协议（与 Cv5 行同口径）。
- `_v7_ctx_session_seq` 增 v4 分支：链上逐窗携带 `R_a`（上一窗预测的窗首帧
  根 6D）+ 出口组合；首窗/复位 `R_a = I`。
- 指标口径不变（PA/Global/Jitter/RO/RO-Drift 定义照旧）——十指标与 v1/v3/Cv5
  可比。
- 验收判据（用户裁定）：T2M **offset 允许存在、要求稳定**——PA 回基线附近
  （+15.7 → 期望 ≤ +3 级）+ RootOrientationDrift 显著下降 + 窗间 |Δyaw| 收紧
  （80%+ 不回落到 63%）；绝对 RootOrientation 允许几十度（首窗 offset，
  部署外部 IMU 一次性纠初始航向）。V/VT 行精确 = Cv5。

## §6 边界与性质

- 首窗自由不变：T 行首窗 = 绝对模式先验起跳，offset 由此产生——不解决、
  不声称解决（用户已裁定）。
- **offset 稳定性变为结构性性质**：绝对航向每链只出现一次（首窗），此后
  沿链只有残差增量；drift = 增量之和，增量正是被训练的对象（可正则化）。
- 暴露偏差结构性消除：目标空间无锚点 → 无「复制锚点」捷径可学。
- 与 F2a（f2_repr）的关系：同哲学（heading 拆出/朝向系轨迹），v4 推广为
  「整个运动在锚点系内」。
