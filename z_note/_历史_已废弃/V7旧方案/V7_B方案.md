# V7_Bv1 方案（候选 B：A + 接触参与根运动；2026-10-25 设计，已实现、未发射训练）

结构同 [V7_A方案.md](V7_A方案.md) §2（独立证据 + 共享生成，三条件硬关闭分支）；本方案只新增一种机制——**接触参与的根运动建模**（模型设计思路 §3 候选 B）。未列章节与 A 一致。

## 1. 设计主张与机制规则（新增部分）

- **接触状态与运动一致性通路**：可信支撑窗口内，足底世界速度 → 0；软权重 = 接触概率（接触不意味着任意足部点绝对静止——不把接触帧踝关节速度硬压零，用软权重）。
- **梯度经 FK 回传**：足-地一致性损失通过 FK 回传到根运动与下肢生成——不只训一个接触头，也不是推理时借 GT floor 修正输出。
- **推理零额外消费**：不新增推理侧组件；推理不消费 GT 地面高度、GT 接触或逐帧 GT 根位置。
- **目标**：E5 的根运动与足地指标；局部 PA 可以持平，不要求触觉到处修改健康视觉的关节角。

## 2. 模型结构（新增部分）

- 无新参数：与 V7_Av1 逐参数同构（`AnySoleModelV7(contact_root=True)`，损失侧开关）。
- 数据流同 A §2.1；`out` 额外暴露 `z_root / z_parts / m_v / m_t`（损失与诊断用）。

## 3. 训练（新增部分）

- 采样/优化/checkpoint 规则同 A §3；额外预注册 **λ_foot = 1.0**。
- **L_foot**（`compute_losses_v7` 内，由 STRUCTURE 标志 `v7_contact_root` 驱动；B 入口 `CONFIG_EXTRA` 将 `lambda_foot=1.0` 注入有效配置与 checkpoint，总损失使用该权重；缺项直接报错，train.py 无 --lambda-foot CLI）：
  ```
  kp  = FK(x0_hat, trans_hat + trans_anchor, offsets, parents)     # (B,tw,24,3)
  disp = kp[foot]_{t} − kp[foot]_{t-1}                             # (B,tw−1,2,3) m/帧 @40Hz
  w   = detach(sigmoid(contact_logits))[:, 1:] × t_present          # 软权重（支撑）
  L_foot = Σ(‖disp‖²·w) / Σw   # 单位 (m/帧)²，λ_foot=1.0 按此单位
                               #（40Hz 下等价零速度约束；换算 (m/s)² = ×1600）
  ```
  w **detach**（2026-10-25 评审修订）：防止接触头通过压低难帧概率逃避约束。
- **v1 简化（已登记）**：仅软权重，无连续支撑区间筛选——「可信支撑区间」（模型设计思路 §3）留待 v2。
- 已知输入（设计文档 §9）：现有接触头 F1 0.90、摆动相召回 0.51（偏接触）——支撑区间判准偏保守，B 的增益可能因此受限；验收时接触头指标并报。

## 4. 评估（预注册口径，无结果数字）

- 验收顺序/十指标同 A §4；**重点指标 = traj_ATE / GlobalMPJPE / FootSliding / GroundPen**（E5 根运动与足地行）。
- 判据：足地指标改善、局部 PA 持平（允许不明显退化）；干预行 = 关掉接触监督（λ_foot=0 对照）与接触头输入置零的差异归因。
- 已知边界（模型设计思路 §5）：当前公共评估存在逐窗 GT trans_anchor——其范围须明确报告，不把该成绩说成自由积累的长轨迹能力。
