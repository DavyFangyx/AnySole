# 纯触觉测试：修正时钟下的 T×GT 对齐（2026-10-20）

**对象**：用 `offset_correction.csv`（视觉↔动捕逐 session 修正表）平移 GT 采样后，触觉 T 与 SMPL GT 的逐帧对齐质量。不掺 V——纯触觉数据对 GT 的验证。

**方法**：每 session 每脚，GT 足底热图和值（D8 口径：g0 地面 + 3cm 阈值 + 轴保护）× T 48 格力和值的 Pearson 相关（r 越高 = 对齐越好）；「最佳平移」为 ±3 帧整数扫描的最优残差（半帧粗网格，A 类基准 +2~+3 帧 = 几何接触先行于载荷的定义性超前，非时钟）。

## 判读

1. **B 类 session 的相位差由修正表修复**：S5091 r 从 ≈0/负 → 0.73~0.75；S5031（+26.5 帧极值）从 −0.71/−0.54 → 0.68/0.69；S12042、S13112 同步改善。用户 10-20 在 D8 看到的「相位差」确认是动捕时钟残差，修正后消失。
2. **A 类 session 逐位不动**（修正表对已对齐 session 零影响），对照干净。
3. **触觉数据本身一直是对的**：修正时钟后 T×GT 对齐质量在多数 session 达 r≈0.6~0.8；剩余残差 ±1~3 帧 = 几何接触（顶点 <2cm）先行于载荷建立的定义性超前，非时钟问题。
4. 天花板因素：S13112（上楼梯）的 r 上限受单平面 GT 限制（台阶支撑期 GT 判悬空，action 11 已知局限）；S13061 R 校正后 r 略降（0.142→0.059），该 session 残差估计精度有限（fleet 分类依据），单足单 session 不构成反例。

## 结论

修正 offset 表有效，触觉×GT 的相位对齐问题解决。后续凡消费 GT 的触觉实验（探针/接触/评估），应使用 `corrected_time.py` 的修正采样；是否把修正固化进共享事实层（offset_s 重同步，50 个 B 类 session）待用户裁定。
