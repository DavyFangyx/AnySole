# VT 统一运动模型设计思路

日期：2026-10-25。供后续设计几版模型使用，不预先宣称实验达标（实现状态见 §8 版本登记）。实验目标以 [实验计划](../实验计划.md) 为准，checkpoint 与比较方式以 [ckpt 规则](ckpt规则.md) 为准。

## 1 要解决的具体问题

一个 U 经 V+T 联合训练，使用同一个 checkpoint，在 V / T / VT 输入下直接生成运动。优先验证 E2 与 E5，有实测互补后再验证 E1。E3 接口可以保留，当前不扩展多视角训练或 TTA。

已有结果支持：触觉包含足地状态信息，视觉失效时可能帮助足部与根运动；不支持把“T 永远不能帮助姿态”“一个 T 编码器不能同时做接触与运动”写成定律。旧结论还混有早期 checkpoint、未完成训练、训练监督与表达通路的影响。

新的重点是：保留干净的模态证据，让两种证据共同生成运动，并给触觉一条真正可达根运动的路径。没有必要强迫两种模态拥有相等权重，也没有理由永久冻结视觉主干来获得零税。

## 2 建议的共同骨架

```text
V：HRNet 缓存 2051/帧 → V 编码器与时间建模 → M_V
T：raw108 压力/物理量 → 足底空间与时间编码 → M_T

运动 query → 分别读取 M_V、M_T → 共享运动解码状态
                                      ├→ 关节局部旋转
                                      └→ 根方向 / 根速度
T 编码状态 → 接触状态头

关节旋转 + 根运动 → 同一个 FK → 关节轨迹与物理监督
```

延续现有 SMPL-24、6D 旋转、默认 d=256 与 tw=20 等接口，先避免同时改变表示、骨架、时间窗、视觉骨干和数据划分。T-only 是正式运动生成条件，不再只是“先验塔健康度”附属行。

### 证据流保持独立

V、T 可以各自做充分时序建模，但不要先放进一个无隔离 Transformer，再把融合后的前半段称作纯 V 证据。共享运动 query 分别 cross-attend 两路 memory，融合发生在运动生成状态中。缺失时明确关闭对应分支，保留共享运动先验。

V-only 与 T-only 使用这同一个解码器和输出头，而不是三个互不相通的完整生成塔。这样，视觉条件训练出的运动先验有机会帮助 T-only，触觉条件训练出的支撑规律也有机会改善 V-only。共享参数仍可能负迁移，必须实测，不能由结构直接宣称 E1 成立。

### 按运动因素分工

局部姿态 query 负责身体构型，根运动 query 负责根方向、速度与时间积累；两者在生成阶段可以交换状态。触觉优先进入根运动、支撑状态及下肢相关 query，不必平等干预所有关节。

T-only 上身依赖条件运动先验。压力不能唯一确定某次手臂运动，这属于观测歧义。可以学习与下肢、动作时序相关的统计预测，但不能把视觉教师的某一次不可观测上肢动作强制蒸馏给触觉，再把误差解释为触觉失效。

### 输出保持运动学一致

先输出旋转与根运动，再通过 FK 得到关节位置。不要独立修六个关节点，却让旋转、SMPL 导出和其他指标继续读取未修正的运动。姿态、足部位置、世界轨迹与物理评分应来自同一份最终运动。

## 3 三个候选方向

### 候选 A：独立证据，共享生成

使用上述共同骨架，以独立 cross-attention 读取 V/T，缺失模态硬屏蔽；先用简单的可训练组合，不预设复杂不确定性或额外残差头。根 query 能直接读取 M_T，避免 V4 那种“触觉只能改关节点、结构上改不了轨迹”的限制。

这是优先验证的最小候选。它回答共享生成在干净输入通路与正确三条件监督下，是否已经能建立互补。若失败，先排查输入条件、梯度与信号兑现，不立刻叠加更多门控。

### 候选 B：在 A 上增加接触参与的根运动建模

增加明确的接触状态与运动一致性通路。可靠支撑时，足底相对运动约束根速度；相关损失通过 FK 回传到根运动和下肢生成，不只训练一个接触头，也不在推理时借 GT floor 修正输出。

静态支撑、滚动触地、离地和真实滑动需要区别处理。接触不意味着任意足部点绝对静止，不能把所有接触帧的踝关节速度硬压成零。先使用可信支撑区间、软权重和现有足地定义。

地面参照允许训练监督和评分；推理不能使用 GT 地面高度、GT 接触或逐帧 GT 根位置。当前公共评估存在逐窗 GT trans_anchor，应保留并明确报告其范围，不能把该成绩说成自由积累的长轨迹能力。

这一方向的目标是 E5 的根运动与足地指标，局部 PA 可以持平，不要求触觉到处修改健康视觉的关节角。

### 候选 C：在 A 或 B 上增加可靠性路由

根据视觉证据质量、触觉有效性以及两路预测分歧，按时间、部位或任务调整信任。先从窗口级/根与下肢级开始，不假设当前 2051 维全局视觉缓存含有准确足部可见度。更细的部位可见性需要相应输入支持。

训练时可以用预测误差和人为退化标签监督质量估计；推理时只能读取输入与预测质量。GT 误差只能用于训练标签和离线诊断，不能成为运行时“视觉健康选择器”。

若使用方差做融合，必须说明它如何校准。现有 V5 的方差主要经最终运动任务间接影响相对混合权重；它不能自动当成可信误差条。接触的全局两标量权重也不能替代随帧变化的质量路由。

三种方向共享同一基础与数据口径，每版只明确新增一种机制，避免一次同时改主干、损失、窗口和输入。这里是候选设计顺序，不启动实验计划中暂缓的完整 E4 网格。

## 4 训练接口与损失要求

训练样本先决定实际可用模态，输入置零、attention mask、损失掩码都从同一个决定产生。建议先使用明确的三条件配比，例如沿用 `[0.5,0.25,0.25]`，而不是叠加多套彼此独立的 dropout。视觉遮挡仍是“视觉在场但退化”，不要直接等同缺失。

基本损失可以写成：

```text
L = 当前输入条件的完整运动监督
  + 有效触觉条件下的接触监督
  + 运动输出上的时序 / 足地一致性监督
```

完整运动监督应覆盖局部姿态与根运动。缺失 T 时，不能仍要求 T 编码器凭零输入重建当前样本；缺失 V 时，也不能误把 V 塔当有视觉证据的预测来监督。T-only 由有效 T 与共享先验生成全身，仍然接受正式运动标签。

零压力可能是真实离地，不能据“张量全零”推断触觉缺失；使用明确的在场掩码。默认不产生 V、T 同时缺失的样本，除非另外定义无条件生成任务。全 masked attention 需要正确跳过对应证据，不能产生 NaN。

接触与运动是合理的多任务组合，先观察公共 T 参数上的梯度量级、方向和单模态收敛，再决定是否需要私有投影或梯度处理。不预先上 PCGrad、复杂权重调度或复制多个 T 编码器。压力重建、CoP、相位等辅助任务仅在明确解决问题时加入，不一次堆齐。

若使用健康视觉下的输出一致性约束，必须同时保留 GT 运动监督，并明确目标分支与 stop-gradient。仅让两个预测互相靠近可能一起退化；零初始化或小残差也不能保证训练后的零税。

“零税”目前只作为关键指标不明显退化的待验收目标；若最终要求健康时 VT=V 逐位相同，需另设计硬路由及可部署的健康判断，并接受可能错过正常状态下触觉增益的取舍。不能在论文或报告里混用这两种含义。

## 5 公平性与能力边界

- U、S_V、S_T、S_VT 需要相同划分、运动标签、评分协议和可比预算。SV 也能使用训练 GT 派生的接触标签时，应保持监督一致；否则“触觉正迁移”会混入额外监督的收益。
- 触觉可约束支撑与相对根运动，但不能单独确定任意世界位置、绝对航向和相机外参。T-only 世界系输出含学习先验，不能声称压力唯一观测到这些量。
- 单个强视觉模型更强后，VT−V 可能缩小。必须同时报告 V、VT 的绝对误差与关掉 T 的干预，不为扩大触觉增益而削弱 V 基线。
- 所有帧数、会话、时间轴、压力/视觉对齐异常都直接报告，不补齐或截断；训练与验证缺帧处理不能各用一套规则。

## 6 用户设计后提供哪些内容

每版给出数据流、各 tensor 的形状与坐标系、V/T/VT 三条实际前向路径、损失及掩码、参数共享/冻结范围、根轨迹与 FK 的计算，以及计划使用的 checkpoint 规则。无需先写完整训练脚本或启动长训练。

审查时重点检查：缺失输入是否泄漏；触觉是否真能影响根运动；三条件是否共用生成能力；健康视觉是否仍有有效 GT 监督；门控是否可部署且有梯度；位置与旋转是否一致；E1 是否存在可检验的迁移途径；以及 E2/E5 是否能用同一个 checkpoint 验收。

## 7 第一轮验收

先核对三条件和缺失掩码，用小规模真实输入确认运动输出有限、FK 一致、T 通路可达根运动，并检查同一个样本在更换真实 T 时的输出变化。敏感性只证明使用了 T，不能证明使用正确。

随后按新 checkpoint 规则做完整 val E2/E5。冻结一份 U 后再跑 test；有互补再训练或复核 E1 专家。第一轮不承诺十项全赢，不用换骨架、换有效帧或换 checkpoint 来制造达标。

## 9 附录：已知输入与建议（2026-10-25）

- **候选 B 的接触质量已知输入**：现有接触头实测 F1 0.90、摆动相召回 0.51（偏接触）。B 的「可信支撑区间」依赖此头——若摆动相召回不改善，软权重会偏保守（支撑判准、漏掉摆动）；B 的足-地一致性增益可能因此受限。可在 B 的验收中把接触头指标并报。
- **训练时长（建议谨慎采纳）**：740 epoch 是「从零训练」的遗产配置。V7 三候选从零训练，740 合理；但后续若出现挂件/微调型变体，第一轮应大幅缩短或早停（实测：挂件型 best 锁死 ep5、微调型 0.1× 漂移 740 epoch 毁骨架）。
- **选点准则警示**：勿让 val 选点指标跟踪「被测机制本身」（实测 V4 家族 11 格 best 锁死 ep5：val 面板应用修正后骨架，修正使 val 变差 → 选点与训练反向）。V7 无此结构，但任何「T 参与 VT」的新机制都应先检查选点指标是否与之绑定。
