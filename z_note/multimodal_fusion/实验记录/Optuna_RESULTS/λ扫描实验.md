## 3 判读

1. **V5_Av1 塌缩性质（2026-10-25 正式重读修正）**：1/0 = 105.0（ckpt_best 落 ep665）。canonical 生产轴 113.1、5-fold 138.6±80.8 的既往读数含**选择假象**——ckpt_best（val/tau0 VT）在冻结载体变体的平坦曲线上落到 ep5~10（先验塔欠训）。ckpt_last 正式重读（rebaseline 全 54 格落盘）：5-fold 逐 fold = 109.5/89.9/81.5/89.9/83.2 → **90.8±11.1**；wo05 1/0 = 97.1；生产轴 drop = 93.8。真实水平 ≈ **91–97** 持续偏弱（非塌缩），λ 3/1~4/1 修复（→85–87）仍成立且必要。全 18 格 best/last 复核仅 1 格差 >8mm（1/1：97.0→87.4）——本扫描其余结论不受选择假象影响。
2. **V5_Av1 修复选项**（先验塔健康度口径）：1/1 与 2/0 仅把 T2M 拉到 ~97；3/0（88.7）与 4/0（86.4）PA 达标但轨迹行仍烂（λ_prior_traj=0 预注册设计）；**3/1（91.1）与 4/1（86.6）PA + 轨迹行双修，4/1 已接近 Av4 折叠均值 84.7**——V5 先验塔天花板与 Av4 同水平，不需要换载体。lt0 行单调（105.0→96.8→88.7→86.4，lp3 跳 −8.1）。**但对照重训 Step2Motion 基线（PA 74.39）：全扫描最优（V4 1/1 84.8）仍差 ~10mm——λ 修的是稳定性，竞争化差距是训练目标问题（先验塔「从没按竞争目标训过」），不是 λ 网格可补。**
3. **V4_Av1 不需要调（稳定性口径）**：全八格 84.8–97.0 稳定过旧基线，λ 只做精修；最优点 1/1、3/1（≈84.8）。lt0 行同样单调（97.0→93.5→92.2→86.6），lt1 行平坦 ~85（2/1=90.3 被两侧 84.9/84.8 夹住，按 run 噪声登记）。
4. **同配方 V4 优于 V5 平均 ~10mm**（1/1：84.9 vs 97.0 等）——V4 的 L_corr_prior（λ_pos 3.0）是先验塔路径的第三条监督通道，λ_prior=1 时也不欠训；V5 无修正头，λ_prior 是唯一通道。λ≥3 后差距收敛（4/1：87.2 vs 86.6）。
5. **V5_Av4 两格（1/0、1/1）**：T2M 99.2 / 100.3——距重训基线 74.39 差 25mm，且其 T2M ATE（353/91）在 lt0 时也差于基线；ΔPA +0.11 微税；但 **Δ踝足 −1.10/−0.90、ΔPen −3.18/−0.57 为全场最大兑现**——scratch 载体 V2M 弱（38.66 vs 冻结载体 37.5–37.9）、兑现空间大的天花板效应实证，与「V5_Av4 兑现归因审计补充」§3.1 的基线解释同向。
6. **兑现侧（cam3 轴）**：V5 家族 ΔPen −0.73~−0.96 八格一致、全场最强；V4 的 ΔPA 微正（−0.22~−0.32）而 V5 近零（−0.02~−0.03）——门控 vs FiLM 的结构差异。Δ 全部不随 λ 变化——**cam3 轴上没有「修 T2M 吃兑现」的证据**；occ050 轴未覆盖。
7. **机制**：λ_prior_traj 0→1 是给共享 t_temporal 编码器新开一条监督通道（轨迹头回传改善 T 特征），故 T2M PA 与轨迹行同涨；λ_prior_pose 只是同一通道的权重加强——通道数量变化 > 权重变化。lp4 两行汇合（86.4 vs 86.6，lp3 时仍有 2.4mm 差），λ_prior_pose 足够大时 λ_prior_traj 的 PA 影响被吸收。
8. **对新基线的全列对照**：姿态侧（PA 74.39 / MPJPE 152.13）重训基线强于全部扫描格（最优 84.8 / ~150 量级）；轨迹侧（ATE 222.53）扫描格 lt1 行（82–91）强 ~130mm、lt0 行（257–312）差于基线——**U@T 块的全列比较是混合的，按列分别对标，不存在单一行全面过线的格子**。

## 4 数据边界

- 单 run 无重复：±5mm 内的格间差异（2/1 类离群）按噪声登记，不按结构解释。
- wo05 split：train 无绕圈跑 4 条（S11051/S11053/S7053/S8053），与 canonical 的读数差异部分来自训练集构成。
- cam3 轴：occ 档兑现结构不受本轮覆盖。
- V2M 恒等验证归因干净：V4 全格 37.91、V5_Av1 37.53–37.56、V5_Av4 38.66–39.96（scratch 载体随 λ 微动）——λ 只动 T 侧。
