# 全流程探针实验

对生产模型（V3_3B ckpt_best）全流程各阶段表征的零训练探针：编码器输出 → 融合输出 → 门控与缺失流。回答：T 的增量信息在哪一级被读到/被摧毁，融合架构各部件行为如何。

## 1. 模型结构与中间量

- **零训练**：只跑生产 ckpt 前向，不训练模型；ridge 在 TRAIN 帧拟合、VAL 帧评估（λ 网格 TRAIN 内留出选参）；
- **特征条件**：同一批窗口跑三次前向、只改 config_id（VT / V-only / T-only），编码后 null 替换——编码器输出与输入条件无关；

```
V 特征 ──编码──▶ v_tok ──┐                                   F（V）
                         ├─拼接(vt)──▶ 融合 Transformer ──▶ F ──▶ [真实 pose head 拿走]
T 压力 ──编码──▶ t_tok ──┘                                   F（T）
```

| 读出行 | 含义 |
|---|---|
| v_tok / t_tok | V / T 编码器单流（256d/帧） |
| vt | 融合前拼接（512d）——输入级天花板 |
| F_VT / F_V / F_T | 融合后记忆（512d），三条件——pose head 的输入 |
