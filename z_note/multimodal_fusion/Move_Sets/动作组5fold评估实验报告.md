## 判读

1. **cam3 上 T 无按动作效果**：除 V3_Bv1（训练融合带税）外所有模型所有动作 |ΔPA| ≤ 0.35——与干预实证（cam3 T 不参与）一致。V3_Bv1 cam3 税集中在绕圈跑（+4.3）/横移（+3.1）/开合跳（+3.1）。
2. **T 兑现随 V 失效出现、按动作分化**（occ050 主表）：兑现最强三动作 = 坐下站起 / 深蹲 / 单脚站立（V5_Av1 踝足 −19.6/−9.2/−10.9；V4_Av1 −101.8/−37.1/−24.8，方差大、符号可信）；走路类（折返慢走/快走/上楼梯）中等兑现、V3_Bv1 融合线最强（03/04 踝足 −36~−37）；开合跳/横移弱兑现。
3. **绕圈跑 = 全矩阵唯一系统性不兑现动作**：occ050 踝足 V5_Av1 +7.5 / V4_Av1 +0.8 / V3_Bv1 +4.2（税），cam3 上 V3_Bv1 +14.2 税——T 对绕圈跑无帮助甚至有害。站立重心移两线分化：V5_Av1 强兑现（−15.0）、V4_Av1 不兑现（+1.9）。
4. **结构差异**：V3_Bv1（训练融合）= 唯一 cam3 即动作异号的线（带税）、occ 档走路类兑现最大；V5_Av1（PoE）= 兑现最均匀（除绕圈跑全动作负）；V4_Av1（部位 token 门控）= 兑现极集中于蹲/坐/单脚站但方差大；V5_Av4（V 从零）= 各档量级最小（踝足 −0.3~−4.2），从零 V 流未增强 T 兑现（比 Av1 小一个数量级）。
5. **机制解释**：T 提供地面真值 → 帮地面相关的视觉失效（蹲/坐/单脚站/走路贴地），帮不了轨迹型失效（绕圈跑转向）——与「T 有效性条件 = 地面参照量」一致。
6. **数据边界**：04/05/08 每 fold 训练 0~2 会话，读数按泛化理解；05 不兑现可能与其稀缺（全库 4 条）相关。
