# V5_Av4 兑现归因审计补充（2026-10-24）

对「V5_Av1 T2M 极度退化 / Av4 修好 T2M 但 occ 兑现缩水」论断逐项核实。数据源 = `results/experiments/per_action_folds/*/metrics/{session_detail_test,test}.json` 逐 fold 重算（动作映射 = `session_manifest.jsonl` 官方口径（cam3 = 主 manifest，2026-10-24 起），与 10-24 修正版报告数字一致）。

## 1 核实成立

- T2M PA：Av1 **138.6±80.8**（fold：296.9 / 89.4 / 129.5 / 94.2 / 82.7）vs Av4 **84.7±2.1** vs Bv1 **81.4±2.7**——「塌缩、Av4 修好、接近 Bv1」全部成立。
- 塌缩 fold = fS13S14，全动作 271–326（fold 级全局塌缩，非动作特例）。
- 塌缩只发生在 cam3 运行：Av1 occ010 T2M 91.1±9.6 / occ050 90.1±8.6 稳定 → run 级收敛噪声，非 fold 数据属性。
- 两变量框架成立：Av1→Av4 仅改 carrier_from="scratch" + λ_prior 1/0→3/1（`configs/z_gen/model_registry.py` 逐项核实，其余 train_args 相同）；ckpt_best 选择准则同为 val/tau0 VT，无选择准则混淆。
- 兑现缩水量级成立：踝足 mean|Δ| 8.4→2.0（4.2×）；Pen 13.0→3.5（3.7×）。「一个数量级」只对踝足成立。

## 2 不成立

- **「兑现谱形状没变」**：Spearman(Δ踝足) = −0.07（p=0.83）、Spearman(ΔPen) = 0.06——形状完全改变。Av1 最强动作（坐下站起 −19.6 / 站立重心移 −15.0 / 单脚站立 −10.9）在 Av4 变为最弱（−2.4 / −0.4 / −0.3）；Av4 相对最强 = 上楼梯 −4.2 / 横移 −3.9（Av1 里横移最弱 −0.8）。

## 3 漏掉的检查

1. **V2M 基线大幅移动（最大漏点）**：Av4 的 V 流从零在 occ050 数据上训练 → V2M 踝足比 Av1 好 35–92mm（坐下站起 199→107、单脚站立 183→139、站立重心移 122→87）；基线改善量与兑现缩水量逐动作相关 Pearson **−0.86（p=0.001）**。Av4 绝对 VT2M 在全部 11 动作优于 Av1（−5.1 ~ −75.0mm）。→ Δ 缩水主体 = 天花板效应（V 已自己做到，T 无剩余空间），不是 T 能力损失。
2. **干预读数（robust_tdrop）给出另一半**：Av1_occ050 VT2M−tdrop（PA）= −1.8/−0.7/−1.2/−2.0/−0.2（T 有用）；Av4 = −0.12/−0.00/+0.12/−0.13/−0.00（≈0）——按干预口径 T 边际贡献在 Av4 确实归零。两效应并存：基线变强 + T 贡献消失（可读为：可训练载体把 T 的信息冗余吸收进 V，零初始化 FiLM 无边际收益偏离恒等）。
3. **λ 归因有反例**：V4_Av1 已是 λ 3.0/1.0，T2M 仍不稳（118.1±38.6，两 fold ~165）→ λ 3/1 不是 T2M 稳定的充分条件，「λ 1/0 欠训 → 塌缩」因果被削弱（V4 先验塔结构不同，非严格反例）。
4. **fold 内相关（现有 JSON 可算，无需新训练）**：Av1 内部 T2M 越差兑现越好——Spearman(T2M, Δ踝足) −0.70 / (T2M, ΔPen) −0.80（n=5，p=0.19/0.10）；最塌缩 fold（T2M 297）兑现最好（踝足 −14.3 / Pen −20.4）。无证据支持「修 T2M = 保兑现」。
5. T2M 轨迹行：Av1 ATE 379 / Global 499（λ_prior_traj=0 为预注册设计选择、T2M 不参与承诺）→ Av4 96 / 203。「修好 T 通道」中轨迹行是设计开关的直接后果，非意外缺陷。

## 4 对提议消融的评估

- 缺格属实：注册表无「V5 结构 + E 载体 + λ 3/1」。
- 该格足以完成归因：E 载体冻结 → V2M 逐位不变 → 兑现变化只能归 λ。判据 = 绝对 VT2M + tdrop 间隙 + Δ 三者同报（该格 V2M 不变，Δ 干净）。
- 可选补格：scratch 载体 + λ 1/0（2×2 第四格），检验 λ 在 scratch 语境是否无关。
