# 当前模型结构：V3_3B（2026-10-08）

主模型 **V3_3B** = anysolev2 回归式模型（`anysole/models/common/model_v2.py`），SMPL-24 原生协议，输出 144 维 6D 姿态。入口 `anysole/models/v3_3b.py` 固定结构：`t_encoder=foot_conv`、`pose_parts=9`、`soft_parts=True`、`gate=sigma`、`v_input=hrnet`、`tactile_input=raw108`、`f2_repr=False`。

数据流一句话：**V（HRNet 特征）→ v_tok，T（鞋垫压力 108 维）→ foot_conv → t_tok；[v_tok; t_tok] 拼起来过一个融合 Transformer 得 F；pose head 的 9 个部位 query 对 F 做「V 半段 / T 半段」双流交叉注意力，用 σ 门控加权，9 个部位姿态假设经 soft A 矩阵按关节混合成最终姿态**。

## 1. 输入与编码

### V 流（视觉）
- 输入：冻结 HRNet 特征 **(B, 20, 2051)** = 2048 维 HRNet + CLIFF bbox 3 维（40Hz 帧率，窗口 tw=20）。
- 编码 `LinearTemporalEncoder`（`common/encoders.py`）：`Linear(2051→256)` → LayerNorm → + 正弦时间位置编码 → + 模态嵌入 → **v_tok (B,20,256)**。

### T 流（触觉）
- 输入：**(B, 20, 108)** = cat([T_raw 96 维压力, T_phys 12 维物理量])。
- 编码 `FootConvEncoder`（`common/foot_encoder.py`）：每脚 48 格压力重排为 **4×12 网格**（行=内外侧，列=脚跟→脚尖），右脚镜像后与左脚**共享**同一卷积栈（Conv2d(1,32,3) → Conv2d(32,64,stride=(1,2)) → Conv2d(64,64,3) → 4×6×64=1536 → Linear 128）；每脚 8 维手工特征（T_phys 6 维 + 接触面积比 + 压力变化率）经 MLP 到 128；两者拼接 → Linear(256→256)。每帧产出 [左, 右, 全局] 3 个 token → 4 层时序 Transformer → 合并回 **t_tok (B,20,256)**，与 v_tok 同形。

### 模态缺失处理
训练/评估的三条件由 `config_id ∈ {0=VT, 1=V-only, 2=T-only}` 控制（`train.py: condition_inputs` + `encoders.py:146-181`）：缺失模态的整条 token 流被替换为**可学习 null token** `null_v / null_t`（(1,1,256) 参数，normal std=0.02 初始化）。训练条件采样比例 **0.5 VT / 0.25 V-only / 0.25 T-only**。

## 2. 融合（第一层：早期拼接）

`common/fusion.py`：`tokens = cat([v_tok, t_tok], 1)` → **4 层 pre-LN TransformerEncoder**（nhead=8, ff=1024）→ **F (B, 40, 256)**。前 20 个 token 为 V 源、后 20 个为 T 源——这个顺序被后续门控层依赖（硬校验）。F 同时供 pose head、traj head、aux heads 使用。

## 3. Pose head（第二、三层融合）

`common/pose_head.py`，`head_mode="regress"`（直接回归，无扩散链）：

- **查询**：9 个部位的可学习 query **(1, tw, 9, 256)** + 时间 PE + 组嵌入；9 部位 = root / torso / headneck / l·r_arm / l·r_leg / l·r_foot（`types.py` PART_NAMES）。
- **每层 GatedDecoderLayer**（6 层）：
  ```
  z ← z + SelfAttn(z)                    # 部位间自注意力
  e_V = CrossAttn_V(z, F; 只允许看 V 半段)
  e_T = CrossAttn_T(z, F; 只允许看 T 半段)
  σ  = Linear([z, e_V, e_T] → 2)         # 每部位对两流的"信任分"
  g  = softmax([σ_V, σ_T, τ_p])          # 三路权重，和为 1
  z ← z + g_V·e_V + g_T·e_T              # 先验支 g_∅ 就是残差 z 本身
  z ← z + FFN(z)
  ```
  - τ_p 是**按部位的先验偏置**：T 信息部位（root/legs/feet）低 τ、V 信息部位（torso/headneck/arms）高 τ，钳位 [-4,4]。
- **soft A 矩阵**（第三层融合）：`part_logits` **(9,24)** 初始化为 ±3（复现人为 9 部位划分）；A = softmax(part_logits / T)。每个槽有一个全姿态头 Linear(256→144)，输出按关节混合：`out = Σ_p A[p,j] · hypo_p[j]`。

## 4. 其他头与损失

- **traj head**：F 按 V/T 两半池化 → 2 层 encoder → 每帧速度 → cumsum 出轨迹（out_dim=3，非 f2 表征）。
- **aux heads**：从 F 的 T/V 半段重建压力/视觉特征（跨模态正则）。
- 损失表（V3_3B 实际训练值）：

| 损失 | 权重 | 含义 |
|---|---|---|
| L_pose | 3.0 | 姿态 6D MSE（native 空间） |
| L_traj | 1.0 | 根轨迹（含速度/差分） |
| L_kp | 1.0 | FK 关节位置监督 |
| L_trec / L_vrec | 0.1 / 0.1 | 触觉/视觉重建 |
| L_assign | 0.05 | A 矩阵逐关节熵 + 槽负载平衡 |
| L_sigma | 0.01 | σ 门控监督（β-NLL，见下） |

- **σ 门控监督（β-NLL）**：`v = g_V·e^{−σ_V} + g_T·e^{−σ_T}`（σ 大 = 信任高），`L_sigma = β·mean(r_p²/v + log v)`，β=0.5，σ 钳位 [-3,6]；误差目标与门权重、A 矩阵全部 stopgrad，σ 是唯一活参数。训练前 `sigma_freeze_frac=0.1`（前 10% 步）σ 冻结为 0。

## 5. 训练与评估

- 训练：从零随机初始化（09-24 独立性规则，无 warm-start）；tw=20、stride=20、lr 1e-4、warmup 0.05、grad clip 5.0、epochs 740、batch 256、seed 1。
- 评估：session 级推理（非重叠窗口、窗口缝 crossfade），指标唯一实现 `anysole/utils/metrics.py`（PA-MPJPE 等）；val 三条件（生产 ckpt_best）：**VT2M 49.1 / V2M 42.0 / T2M 91.4**（PA，mm）。
- 模型谱系：V3_2（9 部位**硬**头，无门控）→ V3_3A（+soft A）→ **V3_3B（+σ 门控，当前主模型）**；F5 part_decoder 作废归档（encode_stream 缺 LayerNorm 根因）、V4A/V4B 为分组学习实验（结论：人为 9 部位是合格选择）。
- 定位：结构由入口脚本硬编码并记入 ckpt config；ckpt 在 `results/AnySole/V3_3B_joint_and/<完整字段串>/checkpoints/`（字段串=超参记录）；专才 V3_3B_vonly/tonly 为同架构、只改训练条件采样、独立从零。

## 6. V3_3C（冻结残差变体，2026-10-09 起）

「定向修复」槽位的裁定实现（设计与判读见 T信息量判定实验.md §5）：**冻结
V3_3B_vonly 专才全部参数 + 只训一个 T 残差分支**。

- 结构：与 V3_3B 完全同构（STRUCTURE 只多 `residual_t=True`），新增
  `TResidualBranch`（LayerNorm + Linear(256→256) GELU + Linear(256→144)，
  **末层零初始化**，~103k 参数 / 0.56%），只读冻结 `t_tok`。
- 前向：`x0_hat += (config_id==VT) * branch(t_tok)`——V-only/T-only 掩码旁路，
  V2M 输出恒等于专才；零末层 ⇒ 训练起点 VT ≡ V（结构保证，实测与基底
  |diff| ≤ 4.8e-07 = BLAS 舍入噪声）。
- 训练：从 V3_3B_vonly `ckpt_best.pt` fine-tune（--init-from），只采 VT 窗口
  （--config-probs 1 0 0）、200ep、λ_assign/λ_sigma 清零、sigma_freeze_frac=0；
  optimizer 只含分支参数。09-24 独立性规则的有意例外，血缘记 manifest
