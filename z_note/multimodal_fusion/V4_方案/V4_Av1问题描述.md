# V4_1 问题描述（2026-10-19）

本文档面向外部专家提问：在「模态按部位归属」的思路下，多模态人体运动估计模型应如何实现。

## 1. 任务与数据

- **任务**：**从视觉（V）与鞋垫触觉（T）估计 3D 人体运动。**输出 = 骨盆相对 SMPL-24 骨骼姿态（24 关节 × 6D 旋转）+ 世界系根轨迹（3 维/帧）。
评估：MPJPE 家族（PA/Global）、根轨迹 ATE、物理合理性（足底穿透 / 足部滑步 / 加速度抖动）。
- **V**：单目 RGB 视频；每帧人体 crop 的 2051 维视觉特征（HRNet 主干 2048 维 + 相机几何 3 维）。评估含下半身遮挡条件（bbox 底部 10% 涂黑，occ010）。
- **T**：鞋垫压力，每帧 108 维（96 压力网格 + 12 物理量），传感器只覆盖脚底。
- **监督**：
  - 姿态：全身 SMPL 姿态 + 世界系根轨迹。
  - 接触：每足软接触标签。
  - 足地交互：GT 足底热图/CoP 与触觉热图/CoP 配对数据已具备（D_Test8），当前未用于监督。
- **协议**：三条件——V2M（仅 V）、VT2M（V+T）、T2M（仅 T），同一模型三种读出；T 的贡献 = VT2M − V2M。
- **载体**：现行载体为回归式时序 Transformer；三条件协议与载体无关。

## 2. 设计意图

T 的传感器只在脚底，但 T 携带的信息对全身各部位的贡献不同（§3.1）。设计意图：**最大化利用这一部位差异——按部位分离模态通道，每个部位只接触其归属模态**，使「T 只服务足部、其余部位纯视觉」成为模型结构事实，而非训练结果。

## 3. 证据

### 3.1 T 贡献的部位分裂（零训练线性探针）

在现有模型的编码器特征上做零训练 ridge 探针（弱判据：测出即有信息；未测出不排除无信息。量级为弱基线相对量，只引符号）：

- T 的增量信息在部位上显著分裂：正信号只在足部（踝足）；上身/手无正信号。
- T 有全局增量（GlobalMPJPE、根轨迹 ATE 显著）。
- 物理合理性三行（足底穿透 / 足部滑步 / 抖动）线性探针无正信号（显著为正）；按弱判据口径不作「无 T 信息」主张。

### 3.2 T–V 交互机制测量（供设计参考）

| 交互形式 | 实测结果 |
|---|---|
| T 特征混入共享生成通路 | 姿态误差税（PA 显著变差，~13mm）——T 污染 V 表征的代价已量化 |
| T 经推理侧零参数物理修正（物理残差驱动，只写根 Y/踝） | 零姿态税；接触读出可靠（F1 ≈ 0.9）；实测收益 = 足部滑步改善。穿透修正需绝对地面高度：当前来自 GT（GT 口径 −9.9，不作 T 宣称）；T 只能给足−地相对约束（gauge 自由度，T 口径 ≈ 0）——绝对地面需由 V 的相机几何提供 |
| T 单独估计全身（T2M） | ≈ 88mm 量级——T 的全身生成能力有上界，定位为纠偏模态 |

## 4. 模态归属

触觉视觉以及动捕数据是有对应的区域的，其中当前触觉属于局部信息，动捕与视觉具有全局信息。

| 部位 | V 输入 | T 输入 | 监督 |
|---|---|---|---|
| 足部 | 有 | 有（唯一） | 姿态 + 接触 + 足地交互（D_Test8 CoP/热图为可选项） |
| 腿/躯干/臂/头 | 有 | 无 | 姿态（骨盆相对） |
| 全局（根轨迹） | 有 | 间接——命题 1 的全局增量 = 命题 2 的足部信息经地面接触向上传递的结果 | 轨迹 |

## 5. 分区参考设计思路

每个部位只能接触其归属模态（这个只是一个参考设计）：

- **世界锚区**（足 + 根轨迹）：V + T，接触/地面监督。
- **局部内容区**（其余全身）：纯 V，骨盆相对监督。
- 交互 = 运动学组合（FK），零学习。

内容区骨盆相对 → 结构上对 T 免疫；锚区是 T 的唯一挂载点。
