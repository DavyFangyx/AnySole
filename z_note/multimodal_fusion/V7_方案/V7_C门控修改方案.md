# V7 C 门控修改方案

日期：2026-10-30。基线为 V7_Cv5（下文简称 Cv5），目标是在继续抑制触觉引入的退化时，保留更多触觉增益。先比较时间粒度与左右部位粒度，再分别验证门的条件输入和显式收益监督。本文件为待实现方案，不代表结构已经实现或实验已经完成。

## 1. 现有结果与问题边界

当前 E6 使用 Δ = VT 误差 − V 误差，单位 mm，负值表示触觉有益。门控版本减少了部分退化，也出现了有益阶段的增益变弱。例如开合跳左脚摆动阶段，Cv4 / Cv5 / Cv7 的平均 Δ 分别为 +4.830 / +1.294 / -9.358。三者为独立训练的模型，各自 V-only 基线不同，这个对照提示选择性问题，不能单独证明原因。

本轮以“门在发挥作用，但选择能力可能不足”为研究起点，不预设门失效、常闭或 T 被忽略。历史 Cv1 的 11 个验证窗抽查记录了 VT 门值随遮挡增加、T-only 门值较高，以及正确 T 优于错配 T；它不是当前 E6 的 Cv4/Cv5 门值实测。当前 E6 对应的 Cv4/Cv5 预测 NPZ 未保存 route_gate，不能将 g≈0.1 当成这些模型的已核实事实。

现有结构的限制是门不能独立满足不同帧、不同部位的需求；交叉注意力和共享解码器仍具备其他选择机制，因此不把“压退化与保增益数学上严格互斥”作为已证实结论。

来源：[现有 C 方案](V7_C方案.md)、[历史审查](V7C审查与后续实验建议.md)、[当前 E6 结果](../../../results_display/Etest/E6_ContactPhaseAnalysis/E6_接触相位分析.md)。

## 2. 基线数据流与保持项

实现依据：`anysole/models/common/model_v7.py`、`anysole/models/common/foot_encoder.py`、`anysole/types.py`。

- 窗长 tw=20，采样率 40 Hz，即 0.5 秒；V/T 编码输出均为 `(B, tw, d)`。
- 门输入为 `x_t = cat(v_tok_t, t_tok_t)`；Cv5 对时间均值池化后，用两个独立 MLP 输出根速度门与姿态门。
- 运动 query 共 10 个：根速度 query 1 个，加 `PART_NAMES` 对应的 9 个姿态 query。
- gate 展开为 `(B, tw, 10, 1)`，六层解码器的 T 交叉注意力输出均乘同一组 gate，再乘 `t_present`。
- 骨盆旋转对应姿态分组 `root`，与根速度 query 是两个不同位置；不得把二者合并。
- FootConvEncoder 内部有左/右/global token，但输出给 V7 前已合并为逐帧 token。本轮左右门首先控制运动接收部位，不宣称已经隔离左右脚的触觉来源。

各新版本保留 V/T 编码器、运动输出头、FK、三条件枚举训练和缺失模态硬关闭规则。前四组使用同一运动/轨迹/接触损失，不新增接触硬门、门值下限、强制开门或向 0.5 收缩的正则。

## 3. 实验矩阵

下列简称只用于本方案，不直接占用新的 V7_Cv 编号；实现时注册独立模型与结果目录，不覆盖 Cv5/Cv7 历史产物。

| 组别 | 时间粒度 | 姿态控制范围 | 门输入 | 新增监督 | 直接比较 |
| --- | --- | --- | --- | --- | --- |
| B 基线 | 窗口 | 全姿态共享 | V/T token | 无 | 现有 Cv5 |
| T 时间门 | 逐帧 | 全姿态共享 | V/T token | 无 | T vs B |
| LR 左右门 | 窗口 | 其余姿态、左下肢、右下肢 | V/T token | 无 | LR vs B |
| TLR 组合门 | 逐帧 | 其余姿态、左下肢、右下肢 | V/T token | 无 | TLR vs T、LR |
| Q 条件输入 | 逐帧 | 同 TLR | 视觉更新后的运动表示与 T 注意力输出 | 无 | Q vs TLR |
| S 收益监督 | 逐帧 | 同 TLR | 同 TLR | 离线相对收益标签 | S vs TLR |

所有组均保留独立根速度门。T/LR/TLR 构成时间与部位两因素对照；Q/S 分别以 TLR 为固定参照，不在 test 上挑选参照。Q 与 S 首轮不组合，避免条件输入与监督改动相互混淆。Cv4/Cv7 继续作为单门/无门的辅助参照。

## 4. 时间门 T

取消门输入的窗口均值池化，复用原来两个 `2d→d→1` MLP，逐帧计算：

```text
x_t = cat(v_tok_t, t_tok_t)                 # (B, tw, 2d)
g_vel_t  = sigmoid(MLP_vel(x_t))            # (B, tw, 1)
g_pose_t = sigmoid(MLP_pose(x_t))           # (B, tw, 1)
```

根速度 query 使用 g_vel_t，全部姿态 query 使用 g_pose_t。门参数量与 Cv5 相同，仍在六层间共享。t_tok 已经过 FootConvEncoder 的时间建模，不将该版本描述成无上下文的独立帧判断，也不宣称它是在线因果模型。

首轮不加平滑损失。若逐帧门导致预测抖动上升，再增加 5 帧段门对照：将 20 帧分为四段，每段平均 x_t 后输出门并广播回本段；其余条件与 T 相同。门值抖动仅作解释，是否需要段门由运动误差和 Jitter_pred 判断。

## 5. 左右门 LR 与组合门 TLR

左右下肢分别使用独立门，分组严格按 `PART_NAMES` 映射，不另写关节序号体系：

| 门 | 接收位置 |
| --- | --- |
| g_vel | 独立根速度 query |
| g_other | 姿态 root、torso、headneck、l_arm、r_arm |
| g_left | 姿态 l_leg、l_foot |
| g_right | 姿态 r_leg、r_foot |

LR 使用窗口均值 `mean_t(x_t)`，四个门在窗内固定；TLR 使用逐帧 x_t，四个门逐帧输出。二者都展开为 `(B, tw, 10, 1)`，沿用现有乘法位置，不改变注意力 memory。

左/右门的 MLP 结构与原姿态门相同。新增左右门初始化时复制原姿态门参数，再独立学习；新增参数初始化不得改变原共享模块的随机初始化。LR 的相同门初始化应复现 B，TLR 的相同门初始化应复现 T。

左右门首轮共享原 V/T 输入，仅增加输出决策的部位粒度。它仍会读到双脚混合证据；若结果提示来源混淆，再另行设计保留左右 memory 的版本，不混入本轮结构对照。单脚站立是主要解释案例；开合跳左右相位不能预设为错开半周期。

## 6. 门的条件输入 Q

“增强 g”首先指提高决策信息与选择自由度，不指把数值整体调大。Q 保持 TLR 的四组逐帧门、MLP 尺寸与六层共享方式，只替换门的输入。

第一层解码器完成 query 自注意力和 V 交叉注意力后，得到 h；再计算尚未乘门的 T 交叉注意力输出 a_T。按上节四组在同一帧内分别平均 query，形成：

```text
u_t,k = cat(mean_query(h_t,k), mean_query(a_T_t,k))  # (B, tw, 2d)
g_t,k = sigmoid(MLP_k(u_t,k))
```

根速度组仅有一个 query。第一层据此计算的门用于本层，并传给后续五层复用；不同时增加逐层独立门。梯度正常经过 h 和 a_T 回传，缺失模态仍由存在掩码硬关闭。

Q 检验的是：门是否需要知道“当前运动部位在视觉更新后处于什么状态，以及 T 将提供什么修正”。它不能单独区分 h 与 a_T 哪一路更有效，首轮将这对条件输入作为一个完整改动评价。

## 7. 显式收益监督 S

S 保留 TLR 结构，在独立训练中增加相对收益监督。不直接移植现有 λ_cond：其他模型中的条件契约会惩罚健康视觉下的融合修正，V7 当前也未将它接入运动损失；它不等同于“健康 T 罚关门”。现有 λ_route 的向 0.5 正则同样不作为收益标签使用。

标签参考模型与 S 的训练主体分离，仅在生成标签时权重固定。标签只来自 train split：对已完成的 TLR 参考模型，在相同 VT 训练窗口分别执行正常门控和单组关门，比较该组关注的 GT 误差。四组分别干预，其余门保持参考值；不在推理时使用 GT，也不从 val/test 生成训练标签。S 使用独立、从零初始化的模型完整训练，编码器、共享解码器、输出头和门均可训练；不能用加载参考权重后只加组件或短暂微调，代替 S 的正式实验。

- 根速度组：逐帧使用 `L_vel,t = mean_xyz((v_hat_t - vel_gt_t)^2)`，D_t,vel 为关门与正常运行的 L_vel,t 之差；v_hat 与 vel_gt 均为 m/s，损失单位为 (m/s)²。不得先对时间求均值，也不使用 cumsum 后的轨迹误差构造逐帧标签，避免早期速度偏差累积支配后续标签。累积轨迹误差继续用于原训练损失和最终验收。
- 左/右下肢组：使用同侧腿足关节的骨盆对齐 FK 位置误差。
- 其余姿态组：使用全身骨盆对齐 FK 位置误差，包含骨盆旋转对下游关节的影响。

逐帧门在多层自注意力中可能影响其他帧。标签干预的首版定义为“同窗内整组关门”，比较逐帧误差，近似该组的时间收益分布；不将其宣称为单个 g_t 的独立因果效应。改用根速度误差消除了 cumsum 的额外累积，但没有消除解码器本身的跨帧耦合。

### S 启动前的硬决策点

TLR 完成后，先在 train split 的原训练窗口网格上进行一次完整的正常/逐组关门干预。开启 eval 模式并关闭随机增强，重复相同前向估计数值噪声；不以滑动平滑后的图判断标签是否可用。落盘保留逐窗逐帧四组门值、对应的 L_on/L_off/D、session/frame 索引及有效掩码，并关联参考 checkpoint、数据版本和干预组。门值在重叠训练窗内可不同，必须保留窗口身份，不能将重复帧冒充独立样本。

逐组汇总门值分位数、窗内/窗间变化，以及 D 的分位数、均值、方差、正/负/近零比例和会话覆盖。门值记录回答“门是否随输入变化”，D 回答“正常注入与关门是否产生可监督的收益差异”；门值变化本身不等于 D 有信息，门值近常数也不自动判为无信息。

每组必须预先登记同单位的数值噪声界限 n_k、最小有意义效应 ε_k、最小有效标签比例及跨会话覆盖要求；ε_k 应高于数值噪声，不能在看到 test 或为让 S 通过后反向降低。数值噪声由 train 的重复前向估计，最小有意义效应按指标精度定义；这些阈值尚未登记时不得启动正式 S。

| 检查 | 通过要求 | 未通过的处理 |
| --- | --- | --- |
| 数据与数值 | 帧/窗口身份完整，误差和 D 有限，重复前向差异在噪声界内 | 报告并修复，不生成替代标签 |
| 绝对效应 | `abs(D)>ε_k` 的标签比例及会话覆盖达到预登记要求 | 不用自标准化放大近零噪声 |
| 选择信息 | D 的有效变化超过噪声，窗内变化在多个会话中出现；按会话重采样检查分布稳定性 | 若仅常数收益或只在会话间变化，不声称支持逐帧选择监督 |
| 标签分布 | 固定温度后，标签有超出噪声的有效变化，非几乎全为 0.5 或同一常数 | 不启动对应的逐帧收益监督 |

不能仅以“方差非零”通过：D 的方差不等于有效信号。若 D 变小且 τ_k 同步取其标准差，D/τ_k 不一定趋近零，反而可能把小噪声放大为伪选择标签。因此先检查原单位下的效应和变化，再构造 `y_t,k = sigmoid(D_t,k / τ_k)`；温度设为 `max(std_train(D_k), ε_k)` 并固定不变。非有限统计直接报错；标准差为零时判为选择信息不足，不靠温度下限绕过门槛。

四组均通过才启动本方案定义的完整 S。部分组通过时，先报告逐组结果；若继续做部分组监督，必须单独登记监督范围和损失掩码，不能静默省略后仍称为完整 S。没有可用标签时停止当前参考模型的 S 标签路线，保留 B/T/LR/TLR/Q 的独立实验。这个结果只能说明当前参考模型及标签构造不适用，不说明门监督方向不可行。

### 训练与参考模型依赖

标签表示参考模型中的相对收益，不是最优门幅度。参考 TLR 已与原门共同适应，可能没有学出潜在的有益 T 修正；即使学生从零训练，固定标签仍继承这一偏差。S 只能检验“该参考模型生成的收益监督是否有帮助”，不能单独检验所有显式门监督。

S 对 VT 条件的四组门计算辅助 BCE；V-only 无 T 注入，T-only 缺少 V，均不使用这套 VT 标签。监督权重通过 val 比较，包含零权重对照；尺度、候选权重与选择结果须在 test 评估前固定。原始运动/轨迹/接触损失保留。

若标签门槛未通过，或完整训练后 S 无改善，先分别核查标签信号、辅助损失与运动损失的梯度量级/方向、学生是否拟合标签及 val 表现，不以一次负结果收口。随后换用无门控的 Cv7 作参照（该组干预 = 该组 T 支路输出置零，标签为零门控偏置的裸 T 贡献），再使用独立种子的完整 TLR 参考模型重复标签可用性检查；必要时用按 val 规则选定的中期 checkpoint 检查参考依赖，不能按 test 挑选参考。若不同参考仍缺少可靠干预差异，应改进标签构造后另立对照，不能靠几次小微调宣布方向无效，也不能无限调参后只保留成功结果。每次未通过及负结果都保留。

这项门值与 D 的联合落盘用于 S 的可行性决策及标签构造，不作为时间门或左右门实施前的诊断门槛；不安排固定门值扫描来决定结构优先级。

## 8. 训练安排

1. 先实现并验证 B/T/LR/TLR，使用相同初始化规则、数据顺序和训练配方从零训练。初始 B 固定为 V7_Cv5_s1（当前数据层，ckpt_last）；若生产代码或有效训练配置已改变，补跑同条件 B，不能混用不可比基线。
2. 首轮统一 seed=1、740 epoch、三条件枚举，主比较固定 ckpt_last，与当前 E6 对齐。损失权重、学习率及调度、warmup、batch size、接触标签版本、split、有效帧和 SMPL 支持策略均以 Cv5 实际运行记录为准，不能只按旧设计文档推定。
3. B/T/LR/TLR 完成后，以固定 TLR 为参照完成 Q；先执行 §7 的 train 门值与干预收益联合检查，通过硬门槛后再从零完整训练 S。S 的标签生成、参考复查与辅助权重选择计入额外训练成本，不把 S 与基础组描述成计算量完全相同。
4. 根据 val 确认的候选补跑 seed=2、3，并为这些种子训练匹配的 B。单种子只作筛选；主结论报告各种子与会话间差异，不把相邻帧当作独立重复实验。

本轮不将新门接在旧 checkpoint 上短暂微调后，与从零训练的 Cv5 作正式结论比较。若做微调探索，结果单独标注。

## 9. 评估与判定

主评估沿用 E6 的有效帧、左右脚分别统计、接触相位和踝足 MPJPE，同时报告每个新模型自身的 V/VT 误差。沿用当前 E6 的 Δ = VT−V；现有汇总 CSV 的 `G(V−VT)` 列标题与数值方向不一致，读取时按实际数值解释，不反转数据。

对每条会话、每侧有效帧计算退化量 H=`mean(max(Δ, 0))`、收益量 A=`mean(max(−Δ, 0))` 及 VT 绝对误差 E。收益越大越好，退化与绝对误差越小越好。候选与参照必须在同会话、同侧、同 frame_id 和相同有效掩码上配对；帧覆盖不同先报告，不通过静默取交集改变评分集合。

主判据是逐会话配对差值与胜/平/负计数。对候选 M 与参照 R（例如 T 与 B），定义：

```text
dE_s = E_M,s - E_R,s       # 负值有利
dH_s = H_M,s - H_R,s       # 负值有利
dA_s = A_M,s - A_R,s       # 正值有利
```

先逐侧报告差值，再将同一会话左右侧等权合并形成一个会话结果；36 条会话才是 36 个配对单位，不能把双脚、帧、窗口当作额外独立会话。每个指标分别报告会话胜/平/负数量、配对差值中位数及四分位范围；会话等权的均值差作为辅助。各指标的平局容忍带按误差分辨率在 test 前固定。另报告“E 改善且 H 不恶化、A 不下降”的联合通过会话数，不能将三个指标的胜场相加。

不确定性使用会话为单位的配对 bootstrap 95% 区间；多种子各自保留配对关系，报告各种子的计数与差值，不把同一会话的不同种子视为新会话。帧相关性使帧级置信区间过于乐观，禁止用帧重采样替代会话重采样；同一被试的会话仍有相关性，36 会话区间不是跨被试泛化显著性的证明。

阶段统计沿用现有会话内均值再跨会话均值口径，并补充同会话同侧同相位的配对差值及胜/平/负计数；未出现的阶段保留为空并报告实际参与会话数，不补零。walk/run 在当前 test 各只有一个会话，分别展示配对结果，只作描述，不单独给动作层面的显著性结论。总体会话统计与动作分组统计同时报告，不用总体均值掩盖动作差异。

| 观察结果 | 可支持的判断 |
| --- | --- |
| T 相比 B 保留更多收益，退化受控且 VT 更准 | 时间粒度提供有效选择能力 |
| LR 相比 B 在左右需求不同的阶段改善 | 部位粒度提供有效选择能力 |
| TLR 同时优于 T、LR 的相关指标 | 两种自由度有组合价值 |
| Q 或 S 相比 TLR 改善上述权衡 | 条件输入或收益监督提供额外价值 |
| 收益与退化一起变大，VT 无改善 | 主要是触觉影响增强，尚未改善选择 |
| Δ 更接近零，但收益下降、VT 无改善 | 仍在整体收缩，不能判为成功 |

主结论使用完整 canonical test；S14072、S14071、S13071、S13072 与单脚站立作为解释案例，不据此选模型。总图的双脚平均和 20 帧平滑只用于展示，验收使用有效帧上的分脚未平滑数据。

同时复评 E2 三条件与 E5 既有遮挡档，报告全身/足部误差、轨迹、滑步、穿透及 Jitter_pred。E6 骨盆对齐指标不能评价根平移门的价值；也不能用 E6 足部改善代替全身和 T-only 验收。若存在收益与其他指标的交换，列出交换，不事后改变成功口径。

门值可随推理记录以解释新结构；TLR 在 train 上的逐帧门值与逐组 D 联合落盘是 S 的必需步骤。不设置“g 必须更大”或“必须严格按接触开关”的成功标准。任何帧数、帧号、valid、缺文件或标签版本不一致均先报告，禁止补齐、截断或伪造；仅在原协议明确的有效帧上评分。
