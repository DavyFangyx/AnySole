## 4. 机制判读

1. **翻转（flips >30°）**：Cv5 198 次（92% 在窗口边界）→ 锚链/AR 反馈 = 0 次。
   "0 flips" 以运动能量换取：AR 欠幅 −60%、v4 过幅 +78%（幅度对照见续写 v4 文档 §12）。
2. **暴露偏差**：AR 携带版 teacher-forced val T2M PA 18.1 → 串行评估 114.6；
   scheduled sampling（ARSS2）修回 90.4 / drift 22.1。
3. **观察窗**：AR2 对窗长单调改善（obs20→40→80：PA 133→110→92、drift 41→31→18）；
   AR2M 的拐点在 obs80（91.6→90.4→**82.8**）——**AR2M+obs80 是 V7 全家族唯一回到老线水平的组合**
   （≈V4_Av4 82.9 / V5_Av5 83.8）。gb 增强对 Cv5 有效（89.4→87.3、V 行无损）但对 AR2M 有害（91.6→93.9）。
   AR2 对窗长敏感且单调（obs20→40→80：PA 133→110→92、drift 41→31→18、trajRelATE 840→746→635）；
   AR2M（只接力状态、不接力完整姿态）对窗长不敏感，且 obs20 即达 91.6——
   状态级接力 + 相对运动是更优的信息结构。
4. **v4 系附带收益**：GroundPen Cv5 42.1 → Ctx4 20.3 / Ctx4R 16.2 / Ctx4B 12.8。
5. **AR2 选点口径**：teacher-forced 单步 val 不可作选点判据（2026-11-02 裁定）；
   AR2 sd2 的 R1Test T2M GIF 来自 00251（failed）非正式评估导出，抖动不代表正式矩阵。
6. **回归收口 vs 串行（2026-11-02 裁定）**：AR2R/AR2RT（双向并行前向 + 航向跨窗积分）
   实测：T2M PA 87.8 全现役最优但 drift 41.6 最差；串行 AR2M drift 19.9 但 PA 91.6。
   判读：**逐帧串行因果前向在压制航向漂移上做真活，不可省略**；双向前向利于姿态重建。
   VT 零初始化残差机制方向正确（VT−V 差 +7.0→+1.8，结构保证不亏部分兑现），
   绝对值被协议拖累。方向候选 = 混合协议（姿态走双向前向、Δyaw 走串行因果）。
7. **功能幅度审计（2026-11-02；输出性质，口径无关，不作指标排名）**：
   T2M 身体运动 RMS（去根局部、36 会话中位数，mm）：V3_Bv1（旧线）118.6 / Cv5 100.7 / AR2M 100.1 /
   AR2_tw80 44.6 / ARSS2 30.7，GT 111.5。翻转>30°：V3_Bv1 225 / Cv5 198 / **AR2M 3**。
   裁定：**T2M 自由生成幅度 ≈100mm 为硬验收门槛**（防「不动换不翻」假成功）；旧线满幅度但同样有翻转缺陷，
   AR2M 是现役首个同时满足 满幅度 + 3 翻转 + drift 19.9 的配置——「旧线姿态学习 + 现役稳定性」的合成已存在。

## 5. 根因判读（现役口径内）

- **旧线数字作废（2026-11-02 裁定）**：V3_Bv1 / V3_4a / V4_Av4 / V5_Av5 的训练/测试划分与数据处理已多次变更，数字与现役 test_brief 不可比；「历史最好 78-83」「无模型到过 70」等旧口径结论一并作废。现役口径下 T2M 基线 = Cv5 89.4，「70」在现役口径下没有任何证据。
- **航向系表征的现役证据（同数据同口径）**：AR2M（相对运动 + 状态接力，F2a 同源哲学）drift 19.9 vs Cv5 33.4、PA 91.6 vs 89.4 基本持平——「航向拆出目标空间」方向由现役数字支持，不由 V3_4a 旧数字支持。
- 续写线（锚链/残差/AR 反馈/SS）是在重新发明 F2a 哲学的一部分（v4 方案文档自认同哲学），最好成绩 ARSS drift 22.1 / PA 90.4。
- 路径候选：F2a 航向系表征移植回 V7 骨架（v4 锚点系残差 + F2a heading 拆出 = 同一件事的两半）。依据 = 设计逻辑 + AR2M 现役证据；如需对照，在现役口径下重训该表征，不重跑旧线。
