# V7 视觉热启动实验（V→T 状态接力，无 IMU 全局坐标）

日期：2026-11-02。状态：协议已实现（脚本+测试），正式数字在跑。

## 1. 主张

- T 无世界系绝对参照：yaw 不可观测（探针 20261101 裁定 test 无高于机会信号），
  roll/pitch 受重力与接触弱约束。T2M 冷启动的全局航向只能约定（ψ=0）。
- **V 热启动**：会话开头用视觉（V 或 VT）跑预热窗，建立全局坐标系与初始运动
  状态（外部航向状态 ψ、位置、姿态反馈），随后切换纯 T 独立续写——触觉在
  无 IMU 条件下获得宏观坐标量。
- 模态融合贡献：视觉提供一次性绝对参照，触觉提供持续性；同属联合训练一个
  ckpt 的正迁移。与 E7（动态可用性）的关系：单点切换的退化形态，状态连续性
  由 AR 外部状态接力承担。

## 2. 协议（visual_warmup_compare.py，2026-11-02 起正式口径）

| 项 | 口径 |
|---|---|
| 三臂 | cold_T（全程 T）/ V_to_T / VT_to_T |
| 预热 | prefix_windows=2（40 帧 = 1s @40Hz），窗口边界切换 |
| 状态 | ψ、位置、148/147 维反馈全部用预测值跨窗接力；无 GT 初始化、无 GT 锚 |
| 评分 | 只评 T 后缀（预热帧不入分，三臂同帧同掩码） |
| 历史 | V_to_T 臂预热期 T 历史不可用（obs_history 屏蔽）；切换后视觉 token 不进入观测窗 |
| 指标 | PA / MPJPE（骨盆对齐）/ RootOrientationError / RootOrientationDrift / Jitter / 身体运动幅度 RMS（防缩小动作换稳定）/ pa_first20 / pa_last20 |

验收判据：V_to_T 在 T 后缀的 drift/RO 显著低于 cold_T 且幅度不缩水；VT_to_T
作增量参照（预热期触觉是否再贡献）。测试 tests/test_visual_warmup_compare.py
（3 项，含相对 GT 重建与纯预测状态断言）。
