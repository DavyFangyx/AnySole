# V7 继承路线：VT 预热 → T 续写（实验定义，2026-11-03）

先定义后动手；本文件不含任何训练结果，数字出处见第六节。

## 一、要证明什么

- 机制（E9）：T 单独生成时世界系朝向没有参照；V / VT 预热得到的历史可以交给 T 续写。
- 判据：预热后 T 后缀的 RootOrientation（绝对误差），按会话初始航向偏移 |ψ0| 拆分。PA 只属于基本盘。

## 二、与「VT 不同窗长」路线的关系

两条路线相互独立。窗长路线（model_v7.py 的 v_cur：V 裁到当前窗、T 保留 obs_context）不在本文件范围；继承路线不依赖 v_cur，也不改 V、T 各自的窗长。

## 三、底座与结构

- 底座：V7_Cv5AR2M_tw80（obs80，11-02 权重）初始化；ar2_fb 保持 False（不走加性反馈）。
- 新增：零初始化读通道，把 VT 前缀的表示交给 T 帧；具体形式读代码后补。
- 主干冻结，只训读通道；无前缀时前向与底座逐位一致（断言验证）。
- 新模型走新文件或子类，不改 model_v7.py。

## 四、训练样本

- 一部分 T 样本带 VT 前缀（模型自己的 VT 前向，不反传），其余保持无前缀，冷启动能力不丢。
- 带前缀比例、前缀长度待定，在 val 上定，不用 test。
- 损失只打 T 后缀。

## 五、验收（看结果前定）

基本盘：
- 无前缀：T2M、V2M、VT2M 与底座逐位一致。
- 带前缀：后缀 PA 不劣于 cold_T；幅度在 [90,120]；翻转 ≤10。

机制：
- 后缀 RootOrientation 相对 cold_T 的变化，按 |ψ0| 拆成 ≥20° 与 <20° 两组。

防捷径：
- 评估加「复制前缀末帧」基线；带前缀样本上记 1−L_total/L_copy。
