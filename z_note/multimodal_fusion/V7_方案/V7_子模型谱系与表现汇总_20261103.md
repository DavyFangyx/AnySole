# V7 子模型谱系与表现（2026-11-03 改版）

## 评判标准：每个模型只看两件事

- 基本盘：T2M 冷启动 PA 达到基线水平（Cv5 89.4；常数均值姿态地板 104.14），幅度在 [90,120]，翻转 ≤10；V2M/VT2M 的 PA 与视觉基线同档（WHAM 47.8 / GVHMR 51.1 / SAM3DB 51.8）。
- 机制：该模型要证明的东西。E9 = V/VT 预热 40 帧后切 T 续写，世界系朝向可以交给 T，读数用 RootOrientation，PA 不作判据。
- 两项同时成立才算交付；机制成立但基本盘塌了，不算。

口径：test 36 会话，PA 单位 mm、越低越好。数字出处：z_note/现状.md、V7_技术路径全景与性能汇总_20261102.md、本轮零训练评估。AR2 族数字均为 11-02 权重（重训后的权重没找到），评估期先验高度 0.887。

### 图 2：AR2 / AR2M 相对 Cv5 改了什么

```
输入: V、T 流不再只有当前 20 帧，而是 [历史 + 当前]（obs80 = 60 历史 + 20 当前）   [改]
解码器: 自注意力加因果掩码（帧 t 只看 <= t）                                      [改]
读出（相对运动，替换 Cv5 的绝对姿态）:
  根 6D 强制去航向 -> tilt                                                       [改]
  dyaw_head -> Δyaw（逐帧航向增量）                                              [新]
  部位头 -> body 6D；根速度头 -> 航向系速度 v_head
  vis_yaw_head / vis_gain_head（读 v_tok，只有 V/VT 行有用）                     [新]
网络外部状态（没有 GT 平移锚）:
  ψ <- ψ + Δyaw；V/VT 行再 ψ += g * wrap(vis_yaw_ema - ψ)
  p <- p + Y(ψ) * v_head / 40
  世界姿态 = Y(ψ) * tilt

AR2 比 AR2M 多一条: 上一帧 148 维 [Δyaw, tilt/body, v_head] -> Linear -> 加到全部 query（反馈支路）
AR2M: 这条支路不建（ar2_fb=False），跨窗只传 ψ 和 p 两个物理量，姿态传不过去

注意: V/VT 行与 T 行共用同一套相对读出，没有绝对读出分支（读 model_v7.py:374-380、dataset.py:527 确认）
```

### 图 3：E9 暖启动（评估协议，不改权重）

## 一、主推模型：V7_Cv5AR2M obs80（cell：V7_Cv5AR2M_tw80_s1）

相对 Cv5 加了什么：因果掩码，相对运动表征（Δyaw、去航向 tilt/body、航向系速度），外部航向状态 ψ 与自由积分位置，观测上下文 80 帧；没有反馈支路。

设计思路：T 观测不到世界系朝向，所以把全局量拆到网络外部的状态里。有视觉时由视觉初始化，无视觉时由预测增量累积。T 吃长窗，因为 T 学的是步态相位。

| 项 | 数字 | 判 |
|---|---|---|
| T2M PA | 82.76（Cv5 89.4，Step2Motion 82.58） | ✓ |
| T2M 幅度 / 翻转 | 108（GT 约 111）/ 1 次（Cv5 198 次） | ✓ |
| V2M / VT2M PA | 48.41 / 51.05，与视觉基线同档 | ✓（比 Cv5 差 10 左右） |
| 机制 E9（预热期视觉增益固定为 1，声明协议，无调参，test 单次） | RootOrientation 43.5 → 26.7；PA、幅度、Jitter 逐位不变 | ✓，但收益集中在初始偏移 20° 以上的 5 个会话（112.9 → 28.8），其余 31 个会话持平 |

为什么主推它：

1. 它是唯一两项都过的：基本盘过关，又有跨窗外部状态，E9 能做。
2. Cv5 系的 V/VT 更强（37.5/40.5），但没有状态接口，暖启动脚本对它直接报错，E9 做不了。它的 GlobalMPJPE 和 traj_ATE 还带每窗 GT 平移锚，和 AR2 族不可比。
3. 凡是加了姿态反馈的变体，基本盘都塌了（见第二节）。

它还没过的基本盘缺口：

- V2M Drift 偏高（obs20 为 17.1，视觉基线 3.9–10.4），约 79% 来自上面那 5 个大偏移会话，其余 31 个会话为 4.5。
- Jitter 1303（GT 190）。
- 竖直漂移：每会话固定的竖直速度偏置，原因在积分链，没修。
- GlobalMPJPE、traj_ATE 要换成 traj_ATE@0.5s 才能和 Cv5 比。
- 单种子，权重是 11-02 版。

在训候选：V7_Cv5AR2MP（相对 AR2M obs80 只加一项：T 档 30% 有历史的样本改成「历史 V 真实、当前窗 V 为 null」）。训练进行中（21:05 读到 epoch 113），epoch 110 的 val PA：T 75.73、V 55.16、VT 54.71。V/VT 目前高于 AR2M obs20 的最终 val（V 39.2、VT 42.9），但才训到 epoch 110 且上下文不同（obs80 对 obs20），不下结论，需要继续看。替换主推的条件：V/VT/冷启动 T 的 val 不劣于 AR2M obs80，幅度保持在 [90,120]，后缀朝向有改善。
