# V7_Cv1 方案（候选 C：A + 窗口级可靠性路由；2026-10-25 设计，已实现、未发射训练）

结构同 [V7_A方案.md](V7_A方案.md) §2（独立证据 + 共享生成，三条件硬关闭分支）；本方案只新增一种机制——**窗口级 T 信任门**（模型设计思路 §3 候选 C 第一版）。未列章节与 A 一致。

## 1. 设计主张与机制规则（新增部分）

- **按可靠性路由信任**：根据两路证据的质量按窗口调整对 T 的信任；第一版 = 窗口级（tw 即窗口），不假设 2051 维视觉缓存含有足部可见度（更细的部位可见性需相应输入支持）。
- **推理只读输入与预测质量**：GT 误差只允许用于训练标签与离线诊断，不能成为运行时「视觉健康选择器」——本版门只读 v_tok / t_tok，满足可部署要求。
- **v1 无显式质量标签**：门端到端由主运动损失学习（质量估计的显式监督——预测误差 / 人为退化标签——留待 v2 接入；λ_route 键位已预留）。

## 2. 模型结构（新增部分）

- 新增参数：`route_mlp`（Linear(512→256)→GELU→Linear(256→1)）。
- 数据流新增一步（同 A §2.1 之外）：
  ```
  g = sigmoid(route_mlp(mean_t(cat([v_tok, t_tok]))))  # 两路 token 窗口均值池化 → (B,1)，
                                                       # 每训练窗口一个标量门（窗口级原义，
                                                        # 2026-10-25 评审修订），bias 0 = 中性 0.5
  解码器每层 T 交叉注意力输出 × g.view(B,tw,1,1)        # 逐窗缩放（与 t_present 硬关闭叠加）
  ```
- `out` 额外暴露 `route_gate`（监控 / 损失）。

## 3. 训练（新增部分）

- 采样/优化/checkpoint 规则同 A §3；**λ_route = 0**（v1 纯端到端，无显式标签）。
- 预留键位：λ_route > 0 时启用向中性 0.5 收缩的正则（防止无监督塌缩到 0/1 两端）；v2 接入质量标签后替换为 BCE 监督。

## 4. 评估（预注册口径，无结果数字）

- 验收顺序/十指标同 A §4；额外检查：
  - **门的行为**：cam3 轴上 g 是否倾向压 T（V 可靠）、occ 轴上是否抬 T（V 退化）——与「可靠性路由」的期望方向一致才作数。
  - **敏感性不等于正确性**：同一窗口换真实 T 的输出变化只证明门放行了 T，不证明放行得对；正确性由 Δ（VT−V）与干预行判定。
  - **校准问题**（模型设计思路 §3）：若后续引入方差做融合，必须说明校准；本版门是学出来的标量权重，不是误差条。
