# V6_1A 方案（模态平衡训练，2026-10-19 设计；机制已实现，首批对照 2026-10-20）

**定位：训练机制（数据增强 + 损失配方），不是模型结构——与结构线 V4_1A（`V4_1A方案.md`）、V5_1A（`V5_1A方案.md`）及现行 G/H 线正交组合：结构线回答「T 在哪里兑现」，本方案回答「T 怎么被训练出来」。**

外部专家训练机制路线的三条腿按项目侧现状分级：腿① 多分支损失与 H v2 aux 重建（队列 00548/00549）同构——登记引用，不重复设计；腿② 结构化丢弃为净增核心，落在 HRNet 特征缓存数据线上（已实现，§2/§5）；腿③ 两阶段已被 V3_3C/V3_3D 判死——按已裁定条目收录为规则，不给新设计。

## 1. 设计主张与机制规则

**理念：「分支独立可解，失效态常在。」** 训练时系统性地制造模态失效状态（V 遮挡/缺失、T 缺失），用损失配方强制每个分支在失效态下仍独立解决其可观测子任务；评估三条件协议不变（同一前向三种读出，与载体无关）。

| 规则 | 证据 |
|---|---|
| 分支独立规则：T 分支损失只监督 T 可观测子任务（接触 + 压力重建）；V 分支在载体冻结继承（E v2.1 底座）下结构上独立可解（V 流即主输出塔） | 接触可读性探针 B（F1 0.93–0.98）；命题 2 载体依赖：T 编码器监督收窄为「仅接触」后足部线性信息消失，aux 重建恢复（B 配方已验证） |
| 失效态规则：T 的有效性条件 = V 失效与地面参照量——训练常驻 V 失效态，模型才学会用 T | V 削弱实验：occ050（下肢全失档）踝足部 Δ 翻转为真增益（主线 −3.57、PA −0.04 持平） |
| 落地规则：V 输入 = 每帧 2051 维 HRNet 特征缓存（2048 + 相机几何 3），不是 RGB——训练侧遮挡只能发生在特征缓存级：occ010 独立缓存混合 + 整窗置零 | V4_1问题描述 §1；dataset.py：V_feat (n_frames, 2051) 逐会话缓存装载，无空间结构 |
| 判死规则：冻结基底 + 输出加性修正的组合不再作为候选结构（任何输出空间封顶 ~−1mm） | ridge 界 + V3_3C 训练兑现 +0.84/+0.03、V3_3D ≈ 0（8 配置套件）。转写：① 冻结基底 + 输出加性修正不再作为候选结构（姿态/位置空间皆然）；② 两阶段结构形态判死，「每个分支独立可解其可观测子任务」作为训练配方保留；③ 「目标 = x_gt − x_V」的残差监督保留给联合读出结构线（V4_1A 读出侧），由 V4_1A 预注册 |
| 范围规则：本方案只动训练数据与损失，不新增模型组件（除腿① 已登记的 aux 重建外） | — |

## 2. 训练机制（模型结构零改动）

### 2.1 数据流（增强开关落在数据线的位置）

```
V 缓存 cam3（2051/帧） ──┐
                          ├─ occ_mix（窗口级采样 p_occ）─▶ V_feat ──▶ 载体 V 流（不变）
V 缓存 occ010（2051/帧） ─┘
condition_inputs 层（train.py 既有，整窗置零）：
  V_feat ── null-V（p_nullV）──▶ v_enc
  T 输入 ── null-T（p_T）───────▶ t_enc
T（108 维压力）──▶ t_enc ─▶ t_tok ─┬─▶ 接触头 ─▶ L_contact（λ=1.0，air 加权 2.0）
                                    └─▶ 压力重建头 ─▶ L_trec（λ=0.1，H v2 已登记）
V 流 ─▶ 姿态/轨迹塔 ─▶ L_pose 3.0 + L_traj 1.0（主损失；冻结继承时 V 分支独立可解为结构保证）
```

### 2.2 组件

**a) occ_mix（净增，dataset 级窗口采样）。** occ010 是独立特征缓存（bbox 底部 10% 涂黑后重跑 HRNet，`model-input://AnySole/adapter_v1/visual/hrnet/cam3_occ_lower010`），与 cam3 缓存同帧轴、同窗口网格（共享 facts 帧轴，G 同口径）→ 同窗可替换。数据线 = cam3 ∪ cam3_occ010 共享窗；batch 内按 p_occ 逐窗采样 occ 缓存（采样粒度 = 窗口，整窗一致，在 `__getitem__` 前决定）。参数预注册：**p_occ = 0.2**（专家区间 0.2–0.3 的下端；0.3 作扫描记录）。足部特征级丢弃裁定：HRNet 特征缓存无空间结构（2051 维无部位标注）→ 足部区域的 V 失效由 occ010 缓存承载（遮挡档口径 010 = 足部），接入面不设特征维裁剪开关；可扩展档位 occ020/030/050 缓存已齐（足+踝/到膝/下肢全失），登记不进 v1。载体缓存口径中立：冻结继承时单一 cam3 载体即可（occ 窗的 V 流出错 = 训练 T 的目标状态，冻结同时保证 V 流不被 occ 窗损伤）；从零训练载体时 occ 窗直接训练 V 的遮挡鲁棒性。

**b) 整段 V → null-V 注入（机制已存在，引用）。** 现有 null 机制两层：输入置零（train.py `condition_inputs` 层，H 口径，无学习参数，H 已用 10% 训练 T2M null-V 先验）与编码后 learned null_v token 替换（`ModalEncoders` 编码后层，B 线口径）。裁定：默认 = 输入置零；learned null token 有已登记失败形式（探针 3：null_v 被当常数偏置用，「错用缺失流零代价」），不作默认。参数预注册：**p_nullV = 0.1**（H 现行 10%）。

**c) T 丢弃 → null-T 注入（机制已存在，引用）。** T_raw/T_phys 输入置零（condition_inputs 层，同 V）；B 线 config_probs 采样路径（`--dropoutVT`）为同一机制的既有开关形态。参数预注册：**p_T = 0.1**。T-drop 样本上接触头照常前向、接触损失照常计算——null 输入的接触读出被训成标签先验（与 H null-V 先验同构）。

**d) 损失接口（losses.py 既有权重键，无新增项）。** `lambda_contact`（1.0，air 加权 `lambda_air` 2.0，G 生产值）、`lambda_trec`（0.1，B 已验证配方；模型侧 `t_rec_head` 已实装于 model_v3h.py，state dict 与 v1 逐键兼容——即腿①，与 H v2 aux 重建同构，登记不重复立项）、`lambda_pose`（3.0）、`lambda_traj`（1.0）。

**e) 模型侧改动：零。**

三开关逐窗独立采样，允许叠加；组合占比：无干扰 cam3 窗 = (1−0.2)(1−0.1)(1−0.1) = 0.648（精确；0.63 为 occ∧nullV 互斥近似，差 = 双计项 0.018）。增强开关全部训练侧；评估三条件面板不变。

### 2.3 三条件开关

| 条件 | 读出 | 训练时可见的失效态 |
|---|---|---|
| V2M | V 流（载体定义） | null-T 窗、occ 窗、null-V 窗 |
| VT2M | 结构线融合读出 | 全态窗联合训练 |
| T2M | 载体定义（H 口径 null-V 先验；E/G 口径 T 先验流） | null-V 窗 = T2M 训练样本 |

V6_1A 的增强开关全部训练侧；评估三条件 = 同一前向的三种读出（回归载体，config_id 被忽略），语义不因本方案改变。

## 3. 训练

- **数据**：cam3 ∪ cam3_occ010 共享窗（G 同口径）；occ_mix p_occ=0.2（窗口级）；null-V p_nullV=0.1；null-T p_T=0.1；三开关逐窗独立、可叠加。
- **损失**：L = λ_pose·L_pose + λ_traj·L_traj + λ_contact·L_contact + λ_trec·L_trec（选点 3.0/1.0/1.0（air 2.0）/0.1）；腿② 不新增损失项。λ 预注册单点（继承现行生产值；不设网格）；下一选点 λ_trec=0.3 登记为记录。
- **载体与初始**：按结构线载体规则（默认回归底座，三条件协议与载体无关）；V 流冻结继承 E v2.1 时 occ 窗只训练 T 侧（cam3 → `V3_3E_f6_soft`，V2M PA 38.58 账本；λ_V 不单列——V 流即主输出塔为结构保证，从零训练下该分支 = 主损失本身）；从零训练按独立性规则。
- **超参**：继承结构线载体现行配方（740 ep、batch 256、lr 1e-4、tw 20、stride 20）——V6_1A 只加增强与损失选点，不动其余，保证 A/B 干净。
- **对照**：增强全关（p=0）同配方 = V4_1/V5_1 载体现行基线（已训已测，B1 参照）；occ_mix / null-V / null-T 单开关消融各 1 run（登记，未跑）。
- **评估**：cam3 + occ010 双配置三条件统一面板（G/H 同口径），which=best。
