# T 增强三组实验方案（2026-10-21）

目标：把 T 的"足-地界面子空间"做厚，验证增强后的 T 能否在 cam3 常规
条件上兑现。三组：维度 2（显式物理特征）、维度 3（D_Test8 监督）、
原模型的足-地界面指标评估。**兑现判据 = T 归因**（--z-src V 干预确认），
禁止 floor 燃料（无 GT floor 通道、无锚-几何）。

## 1. 基座与命名

- 基座 = **V5_1A**（z 专家 + PoE = 唯一被干预确认的 T 兑现结构）；
  数据轴 = **offset 修正轴**（当前生产轴），cam3。
- 新增两个编号：
  - `V5_1_tphys_cam3_offfix`（维度 2）：T_phys 12→20 维显式物理特征；
  - `V5_1_d8_cam3_offfix`（维度 3）：足-地监督（CoP 重建 + 着地模式分类）。
- 参照 = `V5_1_cam3_offfix`（已训，V2M PA 37.07 / VT2M 37.06）。

## 2. 维度 2：显式物理特征（T_phys 12 → 20）

现状（`anysole/data/pressure.py` `_foot_phys`，每足 6 维）：CoP(x,y)、
合力、包络、空间梯度均值、合力一阶差分。**缺失**：

| 新增量（每足） | 物理含义 | V 物理不可达 |
|---|---|---|
| 接触面积 | 激活格数归一化 | ✓（视频看不到压力分布） |
| 凸包长轴（2 维） | 着地模式：长轴方向（跟-尖投影）+ 椭圆率 | ✓ |
| 双足力比 + CoP 距离（2 维，全局） | 站立期左右重心转移 | ✓ |

- 实现：`physical_tokens` 加 `t_phys_v2` 分支（12→20 维，向后兼容）；
  dataset 加 `t_phys_v2` 旗标（随 ckpt config 记录）；`FootConvEncoder`
  的 feat 输入维按旗标构建（STRUCTURE 登记 `t_phys_v2`）。
- 改动面：`pressure.py` / `dataset.py` / `foot_encoder.py` / 入口
  `v5_1.py` / 两处 registry / z_gen。

## 3. 维度 3：足-地监督（D_Test8 口径）

监督目标 = 从 t_tok 读出的三个头（多任务，命题 2 教训：不许单任务）：

1. **触觉 CoP 自重建**（λ=0.1，v2 aux 先例）：从 t_tok 重建 T 侧 CoP
   ——自监督、无 GT 口径风险；
2. **着地模式三分类**（heel / midfoot / toe strike）：标签从 T 侧压力
   激活序列派生（落地事件首触区），`derive_phase_gt` 同源逻辑；
3. **GT CoP 回归**（D_Test8 口径，g0 地面）：SMPL archive 正演
   `foot_heat + cop_from_grid` 现算。

**已知风险（审计 A/B/C）**：GT CoP 在网格轴俯仰下钉趾端（类型 C）、
2cm 阈值卡鞋底（类型 B）——GT CoP 回归头可能学到退化目标。裁定：
头 3 以 λ=0.1 起步、与头 1 同权不高于自重建；若训练后 GT CoP 头输出
方差坍缩（钉趾端签名），头 3 判退化、自重建头为准——**以数据为准，
不预设**。

## 4. 原模型足-地界面评估（零训练）

对已训模型（V5_1_cam3_offfix、V4_1_cam3_offfix 及两个新模型）加
**足-地界面指标组**（eval 面板扩展，零训练）：

- 接触：F1 / recall / air_recall（f6_soft 口径）；
- CoP：T 侧 CoP vs GT CoP 的逐帧误差（g0 口径）；
- 物理：穿透 / 滑步（现行口径）；
- 着地模式：三分类准确率（T 侧派生标签）。

## 5. 预注册判据（cam3，test，offset 轴）

1. 安全：VT−V 的 PA 族 ≤ +0.1（零税）；
2. 主判据：足-地界面组（穿透/滑步/CoP 误差）VT−V 为负，**且
   --z-src V 干预确认 T 驱动**（Δ 只说明"变了"，干预说明"谁变的"）；
3. 参照对照：与 `V5_1_cam3_offfix`（T_phys=12、无足-地监督）逐行对比
   ——增强的净贡献 = 新模型 − 参照；
4. 无 floor 燃料：模型不消费 GT floor（V5_1A 结构本身无锚）✓。

## 6. 训练与队列

- 规格与 V5_1 一致（740ep、batch 256、VT 90% / V 零化 10%、
  λ_trec=0 / λ_contact=1 / λ_phase=1 / λ_cop=1）；
- 队列：`v5_1_tenhance` 系列 conf（两个新编号，cam3+offfix）；
- 干预：训练完成后各跑一次 --z-src V 评估（判据 2）。

## 7. 实现顺序

1. 维度 2（数据 + 编码器 + 入口 + registry + 冒烟）→ 入队；
2. 维度 3（SMPL 正演监督管线 + 三头 + 冒烟）→ 入队；
3. 足-地界面评估面板（零训练，先行跑参照模型）。
