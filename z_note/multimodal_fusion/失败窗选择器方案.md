# 失败窗选择器方案（路径 B，2026-10-20 设计）

**定位**：推理侧窗口级路由——V 失败的窗口启用 T 通道，其余窗口纯 V。与结构线
正交组合：结构线（V4_Av1 / V5_Av1 / 3B 形态）回答「T 怎么兑现」，本方案回答
「**何时用 T**」。载体无关；本方案不自带 T 机制，与结构线组合后才有可测实体。

## 1. 前提验证（2026-10-20）

### 前提 1：T 的增益是条件性的（记录口径，待本方案干净测试）

`V削弱实验报告_offset前.md` §3：3B 载体上按 V 自身 PA 误差十等分，VT 在 d10（V 最失败的
10% 窗口）胜率翻转为 65.1%、Δ −7.16mm（上身 −8.9 / 踝足 −4.7），其余九成窗口
VT 一律劣于 V；难窗簇状分布（63 窗中 32 相邻对，集中在 19 个会话特定片段）。
判定实验总判读：3B 的绝对数字与难窗分层**不作证据、留作记录**——本方案即
该现象的干净测试。

### 前提 2：误差方向在任何窗口都不 T 可读（已证伪，探针
`z_note/probes/probe_v3_hv5_error_readability.py`，626 测试窗）

| 逃逸口 | 检验 | fracT |
|---|---|---|
| 平均掉条件特异结构 | 条件内拟合（TRAIN 同层 fit → TEST 同层 score） | p10 1.025 / t4 1.006 / a4 1.005 |
| 难窗口里可读 | V 误差十等分（d10 = PA 90.9mm） | d10 1.005 |
| 转折/变速瞬间可读 | 运动特征四分位最极端档 | t4 1.004 / a4 1.007 |

判读：**被路由的机制不能是「读误差的修正头」**（任何窗口都读不出）；前提 1 的
d10 增益（若复现）来自 T 的内容/状态通道，不是误差读出。

### 前提 3：难度可由窗口运动学预测（本次扫描副产品）

V 难度与运动学强相关（四分位 PA）：加速度 24.0 / 31.2 / 43.7 / **59.9** mm；
速度 25.3 → 56.7；摆动占比 27.1 → 53.3。→ **选择器的钥匙 = 窗口运动学统计量**
（推断时从预测/输入可得，不消费 GT、不消费 T 特征）。

## 2. 设计主张与规则

| 规则 | 内容 | 证据 |
|---|---|---|
| 钥匙规则 | 窗口级运动学统计门：加速度/速度/摆动占比（TRAIN 四分位阈值，零参数硬门起步；可训门作对照） | 前提 3 |
| 路由规则 | 路由对象 = T 内容/状态通道（V5_Av1 z 加权 / 3B 融合门控 / V4_Av1 修正分支开关，随结构线裁定）；**不路由修正头** | 前提 2 |
| 零税规则 | 未选中窗口 T 通道结构上关闭（纯 V 前向）——全窗零税为安全判据 | 零税结构保证 |
| 判据规则 | V 削弱实验 decile 协议：d10 Δ/胜率为主判据，全窗 Δ ≈ 0 为安全判据，occ010 双配置 | 前提 1 记录口径 |

## 3. 机制

- **钥匙特征（窗口级，20 帧）**：a_w = 骨盆速度差分量均值、s_w = 骨盆速度均值、
  w_w = 足速超阈占比；阈值 = TRAIN 窗口四分位（推断时同一统计量，零 GT 依赖）。
- **门**：硬门（q4 阈值，零参数）为起步形态；可训门 g(运动学, v_tok) 为对照
  （二分类头，训练标签 = decile ≥ d9 的 oracle 难度档）。
- **被路由机制（适配器接口，结构线提供）**：
  1. V5_Av1：难窗内 z 合成权重压向 T 专家（PoE 的硬门极端版）；
  2. 3B 形态：难窗内 T 流门控放开（易窗 T 流关闭）；
  3. V4_Av1：难窗内修正分支启用（注意：其修正头受前提 2 压制，预期低）。
- **评估层**：val 626 窗 decile 分层（vdegrad.py 协议扩展），报 d10 Δ/胜率 +
  全窗 Δ + 难窗簇一致性（相邻窗对同向率）。

## 4. 预注册判据（cam3 + occ010，val decile 协议）

1. 全窗 PA Δ ≈ 0（零税，安全判据）；
2. d10 Δ < 0 且胜率 > 50%（主判据，与 3B 记录同向）；
3. 门选中的窗口与 decile 定义的难窗重叠率（钥匙有效性诊断项，不作判据）。

## 5. 落地与依赖

- **依赖结构线开工顺序**（V4_Av1 / V5_Av1 队列 conf 已生成）；本方案 = 结构线的
  推理侧开关 + 评估脚本扩展（decile 协议已在 `results_display/script/vdegrad.py`）。
- 若结构线裁定为修正分支组合：v4 落点修复（踝 7/8，`V3_H设计错误裁定.md` §1）
  是前置条件；但按前提 2，该组合的预期收益已压至最低。
- 首选组合（按证据）：**V5_Av1 z + 难度门**——PoE 本身是软路由，硬门是它的
  难度加权极端版，改动最小、与前提 2 无冲突。
