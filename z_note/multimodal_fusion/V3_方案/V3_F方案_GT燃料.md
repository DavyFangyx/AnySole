# V3_Fv1 方案（2026-10-17；完整模型在现有采样器条件下归档，组件潜力未封口）

独立生成式模型（`anysole/models/common/model_v3f.py`）：**扩散运动先验（V 条件）+ T 采样引导（接触/地面能量）+ 推理侧接触精修**。三条件 = 同一采样器开关不同项。无融合 Transformer、无门控、无 null token。

**GT 应用位置（2026-10-19 审计标记）**：训练 = 扩散先验以 GT 姿态为标准监督（无 GT floor 燃料）；GT 会话 floor 作为地面参照进入**推理侧 T 采样引导的接触/地面能量项与接触精修**——指标提升与 T 无关的部分已标记。

## 1. 设计主张与机制规则

**「生成与观测分层」：p(x|V,T) ∝ p(x|V)·p(T|x)。** 先验负责流形（任何条件下都输出完整、合理的运动），观测负责把样本拉向与证据一致的区域；两者永不共享表征。
| 规则 | 证据 |
|---|---|
| T 的修正通道开在世界/位置空间 | 姿态空间装不下 T 的位置增量（−10.6→−1.26，~88% 转换损耗；T 信息量判定实验 §3.1） |
| V 与 T 不共享表征 | B 形态融合 Transformer 把 T token 混进 V 半段（Δ_fusion +13.06；全流程探针）——范围声明：证伪对象为 B 形态融合，不作融合路线一般性否定 |
| 缺模态去似然项，不塞 null token | 探针 3：null 流零代价误用 |
| 接触 = 已实证的 T 读出（F1 0.93–0.98，判定实验 B 过闸）；速度/足高探针无正信号 | 按探针下界保护：不设回归头是设计选择，不作「唯一读出/不可读」主张 |
| 学习式路由不可靠 | σ 门控不路由（全流程探针）——路由由物理量（接触）承担，无门控 |

## 2. 模型结构

### 2.1 数据流

```
状态 x = [姿态 144 | 根轨迹 3 | 软接触 2]（逐分量归一化，单位噪声扩散）

V (HRNet 特征) ──冻结 vonly 编码──▶ v_tok ────────────────┐
                                                          ▼
x_T (高斯噪声) ──▶ DiT 去噪器（帧 token + 时间步嵌入，对 v_tok 交叉注意力）
    ▲              │                                        │
    │ DDIM 50 步   └─ x̂0 ──(VT 开)─▶ E_contact+E_ground 梯度推进（每步）
    └──────────────┘                                        ▼
T (压力 108) ──foot_conv(从零)──▶ t_tok ──▶ 接触头 ──▶ contact_p
                                                        │
                                  采样末 ──▶ 精修层（Adam，只动根+腿链）──▶ 输出
```

### 2.2 组件

- **状态与去噪器**：x ∈ (B, 20, 149)，姿态用 6D、轨迹为 anchor 相对世界轴、接触为 f6_soft 连续值；逐分量 mean/std 归一后扩散（线性 T=1000 调度、x0 预测、DDIM 50 步）。去噪器 = 4 层 DiT 块（时间自注意力 + 对 v_tok 交叉注意力 + FFN；TimestepEmbedding 含 E1/E2 的 LayerNorm 教训）。
- **V 条件**：冻结 vonly 专才编码器（每配置一份：V3_Bv1_vonly / V3_Bv1_cam3_occ010_vonly，仅复制 `encoders.v_enc.*` 并冻结）；训练 10% V 零化 = 无条件先验（T2M 通道），无学习参数 null。
- **T 接地层**：foot_conv 编码器从零训练 + 接触头（f6_soft pos-weighted BCE，唯一监督 T 输出）；根速度/足高不设回归头（§1 规则 4）。
- **引导能量**（torch 可微、无参数，采样每步对 x̂0 求梯度）：E_contact（软 BCE 对接触头读数）+ E_ground（接触脚贴地 / 摆动脚防穿透）。v1 引导不含 E_support（滑步证据混杂：探针 +2.15\*、3D 位置修正 8/8 滑步变差、对接触误标敏感——只进精修层）。
- **精修层**（采样末、零参数 v1）：变量 = 根平移 Δ + 腿链 8 关节（髋/膝/踝/足 × 2）axis-angle 旋转增量，Adam 数步最小化 E_ground + E_support；上半身关节不在优化变量里——结构上不可能被 T 改动。
- **阶段 2（未启动）**：前向模型 f(姿态, 接触, 脚部运动学)→足压，E_forward = −log p(T|x) 作引导升级。

### 2.3 三条件开关（同一采样器）

| 条件 | 先验 | V 条件 | T 引导 | 精修层 |
|---|---|---|---|---|
| VT2M | p(x\|V) | 开 | 开 | 开 |
| V2M | p(x\|V) | 开 | 关 | 关 |
| T2M | p(x) 无条件（V 零化） | 关 | 开 | 开 |

T 流输入三条件恒定（接触头始终读真实压力），开关只作用采样器。

## 3. 训练

- 数据：cam3 ∪ cam3_occ010 共享窗；config_probs [1,0,0]（无条件采样、无 null token）；V 条件 dropout 10%。
- 损失：L_pose = 归一化状态 x̂0 MSE（λ=3.0）+ L_contact（λ=1.0）；无 aux 重建、无门控、无 A 矩阵。L_kp 1.0（世界系 FK 关键点 MSE）为 2026-10-17 后加入——基线批次训练时未激活，--variant lkp 两配置重训结论：底盘/兑现/滑步/T2M 全部零变化（扩散训练框架下监督空间错位不是瓶颈；回归框架下 L_kp 有效）。
- 预注册判据：① VT 的 PA 税 ≈ 0（结构保证，不靠训练运气）② 地面参照量（GlobalMPJPE/ATE/穿透/接触 F1）VT 占优——对照 −10.6/−19.9 兑现度 ③ T2M 弱条件（无条件先验+引导，~90mm 量级，不劣于现状即可）④ 滑步行为记录（E_support 风险预注册）。
- 前科对策：Test9.1 恒等回声（根因=头结构，已修）、Test12 收敛慢——先小规模试训验证采样链与引导数值健康，再全量。

### 4.2 跨模型定位

零税（ΔPA −0.87）但底盘最弱（V2M PA 47.93，扩散采样链税 ~9mm）+ 滑步税 +14.36——Δ 不可与回归线直接比。全表见 `V方案_性能对照.md`。

### 4.3 裁定状态（负向均为条件负向，参考框架正向）

- **整体归档**：作为完整模型在现有采样器条件下归档（非对组件潜力的否定）。
- **主瓶颈**：现有采样器下的扩散先验——V-only 47.9 vs 回归式 40.0（8mm）；val tau0 33.8 → test 采样 66.2（~30mm 链代价）；滑步底子 ~30（回归式 9.7 的 3 倍）。采样链质量 = F 一切结论的前置条件（修好前不封口）。
- **对照组撤回**：V3_Gv1 缝补式对照已撤回（2026-10-17 裁定：推理链替换定位模糊，编号让位全新 V3_Gv1 设计；脚本与结果已删）。保留为知识的两条前置条件：接触头 air recall 达标、载体（底盘）质量达标；Adam 精修劣于闭式为实测（滑步税 +14 全源）。
- **转移性知识**：零税原则、闭式约束优于自由优化（实测）、兑现与税可解耦（由 V3_Ev1 v2.1 完成）。
