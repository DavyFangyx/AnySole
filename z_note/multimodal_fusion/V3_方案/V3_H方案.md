# V3_Hv1 方案（2026-10-17 裁定；首批结果 2026-10-18 落定，零税 + 兑现全面 ≥ E 且 ATE 安全）


独立回归式模型（`anysole/models/common/model_v3h.py`，残差层 `anysole/utils/constraints_h.py`）：**纯 V 姿态主干 + T 接触头 + 推理侧零参数残差层（v1 两通道）**。三条件 = 同一回归塔的三个读数，无条件采样、无 null token、无门控、无 T 姿态塔、无 sigma 头。

独立模型：不 import E/F/G 任何管线代码；只继承两件已验证物——f6_soft 接触标签（数据）与 vonly 编码器权重（V 特征）。与 V3_Gv1 的关系：同一数据基座（cam3 + occ010、f6_soft、三条件协议）上不同技术理念的独立实现——G 前馈因式化「完整流形，分部证据」，H 反馈纠偏「完整流形，残差归零」；两线无依赖。

## 1. 设计主张与机制规则

**理念：「完整流形，残差归零」——T 不预测，T 纠偏。** 流形只有一个生成者（V 塔，任何条件下输出完整、合理的运动）；T 先定义物理状态 state_T（接触；地面属锚区——GT/未来 V 相机几何，2026-10-19 口径修正），修正由 V 假设与该状态的物理残差驱动；残差为零则修正为零（零税从「通路隔离」升级为双保险）。

x ← x_V ⊕ Σᵢ αᵢ · g(rᵢ(x_V, state_T))，g 单方向饱和、αᵢ 固定标量。

**载体 = 回归**：三条件协议与载体无关；扩散底盘代价已量出（F V-only 47.93 vs 回归 38.58）；回归三条件实测不劣（T2M 95.77 vs 117.65、V2M 38.58 vs 47.93，test ckpt_best）。
| 规则 | 证据 |
|---|---|
| 生成通路 T 禁入——零税结构保证 | E/F 两次兑现；对应 B 形态融合污染 Δ_fusion +13（范围声明：证伪对象为 B 形态融合，不作融合路线一般性否定） |
| T 特征只进入有探针硬证据的部位×指标——足部姿态（路径 A：anklefoot −1.96\*、r_foot −2.89\*）是唯一符合者；上身/手无正信号，不进 | T 信息量探针（弱基线相对量口径，见 G 方案衡量规则） |
| 学习式路由禁用——权威来自残差（可测量）与接触置信（校准阈值），不来自可训练门控 | σ 门控不路由、β-NLL σ 塌缩前科 |
| 修正单方向、固定增益、饱和、SG-7；不动根 | 两个已定位失败形式（支撑静态注噪、贴地推根 ATE+7.3）的反面 = 本方案约束形式 |
| 饱和规律内禀化——兑现随载体强度递减不是经验预算，是架构性质 | 载体越强 ⇒ 残差越小 ⇒ 修正越小 ⇒ 税恒为零 |

## 2. 模型结构

### 2.1 数据流

```
V (HRNet 特征) ──v_enc(冻结 vonly)──▶ v_tok ──▶ 4 层时序 Transformer ──┬──▶ 9 部位姿态头 ──▶ pose_v (144 维 6D)
                                                                       └──▶ 轨迹头 ──▶ trans_hat (3 维/帧)
T (压力 108 维) ──foot_conv──▶ t_tok ──▶ 接触头 ──▶ contact_logits (每脚 1 维)

推理链：V2M = [pose_v, trans_hat]；VT2M = 残差层(pose_v, trans_hat, contact_logits)；
T2M = 残差层(null-V 前向的 pose_v, trans_hat, contact_logits)（V 输入零化，修正只接地）
```

### 2.2 组件

- **v_enc（冻结）**：HRNet 特征 (B,tw,2051) → v_tok (B,tw,256)。权重复制自每配置的 vonly 专才 ckpt_best（V3_Hv1 → V3_Bv1_vonly、V3_Hv1_cam3_occ010 → V3_Bv1_cam3_occ010_vonly），14 键冻结，入口装载 + sha256 provenance；embeddings 不冻结（time_pe 正弦、模态行随 T 流训练，F 线先例）。
- **v_temporal**：4 层 pre-LN TransformerEncoder（nhead=8、ff=1024、gelu），从零训练。
- **V3HPoseHead**：9 部位硬划分（PART_JOINTS）、6 层 TransformerDecoder 单流交叉注意力，无门控、无 soft A、无 sigma 分支（H 无 NLL/回退）；输出 pose_v (B,tw,144)（pose_mean/std 归一化同 E 机器）。**无 T 姿态塔、无先验头——H 与 E 的结构性区别：E 的 T 塔复刻生成（T2M 级），H 的 T 侧不出内容。**
- **V3HTrajHead**：2 层时序 encoder → 每帧速度 → cumsum 轨迹 trans_hat (B,tw,3)。
- **foot_conv**：108 维压力 → t_tok (B,tw,256)，从零训练。
- **V3HContactHead**：t_tok → MLP(256→64→2) → 每脚接触 logits；f6_soft pos-weighted BCE（λ=1.0）。生产特性（cam3 ckpt_best 全测试集实测）：F1 0.91、recall 0.92、air_recall 0.50、sigmoid 均值 0.78——置信偏接触，**TAU_C=0.8 闸门实测 84.75% 足帧激活**（与 G 线 pos-weighted 头 sigmoid 徘徊 0.5、0/80 帧不触发的情况不同，H 的头置信分布可达 0.8 档）。
- **地面估计（零参数递推滤波）**：floor_src="t" 诊断开关用——接触置信帧足高 25% 分位；主判据 "gt"（数据集会话 floor，E v2.1 同口径）。**⚠ 2026-10-19 审计：主判据 gt 的穿透兑现 = 锚-几何完备性，并非触觉作用。**

### 2.3 残差层（融合 = 单遍应用，应用层零可训参数，`constraints_h.py`）

| 通道 | 残差 | 修正 | 证据与额度 |
|---|---|---|---|
| 穿透 | r_p = max(0, floor̂ − h_foot) | dy = 0.5·r_p 双足平均（仅升不降、SG-7、加至根 Y） | E −10.7（GT floor 版）为上限参照；gt 口径实测 −9.92 / −9.00；t 口径 −0.84（来源税，见 §4.3 ②）；**机制归类 = 锚-几何，非 T 兑现（2026-10-19 审计）** |
| 支撑 | r_s = 接触置信帧（c>TAU_C）足部帧间水平位移 Δ | 踝-偏航阻尼 γ = clamp(−0.5·(Δ·e)/r)（e = 足绕踝水平切向、r = 踝-足水平臂长；γ 上限 0.1 rad；只写踝关节、不动根、不改足高、SG-7） | 滑步无 T 线性证据（探针 +2.15\*）→ 接触消费的几何正则；GT 接触帧 Δ≈0 → 零修正（残差归零的结构性质，冒烟实测 GT≈恒等 max\|d6\| 4.5e-4）；**机制归类 = T 门控，非 T 信息兑现（2026-10-19 审计）** |

- **floor_src 开关**（G 同源裁定）：主判据 "gt"；"t" = T 派生 floor 为诊断开关——接触只给相对约束、不给绝对高度（gauge 自由度），系统性姿态偏置下自锚定 floor 继承同量偏置 → gap≈0（冒烟实测：GT 姿态 t-floor 与 GT floor 均值差 12.4mm；+50mm 偏置下修正最大 0.05mm ≈ 零触发）。
- **足部通道不进 v1（冒烟证伪，2026-10-17）**：零阶几何形式的平足参照在本骨架不成立——足关节在趾部（无跟关节），GT 接触帧踝→足向量与竖直方向夹角均值偏差 0.50 rad、足关节局部「足底法向」均值偏差 0.20 rad（p95 0.44 rad），不存在稳定几何参照；任何固定参照的朝向对齐都会在 GT 正确姿态上产生偏置。足部姿态兑现（探针硬证据 −2~−3）整体移入一阶对照实验（T 特征残差头）。
- 全局/ATE 不设专用通道（贴地推根失败形式的反面 = 不动根）：其兑现完全通过足部坐标的修正间接实现（实测 −3.0 / −1.6，见 §4.3 ⑥）。

### 2.4 三条件开关（同一回归塔）

| 条件 | V 条件 | 残差层 |
|---|---|---|
| V2M | 开 | 关 |
| VT2M | 开 | 开 |
| T2M | null-V（无条件先验） | 开（修正不产生内容，只接地） |

T 流输入三条件恒定（接触头始终读真实压力），开关只作用残差层。

## 3. 训练

- 数据：cam3 ∪ cam3_occ010 共享窗（与 G 同基座）；训练条件 VT 90% / V 零化 10%（T2M 协议代价——H 无 T 塔，null-V 先验只能靠输入零化训练；无学习参数 null token）。V2M 若被 dropout 损伤，下调零化比例或豁免 T2M 为记录。
- 损失：L_pose 3.0（6D MSE）+ L_traj 1.0（速度+差分）+ L_contact 1.0（pos-weighted BCE）。无 aux 重建、无门控、无 A 矩阵、无 NLL。
- 从零训练（独立性规则）：epochs 740、batch 256、lr 1e-4、tw=20、stride=20。
- 对照实验（一阶）：v1 + 足部残差头（t_tok → 足部残差，接触门控、输出饱和）——测探针足部硬证据能否在零税结构内兑现 −2~−3。零阶几何形式 = 同一通道的消融下限。

## 6. 修改历史

- **V1**：零参数残差层双通道（穿透 + 支撑）。穿透通道消费 GT 会话 floor——兑现 = 锚-几何非 T，已废弃。
- **V2**：v1 + T 流 aux 压力重建（λ_trec=0.1）——命题 2 载体依赖修复：T 编码器监督恢复足部信息。
- **V3**：v2 + 一阶足部残差头（接触软门控、饱和 0.05、只写足关节 6D）——落点 = 叶关节，位置效应恒 0（错误一）。
- **V5**：v3 − 穿透通道（无锚版：不消费任何 floor 输入；v4 空号）。
- **V6（现行）**：v5 + 残差头落点改踝 7/8（错误一修复）。
