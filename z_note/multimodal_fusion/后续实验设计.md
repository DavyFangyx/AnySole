# T 信息量判定 → 后续三实验设计（2026-10-09 裁定）

承接 `T信息量判定实验.md`（三探针结论：输入级 T 对脚/踝仅 1~2.6mm 信息、
融合污染 ~3mm、门控不路由 + null-V 免费搭车）。外部分析把「VT 不优于 V」
拆成两个子命题：①「VT ≥ V」是联合训练模态竞争问题而非互补性证伪；
② PA-MPJPE 抹掉了 T 最擅长的全局/接触/物理量，是错的尺子。

本设计执行三实验（**实验 4 = VT-only 重训主线，挂起**）：

| # | 实验 | 内容 | 成本 |
|---|---|---|---|
| 1 | 冻结残差（Test3_ResidualTest） | 冻结 V3_3B_vonly 专才 + 零初始化 T 残差分支，只采 VT 窗口微调 200ep | 一次短训 |
| 2 | 物理指标（Test4_PhysicalTest） | 非 PA 指标全面板 + per-session bootstrap CI + 新增全局 MPJPE/地面穿透 | 零训练，重跑 eval |
| 3 | oracle 分层（Test5_OracleTest） | 逐窗口 min(err_V, err_VT) 互补上限 + V 误差 decile 分层 + VT 胜率 | 零训练，重跑 eval |

## 裁定记录（用户拍板）

- 范围：1+2+3；实验 4 挂起。
- 实验 1 冻结基底：**V3_3B_vonly 专才**（`results/AnySole/V3_3B_vonly_joint_and/checkpoints/ckpt_best.pt`），
  其 F 从未被 T 污染，是「T 修正最好的 V」的最干净基底。
- T 编码器（FootConv）**一并冻结**：残差只读冻结 t_tok，与探针 1 的输入级
  上限严格对齐；可训练 T 编码器消融暂不做。
- 残差结构：只读 t_tok（不读 F）→ 逐帧修正加在 x0_hat；末层零初始化；
  V-only/T-only 按 config_id 掩码旁路 ⇒ V3_3C 的 V2M 输出恒等于专才，
  专才既有数字直接当基线（无需重训/重跑）。
- 训练：--config-probs 1 0 0（VT-only）、200ep、lambda_assign/lambda_sigma 清零、
  sigma_freeze_frac=0（防止前 10% 步把冻结 σ 前向置零）。
- oracle 对照：**主线 V3_3B 同网络 V vs VT**。

- 模型名 **V3_3C**：fix note §3.5 预留的「定向修复」槽，实现方式裁定为
  冻结残差（替代原从零重训修门控方案）。
- 逐窗口误差从未落盘 ⇒ eval 加 `--dump-detail`（per-window/per-session 明细）

## 预注册判读标准

- **实验 1**（与探针 1 上限对齐）：残差分支的可实现上限 ≈ 输入级 Δ_input
  （脚/踝 1~2.6mm）。拿到 1~3mm 脚部增益 ⇒ T 的 PA 价值封顶在此、融合污染
  可修（冻结残差即 V3_3C 替代实现，选项 A 落地）；拿到 0 ⇒ 现有 t_tok 无
  兑现空间。无论哪种结果，residual-VT 应 ≤ V-spec + δ（结构保证的
  VT ≥ V 兑现）。
- **实验 2**：物理指标（GlobalMPJPE / GroundPen / 接触 F1 / 根轨迹 / 滑步 /
  jitter）上 VT 是否优于 V（配对差 CI 排除 0）。不受探针 1 的 pose 上限
  约束，是叙事主战场。
- **实验 3**：oracle gain = V_mean − oracle_mean > 0 且 VT 胜率 > 50% ⇒
  互补性存在但被平均稀释；≈0 且胜率 ≈50% ⇒ 两者犯同样错误，T 冗余实锤。

## 实现要点（代码级）

- `anysole/models/common/t_residual.py`：TResidualBranch（LayerNorm + 256→256
  GELU + 256→144，末层零初始化，~103k 参数 / 0.56%）。
- `anysole/models/v3_3c.py`：STRUCTURE = V3_3B + residual_t=True；build()
  全冻结后仅解冻 t_residual（optimizer 在 --init-from 后构建，自动只含分支）。
- `model_v2.forward`：`x0_hat += (config_id==VT) * branch(t_tok)`；
  out 增 x0_residual（detach）。
- `eval.py --dump-detail`：window_detail_<split>.json（每窗 PA 整体+9部位+4区域/
  MPJPE/global MPJPE）+ session_detail_<split>.json（每会话全指标行，snake_case）。
  开/关 dump 时 pooled 逐位一致（逐会话累加后按原加法序列合并，A4 冒烟实测）。
- 新指标：`metrics.py` 的 ground_penetration（native Y-up、floor = GT 5 分位）
  + global_mpjpe（未对齐）+ cluster_bootstrap_ci（会话簇 bootstrap CI）。
- 血缘（09-24 独立性规则的有意例外）：runner manifest 记基底 ckpt 路径 +
  sha256 + fine_tune_base=true。
