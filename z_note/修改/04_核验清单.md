## ① 改动 A/B 的实现位置与配置键清单

### 改动 A：多步自由 rollout 损失（默认关）

| 配置键 | CLI | 默认 | 说明 |
|---|---|---|---|
| `ar_rollout` | `--ar-rollout` | off | 训练期闭环 rollout 损失开关；仅 enum 训练 + ar2_fb=True 有效（否则报错，死开关防御） |
| `ar_rollout_max` | `--ar-rollout-max` | 8 | L_max（课程终点） |
| `ar_rollout_schedule_frac` | `--ar-rollout-schedule-frac` | 0.6 | L 课程斜坡占总步数比例 |
| `ar_rollout_detach` | `--ar-rollout-detach` | True | 反馈梯度截断（只影响优化、不改反馈来源） |

实现位置：

- `anysole/models/common/model_v7.py`
  - `AnySoleModelV7.rollout_forward(...)`：闭环 rollout 前向（帧 1..L 反馈 = 帧 t−1 模型输出组装 `[Δyaw_total + tilt/body + v_head]`，与 eval `ar2_session_chunks` 更新式同构；帧 0 保留 batch 携带 = 推理口径；帧 L+1.. 保持 GT 反馈 TF 尾帧）。编码器只跑一次，逐帧前缀解码（`max_frames`）。
  - `V7MotionHead.forward(max_frames=None)`：前缀解码支持（query/时间 PE/因果掩码/门逐帧切片；默认 None = 原行为逐位不变）。
- `anysole/train.py`
  - `_ar_rollout_curriculum(global_step, total_steps, tw, l_max, schedule_frac)`：L 课程公式。
  - `backward_v7_enum(..., ar_rollout_len=0)`：>0 时用 rollout 前向替换模型调用；`ar_ss/ar_noise` 互斥守卫。
  - 主循环：L_cur 计算 + 传参；`--ar-rollout` 要求 enum + ar2_fb 的守卫。
- 与 `--ar-ss` 的区别（实现注释已写清）：SS = 逐帧按概率替换单帧反馈（两遍式缓存，反馈来源 = GT 条件下的输出，开环）；本改动 = 连续 L 帧真实闭环 rollout（反馈来源 = 自预测条件下的输出，误差段内复合——修改 03 靶心 0.53→0.05 的对应项）。
- 缓存纪律：无跨 minibatch 缓存（rollout 全批内闭环构造）；帧 0 保留 batch 携带（同 `_ar_ss_cache` 修正口径）。

## ② 开工记录（选值与依据、AR2M 裁定）

见 `04_AR训练目标与自由生成对齐.md` 末尾「实现状态」节（与本节同源）。要点：

- **裁定**：R/RD 结构基座 = **AR2（ar2_fb=True）**。依据：03 测量 AR2M 无反馈支路（ar2_fb=False、prev_state 不消费），TF≡rollout 按构造，改动 A 无作用对象；分叉只在带反馈的 AR2 上可测（0.53→0.05）。「rollout 单独贡献」= R − V7_Cv5AR2_ctx20_s1；R − AR2M 为混合差，判读分开登记。
- **L_max = 8**（0.2s ≈ 一个迈步段）：03 自由 rollout R=5 处支配度已 0.82→0.41；代价 ≈1.6× 前向。val 校准顺延（本轮不发射）。
- **课程斜率 frac = 0.6**：前 60% 步数 L 线性 1→8、后 40% 固定 L_max（选点期稳定）；同 sigma_freeze 哲学。
- **投影维度 k = 16**（总反馈 26 ≤ 32）：Δyaw+tilt+v_head 原始保留 10；k=16 ≈ 非根关节粗粒度整体配置；138→16 压缩 8.6×。
- rollout 概率 1.0（L=1 起点即课程；TF 尾帧同窗供 TF 损失）；detach 默认开。
- 合并窗口语义 / 三行统一应用 / 模型侧降维等设计选择见 04 文档「实现状态」。
