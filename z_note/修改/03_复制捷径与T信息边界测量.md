# 修改 03：复制捷径与 T 信息边界测量（零重训 + 小探针）

## 一句话目标

回答整条 T2M 线上**最关键且从未被测量**的问题：T2M 的 89.4 里，有多少来自压力，有多少只是运动先验？并量化 40 Hz teacher forcing 下「抄上一帧」这条捷径对训练目标的支配度。

本修改只测量、不改模型。它的结论决定 04 是否值得做。

## 为什么（现有缺口）

### 缺口 1：没有「不用 T」的同模型对照

E2 的 U@T 行是 89.4，但没人跑过「同一个 ckpt，T 输入置零」。`--null-t` 开关已存在（`anysole/eval.py` 的 `null_t`、`anysole/utils/eval_protocol.py:779-781`），但**只在 v4_1 分支生效**，V7 分支没接。

而 T2M 条件下 `condition_inputs` 本就把 V 置零，所以 `T2M + null-T` = **全部输入为零 = 模型的无条件先验**。这一个数直接给出：Cv5 的 89.4 里压力贡献了多少。成本 = 一次评估。

### 缺口 2：codex 两次提出、从未执行的条件探针

codex 对话 L1030、L1057–1060 两次把「已有运动历史后，增加压力是否预测得更好」列为最有判别力的下一组对照，全程零结果。T2M 这条线的全部合法性压在这个未测量的假设上。

### 缺口 3：复制捷径的量级已有强证据，但未被量化进训练目标

- 主会话实测：**复制上一帧 GT 的 PA = 4.6 mm**（40 Hz，0.5s 一窗内上一帧几乎就是答案）。
- AR 携带版 teacher-forced val T2M PA = **18.1**，比纯复制还差；同模型串行自由生成 test = **114.6**。
- codex L2069–2074（S13021，80 帧）：T2M 在 GT 历史下把压力**整个置零**，误差只从 18.98 涨到 19.65（+0.66 mm）。

这三条共同指向：teacher forcing + 逐帧 MSE 下，训练损失的绝大部分可由复制算子拿到，压力支路拿不到梯度压力。但「绝大部分」没有数字。

## 要做什么

### 步骤 1：null-T 接入 V7 分支（最便宜、最决定性）

1. `anysole/utils/eval_protocol.py` 的 `null_t` 置零逻辑解除 v4_1 限定，使其对 `v7_mode` 生效（`:779-781` 已是无条件置零，确认 `anysole/eval.py` 侧的开关路由与断言不拦 V7；若拦，改路由）。
2. 对 `V7_Cv5_s1`（ckpt_last，与 E2 同一 ckpt）跑三条件 × {正常, null-T}，`split=test`，36 会话同帧同掩码。
3. 同时对 `V7_Cv5AR2M_s1` 与 `V7_Cv5AR2R_s1` 跑同一对照（AR 族的反馈支路可能自带运动先验，需区分）。

**这一步的读数就是结论**：T2M 行 null-T 后 PA 若仍在 89–91，则现役 T2M 的姿态精度与压力内容无关，它在输出一个运动先验。

### 步骤 2：同容量条件探针（历史 vs 历史+T）

新脚本 `z_note/probes/probe_history_vs_T.py`（`z_note/probes/` 不入 git，产物落 `results_display/Etest/E8_ComplementarityProbe/detail/`）。

- **三臂，同容量、同训练预算、同 val 选参**：
  - `H`：只给运动历史（过去 N 帧的去根局部姿态 + 航向系速度 + Δyaw，**GT**）
  - `H+T`：历史 + 压力（raw108 + T_phys，同时间上下文）
  - `T`：只给压力（= 已有探针口径，作连接旧结论的桥）
- **两个目标**（分开报，不合并）：
  1. 下一帧及未来 K 帧（K ∈ {1, 5, 20}）的**去根局部关节位置**
  2. 同步长的 **Δyaw**（环绕安全误差 + 符号技能 + 对「恒输出 0」的 RMSE 比值）
- **口径**：train 拟合 / val 选超参 / test 评估；`split_csv` 用 canonical；指标用 `anysole.utils.metrics.pa_mpjpe`，不自写对齐。
- **必带基线臂**：常数均值预测器（机会水平）与「复制输入历史最后一帧」（捷径水平）。缺这两臂不出结论。

判读规则预注册：`H+T` 显著优于 `H` → 压力在历史之外有增量信息，T2M 路线有信息基础；`H+T ≈ H` → 现有压力表征在该粒度上不提供历史之外的信息，杠杆在表征而非生成结构。

### 步骤 3：复制捷径支配度分解

新脚本 `results_display/script/e0_tf_shortcut.py`：

- 在 **train** 上，对 `V7_Cv5AR2M_s1` 的训练反馈口径，分解 teacher-forced 单步损失：
  - `L_total`（实际目标）
  - `L_copy`：用「复制反馈帧」作为预测时的同一损失
  - 比值 `1 − L_total/L_copy` = 模型相对纯复制的净改进
- 同时在 **自由 rollout** 下出同一分解（rollout 长度 ∈ {1, 5, 20} 帧），画出两条曲线的分叉点——这是 04 要对准的量。
- 不改训练代码，用 ckpt 前向 + 复用 `anysole/train.py` 的 `backward_v7_enum` 损失定义（只读、不反传）。

## 验收判据（预注册）

1. 步骤 1 的六组数字（三条件 × 两臂）全部落盘，同帧同掩码，帧数登记一致。
2. 步骤 2 五臂（H / H+T / T / const / copy）× 两目标 × 三步长全表，每格带 val 选参值与 test 值。
3. 步骤 3 给出 `1 − L_total/L_copy` 在 teacher-forced 与自由 rollout 两种口径下的曲线。
4. **不要求任何数字朝某个方向走**。本修改的产出是三个读数，任一方向都是有效结论。

## 边界

- 不改模型结构、不重训、不发射训练 conf。
- 不用 test 选任何超参；探针超参一律 val 选。
- `--null-t` 的接入只解除分支限定，不改置零语义、不改默认值（不传开关时行为逐位不变）。
- 旧探针的 offset 前数字（T 信息量系列的 −10.6 / −19.9 / frac 0.320 等）只作机制参照，**不与本轮数字并表**。
- 评估用卡限 cuda:4/5/6/7。
