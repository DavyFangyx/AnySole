`"trajectory": "ground_truth_previous_frame_translation_anchor_per_window"`、
`"free_integration": false`。**所以这不是隐瞒，是声明过的口径**——但它仍然是

在审稿视角下会被整列质疑，而且质疑的是**全族**，不止 Cv5。

### 修法：自锚列升主列，GT 锚列降诊断列

论文主表改用 `GlobalMPJPE_self`（零 GT 锚），`GlobalMPJPE` 退到附录并标注
「每窗消费 1 个 GT 平移锚，与 AR 族及外部基线不可比」。

### 关键：老格不必重训就能补上这一列

TA 的锚头输入是 `m_v.mean(1).detach()`（`model_v7.py:793-800`）
⇒ `∂L_tanchor/∂θ_主干 ≡ 0`。**所以「联合训练锚头」与「在冻结 ckpt 上事后拟合锚头」
在信息流上完全等价**——主干从未被锚头影响过。事后拟合甚至更良定义：
联合训练时锚头追的是一个还在移动的特征分布，事后拟合的是最终分布。

`out["m_v"]`（`model_v7.py:916`）已经在返回体里。于是：

**改动 A（事后锚头拟合，零重训）**：对任一已完成的 Cv 族 ckpt，
用 train split 跑一遍前向、取 `m_v.mean(1)`，拟合同构的
`Linear(d,d)+GELU+Linear(d,3)`（d=256 → 66 563 参数，分钟级），
存成 ckpt 旁挂的 `anchor_head.pt`，评估时加载 → 四个自锚列全族可得。

覆盖：`V7_Cv2` / `V7_Cv5` / `V7_Cv7` / `V7_Cv5SD2` 四格，零训练成本。
`V7_Cv5TA` 已有联合训练版本，正好当**事后拟合 vs 联合训练的对照**
（预期：两者 `AnchorErr` 同量级 ~102mm；若事后拟合显著更差，说明
`m_v` 的分布在训练末期仍在漂，是一条值得报的诊断）。

**改动 B（协议声明）**：`evaluation_contract` 增 `primary_trajectory_readout` 字段，
取值 `"model_estimated_anchor_per_window"`；`z_note/评估/评估配置说明书.md`
按「只插入不改既有条目」记一条主列迁移说明。

> 留档：TA 正式格 21:40 起跑，`train.py` 的 RNG 存/复 21:38 落地
> ——**该修复在 TA 正式训练里是生效的**，零税契约的三条前提齐备。

## 三、AR 分支的思路，哪些能用到 Cv5 上

逐条过，结论分三类：**可直接移植 / 换形式移植 / 不移植**。

### 可直接移植 ①：`vt_t_residual` —— VT 零初始化触觉残差（来自 AR2RT）

AR2RT 的 `vt_t_residual`（`model_v7.py:635-641`）用 `fork_rng` 建两个零初始化
适配器，仅在 `v_present & t_present` 同现时生效 ⇒ **init 时 VT ≡ V 逐位相同**。

**实测它不依赖 `ar2`**：`Cv5 + vt_t_residual` 构建通过（2 487 159 参数），
`Cv5 + root_sd + TA + vt_t_residual` 也通过（2 491 579 参数）。

**为什么 Cv5 现在就需要它**：无遮挡档 `Δ(VT−V)` 在 PA 上是 **+0.15**
（29.06 vs 28.91，measurements §7）——**VT 比 V 略差**。遮挡档全线为负是本项目
最强的触觉证据，但无遮挡档这个正号是叙述上的一根刺（「加了触觉反而退了一点点」）。
零初始化残差把这个符号**由结构钉死为 ≤0**：清洁场景残差可退化为零，不可能变负收益。

论文命题「触觉 = 零税鲁棒性模态」从此有结构载体，而不只是一条经验曲线。
→ 立为 **`V7_Cv5RT`**。

### 可直接移植 ②：旋转锚头 —— AR2 「航向要特殊处理」的 Cv5 对应物

AR2 线最硬的收益是航向：T2M Drift 34.87（Cv5）→ 19.74（AR2MA），
V/VT 15.6/15.7（AR2M）→ 5.4/6.3（AR2MA）。

但 AR2 的实现方式（相对 tilt + 外部 ψ 链 + 自由积分）**不能移进 Cv5**：
`model_v7.py:507-509` 有显式互斥守卫（`root_sd` 是世界系根头，`ar/ar2` 用航向系根目标）。

**可移植的是那个洞察，不是那套实现**：航向是又一个「V 可读、T 不可读」的量，
而 Cv5 的窗独立结构下它的正确形态就是**旋转锚头**——和平移锚头同构，
V/VT 从 `m_v` 读出窗的绝对朝向，T 行走链式/恒等。

这套代码 **ctx4b 已经写好了**（`model_v7.py:534-556` 构造、`:712-728` 使用、
`L_anchor` 对 T 行掩码）。实测 `root_sd + TA + ctx4b` 可共存（2 488 160 参数）。
→ 立为 **`V7_Cv5RA`**。注意 ctx4b 还带 `ctx3` 上下文链，需要先剥出纯锚头部分，
或接受 ctx3 一起进来（那就是两个结构变更，按既定纪律应剥）。

### 换形式移植：单标志贯穿三处（来自 `v7_abs_vrows`）

09 的 `v7_abs_vrows` 一个标志同时落在**读出 / 目标 / 组装**三处
（`model_v7.py:408`、`losses.py:1084,1168`、`eval_protocol.ar2_session_chunks`）。
漏任何一处都是静默的口径错配（把世界系速度又旋转一次），**不会报错**。

07 覆盖了「读出+目标+评估列」，08 覆盖了「读出+目标+评估」，但都是逐个想出来的。
→ 立为全项目约定：**任何改变目标空间的标志，必须同时审这三处，
并在入口文件 docstring 里逐条列出**（`v7_c2ar2ma.py:14-19` 是范本）。

### 换形式移植：航向/轨迹块的声明式配平（来自 09 的诊断）

用户已定位：AR2 三项航向损失合计 0.054/0.060 = `L_pose` 的 13–14 倍。

补一条代数事实（已对 `losses.py:1139-1147` 核实）：令 `c = cumsum(dyaw误差)`，则
`L_cumyaw = mean(c²)`、`L_dyaw = mean((Δc)²)`、`L_dyaw_td = mean((Δ²c)²)`
——三项是**同一个量的 0/1/2 阶导数阶梯**（H² 范数），不是三个独立目标。
实测 0.037 : 0.006 : 0.010 正是白噪声下 `(T/2 : 1 : 2)` 的形状
⇒ **内部比例本来就对，问题纯在块级尺度**。用户「合计压到 ~0.1」方向正确。

对 Cv5 族的意义：这是 07 失败机制的同一个病（`L_traj_dir` 是 Cv5 整个 `L_traj`
的 4.6 倍 → PA 退 5.7mm）。B′ 用恒等式解决了 07 那一例，但**通用工具应当是
声明式比值**：

```python
lam = float(weights.get("block_scale", 1.0)) * (
    l_pose.detach() / block_raw.detach().clamp(min=1e-8))
```

`=1.0` ⇒ 该块恒等于 `L_pose` 量级。因为 `L_pose` 训练中降两个数量级，
固定常数在 ep50 与 ep700 的实际挤占比完全不同，声明式比值不受影响。
→ 作为 `Cv5RA` 的配套（锚/航向块同样会挤占），不单独立格。

### 不移植：长观测窗 `obs_context`

AR2M 用 tw80。measurements §5 已否定：固定短 horizon 目标时上下文
0.5s→10s 只从 −47.0% 走到 −49.1%，长窗收益来自目标被平均。不移植。

### 不移植：自由积分轨迹

AR 族 `n_gt_anchors_used = 0` 看似更干净，但代价是 `GlobalMPJPE` 1296–1650mm。
与 TA 自锚列的 105.21 是 **12 倍差，且两边都是零 GT 锚、同口径可比**。
⇒ **窗独立 + 每窗重锚是对的，链式自由积分是错的**。这正是用户最初那个问题
（「速度回归会漂移」）的量化答案，应当作为论文里 Cv5 架构选择的正面论据，
而不是把 AR 族往主线里搬。

## 五、边界

- Cv5 保留为基线，一行不改；SD/SD2/TA 三格保留为消融，不删不覆盖。
- AR 族（AR2M/AR2MA/AR2MSC）**不进主线表**，作为「为什么选窗独立」的对照留档；
