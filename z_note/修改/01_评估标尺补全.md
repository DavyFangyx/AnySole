# 修改 01：评估标尺补全（零重训）

## 一句话目标

给现有评估层补三类参照行——**常数均值姿态地板、平凡时序基线、窗内帧号剖面**——让每个模型的数字可以被判读为「相对完全不看输入拿到了多少」，而不是只能彼此相对排名。

## 为什么（现有缺口）

现役评估面板（`results_display/Etest/`）十指标全部是模型之间的相对比较，缺机会水平参照。后果：T2M PA 89.4 这个数字在报表上无法判断是「学到了东西」还是「接近不看输入」。E8 探针三臂（M_V / M_T / [M_V,M_T]）同样缺常数基线臂。

主会话 2026-11-03 现算的地板值（test，36 会话，kp_gt 24 关节，逐帧相似对齐）：

```
常数均值姿态（train 拟合）        104.1 mm
常数均值姿态（test  拟合）         98.8 mm
复制上一帧 GT      (25 ms)          4.6 mm
复制 5 帧前 GT     (0.125 s)       21.5 mm
复制 20 帧前 GT    (0.5 s = 一窗)   60.0 mm
复制 40 帧前 GT    (1.0 s)         73.0 mm
```

同口径从导出 npz 重算的模型值（与官方 `test_brief.json` 逐位一致，管线已自验）：
V3_Bv1 82.71 / V3_Bv1_denoised 80.65 / V7_Cv5_s1 89.39 / AR2R 87.76 / ARSS2 90.43 / AR2M 91.63 / AR2_tw80 91.73 / Ctx4 95.19。

## 要做什么

### 1. 新脚本 `results_display/script/e0_reference_floors.py`

计算并落盘三类参照，口径与评估协议严格一致：

- **GT 来源**：`AnySoleDataset(mode="eval", ...)` 的 `kp_gt`（24 关节、世界系），`split=test`，`contact_method=f6_soft_time_accel_state_smpl24_v1`，`seq_root/split_csv/cache_root` 取 `anysole.types` 默认（cam3）。
- **指标**：`anysole.utils.metrics.pa_mpjpe`（逐帧相似对齐，含尺度）+ `mean_point_error` 的 MPJPE（骨盆对齐），与 `_session_metrics` 同函数、同常量，不自写对齐。
- **常数均值姿态**：`(kp_gt − kp_gt[:, :1])` 在 **train** 上求均值 → 作为每帧预测；另出 test 拟合版标为「乐观地板」。
- **平凡时序基线**：lag ∈ {1, 5, 20, 40} 帧，逐会话 `pa_mpjpe(gt[:-lag], gt[lag:])`，帧数加权。
- 两类参照都要出十指标里**可定义的那几项**（PA-MPJPE、MPJPE、Jitter_pred、FootSliding、GroundPen）；对常数姿态不可定义的（traj_ATE、RootOrientationDrift）留空并在 `metric_reasons` 写 `not_applicable`，沿用 Step2Motion 行的能力门控写法（见 `results/baselines/Step2Motion/metrics/test_comparison.csv`）。

### 2. 新脚本 `results_display/script/e0_window_profile.py`

按**窗内帧号**（tw=20，`frame_index % 20`）拆解两个量，输入 = `results/cells/<cell>/predictions/eval_motion/<session>_<mode>.npz` 的 `joint_xyz_world` + `valid_mask` + `frame_indices`：

- **jerk 剖面**：三阶差分，`FPS=40`，`‖j‖` 关节均值；输出 20 个窗内位置的均值。
- **PA 剖面**：同窗内位置的 `pa_mpjpe` 均值。
- **接缝分解**：接缝帧定义 = 窗内帧号 ∈ {18, 19, 0, 1}（4/20 帧）；输出 `全帧 / 非接缝 / 接缝 / 接缝占总量%`。
- 支持 `--cells` 多模型、`--mode T2M|V2M|VT2M`，GT 行必出（作为「均匀」的参照）。

主会话已测得的值（agent 须复现，容差 ±1%）：

| 模型 | jerk 全帧 | 非接缝 | 接缝 | 接缝占总量 |
|---|---|---|---|---|
| GT | 129 | 130 | 124 | 19% |
| V3_Bv1 | 2284 | 1862 | 3970 | 35% |
| V7_Cv5_s1 | 1895 | 217 | 8607 | 91% |
| V7_Cv5AR2M_s1 | 1282 | 386 | 4867 | 76% |
| V7_Cv5AR2R_s1 | 1055 | 347 | 3887 | 74% |

PA 剖面参照：Cv5 窗内 88→94 单调微升，全帧 89.4 / 去 {0,19} 后 89.2（**接缝不吃 PA**）。

### 3. 接入展示层

- `results_display/script/e_results_export.py`：E2（表 1）与 E4（表 2）在各条件块的**首行**插入参照行，命名 `Reference / 常数均值姿态`，走 `_baseline_rows` 同一数据驱动路径（读 1 的产物 json，不读 md）。
- 产物落 `results_display/Etest/E0_ReferenceFloors/`：主干表放根层（`Full_Table1_E0_Floors.csv`、`Full_Table2_E0_WindowProfile.csv`），说明 md 下沉 `detail/`，不建 README。
- 导出凭证写入 `results_display/Etest/receipts/`，沿用现有 receipt schema（含 sha256）。

### 4. E8 补常数基线臂

`results_display/script/e8_probe.py` 三臂（M_V / M_T / [M_V,M_T]）增加第四臂 `const`（TRAIN 均值预测器），7 个目标全出。这一臂是机会水平，不进「赢家」判定、只作判读参照。

## 验收判据（预注册）

1. `e0_reference_floors.py` 输出的 train 拟合常数均值姿态 PA = **104.1 ± 0.3 mm**，lag=1 = **4.6 ± 0.1**，lag=20 = **60.0 ± 0.5**。
2. `e0_window_profile.py` 复现上表五行，接缝占总量相对误差 ≤ 1 个百分点。
3. 从导出 npz 重算的 V7_Cv5_s1 T2M PA 与 `results/cells/V7_Cv5_s1/metrics/test_brief.json` 的 `89.3946` 差 < 0.01 mm（管线一致性自检；不一致说明重算口径有偏，先修脚本不改结论）。
4. E2/E4 表插入参照行后，**所有原有行数字逐位不变**（diff 只有新增行）。
