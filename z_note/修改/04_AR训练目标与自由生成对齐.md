# 修改 04：AR 训练目标与自由生成对齐（1 次训练）

## 一句话目标

把 AR 的训练目标从「teacher-forced 逐帧 MSE」改成「**多步自由 rollout 上的损失**」，让被优化的对象与最终验收的行为（自由生成）成为同一件事。

## 前置依赖

**必须先完成 03。**若 03 的步骤 1 显示 T2M 行 null-T 后 PA 不动（即压力不参与姿态），本修改的预期收益上限只在「先验质量」这一侧，须在开工前把这一点写进本文档的开工记录，并相应下调验收阈值。

## 为什么（现有证据）

codex 对话末尾（L3432）自己的结论是「训练优化的对象还没有完整对应最终自由生成的行为」。本轮补上的量化依据：

| 证据 | 数字 | 出处 |
|---|---|---|
| 复制上一帧 GT 的 PA | **4.6 mm** | 主会话 2026-11-03 实测（test，kp_gt 24 关节） |
| AR 携带版 teacher-forced val T2M PA | 18.1 | V7_续写v4残差分解方案.md §12 |
| 同模型串行自由生成 test | **114.6** | 同上 |
| GT 历史下把压力置零，T2M 误差变化 | 18.98 → 19.65（+0.66） | codex.md L2069–2074（S13021，80 帧） |
| 已裁定 | teacher-forced 单步 val 不可作选点判据 | 2026-11-02 用户裁定 |

读法：40 Hz 下 teacher forcing 的目标被复制算子支配，压力支路与长程结构都拿不到梯度压力；自由生成时历史换成自预测，误差复合 → 塌回 ~90–115。

同时 AR2 族已经在**全局稳定性**一侧做出了真活，这部分必须保留：drift 33.4 → **19.9**（AR2M）、翻转 198 → **3**、幅度 RMS 100.1（GT 111.5）。

## 要做什么

基线 = `V7_Cv5AR2M`（现役唯一同时满足 满幅度 + 3 翻转 + drift 19.9 的配置），在它上面做两处改动，各自独立可关：

### 改动 A：多步自由 rollout 损失

- 训练期在同一会话、时间连续的片段内，以概率/课程方式用**模型自预测**替换反馈，rollout 长度 L 从 1 线性升到 L_max。
- 损失在 rollout 的**全部 L 帧**上定义（不只末帧），分量沿用现有定义（姿态 / 航向系速度 / Δyaw / 多帧累计相对 yaw / 接触头），不新增损失项。
- 与现有 `--ar-ss`（scheduled sampling，`anysole/train.py:823`、`:2191-2200`）的区别必须在实现里写清：SS 是**逐帧按概率**替换单帧反馈，本改动是**连续 L 帧的真实 rollout**，梯度可选截断（截断与否只影响优化、不改反馈来源）。
- 缓存纪律沿用 `_ar_ss_cache`（`anysole/train.py:224`）的既有修正：帧 0 保留 batch 携带（= 推理口径），缓存不跨 minibatch 复用。

### 改动 B：反馈降维（低维相对状态）

- 现 AR 反馈 = 上一帧完整姿态 144 维 + 根速度 3 维（`_v7_ar_session_seq` 的 `prev = torch.zeros(147)`）。改为只携带**低维相对状态**：根倾斜 + 航向系速度 + Δyaw + 身体姿态的低维投影（投影维度由实现定，建议 ≤ 32）。
- 依据：AR2M（只接力状态、不接力完整姿态）对观察窗长**不敏感**且 obs20 即达 91.6，而 AR2（接力完整姿态）对窗长强敏感且 obs20 只有 133.1——状态级接力已被现役数字证明是更优的信息结构（见 V7_技术路径全景 §4.3）。
- 本改动是把这条结论推到反馈通道。

### 开工裁定：R/RD 结构基座 = AR2（ar2_fb=True）

03 测量（06_测量报告_01-03.md §3.3）：**AR2M 无反馈支路（ar2_fb=False、prev_state 不消费），TF≡rollout 按构造——改动 A（多步 rollout 损失）在 AR2M 原样上没有作用对象**；分叉只在带反馈的 AR2 上可测（复制捷径支配度 0.53→0.05）。按本文档意图（「把 AR 训练目标从 teacher-forced 逐帧 MSE 改成多步自由 rollout 损失」），改动 A 必须伴随反馈支路开启。裁定：

- **R 格 = AR2 结构（ar2_fb=True）+ 改动 A**；RD = R + 改动 B。
- 「rollout 损失单独贡献」= R − V7_Cv5AR2_ctx20_s1（对照 AR2 纯 TF 格，已有）；R − AR2M = {反馈支路, rollout 损失} 的混合差，判读时分开登记。
- 基线 V7_Cv5AR2M_s1（obs20 格）原样不重跑。

### 实现设计选择（登记）

1. **合并窗口语义**：帧 1..L = 闭环输出、帧 0 与 L+1..tw−1 = TF 输出；损失分量（姿态/航向系速度/Δyaw/累计 yaw/接触）在合并序列上沿用现有定义——累计 yaw 与世界轨迹链在「闭环段 + TF 尾」混合序列上积分（课程期语义；L=tw−1 时整窗闭环 = 自由生成）。不新增损失项名目。
2. **三行统一应用**：rollout 对 V/VT/T 三条件统一生效（同现有 SS 路径的全条件口径）；不改变 11-02 裁定的 V/VT 行条件分离设计。
3. **前缀解码省算力**：闭环逐帧解码用 pose_head 的 max_frames 前缀（因果掩码 → 与全窗解码数学一致，容差 ~1e-6 浮点舍入），编码器只跑一次。
4. **改动 B 模型侧降维**：外部接口仍 148 维（dataset/eval/infer 协议零改动），ar2_body_proj(138→16) 在模型内部投影；02/03 评估链不动。eval 侧仅 _load_model 新增 ckpt config 回放 v7_ar2_lowdim/v7_ar2_fb_dim 两键。
5. **改动全关契约**：rollout 键默认关 + lowdim 键默认关 → R 入口与 AR2 逐位一致（state_dict 键值 bit-equal、前向 bit-equal、backward_v7_enum 损失 bit-equal）；与 AR2M 的共享参数逐位一致（dyaw_head 首层除外——AR2 的 fb 构造在 RNG 存/复块内先于 dyaw_head 消耗 RNG，为 AR2 vs AR2M 既有差异）+ fb 零初始化下前向输出与 AR2M 逐位一致。冒烟见 tests/test_v7_ar2_rollout.py（14 项全过）。
