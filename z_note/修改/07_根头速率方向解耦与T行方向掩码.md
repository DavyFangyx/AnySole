# 修改 07：根头速率/方向解耦 + T 行方向掩码（V7_Cv5SD）

立项：2026-11-04。依据：`results/diagnostics/20261104_t_row_observability/measurements.md`（本轮只读测量，8 份探针脚本已入库）。

## 一句话目标

当前根头回归**世界系速度 3 维向量**，V2M/VT2M/T2M **共用同一目标、无按行掩码**（`anysole/utils/losses.py:101` `l_vel = F.mse_loss(v_hat, vel_gt)`）。实测 T 行的**幅度通道已优于地板 53%、方向通道在地板以上 4%**，相乘后净值回到地板。本修改把根头读出改成（水平速率，水平单位方向，垂直分量）三通道、按通道监督、T 行屏蔽水平方向项，让已经存在的幅度信号可报且不被不可观测的方向通道污染。

## 测量依据（三条，决定了下面每一处改动）

1. **T 行损失全在方向通道**。20 帧窗端点位移，GT 幅度 191.6mm（= 零输出地板）：
   T2M 全误差 188.9（−1.4%）/ 仅幅度错 **89.4（−53.3%）** / 仅方向错 **199.3（+4.0%）**，中位夹角 40.5°。
   （V2M 对照：69.2 / 54.6 / 52.7，中位夹角 13.9°。）
2. **方向借不到别处**。用姿态头自己的根航向前向轴当方向，T2M 190.3mm（仍在地板附近）；根因是本数据集 GT 行进方向与 GT 身体前向轴**中位夹角 48.9°**（369 个位移 >2cm 的窗），转身/侧移占比高。
3. **速率标量是压力唯一强可读通道**（纯压力特征、无接触标签、无运动学量、留一受试者 7 折）：
   航向系速率 W=200 **−55.9%（7/7）**；世界系分量 −9.9%/−9.5%；航向系侧向 **+24.3%（不可读）**。

## 改动清单

### 改动 A：根头三通道读出（结构变更 → 新版本号）

**文件**：`anysole/models/common/model_v7.py`

A1. `:170-171` 根头输出维度 3 → 4：

```python
# 原
self.root_head = nn.Sequential(nn.Linear(dim, dim), nn.GELU(), nn.Linear(dim, 3))
# 改（仅 root_sd 为真时）
self.root_head = nn.Sequential(nn.Linear(dim, dim), nn.GELU(),
                               nn.Linear(dim, 4 if root_sd else 3))
```

A2. `:361` 读出改为三通道组装（**仅 `root_sd` 为真时走新支路，否则逐位不变**）：

```python
o = self.root_head(z_root)[:, :, 0, :]           # (B, tw, 4)
s_hat = F.softplus(o[..., 0])                    # 水平速率 m/s，非负
d_hat = F.normalize(o[..., 1:3], dim=-1, eps=1e-6)   # 水平单位方向 (x,z)
vy_hat = o[..., 3]
v_hat = torch.stack([s_hat * d_hat[..., 0], vy_hat, s_hat * d_hat[..., 1]], dim=-1)
```

轴约定：y-up、`forward_axis = +Z`（与 `metrics/val.json` 登记一致），水平面 = (x, z) = 下标 `[0, 2]`。

A3. `out` dict 增键 `s_hat` / `d_hat` / `vy_hat`（`:797` 附近），**`v_hat` 的形状与语义保持 (B, tw, 3) 世界系 m/s 不变**。

> **这条是本修改最重要的边界**：`v_hat` 契约不变 ⇒ `trans_hat = cumsum(v_hat)/FPS`（`:793`）、`eval_protocol.py:1031-1032` 的 `out["trans_hat"] + anchor`、`L_foot` 的 FK 回传（`losses.py:1166-1183`）**全部不动**。改动被关在「头 + 损失」两处。

A4. 退化防护：`F.normalize(..., eps=1e-6)` 保证数值安全；**不加前向报错**（方向模长趋零是合法的静止态，不是故障）。改为在诊断里登记 `||o[...,1:3]||` 的分位数，低于 1e-4 的帧占比入 run.log。

A5. 构造参数 `root_sd: bool = False` 加入 `PoseHead` 与 `AnySoleModelV7` 签名，由 STRUCTURE 标志驱动，默认 `False`。

### 改动 B：损失按通道分解 + T 行方向掩码

**文件**：`anysole/utils/losses.py`

B1. 新增 `_trajectory_losses_sd(out, batch, weights, config_id)`，与 `_trajectory_losses`（`:87-122`）并存、不改原函数：

```python
vel_gt   = batch["vel_gt"]                                  # (B,tw,3) 世界系 m/s
speed_gt = vel_gt[..., [0, 2]].norm(dim=-1)                 # (B,tw)
dir_gt   = F.normalize(vel_gt[..., [0, 2]], dim=-1, eps=1e-6)

L_speed = F.mse_loss(out["s_hat"], speed_gt)                       # 全行
L_vy    = F.mse_loss(out["vy_hat"], vel_gt[..., 1])                # 全行
# 方向：速率加权（静止帧方向无定义，不能等权）+ T 行屏蔽
cos  = (out["d_hat"] * dir_gt).sum(-1)                             # (B,tw)

L_dir = ((1.0 - cos) * w).sum() / w.sum().clamp(min=1e-6)
```

B2. 多尺度位移项**拆成向量项与标量幅度项**（原 `l_delta` 是向量差 MSE，对 T 行会把方向惩罚重新带回来）：

```python
for delta in valid:                       # 沿用 DEFAULT_TRAJ_DELTAS = 2,4,8,19
    pv, gv = x_hat[:, delta:] - x_hat[:, :-delta], x_gt[:, delta:] - x_gt[:, :-delta]
    # 向量项：非 T 行

    # 标量幅度项：全行（= 实测可读的那个量）
    delta_mag.append(sw * F.mse_loss(pv[..., [0, 2]].norm(dim=-1),
                                     gv[..., [0, 2]].norm(dim=-1)))
```

B3. 权重键（新增，全部走 `_weight(weights, ...)`，**默认值让 V/VT 行的总尺度贴近原口径**）：

### 改动 B 的配平形式（B′，恒等式再分配——建议的第二臂）

水平分量上有一个**精确恒等式**（`v = s·d`、`v_gt = s_gt·d_gt`，`d` / `d_gt` 为单位向量）：

```
‖v − v_gt‖²_h = (s − s_gt)² + 2·s·s_gt·(1 − cos)
```

即原 `l_vel` 的水平部分本来就**恰好**拆成「径向（速率）项 + 横向（方向）项」，
不需要新造一个尺度。把 B1 按这个恒等式写：

```python
inv3    = 1.0 / 3.0                     # 还原 F.mse_loss 对最后一维取均值
L_speed = inv3 * ((s_hat - speed_gt) ** 2).mean()
L_vy    = inv3 * ((vy_hat - vel_gt[..., 1]) ** 2).mean()
cos     = (d_hat * dir_gt).sum(-1)
trans   = 2.0 * s_hat * speed_gt * (1.0 - cos)        # s_hat 不 detach
L_dir   = inv3 * _masked_mean(trans.mean(dim=1), config_id != CONFIG_T)
```

三条性质都可证：

1. **全权重 1.0 且不掩码时 `L_speed + L_vy + L_dir ≡ l_vel` 逐位相等**（浮点结合序以内）。
   于是「T 行方向掩码」成为唯一的干预变量——与 08 的 stopgrad 零税契约、ctx4b 的零初始化
   同一套方法论：先把新口径摁成老口径的恒等重写，再只放开要测的那一个自由度。
2. **`s_hat` 不 detach**：`∂/∂s [2·s·s_gt·(1−cos)] = 2·s_gt·(1−cos)` 本来就是原 MSE 里
   速度梯度的一部分，detach 掉就不再是恒等式。
3. **静止帧自动处理**：`s_gt = 0` 时横向项权重 `2·s·s_gt = 0`，不需要 `min_disp` 式阈值，
   也不需要现版的 `/Σw` 归一化——`/Σw` 正是把低速帧重新抬回等权、造成膨胀的那一步。

现版三处尺度断点与之对照：`L_speed`/`L_vy` 各缺一个 `1/3`；`L_dir` 用
`Σ(1−cos)·s_gt / Σs_gt` 取代了 `2·s·s_gt·(1−cos)`，既丢了 `s·s_gt` 因子（典型 0.38 m/s 下约 0.29）
又被 `1/Σw` 重新放大约 `1/0.38`。

B2 的多尺度位移项同理：对 Δ 向量用同一恒等式再分配，而不是「向量项 + 标量幅度项」两个
独立权重相加——现版这两项对 V/VT 行把径向分量重复计了一次。

成本：一次训练。与步 3 的差别只有损失配平，结构 / 注册 / 评估列全部复用。

## 与外部基线的关系（留档，防止口径混用）

`Baselines/VP-MoCap` 的触觉→轨迹关系是**接触门控的支撑足里程计**：`FPP-Net` 不产生轨迹（压力是它的回归目标不是输入，`TemporalKpSMPLNet_Series_mlp.py:104-123`）；轨迹全部来自 `PoseTransOpt`，压力只以每帧 4 bit 二值接触进入（`dataset_mmvp.py:128-184`），姿态来自 CLIFF、绝对尺度来自深度图查趾尖像素（`initial_trans.py:30-55`）。它与本修改的「压力幅值 → 速率标量」是两条不同的路，数字不并表。
