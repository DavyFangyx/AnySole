## 引用纪律

- **数字只引 `z_note/归档/` 与 `results/cells/*/metrics/`**。已作废的方案、口径、探针报告已于 2026-11-24 移出至 `_trash/20261124/`（git 历史可恢复），其数字不进论文、不进对照表。
- 旧口径（`_offset前` 系列、V3–V6 方案、codex 对话）保留作机制参考（git 历史），其绝对读数已作废。
- 新增文档先问：它属于「论文层」「方案层」「测量层」还是「数据管道层」，放进对应目录，不要堆在顶层。
