| 目录 | 职责 |

## 引用纪律

- **数字只引 [`现状.md`](现状.md) 与 `results/cells/*/metrics/`**。`_历史_已废弃/` 下的任何数字都不进论文、不进对照表。
- 旧口径（`_offset前` 系列、V3–V6 方案、codex 对话）保留作机制参考，其绝对读数已作废。
- 新增文档先问：它属于「论文层」「方案层」「测量层」还是「数据管道层」，放进对应目录，不要堆在顶层。
