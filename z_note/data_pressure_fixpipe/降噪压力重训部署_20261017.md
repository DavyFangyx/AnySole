## 1. 数据接入裁定

- **分支**：`baseline_step_corrected`（pressure_io 默认版本，values48 =
  processed48）——包内「最终校正值」；
- **接入方式**：新 `tactile_input="denoised108"` variant，**不动正式
  shared/训练入口**（包自述「未替换正式入口」，variant 可回退）；
- **帧网格映射** = build_shared 的绝对最近行规则原样套在交接包行钟上：
  - frame i wall = `video_start_day_s + i/40`，video_start = 源录像
    cam{N} 目录首张 jpeg 文件名的日秒（build_shared.build_one 同口径）；
  - row wall = `wall_time_day_s`（= started_at_iso 日秒 + 原生接收钟，
    与 build_shared 的 pressure_epoch + raw_t_us/1e6 同一约定）；
  - 最近行、无插值、边缘钳位；
- **验证**（S13011）：与 final_fake_marked CSV 的 raw_t_us 映射对照，
  双脚 97.5%+ 帧选中行时间差 ≤ 30ms（≈ 一行间隔）。交接包行集 ≠
  final_fake_marked 行集（256 vs 330 行，独立导出），故映射直接做在
  交接包行钟上、不复用 CSV 行号；
- **覆盖**：train 104 / val 36 / test 36 全有交接包文件，wall 时钟
  100% 有限；
- **接触标签**：保持 shared 原样（固定 GT）——A/B 只隔离触觉输入变化；
- **T_phys**：按 normalize_raw 约定从新值重算（数据集原有路径）。
