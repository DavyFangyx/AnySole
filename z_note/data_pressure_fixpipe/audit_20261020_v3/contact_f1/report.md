## 六、判读

1. **v3 相对 v2 的 F1 变化集中在 tactile_rel 右脚一格，方向为改善。** 8 格中 5 格逐位相等（左脚 4 格全等 + tactile_abs 右脚），3 格有差全在右脚且量级小（tactile_gmm +0.0008、pressure_f6 −0.0009），唯一实质变化是 tactile_rel 右脚 pooled F1 0.7024→0.7467（+0.0443，per-session mean +0.0576），由 320 帧 FN→TP 驱动（FP 仅 +40），recall 0.6018→0.6672。右脚受限是必然的：val 集内 v3 与 v2 的逐值差异全部在右脚（814/619,920 值，18/36 会话），左脚 0 差异。
2. **机制与 v3 设计一致（数值核实）。** tactile_rel 阈值 = 会话 min + 0.25×(max−min)，是四方法中唯一直接受会话最大值支配的方法。v3 的故障格突发清洗把右足会话最大值从突发级拉回正常量级（18 个有差会话全部为最大值下降：如 S14111 右足和 22,377→15,032、S13082 14,156→8,600），阈值随之下降约 600~1,840，原先被突发抬高的阈值误判为离地的帧转判接触。tactile_abs（固定阈值 100）对突发完全不敏感，故 0 差；gmm（谷值）与 f6（逐格基线+迟滞）对单格突发不敏感，仅帧级直接效应（21 / 175 帧），F1 差 <0.001。即：v3 修复的是「故障格读数污染会话最大值」这条路径，受影响方法恰好是阈值取会话极值的 tactile_rel。
3. **方向性：v3 对接触 F1 无任何一格有意义变差。** pressure_f6 右脚 −0.0009 与 tactile_rel 右脚 +0.0443 相比可忽略；所有 |Δ|≤0.0443，且唯一大格为改善。相对 10-19 的 raw→v2 格局（8 格中 7 格略降），v3 没有引入新的下降。
4. **如实登记：** (a) GT 为 motion_f6 主导的运动学标签，压力通道仅作状态机辅助——本表衡量「压力派生 vs 运动学」一致性；(b) pressure_f6 逐格基线在各自版本压力上重标定（方法固有）；(c) tactile_rel 的机制性敏感（阈值取会话极值）是该方法本身的性质：突发修复对它改善明显，同时说明该方法此前被故障格系统性压低 recall；(d) 每脚排除 16/36，样本受限（std 0.15~0.21）；tactile_rel 右脚 v3 的 std 0.1721 较 v2 0.2133 收窄，与会话间阈值扭曲被修复一致。
