## 5. 判读

1. **v3 的故障格突发清洗在探针 Δprobe 读出上可见，v3 与 v2 不可互换。** 关键判据（显著性格局翻转）翻转为真：叶子级 25/560（v1↔v2 为 0/560）、面板级 4/96；FootSliding 位移（3.59）超过 CI 宽度（均值 2.68，比值 1.34）。与 10-19「v1↔v2 平滑差异不可见、结论可互换」相反——故障格清洗（16,308 值）与自适应平滑（对 Δprobe 中性）在探针上的可见性判然不同。
2. **可见性不成比例的来源**（如实登记，非渲染）：输入侧仅 16,308 值（集中在故障突发帧），但 (i) 修理量为大突发值；(ii) 编码器时序注意力把单帧输入差扩散为整窗 token 差（train 26%、test 16% 帧 t_tok 变化）；(iii) vt ridge 权重随训练特征重拟合产生覆盖全部会话的全局偏移。v3−v2 的探针差异并非「只来自修复 test 会话」——逐会话定位显示 FootSliding vt 变化 36/36 会话全正（权重重拟合主导）。
3. **翻转方向混合、无统一方向**：MPJPE A cam1 翻为显著正、GroundPen A cam1 与 traj_ATE cam2 翻为不显著、FootSliding cam3 翻为显著正。除 FootSliding cam3 A/B 外均为边缘翻转（CI 边界越零）。
4. **纪律遵守**：探针量级只引符号不引量级；v3 vs v2 为干净对比（同载体、同 V 数据、v_tok 逐位全等、仅 T 数据版本不同，缓存经今日代码冒烟逐位复现确认无代码漂移）；显著性格局翻转与否是唯一关键判据——本项判定：**翻转，v3 ≠ v2**。
5. 主指标结构（GlobalMPJPE/traj_ATE/PA-MPJPE）显著性 0~1/8 翻转，方向稳定（三版符号一致 8/8 配置）；变化集中在物理三行（FootSliding 1/8 显著性翻转且超 CI 宽度、Jitter_pred cam1 +241 但 CI 宽度 299 未超）与边缘指标。
