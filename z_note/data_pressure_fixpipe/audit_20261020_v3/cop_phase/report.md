## 内置一致性检查

**通过（量化设备漂移）。** v_tok 四键 results（0.452081 / 0.468696 / 0.008065 / 0.011503）与 verdict 在 v3（本跑，CPU）与 v2（10-19，GPU）之间 Δ ≤ 1.6e-9（results）/ ≤ 4.1e-9（verdict）；const 与 n_valid 三版全等。即：编码器 v 分支不依赖 T_tac（架构已知），跨设备算术漂移可忽略，表 2 的 v3−v2 差异全部为数据版本效应。

## 判读

1. **显著性格局零翻转（唯一关键判据）。** 三组判据 12 格（4 通道 × T可读/vt>const/V更强）v2 与 v3 全部同号同判定：T 可读 = phase_L、cop_L 显著，phase_R、cop_R 不显著；vt>const = cop 两足显著、相位两足不显著；V 更强 = cop_L 显著为负、其余不显著。v3 相对 v2 不改变任何启用/停用门槛结论。
2. **v3−v2 差异量级比 v1−v2 大一个档位，但全部在判据尺度之下。** 10-19 v1−v2：results 最大 1.2e-4、verdict 最大 9.7e-5；本审计 v3−v2：results 最大 2.6e-3（phase_R|vt）、verdict 最大 2.8e-3（phase_R|vt|vs_const，整段 CI 平移 −2.5e-3，仍跨 0）。即 v3 的故障格清洗是真实触及探针的数据改动（v1−v2 的平滑差异几乎不可见），但探针判据的 CI 尺度（相位 ±0.02~0.07）远大于该差异，不构成结论级变化。探针量级 = 弱基线相对量，此处只引符号：phase_R|vt 方向为变差，其余多数格为改善或持平。
3. **差异集中在右足通道，与 v3 数据改动分布一致。** val 集 v3−v2 的 814 个改值全部在右足（接触 F1 面同证），phase_R 两读出是变化最大格（raw108 −4.8e-4、vt +2.6e-3）；左足通道与 cop 通道变化 1~2 个量级更小（cop_L|raw108 +3.5e-5 等，经由 108 维特征中右足通道的 ridge 权重间接传导）。方向混合（phase_R raw108 改善、phase_R vt 变差），均不显著，不作兑现或回退论据。
4. **结论（如实）：** 在 CoP/相位 ridge 可读性判据下，v3 与 v2 无可区分差异；显著性格局不变。v3 相对 v2 的数据改动（299 文件 16,308 值、val 集 18/36 会话 814 值全在右足）在本探针上不构成任何启用/停用/更强结论的翻转。
