## E1 同架构专家对比

**目的**：证明正迁移——统一模型单模态推理优于同架构单模态专家（V→T、T→V 两方向），双模态推理不输双模态专家（no-regret）。

**设置**：
- 同架构四个模型：统一 AnySole（模态 dropout）、AnySole-V（仅视觉训练）、AnySole-T（仅触觉训练）、AnySole-VT（始终双模态、dropout=0）
- 三个测试设定 T / V1 / VT，统一模型与对应专家在同一设定下评估

**判据**：
- T 设定：统一 > AnySole-T，看全局指标（traj_ATE、GlobalMPJPE）→ V→T 成立
- V1 设定：统一 > AnySole-V，看足部指标（FootSliding、GroundPen、足部 MPJPE）→ T→V 成立
- VT 设定：统一 ≥ AnySole-VT → no-regret

## E3 多视角一致性锚

**目的**：验证训练期触觉一致性锚赋予无标定多视角融合能力。

**设置**：五条对比线——标定多视角（参考上限）、朴素无标定晚融合、AnySole 无锚、AnySole 有锚、AnySole Vn+T；视角数 n = 1、2、3、4。

**判据**：有锚随 n 提升且接近标定上限；无锚与朴素晚融合提升不明显或下降。

**产物**：表 4——行依次为标定多视角（参考上限）、朴素无标定晚融合、AnySole 无锚、AnySole 有锚、AnySole Vn+T；列 n = 1、2、3、4；正文指标 MPJPE、GlobalMPJPE，均值 ± 标准差；n = 4 单一组合无标准差（表注说明）。图 5（先不生成）——x = 视角数，y = 指标，每方法一条线，阴影带 = 组合间标准差。

## E5 下肢遮挡退化

**命题**：随着下肢视觉证据退化，触觉对世界系运动、轨迹与足-地物理一致性的改善越来越显著。

**设置**：
- 遮挡 5 档：0%（无遮挡）、仅足部、至小腿、至膝盖、整个下半身，从脚向上逐级遮挡
- 下肢定位：GT SMPL 投影或人体 mask；GT 仅用于生成测试输入、不进模型（不算泄漏）
- 遮挡物：随机纹理块或真实物体贴图（先用纯黑 mask 起步），避免「黑色=缺失」的质疑
- 四条线：AnySole 仅 V1（随遮挡正常退化）、AnySole V1+T（退化更慢，触觉开始发力）、外部 V1 基线（退化快）、AnySole 仅 T（水平参考，不受视觉退化影响）

**判据**：V1+T 与 V1 的差距随遮挡等级增大。
