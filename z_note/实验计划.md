#### 命名约定
- **U**：统一模型——V+T 联合训练，训练覆盖 V / T / VT，一个 ckpt
- **U@V / U@T / U@VT / U@V{i} / U@V{i}T**：U 在对应输入设定下推理（{i} = 视角数）
- **S_V@V / S_T@T**：同架构专家——仅视觉训练 / 仅触觉训练

#### 指标（10 指标）

- **关节位置/旋转误差（MPJPE 家族）**：PA−MPJPE（分身体部位）、MPJPE、GlobalMPJPE、W−MPJPE100、MPJRE
- **全局/世界系**：traj_ATE、RootOrientationDrift、GlobalMPJPE
- **物理合理性**：FootSliding、GroundPen、Jitter_pred

**判读纪律**：任何 Δ 指标（如 VT−V）必须与绝对值并排报，否则「V 被废掉」会被误读成「融合成功」。任何 T2M 数字必须报相对常数姿态地板（104.1 mm）的净值与 body_motion_rms，否则「缩小换稳定」会被误读成「变好」。

## 二、正文实验

#### E2 主性能（4.2，表 1）

**目的**：一个 ckpt 在 U@V / U@T / U@VT 每种设定下都不弱于对应外部基线。

**设置**：三块分组，每块先列外部基线、最后一行 U；表注声明三块中的 U 为同一 ckpt、无重训微调。

**U@T 块的对手与我们的回答**：该块唯一外部基线是 Step2Motion（合成 IMU 输入，50 维 / 100 帧窗 / 重叠携带）。**两者都在解「触觉缺全局参照」**——它靠额外传感器补，我们靠推理期视觉预热补。表内并排列出两条路线的结果，表注写明输入不对等（它多一路 IMU），并指向 4.5 的预热结果作为我们的机制回答。

**判据**：U 在三块上与最强外部基线可比；U@V / U@VT 块应明确领先；U@T 块若落后，落后幅度与该块的输入劣势（无 IMU）一起陈述，不用「基线未微调」辩护——Step2Motion 是在本数据上训练的。

**产物**：表 1——`模型类型 | 模型名称 | 10 指标`；三块分隔。参考行（常数均值姿态地板）置于 T 块首行，供判读。

#### E5 何时触觉有用（4.3，图 3）

**目的**：观察下肢视觉证据退化时，触觉对运动重建的增益如何变化。

**设置**：一个 ckpt 固定权重，评估 occ000 / 010 / 020 / 030 / 050（脚向上逐级遮挡）。
- 三条主曲线：U@V、U@VT、外部 V 基线
- 一条水平参考线：U@T（不受视觉退化影响）
- 可选：门控激活值随遮挡档位的变化曲线

**比较**：U@VT 与 U@V 的**交叉点**及交叉点之后的增益斜率；不要求全档严格单调。U@T 水平线给出「纯触觉能达到的水平」，用于判断视觉退化到哪一档时触觉开始主导。

**产物**：图 3（x = 遮挡等级，子图 = 指标）；正文给绝对误差曲线，补充材料给归一化退化曲线与十指标全表。

**已知边界**：occ 缓存为 bbox 底部遮挡；后续可换 GT SMPL 投影或人体 mask 生成遮挡，避免「黑色 = 缺失」质疑。

#### E4 门控消融（4.4，表 2）

**目的**：回答「门控是否抑制了触觉引入的负迁移，作用在哪个轴上」。

**设置**：同配方同枚举训练，唯一差异是有门 / 无门。
- 主对照：双门（V7_Cv5，主模型）vs 无门（V7_Cv7）
- 补充对照：单门（Cv4）、双门 + 随机 dropout（Cv2）——分离「门的数量」与「条件采样方式」
- 条件训练对照：始终 VT 训练（Cv6）——回答「三条件训练是否必要」

**核心分析 = ΔE⁺ / ΔE⁻ 分解**：把触觉带来的误差变化拆成「有害窗口被抑制」与「有益窗口被保留」两部分，门控的作用应体现为前者的削减而不损伤后者。

**判据**：双门相对单门/无门的优势应集中在**根与全局指标**（RootOrientationDrift、GlobalMPJPE、traj_ATE、W-MPJPE100），而不是均匀分布在所有指标上。
**Δ 必须与绝对值并排报。**

**当前证据**（见 [`现状.md`](现状.md) §四.1）：无门 Δ PA +7.54 → 双门 +3.04（−60%），W-MPJPE100 −82%，traj_ATE@0.5s −91%。带门五格 Δ PA 全在 [0.78, 3.04]。
**缺口**：无门臂 n=1（Cv7_s2/s3 已注册未训）。

**产物**：表 2（与 E6 共用）；Δ 表 + 绝对值表并排。

#### E6 接触阶段触觉增益（4.4，图 4）

**目的**：观察触觉在哪些接触阶段帮助视觉，以及门控是否改善这种增益。

**设置**：有门控 / 无门控两模型，其余配方一致；选取走路、跑步、深蹲等连续运动，各跑 V 与 VT。

**阶段划分**：按左右脚接触标签标注稳定支撑、摆动、落脚附近、离地附近；转换时刻取标签变化处、前后各 0.1 s。

**指标**：踝足 MPJPE（关节 7/10 与 8/11 两关节均值，骨盆平移对齐，**非** PA-MPJPE）；G = V 误差 − VT 误差，正值为触觉有帮助。按对应脚状态统计同侧踝足误差。

**产物**：图 4（横轴时间、纵轴 G、背景标接触阶段；两条曲线 = 有门 / 无门）；表进补充材料（单元格 = 「V 误差 / VT 误差 / G」）。

#### E9 航向测试实验（4.5，表 3 + 图 5）

**目的**：检验「触觉缺乏世界系参照」这一先天缺陷能否不靠 IMU、不靠重训，仅靠在推理期用视觉做一段预热来补。

**命题**：一个联合训练的 ckpt，先用视觉分支跑 1 秒（2 窗），把全局参照（航向 ψ、位置 p、根倾斜基准）一次性写进外部状态；此后视觉完全退出观测（人走出画面／关灯），纯触觉续写即可产出全局坐标系下的运动重建。

**为什么这个结构能做到**：AR2 族把「全局参照」与「运动生成」分开——网络工作在无参照的相对空间（Δyaw + 根倾斜 + 局部关节 + 航向系速度），全局量全部住在外部状态里。补全局参照 = 改外部状态的**初始化方式**，零新结构、零重训、零微调。

**T2M 冷启动缺什么**（按不可观测性排序）：

| 缺失量 | 压力可恢复吗 | 冷启动后果 | 预热补什么 |
|---|---|---|---|
| 初始绝对航向 ψ(t₀) | 不可观测（探针 test 帧级 corr 0.01–0.06） | 全局朝向整体 offset；每窗重估 → Cv5 198 次翻转 | V 首窗 vis_yaw → ψ 初始化 |
| 世界系位置 p(t) | 不可观测（位置是速度积分） | 自由积分漂移、traj_ATE 10.6 m | V 首窗建立 p(t₀)、v(t₀)、高度基准 |
| 转向序列 Δyaw(t) | 帧级/块级均无信号 | 冻结或慢转 | **不补**（不可学）——靠结构约束 +「不幻觉转向」验收 |
| roll/pitch 基准 | 弱可观测 | 根倾斜偏移 | V 首窗姿态初始化 tilt 状态 |

**科学问题**：T2M 全局误差里，「初始参照缺失」占多少、「过程证据缺失」占多少？预热消掉第一项，剩下的就是第二项的有界余量。

**设置**：三臂，同一 ckpt、同批会话、同帧同掩码，只评 T 后缀。

| 臂 | 定义 |
|---|---|
| cold_T | 全程纯触觉（基线） |
| V_to_T | 前 2 窗（40 帧 = 1 s）用 V 初始化外部状态，之后纯 T |
| VT_to_T | 前 2 窗用 V+T 初始化，之后纯 T |

硬约束：`GT_state_initialization=false`、`visual_history_after_switch=false`——预热只写状态、不留视觉历史，否则是泄漏。

**模型**：AR2M（航向级）与 ARSS2（姿态级）各跑一遍，区分两级能力。

| 级 | 结构要求 | 收益 |
|---|---|---|
| 航向级 | 相对表征 + 外部 ψ 状态，不需要反馈支路 | 航向 39.4° → 35.5°，PA 不变 |
| 姿态级 | 需要反馈支路（姿态历史接力） | PA 95.73 → **82.90**，航向 38.81° → **20.94°** |

**指标（三层）**：
1. 全局坐标量（主张的直接度量）：RootOrientationError、RootOrientationDrift、T 后缀 trajRelATE
2. 动作质量（防「缩小换稳定」）：PA-MPJPE、MPJPE、Jitter、body_motion_rms（ARSS2 预热三臂幅度仅 45–51 vs GT 108，必须报）
3. 时间剖面（红利衰减）：pa_first20 / pa_last20；扩展为逐窗 drift 与位置误差曲线

**比较**：V_to_T / VT_to_T 相对 cold_T 的下降幅度与**持续时间**。误差随时间回到冷启动水平 = 红利只作用于初始段；全程保持 = 状态接力有效。

**结论口径**：E9 只做 **warmup vs 冷启动**的内部比较，不与 EMU 类方法并表；与 Step2Motion 的路线级对照见 E2 表注。

**产物**：表 3 + 图 5；全量到 `results_display/Etest/V_WarmStart/`。

#### E3 无标定多视角（4.6，小表）

**目的**：验证训练期触觉一致性监督赋予无标定多视角融合能力。

**设置**：四条对比线——外部标定多视角基线（真值外参，参考上限）、TTA 原方法、U@V{i}（TTA 框架）、U@V{i}T + 接触约束（TTA 框架）；视角数 i = 1、2、3、4。
标定上限基线做法：每视角 2D 关键点 + 真值外参三角化 + SMPL 拟合（EasyMocap 类流程），不需训练。

**判据**：U@V{i}T + 接触约束随 i 提升且接近标定上限；U@V{i} 与朴素晚融合提升不明显或下降。

**产物**：正文小表一张（行 = 四条线，列 = i，指标 MPJPE / GlobalMPJPE）；补充材料给视角组合、标定上限基线与各 i 完整结果。

## 三、补充材料实验

#### E1 联合训练与融合收益（补充材料全指标表）

**目的**：观察联合训练对单模态能力的影响，以及推理期融合收益。

**设置**：U（同一 ckpt）→ U@V / U@T / U@VT。

**比较**：U@VT vs U@V / U@T；另加 always-VT 训练（Cv6）作为「不做条件训练」的对照——回答「三条件训练是否必要」。

**当前证据**（见 [`现状.md`](现状.md) §四.2）：Cv5 vs Cv6 三条件全胜（V2M 37.49 vs 43.00、VT2M 40.53 vs 41.35、T2M 89.39 vs 108.45），包括 Cv6 专门训练的 VT 条件——条件训练是免费的。

**产物**：全指标表（补充材料）。

#### E7 动态模态可用性（补充材料）

**目的**：输入配置随时间变化的连续运动中，一个 ckpt vs 按可用性切换的专家组合。

**设置**：选取走路、跑步、深蹲等连续序列，只改变输入可用性，运动本身连续。
- **AnySole-U**：全程同一 ckpt，按当前可用输入推理
- **专家组合**：按当前可用输入调用单视角 / T / VT / 多视角对应模型
- 两者同序列、同时间段、同可用输入

**产物**：补充材料分阶段误差表 + 补充视频；正文用一句话与 4.5 衔接。窗口边界切换的处理方式需在补充材料说明。

#### E8 探针式互补信息（补充材料）

**目的**：检验给定视觉表示后，触觉是否提供额外可解码的运动信息。

**设置**：冻结 U，读取同一批窗口的 M_V、M_T（各 256 维）；ridge 探针，train 拟合 / val 选正则 / test 评估。

| 探针输入 | 用途 |
|---|---|
| M_V | 视觉可解码信息 |
| M_T | 触觉可解码信息 |
| [M_V, M_T] | 加入触觉后的增量 |
| 常数均值（机会水平） | 判读基准 |

**预测目标**：骨盆相对踝足位置，报位置误差（mm）。

**用法**：结果主要用于 4.5 引出一句话——「航向不可观测」由 Δyaw 探针（test 帧级 corr 0.01–0.06）支撑，为 E9 的「外部状态」设计提供依据。

**产物**：三行 + 基线表（补充材料）。
