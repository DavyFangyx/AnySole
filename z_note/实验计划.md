# 实验计划

主线：U 通过 V+T 联合训练，用一个 ckpt 支持不同输入配置，无需为每种配置重新训练。E1 看联合训练与融合收益，E5 看视觉退化下的触觉增益，E6 看接触状态与门控效果，E7 看动态输入下的统一重建，E8 用探针分析互补信息。多视角推理见 E3。

#### 命名约定
- **U**：统一模型——V+T 联合训练，训练覆盖 V / T / VT，一个 ckpt
- **U@V / U@T / U@VT / U@V{i} / U@V{i}T**：U 在对应输入设定下推理（{i} = 视角数）
- **S_V@V / S_T@T**：同架构专家——仅视觉训练 / 仅触觉训练

#### 指标（10 指标）

- **关节位置/旋转误差（MPJPE 家族）**：PA−MPJPE（分身体部位）、MPJPE、GlobalMPJPE、W−MPJPE100、MPJRE
- **全局/世界系**：traj_ATE、RootOrientationDrift、GlobalMPJPE
- **物理合理性**：FootSliding、GroundPen、Jitter_pred

#### E5 遮挡退化下的触觉增益

**设置**：**U@V / U@T / U@VT**
- 训练一次，用验证集确定一份 U checkpoint。
- 固定这份权重，分别评估 occ000／010／020／030／050。

- 遮挡档位：occ000 / 010 / 020 / 030 / 050，从脚向上逐级遮挡；当前沿用 bbox 底部遮挡缓存。

#### E3 多视角一致性

**目的**：验证训练期触觉一致性监督赋予无标定多视角融合能力。

**设置**：五条对比线；
外部标定多视角基线、TTA 原方法、U@V{i}（TTA 框架）、U@V{i} + 接触约束（TTA 框架）

U@V{i} + 真值外参（参考上限）：它回答的问题是「测试时融合单视角模型 vs 专门训练的多视角模型，哪个更好」，实际上的确是两种不同的训练情形，因此实际上还是应该使用 「真值外参」 的上帝模型来进行上界

外部标定多视角基线（真值外参，参考上限）
选简单强的方案：最省事的是「每视角 2D 关键点 + 真值外参三角化 + SMPL 拟合」，EasyMocap 这类工具就是这个流程。你的数据集本来就有标定，可以直接跑，不需要训练。

视角数 i = 1、2、3、4。

**判据**：U@V{i} + 接触约束（TTA 框架）随 i 提升且接近标定上限；U@V{i}（TTA 框架）与朴素晚融合提升不明显或下降。

#### E6 运动状态下的触觉增益与门控效果

**目的**：观察触觉在哪些接触阶段帮助视觉，以及门控是否改善这种增益。

**设置**：两个模型——有门控、无门控；其余训练配方一致。选取走路、跑步、深蹲等几段连续运动，分别运行各模型的 V 与 VT 输入。

**阶段划分**：根据左右脚接触标签分别标注稳定支撑、摆动、落脚附近、离地附近。转换时刻取接触标签的变化，附近范围固定，例如前后各 0.1 s。

**指标**：默认踝足 MPJPE；G = V 误差 − VT 误差，正值表示触觉有帮助。按对应脚的状态统计同侧踝足误差。

**产物**：一张图 + 一张表。

- 图：横轴为时间，纵轴为 G；两条曲线分别为有门控、无门控，背景标接触阶段。
- 表：各阶段的平均误差与增益；单元格记为「V 误差 / VT 误差 / G」。例如左脚：

| 模型 | 0–0.4 s：稳定支撑 | 0.4–0.6 s：离地附近 | 0.6–1.0 s：摆动 | 1.0–1.2 s：落脚附近 |

#### E7 动态模态可用性下的统一运动重建

**目的**：在输入配置随时间变化的连续运动中，比较一个 AnySole ckpt 与按可用性切换的专家组合。

**设置**：选取走路、跑步、深蹲等连续序列，只改变输入可用性，运动本身保持连续。

- **AnySole-U (U@V/T/VT/Vi/....)**：全程使用同一 ckpt，根据当前可用输入推理。
- **专家组合**：根据当前可用输入，调用事先指定的单视角、T、VT、多视角等对应模型。
- 两个系统使用相同序列、相同时间段及相同可用输入。

**产物**：一张图 + 一张表，统一使用一个误差指标，例如 MPJPE。

- 图：横轴为时间，两条误差曲线分别为 AnySole、专家组合，背景标输入模式。
- 表：各输入阶段的平均误差。例如：

| 系统 | 0–2 s：V | 2–5 s：VT | 5–7 s：T | 7–10 s：多视角＋T |
|---|---|---|---|---|
| AnySole：一个 checkpoint | | | | |
| 专家组合：按输入切换 | | | | |

**比较**：同一 ckpt 在各阶段是否达到接近或优于对应专家的表现。多视角阶段沿用 E3 推理流程；当前窗口级输入控制在窗口边界切换。

#### E8 基于探针的模态互补信息分析

**目的**：检验给定视觉表示后，触觉是否提供额外可解码的运动信息。

**设置**：冻结 U，读取同一批窗口的 V/T 时序记忆 M_V、M_T（当前 C 模型的 m_v、m_t）。三组使用同一种 ridge 探针，训练集拟合、验证集选正则参数、测试集评估。

| 探针输入 | 用途 |
|---|---|
| M_V | 视觉可解码信息 |
| M_T | 触觉可解码信息，辅助参照 |
| [M_V, M_T] | 加入触觉后的增量 |

**预测目标与指标**：三组统一预测骨盆相对踝足位置，报告位置误差（mm）。

**产物**：一张三行表。

| 探针输入 | 踝足位置误差 ↓ |
|---|---|
| M_V | |
| M_T | |
| [M_V, M_T] | |

**比较**：[M_V, M_T] 是否优于 M_V、M_T。联合表示优于视觉表示，支持触觉提供额外可解码运动信息；不要求 T 单独优于 V。旧探针借鉴读出方法，不沿用旧结果作为本轮结论。
