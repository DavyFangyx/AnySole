# 缺失率与互补性实验任务书

> 2026-09-22 起草。整个实验组回答一个问题：**模型到底怎么"用"视觉 V 和触觉 T？**
> 分三层：① 模态少了/坏了，性能掉多少（实验 1 热力图）；② 两路是互补还是拼贴
> （实验 2/5/6）；③ 这些性质从哪来（实验 3/4）。
> 已定：D2 暂不处理；实验 1 每格落 SMPL npz（可接 Test1 逐帧动画）；命名与产物归属已回填（§四）：
> 实验 1–6 ↔ R_Test5–10，生成器 `anysole/rho_grid.py`，前端/分析脚本 `results_display/script/r_test5..10_*.py`。

## 〇、背景名词（读下文前只看这一段）

| 名词 | 含义 |
|---|---|
| V / T | V = 视觉流（相机特征，2051 维）；T = 触觉流（鞋垫压力 108 维）。模型重建全身动作 |
| 三配置评测 | 现有评测固定三种输入：都喂（VT2M）、只喂 V（V2M）、只喂 T（T2M）——相当于"整条模态有 / 无" |
| 空 token | 训练时模型被随机要求"只用 V / 只用 T / 都用"（概率 50/25/25），为此学会了两个补位 token（null_V / null_T）：某个模态整个缺席时，用它们顶替。这是本实验组要复用的现成机制 |
| F | V、T 两路 token 过 4 层 transformer 后的融合表征，姿态头从它回归出动作 |
| fseries JSON | 每个模型已落盘的协议指标文件（`metrics/<split>_fseries.json`），**已含三配置的全部部位级指标**（每部位 PA-MPJPE、yaw、接触、关节限位等） |
| PA-MPJPE | 对齐后的每关节平均误差（mm），本实验组的主指标，越小越好 |
| 主线 | V4B（`results/AnySole/V4B_joint_and`），val 实测：VT2M 40.4 / V2M 35.4 / T2M 69.6 |

## 二、各实验详情

### 实验 1：ρ 网格热力图（核心）

**一句话**：把评测从"整条模态有 / 无"的 3 个点，铺成一张 6×6 的图，横轴 V 保留率、纵轴 T 保留率。

**图长什么样**（格内 = PA-MPJPE，角上数字为 V4B val 实测，? 待测）：

```
                    V 保留率 →
              100%   80%   60%   40%   20%    0%
 T ↑  100% ┌──────┬──────┬──────┬──────┬──────┬──────┐
 保       │ 40.4 │  ?   │  ?   │  ?   │  ?   │ 69.6 │
 留   80% ├──────┼──────┼──────┼──────┼──────┼──────┤
 率   60% ├──────┼──────┼──────┼──────┼──────┼──────┤
     40% ├──────┼──────┼──────┼──────┼──────┼──────┤
     20% ├──────┼──────┼──────┼──────┼──────┼──────┤
      0% ├──────┼──────┼──────┼──────┼──────┼──────┤
         │ 35.4 │  ?   │  ?   │  ?   │  ?   │ ~153 │
         └──────┴──────┴──────┴──────┴──────┴──────┘
         V2M                                    纯先验
```

**四个角 = 现在的三个评测点 + 一个新点**：

| 角 | V 保留 | T 保留 | 是什么 | V4B val |
|---|---|---|---|---|
| 左上 | 100% | 100% | VT2M（现有评测） | 40.4 |
| 左下 | 100% | 0% | V2M（现有评测） | 35.4 |
| 右上 | 0% | 100% | T2M（现有评测） | 69.6 |
| 右下 | 0% | 0% | **纯先验**：两路全换成空 token，模型只剩学到的先验（≈ 均值姿态基线 ~153） | 待测 |

**中间 32 格是新的**：保留率 80% = 每帧有 20% 概率把这一帧的 V token 换成 null_V
（T 同理，逐帧独立掷硬币）。100% / 0% 只是特例，所以整张图是同一个机制、自洽的一张——
"缺失"（四个角）和"鲁棒"（中间过渡）不再是两套实验。

**两条 1D 切片 = 现有"鲁棒"实验的正规化**：
- 顶行（T 全在，扫 V 保留率 100%→0%）：V 逐帧损坏多少还撑得住 → 取代 robust_vdrop；
- 左列（V 全在，扫 T）：→ 取代 robust_tdrop。
现有 robust_vdrop 是把 V 的输入帧**连续 20–40% 一段清零**：不是换空 token、不是逐帧随机、
也不扫比例——口径不同，本实验统一掉。

**需要什么**：
1. 模型小改：编码器加可选 mask 参数（默认关闭 → 旧 ckpt 完全兼容，**零重训**）；
2. 生成器脚本：36 格 × 36 session（test split）推理。每格落三样东西：
   ① 该格协议指标（汇总进一份 JSON，与 fseries 同结构）；
   ② **每 session 的 SMPL npz**（与现有 eval_motion 同格式 → 可接 Test1 逐帧动画，看"这一格模型输出了什么"）；
   ③ 表征 dump（F / t_tok / v_tok，给实验 2、5 用）。
   mask 按 (session, 种子) 确定性生成，可复现。

### 实验 2：互补 bar + 探针表 + t-SNE（零重训）

**2a 互补 bar（数据已在盘上，纯画图）**

每身体部位三根柱：V2M / T2M / VT2M 的 PA-MPJPE。判据（贴文"双向互补增益"）：

- 下肢/接触：VT2M 应优于 V2M（T 的贡献）；
- 全局轨迹/yaw：VT2M 应优于 T2M（V 的贡献）；
- **两个方向同时成立才叫互补**；若只是"取两者更好的那个"，就是拼贴。

⚠️ 已有实测提醒：V4B val 上 V2M(35.4) 反而比 VT2M(40.4) 好——所以这张图**必须按部位看**，
拿总 PA 说"融合增益"会被这个数字直接打脸；分析脚本按部位算 Δ(VT−V2M) 与 Δ(VT−T2M)。

**2b 探针表（F 里到底存了什么）**

用 ridge（线性回归，train 上拟合 / val、test 上评）从融合表征 F 解码运动，
比"线性能读出多少"而不是比模型输出（模型输出 = 探针天花板的下界）。表长这样：

| 解码目标 | 从 Ft（只喂 T 的 F） | 从 Fv（只喂 V 的 F） | 从融合 F |
|---|---|---|---|
| 接触/下肢 | 高（T 强项） | 低 | 应 ≈ Ft，不能掉 |
| 全局/yaw | 低 | 高（V 强项） | 应 ≈ Fv，不能掉 |

**结论在最后一列**：融合 F 每行都逼近两个单模态各自的**上界** = 融合吃满了两边、
没被稀释——"共享运动表征 = 完整状态"的硬证据。
现有 `results_display/script/utils/ridge_probe.py` 只做了 VT + pose 一个格子；需扩展 ① 三种输入配置
（Ft/Fv/融合 F 都是各配置下的 F 输出，三者同形同维，公平可比）② 解码目标加
contact、根朝向（yaw 用协议口径算，不能拿局部 MPJPE 冒充）。零重训。

**2c t-SNE**：同一批动作的三种配置 F 做降维散点，按 (动作, 配置) 两种方式着色。
期望：**按动作聚成团、而不是按模态分成两堆** = 模态不变的共享状态。

### 实验 3：dropout 消融 + 单流探针

- **C1（最重要的归因实验）**：训一个**训练时不做模态 dropout** 的模型
  （`--config-probs 1,0,0`，只喂 VT；train.py 已有此参数，**零代码改动**）。
  测试时强行只喂 V / 只喂 T → **应崩**（说明不加 dropout，T 就搭 V 的便车）。
  对照 = 主线（训练时 V/T 各 25% 概率单独出现）能站住 → 证明训练机制是必需的。
  成本：1 次训练。
- **C2 单流探针**：2b 探针表的前两列换数据源——从**融合前**的纯流 token
  （t_tok 单独解码接触/下肢、v_tok 单独解码）证明每条流自己就扛得住自己该扛的信息。
  注意口径区别：Ft/Fv = 融合**之后**的表征（含空 token 补位与融合混合）；
  单流 = 编码器**原始输出**。生成器顺带落盘，零额外推理。

### 实验 4：T2M 上半身 + V2M 遮脚

- **D1**：T 没有上肢信号，但 T2M 能出合理上半身——"合理性"从哪来？
  指标已就位（关节限位违反率、上肢加速度分布差，都在 fseries 的 T2M 列）。
  缺对照：用 ridge 直接从 t_tok 回归上肢姿态（无先验基线），差距 = 先验贡献。
  复用实验 2 的 ridge 框架，**零重训**。
- **D2（V 遮脚）**：**暂不处理**。留档原因：主线 V 输入是 2051 维全局特征，
  没有空间结构，脚部无处可遮；能遮踝/脚关键点的 GVHMR 通道已搁置（权重未下载）。
  后续若提起，备选口径：a) V 侧缺失并入实验 1 的帧级遮挡；b) 恢复 GVHMR 线再谈。

### 实验 5：信任堆叠条 + 注意力

- **E1（实验 1 跑完即免费）**：取热力图三个角（只有 T / 只有 V / 都没有）的**每部位**
  误差画堆叠条 = 每部位"信 V / 信 T / 信先验"的画像。直觉对照（贴文）：
  走路时 T 被遮 → 全局信 V；V 被遮的脚 → 信 T；上半身 → 信先验。
- **E2（定性佐证，不当主证据）**：把姿态查询对 memory 的注意力按 V 段 / T 段聚合
  （6 层 × 8 头），看每个部位主要在看哪边。不改模型：eval 时打开 `need_weights` 钩子即可。

### 实验 6：V-only / T-only 单模态训练

分别只用 V / 只用 T 训练两个模型（`--config-probs 0,1,0` 与 `0,0,1`），各自协议评测 + 探针。
预期指标交错：T-only 赢接触/下肢、V-only 赢全局/yaw——与实验 2 的互补 bar 互相印证。
成本：2 次训练，与实验 3 的 C1 合计 3 个 run，可并行排队。
