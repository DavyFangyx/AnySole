# AnySole V2 设计方案（F 系列）

适用范围：三个任务 VT2M、V2M、T2M，其中 V2M 同时输出压力。身体按 9 个部位划分，不含物理模块。T 定义为**纯压力**。E6.6a/b 用了 GT 合成的 IMU，只作上界参照，不进入主线对比。

---

## 0. 终态结构

```
V：cam3 帧 → 冻结 HMR（离线提取）→ 逐帧 θ_hmr / 2D 关键点+置信度 / 图像 token
     → V 流：9 个部位 token + 1 个全局 token          E_V (B,T,10,d)
T：左右鞋垫 4×12 @原生率 → 按脚卷积（左右共享、右脚镜像）→ 时间卷积降到 40Hz → 时间 Transformer
     → T 流：左脚 / 右脚 / 全局 token                  E_T (B,T,3,d)
   两个流各自带深监督头（只读本流）和部位不确定度 σ_{m,p,t}

部位解码器 Z (B,T,9,d)，每层依次为：
   部位间自注意力 → 时间自注意力 → 局部交叉注意力(V) / (T) → 门控 {V, T, ∅} → FFN
   输出：部位 6D 旋转 / 根轨迹 / 脚接触 / 融合不确定度 σ̂

精修器 R（AMASS 预训练，逐 token 噪声级）：按 σ̂ 决定每个部位加噪多深，然后少步去噪
前向模型 G：M → 压力 / 接触；用于 V2M 的压力输出、一致性损失、AMASS 伪压力
```

**9 部位与运动表示**（SMPL 关节编号）

| 部位 | 关节 | 每帧输出 |
|---|---|---|
| 根 | 0 | tilt 6D + 轨迹 4 维（朝向角速度 ψ̇、朝向系水平速度 2 维、根高度 h） |
| 躯干 | 3, 6, 9 | 18 |
| 头颈 | 12, 15 | 12 |
| 左臂 / 右臂 | 13,16,18,20 / 14,17,19,21 | 24 / 24 |
| 左腿 / 右腿 | 1,4 / 2,5 | 12 / 12 |
| 左脚 / 右脚 | 7,10 / 8,11 | 12 / 12 |

合计 22 关节 × 6D = 132 维，加轨迹 4 维、接触 2 维。

## 1. 起点与路线

**起点选 E3 的配置**：raw108 输入、Tw=20、stride=20、λ_pose=3、λ_con=0。代码基于当前工作区。

理由有三点：
- E3 在不含合成 IMU 的版本里最干净，t-token 已修好，接触项已关掉。
- E4/E5 的改动（噪声缩放、linear schedule、采样步数）只作用于扩散链。F0b 删掉扩散后，这些改动自然失效。
- E6.6 含 IMU 泄漏，不适合作为起点。

| 步骤 | 本步唯一变量 | 主判据 |
|---|---|---|
| F0 | 评估协议、去扩散（改回归）、去 V 重建 | 与 E3 持平，并测出种子噪声 |
| F1 | 视觉输入：HRNet → 预训练 HMR | V2M PA-MPJPE |
| F2 | 运动表示（重力/朝向规范化）+ FK 位置损失 | 根漂移、远端关节 |
| F3 | 窗口长度 + 重叠滑窗推理 | 抖动、拼接跳变、T2M 下肢 |
| F4 | 触觉流独立化 + 流内深监督 | T2M 对 S2M-P；VT2M 相对 V2M 的增益 |
| F5 | 融合结构：部位查询解码器 + 门控 | 部位误差、门控是否可解释 |
| F6 | 接触与滑步损失 | 脚滑、接触 F1 |
| F7 | 不确定度 σ 接入门控 | σ 标定度、鲁棒性验证集 |
| F8 | AMASS 精修器 | 抖动、远端关节、T2M 上半身合理性 |
| F9 | 前向模型 G | 压力输出、T2M、伪压力预训练增益 |

## 2. 实验规范（所有步骤共用）

**判据阈值用种子噪声来定。** F0 用 2 个种子，测出每项指标的标准差 σ_seed。
- "显著改善"：比上一步好 2σ_seed 以上。
- "不劣化"：差距在 1σ_seed 以内。
- 结果落在 1σ–2σ 之间时，补跑一个种子再判断。

**预算与合入规则。**
- 预算按梯度步数对齐。窗口长度变了之后，epoch 数不可比。
- 筛选时跑短预算（约 E3 的 200 epoch 等价步数），胜出配置再跑长预算。
- 新开关默认关闭，关闭时等于上一步的行为。每步只合入胜出配置。

**损失与数据划分。**
- 每项加权损失的量级逐项记日志。新损失项的初始权重，按"首个 epoch 加权后约为主损失的 10–30%"来设，吸取 E1/E2 里 L_con 主导总损失的教训。
- train/val 按受试者划分，并确认与 AMASS 等外部数据没有重叠。

### 评估协议（F0a 实现，之后固定不变）

| 类别 | 指标 | 说明 |
|---|---|---|
| 局部姿态 | MPJPE、PA-MPJPE（22 关节，骨盆对齐） | 按部位分别报，汇总上半身/下半身；踝脚（7/8/10/11）和腕（20/21）单列 |
| 全局 | W-MPJPE（每 4 s 段首帧对齐）、RTE（按位移长度归一化）、朝向漂移 | |
| 时序 | 抖动（沿用 probe_jitter，mm/帧）、加速度误差、拼接跳变 | |
| 接触 | 接触 F1、接触期脚滑（mm/帧） | |
| 压力输出 | 总力 R²、CoP 误差、逐点 Pearson | 仅 V2M |
| T2M 上半身 | 照报 MPJPE，另加加速度分布误差、关节限位违规率；F8c 起加 min-of-K 与 APD | 上半身基本不可观测，不单看 MPJPE |

**评估方式与验证集。**
- val 的每条序列完整推理后再算指标。拼接方式随当前步骤而定。
- ridge-on-F 探针每步都重跑。
- **鲁棒性验证集**：在 val 上合成两种退化，一是 V 的随机段丢失（连续 20–40% 的帧），二是 T 的随机段丢失。F0 起就报告，F7 起作为主判据。

**参照基线（F0a 一次性建立）。**
- E3 的 ckpt 过一遍新协议。
- **S2M-P**：Step2Motion 去掉 IMU 通道后重训，每脚为压力 16 + 力 1 + CoP 2，共 38 维。它是 T2M 的主参照。
- 零训练 HMR：F1 提取特征后补上。
- E6.6a/b：标注"含合成 IMU"，只作上界。

## 3. 主线步骤

### F0 基线重建

**F0a 评估协议与基线。** 模型不改，按上一节实现。

**F0b 去扩散，改为回归**（tag `f0b_regress`，2 个种子）

改动：
1. pose_head 删掉 x_τ 的输入投影和 t token。query 改为"分组嵌入 + 时间 PE"的可学习 token。6 层 decoder（自注意力 / 交叉注意力到 F / FFN）不变，直接输出姿态。
2. train.py 删除 q_sample 和 τ 采样，L_pose 直接作用在回归输出上。
3. eval.py 去掉 DDIM 链，改为单次前向。

不动：输入、融合、轨迹头、辅助头、全部损失权重。

判据：
- 通过：VT2M PA-MPJPE 与 E3（81.2mm）的差距在 2σ_seed 以内，与 ridge-on-F（85mm）同一量级；抖动明显低于 E5 链的 27mm/帧。
- 若明显差于 E3，说明实现有问题（归一化、损失口径），先排查，不进入 F1。

**F0c 去掉 V 重建头**（λ_V=0）

判据：
- T2M 不劣化 → 永久删除。
- T2M 明显变差 → 说明它确实在向 F 灌视觉信息。F1 起保留一个替代目标（改为重建 θ_hmr，而不是 HRNet 特征），一直留到 F5。

### F1 视觉输入换成预训练 HMR

目的：验证"视觉读出天花板"是不是 V1 的第一瓶颈。

改动：
1. **离线提取脚本**。对 cam3 每个 40Hz 帧，用同一 bbox、按各 HMR 模型自己的预处理裁剪，保存以下内容：
   - θ_hmr：22 关节局部 6D + 全局朝向；
   - β_hmr、相机参数；
   - 2D 关键点及置信度；
   - 主干池化 token 和 bbox_info。

   输出不是 SMPL 的模型，先转成 SMPL，或只保留关键点。有 cam3 外参时，把全局朝向转到世界系再保存。
2. **选主干**。候选是 CameraHMR 和 SAM 3D Body。先按新协议算零训练基线（θ_hmr + GT betas 过 FK），只训练胜者；两者差距小于 2σ 时都训。
3. **V-Enc**。V_feat 从 2051 维换成上面的拼接。V-Enc 改为分组 Linear（θ、关键点、图像 token、bbox+相机）求和，再加时间 PE。规模和 V1 相同，仍然没有流内时间模块，保证单变量。
4. **质量特征 q_V**。每帧的关键点平均置信度和 bbox 截断比例，一并作为输入。

不动：T 路 raw108、融合、各头、表示、窗口。tag `f1_hmr_{name}`。

判据：
- 通过：V2M PA-MPJPE 比 F0 显著下降，且不高于零训练 HMR 的逐帧值；新 F 上的 ridge 探针天花板同步下降。
- V2M 仍高于零训练 HMR：说明融合或读出在丢信息。追加 F1b：V 可用时，姿态头预测相对 θ_hmr 的残差；T-only 时残差基底取 0。
- 与 F0 持平：视觉读出不是主瓶颈，重心转到 F3/F4。之后再查 HMR 在本数据集上的域差，比如服装、遮挡、鞋垫连线。

### F2 运动表示 + FK 位置损失

**F2a 表示重构**

改动：
1. 关节数从 24 改为 22，去掉 SMPL 手部的 22/23。关键点 GT 本来就只用 22 个。
2. 拆分根关节。重力轴取 mocap 世界系的竖直轴。朝向角 ψ 由骨盆前向量投影到地面得到，tilt = R_yaw(ψ)ᵀ·R_root，用 6D 表示并归入姿态。
3. 轨迹每帧 4 维：ψ̇、朝向系水平速度（2 维）、根高度 h。差分用窗口前一帧来算，修掉 V1 里 vel_gt[0]=0 的问题；序列首帧复制下一帧的值。
4. 窗口内从 ψ=0、水平位置 0 开始积分，得到窗口局部轨迹。窗口锚点单独保存，供 W-MPJPE 和拼接使用。
5. 所有维度做 mean/std 标准化：在训练集上拟合，冻结后随 ckpt 保存。
6. 姿态头输出 132 维，轨迹头输出 4 维。轨迹损失沿用 V1 的"速度 MSE + 多尺度位移"，位移改在积分后的朝向系轨迹上计算。

判据：根 RTE、朝向漂移、W-MPJPE 显著改善，至少不劣化；MPJPE 不劣化。

**F2b FK 位置损失**

改动：新增 L_fk，即 22 关节 FK 位置与 GT 的 MSE。FK 用 GT betas，以骨盆为原点、在朝向系下计算，权重按量级规则设。

注意：叶子关节（10/11/15/20/21）的旋转不影响这 22 个关节的位置，只能靠旋转损失监督，所以 L_rot 必须保留。

判据：
- 通过：踝/脚和腕的误差显著下降，PA-MPJPE 不劣化。
- 整体 MPJPE 反而升高，说明 L_fk 压过了旋转项，下调权重后重跑。

### F3 窗口长度 + 重叠推理

改动：
1. Tw 取 {80, 160}，与 20 对照。训练 stride = Tw/2，每个 epoch 随机偏移起点。
2. 推理滑窗 stride = Tw/2，按 Hann 窗 w(t) = sin²(π(t+½)/Tw) 加权；50% 重叠时权重之和恒为 1。
   - 旋转：矩阵加权后用 Gram-Schmidt 重正交化。
   - 轨迹：只混合每帧的 4 维速度量，再对整条序列一次性积分，避免各窗锚点不一致。
   - 序列两端按权重归一化。
3. 删除原来的 4 帧 crossfade，由上一条取代。

不动：位置编码仍用正弦（换 RoPE 放到后续，避免混进本步）、模型结构、损失。tag `f3_tw80` / `f3_tw160`。

判据：
- 通过：抖动、加速度误差、拼接跳变显著下降，跳变应接近 GT 的相邻帧差；T2M 下肢误差和根 RTE 改善；VT2M 不劣化。
- 两个窗长结果接近时，优先选 T2M 更好的那个。

### F4 触觉流独立化

**F4a 纯压力、原生率、按脚编码**

改动：
1. **重采样**。左右脚按 t_us 各自插值到统一的高频率 f_p = r·40Hz：原生率不低于 100Hz 取 r=3，否则取 r=2。对齐区间与视频相同。
2. **归一化**。每个 session 一个尺度 s，取"有力帧"上两脚总力之和的中位数；有体重和标定时直接除以体重。逐点除以 s。
3. **每脚特征（原生率）**：4×12 压力图；总力、CoP（2 维）、接触面积比、dF/dt；质量特征 q_T（饱和点比例、死点比例）。
4. **空间编码**。左右脚共享权重，右脚沿内外侧镜像对齐。结构为 Conv3×3(1→32) → Conv3×3(32→64，沿长轴 stride 2) → Conv3×3(64→64) → 展平 → Linear → 128，再与手工特征拼接 → Linear → d，并加脚别嵌入。先写单测确认网格方向：脚跟着地时，CoP 应从脚跟移向脚尖。
5. **时间编码**。每只脚用 Conv1d(k=5, stride=r) 降到 40Hz。每帧组成 [左, 右, 全局=Linear(左‖右)] 三个 token，经 4 层时空分解 Transformer 得到 E_T (B,T,3,d)。
6. **与现有融合的接口**。每帧把 3 个 token 拼接后过 Linear，得到 1 个 T token，替换原来的 raw108 投影。
7. **T 重建目标**改为归一化后的 96 维压力（原生率平均池化到 40Hz）。

不动：V 路、融合、各头、损失权重。开关 `--tactile-input pressure_native --t-encoder foot_conv`，tag `f4a_tstream`。

判据：T2M 的下肢 MPJPE、根 RTE、接触 F1 优于 F3 的 raw108；下肢误差不差于 S2M-P；VT2M 不劣化。

**F4b 流内深监督**（tag `f4b_ds`）

改动：
1. **T 深监督头**，只读 E_T：左右脚 token 输出接触 logit（2 维）；全局 token 输出腿/脚 8 个关节的 6D、tilt 和 4 维轨迹。
2. **V 深监督头**，只读 V token：输出 22 关节 6D。
3. **损失**：标准化空间 MSE；接触用 BCE，本步先直接用 contact.npy。λ_ds 默认约为主姿态损失的 30%。
4. 只要某个流在当前配置下可用，就计算它的深监督。

判据：
- VT2M 相对 V2M 在脚、腿、根上的增益显著扩大，这是抗稀释的直接证据。
- T2M 不劣化。
- 探针：VT 配置下，T 编码器与 V 编码器的梯度范数之比相对 F4a 上升（测法同 E6.6b）。

### F5 部位查询解码器 + 门控

改动：
1. **V 流部位化**。θ_hmr 按部位分组；2D 关键点按关节归属分到部位，躯干和根用肩、髋的中点；每个部位过 Linear → d。图像 token + bbox + 相机组成全局 token。得到 E_V (B,T,10,d)，加部位嵌入和时间 PE。
2. **替换解码结构**。删除融合 Transformer、姿态头和轨迹头，新增部位解码器：d=256、8 头、6 层，Pre-LN，GELU。每层依次为：
   - Z 初始化为部位嵌入 + 时间 PE。
   - **部位间自注意力**，加运动树跳数偏置：每个头、每个跳数（0–4）一个可学习标量。
   - **每个部位沿时间的自注意力**。
   - **局部交叉注意力**：query = Z[t,p]；V 的 K/V 是 E_V[t−4..t+4] 共 90 个 token，T 的 K/V 是 E_T[t−4..t+4] 共 27 个 token，各带相对时间嵌入。
   - **门控**：g = softmax(ℓ_V, ℓ_T, ℓ_∅)，其中 ℓ_m = MLP_m(Z[t,p]) + b_{p,m}，ℓ_∅ = 0，缺失模态的 ℓ = −∞。更新 Z += g_V·e_V + g_T·e_T。b_{p,m} 初始化为：脚/腿/根的 T 取 +1，躯干/头/手臂的 V 取 +1，其余为 0。
   - FFN。
3. **输出**：
   - 各部位线性头 → 该部位关节的 6D；
   - 根 token → tilt + 4 维轨迹；
   - 脚 token → 接触 logit，T 可用时再加上 g_T × T 流的接触 logit；
   - 脚 token → 48 维压力，作为 V2M 的临时压力输出，F9 会替换。
4. **增强丢弃**。在 VT/V/T 类别采样之外，再加两种：
   - 模态段丢弃：概率 0.3，丢掉连续 10–40% 的帧。这些帧的门控 ℓ 置 −∞，流内部用可学习的 mask token 填充。
   - V 部位遮挡：随机把某些部位的关键点置信度置 0，并给 θ 加噪。
5. **若结构变深后训练不稳**，换 AdamW 3e-4 + warmup + grad clip 1.0，并用同一优化器重跑 F4b 作对照。

tag：
- `f5_part9`：主线。
- `f5_part3`：Step2Motion 的三块（左腿含脚 / 右腿含脚 / 其余含根）。
- `f5_nogate`：单一交叉注意力，直接读拼接的 E_V‖E_T。

判据（**先看门控探针，再看主指标**；门控不可解释时，主指标上的提升不采信）：
- 门控探针：T-only 时手臂的 g_∅ 明显高于腿和脚；VT 时脚部 g_T 在支撑相高于摆动相。
- `f5_part9` 相对 F4b：VT2M 手臂误差不劣化；VT2M−V2M 在脚/腿/根上的增益不小于 F4b；T2M 下肢不劣化。
- 对照：part9 在 T2M 根轨迹或 VT2M 手臂上优于 part3；在鲁棒性验证集上优于 nogate。

### F6 接触与滑步

改动：
1. **接触软标签**：取 contact.npy 与压力阈值检测结果的平均。阈值检测在原生率上做，带迟滞、最短持续 3 帧，再降到 40Hz。两者不一致的帧，权重取 0.5。
2. **L_contact**：BCE 直接作用在接触 logit 上，不再走"FK → 速度 → sigmoid"那条路径。
3. **L_skate** = mean_t c_gt·‖v_foot^xy‖²。脚部关节 7/8/10/11 的世界系水平速度，由预测姿态的 FK 加积分轨迹得到。训练时用 GT 接触加权，防止模型把接触预测压到 0 来逃避这一项。
4. **L_height** = c_gt·relu(h_foot − h_ground − δ)² + relu(h_ground − h_foot)²。h_ground 每个 session 取 GT 脚高的 5% 分位数，δ=2cm。
5. L_skate 和 L_height 在前 10% 的训练步内线性升权。
6. **F6b（可选）推理后处理**：预测接触大于 0.5 且持续至少 3 帧时锁定脚的位置，用髋-膝-踝两骨 IK 修正腿部。

tag `f6_contact` / `f6b_footlock`。

判据：
- 接触期脚滑显著下降，接触 F1 上升，V2M 尤其要看，这正是 E3 设 λ_con=0 时丢掉的部分。
- MPJPE 不劣化。
- L_contact 的量级全程稳定，不出现 E1/E2 那样的爆炸。

### F7 不确定度 σ

改动：
1. **T 流部位读出**：9 个可学习 query 对 E_T[t] 做交叉注意力，得到部位证据 token。V 流直接用已有的部位 token。
2. **流内部位头**输出 (μ_{m,p,t}, log σ²_{m,p,t})。μ 是该部位的 6D，根部位还包括轨迹；σ² 是每个部位每帧一个标量。它取代 F4b 的深监督 MSE。
3. **融合 σ̂ 头**：接在解码器输出后，每部位每帧一个。它的残差用 stopgrad 后的主输出计算，只训练 σ̂ 头本身。
4. **损失用 β-NLL**（β=0.5）：stopgrad(σ^{2β})·[r/(2σ²) + ½log σ²]，r 是标准化空间内该部位的平均平方误差。log σ² 截断到 [−6, 3]。前 10% 的步数固定 σ=1，此时等价于 F4b。
5. **接入门控**：ℓ_m += −α·stopgrad(log σ_{m,p,t})，α 可学习，初值为 1。加 stopgrad 是为了让 σ 保持纯标定的含义，不被主损失挪用成门控。

tag `f7_sigma`。

判据：
- **先看诊断**：
  - val 上每个部位的 σ 与实际误差的 Spearman 秩相关明显为正，参考起点为 0.3 以上；
  - T 流腿/脚的 σ 随步态相位变化，支撑相低、摆动相高；
  - V 段丢失的帧，σ_V 升高。
- **主指标**：鲁棒性验证集上 VT2M 显著改善，干净 val 不劣化。
- **σ 塌缩成常数时**：先确认训练中误差本身确实有变化（检查段丢弃概率和遮挡增强强度），再调整 β。

### F8 AMASS 精修器

**F8a 预训练**（可以和 F4–F7 并行）

改动：
1. **数据**：AMASS 加上本数据集训练集的 mocap，转成 F2 的表示（40Hz、22 关节、朝向系，窗长同 F3），每条序列用自己的 betas。
2. **R 的结构**：9 部位时空 Transformer，与解码器同构但去掉交叉注意力，共 8 层。每个 token 的输入 = 带噪部位向量 + 该 token 自己的噪声级嵌入。噪声级嵌入经 MLP 后接 LayerNorm，沿用 E2 的修复。R 预测 x0，损失为标准化 MSE + L_fk。
3. **扩散设置**：在标准化空间里加 N(0,1) 噪声，等价于 E4 的噪声缩放；cosine schedule，1000 步。
4. **逐 token 噪声级采样**（Diffusion Forcing 的思路）：
   - 40%：所有 token 共享一个 τ；
   - 30%：每个部位独立一个 τ，时间上恒定；
   - 20%：上半身（躯干/头/双臂）τ=T，其余 τ~U(0, 0.2T)；
   - 10%：随机部位的随机时间段 τ=T，其余取小 τ。

判据（针对 R 本身）：在 val mocap 上，掩码上半身后补全出的动作合理（看加速度分布、关节限位违规率）；小 τ 时重建误差接近 0。

**F8b 推理接入**（F7 的模型冻结，不重训）

改动：
1. **起始噪声级**：每个 token 的 τ*_{p,t} 满足 (1−ᾱ_τ*)/ᾱ_τ* = c·σ̂²_{p,t}，c 在 {0.5, 1, 2} 中按 val 选。T2M 时上半身的 σ̂ 很大，τ* 会自然接近 T。
2. **去噪流程**：先把 M0 的各 token 加噪到各自的 τ*。全局步 s 从 max τ* 往下递减，每个 token 的当前噪声级取 min(τ*_{p,t}, s)。DDIM 步数在 {5, 10, 20} 中扫描。
3. 精修在 F3 的每个滑窗内进行，重叠混合放在精修之后。

tag `f8b_refine_c{c}_s{steps}`。

判据：
- 通过：VT2M/V2M 的 MPJPE 不劣化；抖动、加速度误差、踝/腕误差显著改善；T2M 上半身的合理性指标改善。
- 探针：按部位统计 ‖M_ref − M0‖ 和误差的变化，确认修改集中在 σ̂ 高的部位。
- 失败处置一：c 趋近 0 时 MPJPE 仍然变差，说明 R 与本数据集的动作分布不匹配。用训练集 mocap 单独微调 R，仍然只用 M。
- 失败处置二：步数越多越差（E4/E5 的现象），固定用少步。

**F8c T2M 多假设**

改动：同 F8b，每条序列采样 K=10 个结果。

判据：
- 报告上半身的 min-of-K 误差和样本多样性（APD）。
- 下肢在不同样本间的标准差应该很小；如果很大，说明精修在改动本来有证据的部位。

### F9 前向模型 G

**F9a 训练 G，并替换压力输出**

改动：
1. **G 的结构**：输入 F2 表示的运动窗口，经 4 层 9 部位时空编码器，取脚 token；每只脚过 Linear → 4×6×32 → 沿长轴上采样 → Conv → softplus，得到 40Hz 的 4×12 压力，同时输出接触。
   - 损失：归一化压力 MSE + 总力 L1 + CoP L1 + 接触 BCE。
   - 训练时给输入运动加小噪声，让 G 能容忍预测误差。
2. **质量检查**：在 val 上用 GT 运动作输入，测总力 R²、压力 Pearson、CoP 误差、接触 F1。总力 R² 未达到约 0.8 之前，不进入 F9c。
3. V2M 的压力输出改为 G(M̂)，删除 F5 里脚 token 上的压力头。

判据：V2M 的总力、CoP、接触 F1 不差于 F5 的压力头；输出的压力与预测动作的接触时序一致。

**F9b 分析-合成一致性损失**

改动：L_cons = ‖G_frozen(M̂) − T_obs‖²，在 VT 和 T 配置下启用，权重设小并逐步升权。

判据：
- 通过：T2M 和 VT2M 的脚滑、接触 F1、根 RTE 改善，MPJPE 不劣化。
- 如果 L_cons 下降而 MPJPE 上升，说明模型在"骗" G。降低权重，或加大 G 训练时的输入噪声。

**F9c AMASS 伪压力预训练**

改动：
1. **构造伪数据**：从 AMASS 中选与本数据集动作类别接近的子集（行走、跑、转身、深蹲等），生成 G(M) 伪压力，并加传感器增强：逐点增益 0.8–1.2、加性噪声、随机死点、每条序列的尺度扰动。
2. **预训练与微调**：先用伪数据以 T-only 配置预训练 T 流和解码器，再按 F7/F8 的配方在配对数据上微调。微调预算与"不预训练"的对照保持一致。

判据：
- T2M 显著改善。
- 另报一项：只用伪数据预训练、未经微调的模型在真实 val 上的 T2M，用来衡量仿真到真实的差距。

## 4. 并行与依赖

- **F0 期间可同时做的离线准备**：F1 的 HMR 特征提取、F4 的原生率压力管线、S2M-P 重训。
- **可以并行的训练**：F8a 只依赖 F2 的表示和 F3 的窗长，可在 F4–F7 期间进行；F9a 的 G 只依赖 F2。
- **严格串行的部分**：模型主线 F0→F7；F8b 依赖 F7 的 σ̂。

## 5. 主线之外的候选

- **流间瓶颈 token**（Attention Bottlenecks）：等 F5 的门控版本稳定后，作为对照实验。
- **结构微调类**：位置编码换 RoPE、V 流加时间编码器、解冻 HMR 的最后几层。
- **质心动力学约束**：借鉴 PhysPT 按 SMPL 蒙皮把网格分成 24 块、计算质量和质心的做法，每个受试者预计算一次，约束"垂直总力 ≈ m(g + z̈_com)"。前提是鞋垫力有标定，或者能用静止站立段标定尺度。
- **重投影损失 / 测试时优化**：训练集有完整 3D GT 时，它对训练的增益有限，更适合用在无标注数据或推理时细化。
- **其他**：T2M 根轨迹的多假设生成、CFG。
