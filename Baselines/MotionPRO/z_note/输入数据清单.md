# MotionPRO 输入数据清单

训练按**同一帧索引**对齐，不读时间戳。一条序列的 `T` 必须一致。默认窗口 `window_length = 20`。

## 1. 原始序列

```text
<sequence>/
├── 0.mp4 ~ 3.mp4     # 多视角视频；训练不直接读
├── pressure.npz      # 触觉
└── smpl.npy          # 动捕 / SMPL 参数
```

| 文件 | 格式 | 内容 |
|---|---|---|
| `0.mp4 ~ 3.mp4` | 视频 | 多视角 RGB，需先抽帧成 `color/` |
| `pressure.npz` | npz | 键名必须是 `pressure`，shape `(T, 160, 120)`，数值约 `0~255` |
| `smpl.npy` | npy dict（`allow_pickle=True`） | 见下表 |

`smpl.npy` 必含字段：

| key | shape | 说明 |
|---|---|---|
| `betas` | `(10,)` 或更长，取前 10 | 体型，整段序列共用 |
| `global_orient` | `(T, 3)` | 根朝向，axis-angle |
| `body_pose` | `(T, 69)` 或 `(T, 23, 3)` | 23 个关节 axis-angle |
| `transl` | `(T, 3)` | 全局平移 |

## 2. 训练真正读取的文件

Dataset 递归搜索 `feature_hrnet.pth` 定位样本，再在同目录按文件名替换读取其余文件。

```text
<sequence>/
├── color/                 # 抽帧图像，.jpg / .png，按文件名排序 = 帧序
├── bbox.npy               # 人体框
├── feature_hrnet.pth      # 视频特征（训练输入）
├── pressure.npz           # 触觉（训练输入）
├── smpl.npy               # SMPL GT
├── keypoints.npy          # 关节 GT
└── contact.npy            # 足部接触 GT
```

| 文件 | 格式 | 用途 | 期望 shape |
|---|---|---|---|
| `color/*.jpg|.png` | 图像 | 检测框、提特征 | 帧数 = `T`，排序即时间序 |
| `bbox.npy` | npy | 裁人、提特征 | `(T, 8)`，每行 `[frame_id, x1, y1, x2, y2, score, 0.99, 0]` |
| `feature_hrnet.pth` | torch tensor | 视频输入 `feature` | `(T, 2048)` |
| `pressure.npz['pressure']` | npz | 触觉输入，再 `/255` | `(T, 160, 120)` |
| `smpl.npy` | npy dict | `beta / theta / trans` 监督 | 见上表 |
| `keypoints.npy` | npy | 关节监督，取前 23 点 | `(T, 24, 3)`，训练用 `[:, :23]` |
| `contact.npy` | npy | 足部接触 loss 权重 | 训练按 `[:, :10]` 切片 |

每个窗口实际送进模型的是：

| 字段 | shape | 来源 |
|---|---|---|
| `feature` | `(20, 2048)` | `feature_hrnet.pth` |
| `pressure` | `(20, 160, 120)` | `pressure / 255` |
| `beta` | `(20, 10)` | `smpl['betas'][:10]` 复制到每帧 |
| `theta` | `(20, 72)` | `cat(global_orient, body_pose)` |
| `trans` | `(20, 3)` | `smpl['transl']` |
| `joint` | `(20, 23, 3)` | `keypoints[:, :23]` |
| `contact` | `(20, 10)` | `contact[:, :10]` |

最后不足 20 帧会零填充。

## 3. 从原始数据到训练数据

```text
0.mp4~3.mp4  --抽帧-->  color/
color/       --gen_bbox.py-->  bbox.npy
color/ + bbox.npy --gen_image_feature.py-->  feature_hrnet.pth

smpl.npy     --gen_kps.py-->  keypoints.npy
smpl.npy + pressure.npz --gen_contact.py-->  contact.npy
```

仓库里没有 mp4 抽帧脚本，`color/` 需自己先整理好。

## 4. 对齐与目录约定

- 同一序列目录内，以上文件第 `t` 帧互相对应。
- 不做重采样，也不读独立时间戳。
- 训练根目录由 config 的 `train_data_dir` / `eval_data_dir` 指定，其下递归找 `feature_hrnet.pth`。
- 原始作者目录层级大约是：`MotionPRO/<date>/<subject>/<sequence>/`。

## 5. 额外模型文件

不是序列数据，但跑通预处理 / 训练需要：

| 路径 | 用途 |
|---|---|
| `data/smpl/SMPL_NEUTRAL.pkl` | SMPL 模型 |
| `data/smpl/smpl_mean_params.npz` | CLIFF / FRAPPE 初始参数 |
| `data/cliff_ckpt/hr48-PA43.0_MJE69.0_MVE81.2_3dpw.pt` | 提 `feature_hrnet.pth` |
| `data/mmdetection/checkpoints/yolox_x_8x8_300e_coco_*.pth` | 生成 `bbox.npy` |

## 6. 复现时注意

- 训练不读原始 mp4，只读 `feature_hrnet.pth` + `pressure.npz`。
- `color/` 文件名排序必须等于帧序。
- `gen_contact.py` 实际写出的是 `(T, 4)`（左踝 / 左脚 / 右踝 / 右脚），而训练 loss 按 10 个接触关节 `[1,2,4,5,7,8,10,11,20,21]` 使用 `contact`。若直接用该脚本结果，shape 对不上，需要先确认或改写成 `(T, 10)`。
