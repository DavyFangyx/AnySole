# MotionPRO 模型完整结构

本文按本仓库代码说明 MotionPRO 的算法与网络结构。训练模型是 **FRAPPE**；图像侧不在训练时跑 backbone，而是离线用 **CLIFF-HRNet-W48** 抽出 `feature_hrnet.pth`。

默认窗口 `T = window_length = 20`。下文 `B` 表示 batch。

## 1. 整体算法

```text
RGB 图 + bbox
    -> CLIFF / HRNet-W48（离线、权重冻结）
    -> img_feature: (T, 2048)

pressure / 255
    -> FRAPPE.resnet（改过的 ResNet18）
    -> pressure_feature: (T, 2048)

img_feature + pressure
    -> FRAPPE（时序编码 + 自注意力 + 交叉注意力 + 迭代回归）
    -> SMPL 参数 (beta 10, theta 72, trans 3)
    -> 训练时再送入 SMPL 得到 23 个关节监督
```

两路输入按同一帧索引对齐，不做时间戳同步。

训练时真正可学习的是 FRAPPE。CLIFF 只在 `gen_image_feature.py` 里跑一次，结果存成 `feature_hrnet.pth`。

## 2. 组件一览

| 阶段 | 组件 | 代码 | 层数要点 | 输出 |
|---|---|---|---|---|
| 离线 | YOLOX-X | `lib/util/gen_bbox.py` | 检测器，不是 FRAPPE 的一部分 | `bbox.npy` |
| 离线 | CLIFF 编码器 HRNet-W48 | `lib/model/cliff/cliff_hr48.py` | stem + 4 stage + 分类头 | `(T, 2048)` |
| 在线 | 压力 ResNet18 | `FRAPPE.resnet` | 1 stem conv + 8 个 BasicBlock + fc | `(B, T, 2048)` |
| 在线 | 时序 GRU | `TemporalEncoder` | 2 层双向 GRU + 投影 | `(B, T, 2048)` |
| 在线 | 自注意力 | `nn.MultiheadAttention` | 1 层，4 head | `(B, T, 2048)` |
| 在线 | 交叉注意力 | `nn.MultiheadAttention` | 1 层，4 head | `(B, T, 2048)` |
| 在线 | FFN | `PositionwiseFeedForward` | 2 个 Linear | `(B, T, 2048)` |
| 在线 | 融合投影 | `fc_output` | 1 个 Linear | `(B*T, 2048)` |
| 在线 | SMPL 回归头 | `Regressor` | 2 个 FC + 3 个解码头，迭代 3 次 | `(B*T, 85)` |

图像和压力共用同一个 `gru`、同一个 `self_attention`。

## 3. 离线图像编码器：CLIFF-HRNet-W48

入口：`lib/util/gen_image_feature.py`。

每帧先按 bbox 裁成 `256 x 192` RGB，再 ImageNet 归一化，得到：

| 张量 | shape |
|---|---|
| `norm_img` | `(B, 3, 256, 192)` |
| `bbox_info` | `(B, 3)`，代码里算了但当前 forward 没用 |

`CLIFF.forward` 只跑 `self.encoder(x)`，回归头全部注释掉了。所以这里只用 HRNet-W48 当 2048 维特征提取器。

配置来自 `cls_hrnet_w48_sgd_lr5e-2_wd1e-4_bs32_x100.yaml`。下面空间尺寸按输入 `256 x 192` 计算。

### 3.1 Stem（2 层 conv）

| 层 | 操作 | 输入 | 输出 |
|---|---|---|---|
| `conv1 + bn1 + relu` | `Conv2d(3, 64, k=3, s=2, p=1)` | `(B, 3, 256, 192)` | `(B, 64, 128, 96)` |
| `conv2 + bn2 + relu` | `Conv2d(64, 64, k=3, s=2, p=1)` | `(B, 64, 128, 96)` | `(B, 64, 64, 48)` |

### 3.2 Stage1：1 个模块，4 个 Bottleneck

- block = Bottleneck，`expansion = 4`
- `NUM_BLOCKS = 4`，`NUM_CHANNELS = 64`
- 输出通道 `64 * 4 = 256`

每个 Bottleneck 内部 3 层卷积：

```text
1x1 Conv -> BN -> ReLU
3x3 Conv -> BN -> ReLU
1x1 Conv -> BN
+ residual -> ReLU
```

| 层 | 输入 | 输出 |
|---|---|---|
| `layer1` 共 4 个 Bottleneck | `(B, 64, 64, 48)` | `(B, 256, 64, 48)` |

### 3.3 Stage2：1 个模块，2 分支，每分支 4 个 BasicBlock

先 `transition1` 分出 2 个分辨率：

| 分支 | 通道 | 空间 | 怎么来的 |
|---|---|---|---|
| branch0 | 48 | `64 x 48` | `256 -> 48`，stride 1 |
| branch1 | 96 | `32 x 24` | `256 -> 96`，stride 2 |

然后 1 个 `HighResolutionModule`：

- 每分支 4 个 BasicBlock（每个 BasicBlock = 2 个 `3x3 Conv`）
- 分支间 SUM 融合（上采样 / 下采样对齐后相加）

| 层 | 输入 | 输出 |
|---|---|---|
| `stage2` | `[(B,48,64,48), (B,96,32,24)]` | 同 shape 的 2 个特征图 |

### 3.4 Stage3：4 个模块，3 分支，每分支 4 个 BasicBlock

`transition2` 再开第 3 分支：

| 分支 | 通道 | 空间 |
|---|---|---|
| branch0 | 48 | `64 x 48` |
| branch1 | 96 | `32 x 24` |
| branch2 | 192 | `16 x 12` |

然后 4 个 `HighResolutionModule`，每个模块每分支 4 个 BasicBlock，再 SUM 融合。

| 层 | 模块数 | 输入 / 输出 |
|---|---|---|
| `stage3` | 4 | 3 个多尺度特征图，shape 不变 |

### 3.5 Stage4：3 个模块，4 分支，每分支 4 个 BasicBlock

`transition3` 再开第 4 分支：

| 分支 | 通道 | 空间 |
|---|---|---|
| branch0 | 48 | `64 x 48` |
| branch1 | 96 | `32 x 24` |
| branch2 | 192 | `16 x 12` |
| branch3 | 384 | `8 x 6` |

然后 3 个 `HighResolutionModule`，`multi_scale_output=True`，4 路都保留。

| 层 | 模块数 | 输入 / 输出 |
|---|---|---|
| `stage4` | 3 | 4 个多尺度特征图，shape 不变 |

### 3.6 分类头：4 路增通道 + 3 次下采样 + 1x1

每路先用 1 个 Bottleneck 把通道抬到 `[128, 256, 512, 1024]`，再逐步下采样相加：

| 层 | 操作 | 输入 | 输出 |
|---|---|---|---|
| `incre_modules[0]` | Bottleneck `48 -> 128` | `(B, 48, 64, 48)` | `(B, 128, 64, 48)` |
| `incre_modules[1] + downsamp[0]` | Bottleneck `96 -> 256`，再 stride2 相加 | 高分辨率 128 维 + `(B, 96, 32, 24)` | `(B, 256, 32, 24)` |
| `incre_modules[2] + downsamp[1]` | Bottleneck `192 -> 512`，再 stride2 相加 | 上一步 + `(B, 192, 16, 12)` | `(B, 512, 16, 12)` |
| `incre_modules[3] + downsamp[2]` | Bottleneck `384 -> 1024`，再 stride2 相加 | 上一步 + `(B, 384, 8, 6)` | `(B, 1024, 8, 6)` |
| `final_layer` | `1x1 Conv 1024 -> 2048 + BN + ReLU` | `(B, 1024, 8, 6)` | `(B, 2048, 8, 6)` |
| GAP | 全局平均池化 | `(B, 2048, 8, 6)` | `(B, 2048)` |

存盘后一条序列是 `(T, 2048)`，训练时切成 `(B, 20, 2048)`。

HRNet-W48 卷积层粗算：

- Stem：2
- Stage1：4 Bottleneck x 3 conv = 12
- Stage2：2 分支 x 4 BasicBlock x 2 conv = 16，外加融合 conv
- Stage3：4 模块 x 3 分支 x 4 BasicBlock x 2 conv = 96，外加融合 conv
- Stage4：3 模块 x 4 分支 x 4 BasicBlock x 2 conv = 96，外加融合 conv
- Head：4 个 Bottleneck + 3 个下采样 conv + 1 个 1x1

这就是论文里的 HRNet-W48 分类骨干，不是从头训的，加载 `hr48-PA43.0_MJE69.0_MVE81.2_3dpw.pt`。

## 4. 在线模型：FRAPPE

代码：`lib/model/FRAPPE.py`。

训练入口：

```python
smpl_params = model(item['feature'], item['pressure'])
```

| 输入 | shape | 含义 |
|---|---|---|
| `img_feature` | `(B, 20, 2048)` | 离线 HRNet 特征 |
| `pressure` | `(B, 20, 160, 120)` | 足底压力，已 `/255` |

原注释写的是触觉 `96 x 96`，本仓库数据是 `160 x 120`。ResNet 最后有 GAP，不依赖固定空间尺寸。

### 4.1 压力骨干：改过的 ResNet18

`torchvision.models.resnet18(pretrained=True)`，改了 3 处：

| 层 | 原 ResNet18 | 本仓库 |
|---|---|---|
| `conv1` | `Conv2d(3, 64, k=7, s=2, p=3)` | `Conv2d(1, 64, k=3, s=2, p=0, bias=False)` |
| `maxpool` | `MaxPool2d(k=3, s=2, p=1)` | `MaxPool2d(k=2, s=1)` |
| `fc` | `Linear(512, 1000)` | `Linear(512, 2048)` |

其余保持 ResNet18：

| 模块 | 块数 | 通道 | stride |
|---|---|---|---|
| `layer1` | 2 个 BasicBlock | 64 | 1 |
| `layer2` | 2 个 BasicBlock | 128 | 首块 2 |
| `layer3` | 2 个 BasicBlock | 256 | 首块 2 |
| `layer4` | 2 个 BasicBlock | 512 | 首块 2 |
| `avgpool` | AdaptiveAvgPool2d(1) | 512 | - |
| `fc` | Linear | 512 -> 2048 | - |

每个 BasicBlock：

```text
3x3 Conv -> BN -> ReLU
3x3 Conv -> BN
+ residual -> ReLU
```

先把压力展成逐帧图：

```text
(B, T, H, W) -> (B*T, 1, H, W)
```

以 `H, W = 160, 120` 为例：

| 层 | 输入 | 输出 |
|---|---|---|
| `conv1` `k=3,s=2,p=0` | `(B*T, 1, 160, 120)` | `(B*T, 64, 79, 59)` |
| `bn1 + relu` | 同上 | 同上 |
| `maxpool` `k=2,s=1` | `(B*T, 64, 79, 59)` | `(B*T, 64, 78, 58)` |
| `layer1` 2 block | `(B*T, 64, 78, 58)` | `(B*T, 64, 78, 58)` |
| `layer2` 2 block | `(B*T, 64, 78, 58)` | `(B*T, 128, 39, 29)` |
| `layer3` 2 block | `(B*T, 128, 39, 29)` | `(B*T, 256, 20, 15)` |
| `layer4` 2 block | `(B*T, 256, 20, 15)` | `(B*T, 512, 10, 8)` |
| `avgpool` | `(B*T, 512, 10, 8)` | `(B*T, 512, 1, 1)` |
| `fc` | `(B*T, 512)` | `(B*T, 2048)` |
| `view` | `(B*T, 2048)` | `(B, T, 2048)` |

卷积层数：stem 1 conv + 8 个 BasicBlock x 2 conv = 17 个 conv，再加 1 个 fc。这就是 ResNet18 的层数。

### 4.2 时序编码器 TemporalEncoder

```python
TemporalEncoder(
    n_layers=2,
    input_size=2048,
    hidden_size=2048,
    bidirectional=True,
    add_linear=False,   # 但 bidirectional=True 时仍会建投影层
    use_residual=True,
)
```

| 层 | 细节 | 输入 | 输出 |
|---|---|---|---|
| permute | `NTF -> TNF` | `(B, T, 2048)` | `(T, B, 2048)` |
| `GRU` | 2 层、双向、hidden=2048 | `(T, B, 2048)` | `(T, B, 4096)` |
| ReLU | - | `(T, B, 4096)` | 同 |
| `Linear` | `4096 -> 2048` | `(T*B, 4096)` | `(T, B, 2048)` |
| residual | 与 GRU 输入相加 | `(T, B, 2048)` | `(T, B, 2048)` |
| permute | `TNF -> NTF` | `(T, B, 2048)` | `(B, T, 2048)` |

双向 2 层 GRU 内部是：

```text
layer0 forward GRUCell  2048 -> 2048
layer0 backward GRUCell 2048 -> 2048
layer1 forward GRUCell  4096 -> 2048
layer1 backward GRUCell 4096 -> 2048
```

图像特征过 **1 次** GRU；压力特征过 **2 次** GRU。`TemporalEncoder` 内部已经有残差，FRAPPE 外面还会再加一次残差。

### 4.3 自注意力 / 交叉注意力

都是 `nn.MultiheadAttention(embed_dim=2048, num_heads=4)`，1 层。

| 项 | 值 |
|---|---|
| embed | 2048 |
| heads | 4 |
| 每头维度 | 512 |
| `in_proj` | `Linear(2048, 6144)`，Q/K/V 拼在一起 |
| `out_proj` | `Linear(2048, 2048)` |
| 内部 | Scaled Dot-Product Attention |

代码里没有设 `batch_first=True`，PyTorch 默认输入是 `(L, N, E)`。特征本身是 `(B, T, 2048)`，因此调用前 permute 成 `(T, B, 2048)`，让 attention 在时间维上做；调用后再 permute 回 `(B, T, 2048)`。结构仍是 1 层 4 头 MHA，输入输出通道都是 2048。

| 调用 | Q | K | V | 输出 |
|---|---|---|---|---|
| 图像自注意力 | img | img | img | `(B, T, 2048)` |
| 压力自注意力 | pressure | pressure | pressure | `(B, T, 2048)` |
| 交叉注意力 | pressure | img | img | `(B, T, 2048)` |

自注意力后都加残差。交叉注意力后是：

```text
fusion = cross_attn(pressure, img, img) + img_sa + pressure_sa
```

### 4.4 PositionwiseFeedForward

2 层 MLP，残差 + LayerNorm：

| 层 | 操作 | 输入 | 输出 |
|---|---|---|---|
| `w_1` | `Linear(2048, 2048)` | `(B, T, 2048)` | `(B, T, 2048)` |
| GELU | - | 同 | 同 |
| `w_2` | `Linear(2048, 2048)` | 同 | 同 |
| Dropout 0.1 | - | 同 | 同 |
| residual + LayerNorm | `x + residual` | 同 | `(B, T, 2048)` |

### 4.5 融合投影

| 层 | 操作 | 输入 | 输出 |
|---|---|---|---|
| concat | 融合特征 + 压力自注意力特征 | `(B, T, 2048)` x2 | `(B, T, 4096)` |
| `fc_output` | `Linear(4096, 2048)` | `(B, T, 4096)` | `(B, T, 2048)` |
| reshape | 展成逐帧 | `(B, T, 2048)` | `(B*T, 2048)` |

### 4.6 Regressor：迭代 3 次的 SMPL 头

这是 SPIN / HMR 风格的迭代回归。初始值来自 `data/smpl/smpl_mean_params.npz`。

每次迭代拼接：

```text
xc = cat(feature 2048, pose 144, shape 10, trans 3)  # 共 2205
```

`24 * 6 = 144` 是 24 个关节的 6D 旋转。`10 + 3 = 13` 就是 shape + trans。所以 `fc1` 写成 `512 * 4 + npose + 13`。

| 层 | 操作 | 输入 | 输出 |
|---|---|---|---|
| `fc1` | `Linear(2205, 1024)` | `(N, 2205)` | `(N, 1024)` |
| `drop1` | Dropout(0.5) | 同 | 同 |
| `fc2` | `Linear(1024, 1024)` | `(N, 1024)` | `(N, 1024)` |
| `drop2` | Dropout(0.5) | 同 | 同 |
| `decpose` | `Linear(1024, 144)` | `(N, 1024)` | pose 残差 |
| `decshape` | `Linear(1024, 10)` | `(N, 1024)` | shape 残差 |
| `dectrans` | `Linear(1024, 3)` | `(N, 1024)` | trans 残差 |

`N = B * T`。`n_iter = 3`，三次都是：

```text
pred_pose  += decpose(xc)
pred_shape += decshape(xc)
pred_trans += dectrans(xc)
```

迭代结束后：

| 步骤 | 输入 | 输出 |
|---|---|---|
| 6D -> 旋转矩阵 | `(N, 144)` | `(N, 24, 3, 3)` |
| 旋转矩阵 -> axis-angle | `(N, 24, 3, 3)` | `(N, 72)` |
| concat | shape + pose + trans | `(N, 85)` |

最终 FRAPPE 输出：

| 字段 | 维度 | 含义 |
|---|---|---|
| `pred_shape` / beta | 10 | SMPL 体型 |
| `pose` / theta | 72 | 24 关节 axis-angle，`3 + 69` |
| `pred_trans` | 3 | 全局平移 |

## 5. 一次完整 forward（按代码顺序）

设 `B=64, T=20`。

```text
img_feature:      (64, 20, 2048)
pressure:         (64, 20, 160, 120)

1) 图像时序
   res_img = img_feature
   img_feature = GRU(img_feature)                         -> (64, 20, 2048)

2) 压力编码
   pressure.view(64*20, 1, 160, 120)
   pressure_feature = ResNet18(...)                       -> (1280, 2048)
   pressure_feature.view(64, 20, 2048)                    -> (64, 20, 2048)

   res_pressure = pressure_feature
   pressure_feature = GRU(pressure_feature) + res_pressure
   res_pressure = pressure_feature
   pressure_feature = GRU(pressure_feature) + res_pressure
   img_feature = img_feature + res_img

3) 模态内自注意力
   img_sa      = SelfAttn(img, img, img) + img
   pressure_sa = SelfAttn(pre, pre, pre) + pressure

4) 交叉注意力融合
   fusion = CrossAttn(Q=pressure_sa, K=img_sa, V=img_sa)
   fusion = fusion + img_sa + pressure_sa
   fusion = FFN(fusion)                                   -> (64, 20, 2048)

5) 再拼压力自注意力特征
   fusion = cat(fusion, pressure_sa, dim=2)               -> (64, 20, 4096)
   fusion = Linear(4096, 2048)                            -> (64, 20, 2048)
   fusion = fusion.reshape(1280, 2048)

6) 迭代回归 3 次
   output = Regressor(fusion)                             -> (1280, 85)
```

对应代码路径：

```text
图像特征 ──GRU──┐
                ├─ SelfAttn ─┐
                │            ├─ CrossAttn(Q=压力, K/V=图像)
压力图 ─ResNet18─GRU x2 ─┴─ SelfAttn ─┘
                              │
                              ├─ + 残差
                              ├─ FFN
                              ├─ concat 压力 SelfAttn
                              ├─ Linear 4096->2048
                              └─ Regressor x3 -> SMPL 参数
```

## 6. 训练时接到 SMPL 上

`app/train_frappe.py` 把 `85` 维拆开后，**网格用 GT beta，姿态和平移用预测值**：

```python
pred_beta, pred_theta, pred_trans = split(smpl_params, [10, 72, 3])
pred_global_orient, pred_body_pose = split(pred_theta, [3, 69])
smpl_result = smpl(
    betas=item['beta'],          # GT shape，不是 pred_beta
    body_pose=pred_body_pose,
    global_orient=pred_global_orient,
    transl=pred_trans,
)
pred_joint = smpl_result.joints[:, :23]
```

| 监督 | 公式 | 权重 |
|---|---|---|
| `loss_theta` | MSE(pred_theta, gt_theta) | 1 |
| `loss_trans` | SmoothL1(pred_trans, gt_trans) | 1 |
| `loss_2d_joint` | SmoothL1，关节 xz，减根关节 | 5 |
| `loss_joint` | SmoothL1，3D 关节减根关节 | 10 |
| `loss_foot` | 接触帧上 10 个足部关节 MSE | 5 |

足部关节 id：`[1, 2, 4, 5, 7, 8, 10, 11, 20, 21]`。

## 7. 和完整模型有关、但不在 FRAPPE 里的部分

| 模块 | 作用 | 是否训练 |
|---|---|---|
| YOLOX-X | 出人体框 `bbox.npy` | 否，只用现成权重 |
| CLIFF-HRNet-W48 | 出 `feature_hrnet.pth` | 否，冻结 |
| SMPL | 参数 -> 关节 / mesh | 否，解析模型 |
| CLIFF 里的 `fc1/fc2/decpose/decshape/deccam` | 原 CLIFF 迭代回归 | 已加载权重，但 forward 被注释，推理不用 |

所以当前 baseline 的可训练网络就是 FRAPPE：改版 ResNet18 + 共享双向 GRU + 共享 Self-Attn + Cross-Attn + FFN + 迭代 SMPL 回归头。

## 8. 适配本数据集的改动

FRAPPE 的网络骨架没有改：还是压力 ResNet18 + 共享双向 GRU + Self-Attn / Cross-Attn + FFN + 迭代 SMPL 回归头。改的是输入、监督和训练流程，让 PressureWasher 数据能直接跑完测试。

### 数据入口

原仓库读公开 MotionPRO 序列和 `data/splits/train|eval` 软链。现在改成从 PressureWasher 转序列：

- 新增 `data_prep/prepare_sequences.py`：视频、压力、BVH/SMPL 按同一帧索引切到 `data/sequences/<date>/<subject>/<session_id>/`
- 训练只读 `data/splits/splits.csv` 的 `train/val/test` 列，不再把旧软链当入口
- 质量表里标成 C/D 的 session 会跳过
- 有 `fake_mask.npy` 的窗口整段丢掉，不进训练集
- 末尾不足 20 帧会零填充，并用 `valid` 标记 padding，测试时不计入指标

### 压力图

磁盘上仍是鞋垫栅格化后的 `(T, 160, 120)`。原 FRAPPE 按 `96 x 96` 设计，直接送 `160 x 120` 会把 ResNet 中间激活撑得很大。

当前做法：`ImagePressureDataset` 加载时双线性缩到 `96 x 96`，再 `/255`。模型实际吃到 `(B, 20, 96, 96)`。`pressure.npz` 没有重转。

### 接触监督

原 foot loss 用 10 个接触相关关节。本数据的 `contact.npy` 是 `(T, 10)`，但只有左右脚两列会为 1，对应列 6/7。

所以训练里 foot loss 只监督 SMPL 关节 10/11（左右脚），权重仍来自接触标签。验证 Contact IoU 也按脚高 < 5 cm 判断左右脚是否着地。

### 训练配置

- `batch_size`: 64 -> 16，避免压力 ResNet 显存爆掉
- 训练结束自动用 best checkpoint 对 `splits.csv` 的 test 列做完整测试
- 测试把非重叠窗口拼回整段 session，写出表 3/4：MPJPE / P-MPJPE / PVE / Accel / W-MPJPE / WA-MPJPE / RTE / Jitter / WBCE

网格监督仍用 GT `beta`，预测只用 `theta` 和 `trans`。这一点和原训练脚本一致，不是这次新改的。
